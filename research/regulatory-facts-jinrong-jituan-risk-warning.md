## 第一节 《商业银行集团客户授信业务风险管理指引》（银监会令 2003 年第 5 号，2003-10-23 公布）

全文来源：https://www.gov.cn/gongbao/content/2004/content_62733.htm （国务院公报 2004 年第 15 号）

| 结论 | 条款号 | 来源 |
|---|---|---|
| 集团客户定义（四特征）：①股权或经营决策上直接/间接控制其他企事业法人或被控制；②共同被第三方企事业法人控制；③主要投资者个人、关键管理人员或与其关系密切的家庭成员（三代以内直系 + 二代以内旁系）共同直接或间接控制；④存在其他关联关系、可能不按公允价格原则转移资产和利润，银行认为应视同集团客户。银行可结合自身管理需要确定单一集团客户范围 | 第三条（原文见上） | https://www.gov.cn/gongbao/content/2004/content_62733.htm |
| 授信业务范围：贷款、拆借、贸易融资、票据承兑和贴现、透支、保理、担保、贷款承诺、开立信用证等 | 第四条 | 同上 |
| 统一授信原则：第六条（一）统一原则——对集团客户授信实行统一管理、集中风险控制；（二）适度原则——合理确定总体授信额度、防止过度集中风险；（三）预警原则——建立风险预警机制，及时防范和化解集团客户授信风险 | 第六条 | 同上 |
| 授信集中度红线（2003 原文口径）："一家商业银行对单一集团客户授信总额超过商业银行资本余额 15% 以上……即视为超过其风险承受能力"，应组织银团贷款、联合贷款、贷款转让等分散风险 | 第十二条 | 同上 |
| 关联交易报告义务：授信协议中约定要求集团客户及时报告"受信人净资产 10% 以上关联交易"的情况（关联关系/交易项目和性质/金额或比例/定价政策） | 第十七条 | 同上 |
| 提前收回贷款情形（六种）：提供虚假材料或隐瞒重要事实；擅自改变贷款用途或挪用；以虚假合同/无真实贸易背景应收票据套取资金；拒绝接受监督检查；重大兼并收购重组影响贷款安全；通过关联交易逃废银行债权 | 第十八条 | 同上 |
| 风险预警条款：第二十三条（信贷管理信息系统须支持全系统集团客户贷款风险预警）；第二十五条（授信后贷款变化、经营财务异常、关键管理人员变动、违规经营、被起诉、欠息、逃废债、提供虚假资料等重大事项须及时登录信贷信息系统）；第二十六条（按行业和经营能力，对授信总额、资产负债/盈利/流动性指标、贷款本息偿还情况、关键管理人员信用状况等"设置授信风险预警线"）；第二十七条（银监会建立大额集团客户授信业务统计和风险分析制度并视情况通报） | 第二十三、二十五、二十六、二十七条 | 同上 |
| 信息披露：总行每年对全行集团客户授信风险作一次综合评估；每年至少向银行监管部门提交一次相关风险评估报告 | 第二十一条 | 同上 |
| 补充（现行有效口径）：该指引后经银监会令 2010 年第 4 号《关于修改〈商业银行集团客户授信业务风险管理指引〉的决定》修订，第十二条改为"一家商业银行对单一集团客户授信余额（包括……各类信用风险暴露）不得超过该商业银行资本净额的 15%"，口径由"授信总额/资本余额"改为"授信余额/资本净额"，且监管可调低该比例 | 修订决定五、第十二条 | https://www.gov.cn/gongbao/content/2010/content_1745857.htm |

## 第二节 《商业银行大额风险暴露管理办法》（银保监会令 2018 年第 1 号，自 2018-07-01 施行）

全文来源：https://www.gov.cn/gongbao/content/2018/content_5306826.htm （国务院公报 2018 年第 20 号）；含全部附件版本：https://www.gov.cn/zhengce/zhengceku/2018-12/31/content_5450190.htm

| 结论 | 条款号 | 来源 |
|---|---|---|
| 大额风险暴露定义：对单一客户或一组关联客户超过其一级资本净额 2.5% 的风险暴露 | 第四条 | 同上（公报版） |
| **单一客户贷款余额/资本净额红线：对非同业单一客户的贷款余额不得超过资本净额的 10%** | 第七条 | 同上 |
| 单一客户风险暴露/一级资本净额红线：对非同业单一客户的风险暴露不得超过一级资本净额的 15% | 第七条 | 同上 |
| **一组非同业关联客户风险暴露红线：不得超过一级资本净额的 20%**；非同业关联客户包括非同业集团客户、经济依存客户 | 第八条 | 同上 |
| 同业单一客户或集团客户风险暴露红线：不得超过一级资本净额的 25% | 第九条 | 同上 |
| 全球系统重要性银行对另一家 G-SIB 风险暴露：不得超过一级资本净额的 15% | 第十条 | 同上 |
| 关联客户（集团客户）定义：存在控制关系的一组企事业法人客户或同业单一客户；按《企业会计准则第 33 号——合并财务报表》控制关系判断标准、实质重于形式识别；至少考虑四特征（同 2003 指引第三条，含"近亲属"表述） | 附件 1《关联客户识别方法》一 | https://www.gov.cn/zhengce/zhengceku/2018-12/31/content_5450190.htm |
| **经济依存客户定义：存在经济依存关系的一组企事业法人客户；经济依存关系=一个客户发生财务困难或违约时可能导致另一个客户无法及时足额偿还债务**；应识别风险暴露超过一级资本净额 5% 的企事业法人客户之间的经济依存关系；判断至少考虑五因素：①一方年度总收入或总支出 50% 以上源于与另一方交易，或 50% 以上产品销售给另一方且难以找到替代购买方；②一方通过保证等方式对另一方融资负代偿责任且金额较大、违约相关性高；③一方偿还债务主要资金来自另一方对其还款；④两方依赖共同且难以替代的融资来源；⑤两方偿还贷款主要来源相同且均无其他收入来源足额还款 | 附件 1《关联客户识别方法》二 | 同上 |
| 预警条款：按监管要求设定内部限额并持续监测、预警和控制；信息系统须"大额风险暴露接近内部限额时进行预警提示" | 第三十一、三十二条 | https://www.gov.cn/gongbao/content/2018/content_5306826.htm |
| 突破红线：应立即报告银保监会；监管措施六项（原因分析、审慎性会谈、监管意见书、限期达标计划、提高监管资本要求、责令降低大额风险暴露），并可行政处罚 | 第三十七、三十八、三十九条 | 同上 |

## 第三节 金控公司监管（2020 试行办法 + 2023 关联交易办法）

### 《金融控股公司监督管理试行办法》（人民银行令〔2020〕第 4 号，2020-09-11 公布，自 2020-11-01 施行）
来源：https://www.gov.cn/zhengce/2020-09/11/content_5712711.htm （中国政府网）；公报版 https://www.gov.cn/gongbao/content/2020/content_5565830.htm

| 结论 | 条款号 | 来源 |
|---|---|---|
| 金控公司定义：依法设立，控股或实际控制**两个或两个以上不同类型金融机构**，自身仅开展股权投资管理、不直接从事商业性经营活动的有限责任公司或股份有限公司；金融机构类型含商业银行（不含村镇银行）、金融租赁、信托、金融资产管理、证券、公募基金、期货、人身/财产/再保险、保险资管及其他；金融控股集团=金控公司及其所控股机构构成的企业法人联合体 | 第二条 | https://www.gov.cn/zhengce/2020-09/11/content_5712711.htm |
| 实质控制认定：取得过半数表决权即实质控制；另有五种视同情形（协议拥有过半数表决权/实际支配权力/任免过半数董事/董事会过半数表决权/其他含 CAS33 控制） | 第三条 | 同上 |
| 监管框架：人民银行审查批准设立、变更、终止及业务范围，跨部门联合机制；人民银行对金融控股集团的资本、行为及风险进行全面、持续、**穿透监管** | 第四、五条 | 同上 |
| 应当设立金控公司的情形（规模阈值）：实质控制含商业银行且金融机构总资产≥5000 亿元；不含商业银行但总资产≥1000 亿元或受托管理资产≥5000 亿元；或宏观审慎监管认为需要 | 第六条 | 同上 |
| 设立条件：实缴注册资本≥50 亿元人民币且不低于直接所控股金融机构注册资本总和的 50% | 第七条 | 同上 |
| 集团风险集中与大额风险暴露：并表基础上管理，建立大额风险暴露管理政策和内控制度，**实时监控大额风险暴露，建立大额风险暴露的预警报告制度**及风险分散措施 | 第三十二条 | 同上 |
| 联合授信与融资风险预警线：牵头建立集团内信息共享和联合授信机制，识别隐性关联企业和实际控制人，**联合设置企业融资风险预警线** | 第三十三条 | 同上 |
| 关联交易集中度数字红线（禁止性）：所控股金融机构（财务公司除外）向金控公司其他关联方提供的融资或担保，**超过提供方资本净额 10% 或超过接受方（关联方）资本净额 20%** 的禁止；金控公司对集团外担保余额**超过其净资产 10%** 的禁止 | 第三十六条（五）（七） | 同上 |
| 监管预警/早期干预机制：并表监管，通过报告制度、现场检查、监管谈话、**风险评估和预警**等方式监控资本充足、关联交易、流动性、声誉等风险；人民银行可**根据风险评估结果区别情形采取风险警示、早期纠正、风险处置措施** | 第三十九、四十五条 | 同上 |
| 风险处置：所控股金融机构经营恶化时金控公司救助义务；违规或经营不善造成重大风险时，人民银行可要求限期整改并采取限制经营活动、限制分红、限期补充资本、调整高管、转让股权等措施；可要求制定集团整体恢复和处置计划 | 第四十六、四十七、四十九条 | 同上 |

### 《金融控股公司关联交易管理办法》（人民银行令〔2023〕第 1 号，2023-03-01 施行）
来源：https://nanjing.pbc.gov.cn/zhengwugongkai/4081330/4406346/4406348/2025092319185496343/index.html （人民银行南京分行转载全文）

| 结论 | 条款号 | 来源 |
|---|---|---|
| 适用范围：经人民银行批准设立的金融控股公司及其附属机构共同构成的金融控股集团；附属机构=纳入并表管理范围的所有机构 | 第二条 | 同上 |
| 关联方定义：与金控公司存在一方控制另一方或施加重大影响、或同受一方控制/重大影响的自然人、法人、非法人组织等，含股东类关联方、内部人关联方及所有附属机构；可按实质重于形式和穿透原则扩展认定 | 第六、七、八、九、十条 | 同上 |
| 关联交易按交易主体分：金控公司关联交易、附属机构关联交易（第十二条）；按管理目标分：集团内部交易、集团对外关联交易（第十三条）；按交易类型分：投融资类、资产转移类、提供服务类、其他类型（第十四条） | 第十二、十三、十四条 | 同上 |
| **重大 vs 一般关联交易金额标准：重大关联交易=单笔交易金额达到金控公司上一年度末经审计的法人口径净资产 1% 以上或超过 10 亿元，或一个会计年度内对单个关联方累计交易金额达到上一年度末经审计法人口径净资产 5% 以上或超过 50 亿元；此后每累计达到净资产 1% 以上重新认定为重大关联交易；一般关联交易=除重大关联交易以外的其他关联交易** | 第十六条 | 同上 |
| 关联交易集中度限制（机制）：按交易类型、单一关联方、全部关联方等分类**审慎设置关键业务领域关联交易量化限制指标**，每年评估可适度调整；设四类限额（金控公司/附属机构/集团内部/对外关联交易），董事会批准后 15 个工作日内报告人民银行 | 第二十二条 | 同上 |
| 禁止性关联交易八项（如内部交易虚构交易/监管套利、对外不当利益输送、隐匿关联关系拆分交易、偏离公允定价、附属金融机构向金控公司提供融资等） | 第二十三条 | 同上 |
| 豁免交易：与关联自然人单笔 50 万元以下、与关联法人单笔 500 万元以下且累计未达重大标准的关联交易可免予逐笔审议披露（统计时合并计算）等六类 | 第二十八条 | 同上 |
| 监测预警条款：对附属机构关联交易按季汇总分析和**监测预警**（第三十条）；对集团内部交易及时收集汇总、监测分析和**评估预警**（第三十一条）；对集团对外关联交易监测分析和评估预警（第三十三条） | 第三十、三十一、三十三条 | 同上 |
| 报告披露：重大关联交易协议签订后 15 个工作日内逐笔报送人民银行及其住所地分支机构；真实、准确、完整、及时报告披露 | 第三十七、三十六条 | 同上 |

## 第四节 银行业实务惯例（非法规强制标准，来源为银行披露/行业文章，标注证据强度）

| 结论 | 证据 | 来源 |
|---|---|---|
