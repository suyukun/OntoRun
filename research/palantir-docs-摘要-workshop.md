## workshop 模块
- **定位**：Foundry 低代码应用构建工具，面向"操作用户"。三条原则：① 数据全部从 **Object 层**读取；**Actions（操作）**负责写回 Object；**Functions（函数）**在对象数据上执行业务逻辑（含遍历链接、聚合）；② 统一设计系统；③ 事件系统支撑互动。
- **设计元素**：标题 → 页面 → 部分（列/行/标签/流/工具栏/循环设计）→ 覆盖（抽屉/模态）。
- **变量（数据流核心）**：6 种定义（静态/函数/对象集聚合/对象属性/对象集定义/变量变换）；类型含对象集/对象集筛选/结构体/时间序列集；变量变换 = 链式操作（字符串拼接/if-else/类型转换/聚合 min/max/sum/avg/cardinality/数学/日期/数组）。
- **对象集**：核心数据单位；微件输入皆对象集变量；默认加载第一行设为活动对象。
- **对象表**：多对象类型、多列排序、函数派生列、**行内编辑（单元格级写回）**、导出（CSV≤1万行、Excel≤20万行）。
- **筛选/聚合/排序**：筛选列表（直方图/单选多选/关键词）；输出"对象集筛选"变量应用到下游；聚合（min/max/sum/avg/cardinality/透视表）；排序默认+用户。
- **动作（写回）**：操作类型 = Ontology Manager 预定义规则集（创建/修改/删除/链接对象）；表单参数由规则自动生成；**提交条件**（正则校验，失败按钮禁用）；行内编辑一次≤20 行（函数）或≤200 行。
- **Functions**：指标卡/复杂对象集/函数支持操作；基于函数的变量用结果缓存（无法禁用）。
- **应用构建**：模块接口 = 模块的 API（变量映射 + URL 查询参数）；嵌入模块 + 循环设计（遍历对象集渲染）；路由/状态保存（外部ID存取）；版本管理（发布/查看/恢复）；自动刷新仅 OSv2 最小 10 秒。
- **AIP 互动微件**：把企业工具（操作/函数/Workshop应用/Ontology语义搜索）接入流程并可读写变量。
