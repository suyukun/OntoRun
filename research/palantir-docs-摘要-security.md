## security 模块
- **权限模型** = 认证+授权，两级：强制（组织/权限标记/分类标记，全有或全无）+ 自由（角色，只能加不能减）。
- **分级**：注册→组织（用户与资源隔离，每用户属一组织、可客座）→空间（项目容器，共享 Ontology）→项目（主要安全边界）→资源；项目级权限继承到子资源。
- **权限标记（强制，AND 合取）**：用于文件/夹/项目，须满足全部标记；沿文件层次与依赖双路继承；应用/移除=敏感操作即全链传播，移除需"扩展访问权限"。脱敏=管道删列+stop_requiring 移除继承标记。
- **对象/属性级**：对象类型由基础数据集支撑，数据权限继承数据集；**Ontology 角色挂对象/链接/操作类型控"编辑配置"，不给数据权限，数据权限仍在数据源**。
- **行级 = 受限视图**：不能作变换输入；策略=规则（AND/OR）比较用户属性/列/常量；策略列空值→行不可见；可基于标记列逐行控制；可作对象数据源，对象继承行级策略。
- **审计**：审计日志属核心企业功能；敏感操作可经"检查点"填理由并记录。
- **CBAC 分类标记**：默认不启用；层级性、类别可析取(OR)；数据分类=文件分类+全部上游数据分类（自动只增不减）；项目分类=最大分类，更高数据不能进。
- **反模式**：标记勿用于授权；策略复杂度放管道、用专用策略列。
