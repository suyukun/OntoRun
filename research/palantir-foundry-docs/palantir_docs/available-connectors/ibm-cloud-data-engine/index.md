# IBM Cloud 数据引擎

IBM Cloud 数据引擎连接器是一个Palantir 提供的驱动连接器。此驱动的官方文档可以在这里 ↗找到。

## 网络

如果使用代理连接，必须允许代理连接到您选择的系统。这意味着代理必须能够到达目标IP地址，并且目标系统必须配置为允许来自代理的连接。

如果使用直接连接，请务必将以下出口策略添加到连接器中：

| 域名 | 必需 |
| --- | --- |
| iam.bluemix.net | 始终 |
| api.dataengine.cloud.ibm.com | 始终。新的 v3 端点，最有可能需要/使用，除非使用旧版本驱动 |
| <Region>.cloud-object-storage.appdomain.cloud | 始终。区域连接属性被映射（也可能由 IBM 返回或作为 CRN 的一部分） |
| resource-controller.cloud.ibm.com | 仅当未提供 CRN 时 |
| sql-api.ng.bluemix.net | 仅旧的 v2 端点被 api.dataengine.cloud.ibm.com 替换 |
