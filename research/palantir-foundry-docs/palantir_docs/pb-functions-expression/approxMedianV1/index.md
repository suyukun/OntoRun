# 近似中位数

> 支持于: 批处理

支持于: 批处理

计算列中值的近似中位数。

表达式类别: 聚合

## 声明的参数

- 表达式- 要计算近似中位数的列。表达式<数字>
输出类型:数字

## 示例

### 示例 1: 基本情况

参数值:

- 表达式:values
给定输入表:

| values |
| --- |
| 2 |
| 4 |
| 3 |

输出:3

### 示例 2: 空值情况

参数值:

- 表达式:values
给定输入表:

| values |
| --- |
| 2 |
| 3 |
| 4 |
| null |

输出:3
