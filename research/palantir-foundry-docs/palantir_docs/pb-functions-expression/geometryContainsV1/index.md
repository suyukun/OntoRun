# 几何包含

> 支持于: 批处理, 流处理

支持于: 批处理, 流处理

确定几何 a 是否包含几何 b。位于多边形边界上的点或线不包含在另一个几何内。

表达式类别: 地理空间

## 声明的参数

- 几何 a- 几何 a。Expression<Geometry>
- 几何 b- 几何 b。Expression<Geometry>
输出类型:Boolean
