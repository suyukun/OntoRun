# 多边形中的第N链

> 支持于: 批处理, 流处理

支持于: 批处理, 流处理

返回几何图形中单个多边形的第n个环。索引从1开始，索引为0表示超出范围。索引等于1返回外部环。索引大于1返回内部环。以下任一条件返回null：几何图形不是单个多边形，提供了要素集合或几何图形集合，索引超出范围，或至少一个参数为null。

表达式类别: 地理空间

## 声明的参数

- N- 要检索的环的索引。索引从1开始，索引为0表示超出范围。索引大于1返回内部环。Expression<Byte | Integer | Long | Short>
- Polygon- 要检索第n个环的多边形。Expression<Geometry>
输出类型:Geometry
