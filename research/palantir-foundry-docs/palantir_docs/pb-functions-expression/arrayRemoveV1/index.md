# 数组移除

> 支持于: 批处理, 流处理

支持于: 批处理, 流处理

返回一个数组，该数组在给定数组中移除所有提供的“值”后。

表达式类别: 数组

## 声明参数

- 数组- 从中移除提供的“值”的数组。表达式<数组<T>>
- 值- 要从数组中移除的值。表达式<T>
类型变量界限:T 接受任意类型

输出类型:数组<T>

## 示例

### 示例 1: 基本情况

参数值:

- 数组: [ 1, 2, 3 ]
- 值: 1
输出:[ 2, 3 ]

### 示例 2: 基本情况

描述: 移除值的所有实例。参数值:

- 数组: [ 1, 2, 2 ]
- 值: 2
输出:[ 1 ]

### 示例 3: 基本情况

描述: 如果未找到该值，则返回整个数组。参数值:

- 数组: [ 1, 2, 3 ]
- 值: 10
输出:[ 1, 2, 3 ]

### 示例 4: 空值情况

参数值:

- 数组:array
- 值:value
| array | value | 输出 |
| --- | --- | --- |
| [ 1, 2, 3 ] | null | [ 1, 2, 3 ] |
| null | 1 | null |
| null | null | null |
