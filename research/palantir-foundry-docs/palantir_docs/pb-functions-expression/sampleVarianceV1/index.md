# 样本方差

> 支持于: 批处理, 流处理

表达式类别: 聚合

## 声明的参数

- 表达式- 计算此表达式的样本方差。表达式<数字>
输出类型:双精度

## 示例

### 示例 1: 基本情况

参数值:

- 表达式:values
给定输入表:

| values |
| --- |
| 2 |
| 2 |
| 3 |

输出:0.33333333333

### 示例 2: 空值情况

参数值:

- 表达式:values

| values |
| --- |
