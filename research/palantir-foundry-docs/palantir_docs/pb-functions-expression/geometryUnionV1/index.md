# 几何联合

> 支持于: 批处理, 流处理

支持于: 批处理, 流处理

合并两个几何图形以创建一个单一的几何图形。

表达式类别: 地理空间

## 声明的参数

- 几何 a- 几何 a。Expression<Geometry>
- 几何 b- 几何 b。Expression<Geometry>
输出类型:Geometry
