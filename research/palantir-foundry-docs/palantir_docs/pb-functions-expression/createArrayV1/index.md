# 创建数组

> 支持于: 批处理, 流处理

支持于: 批处理, 流处理

根据提供的列创建一个数组。

表达式类别: 数组

## 声明的参数

- 表达式- 用于创建数组的表达式列表。List<Expression<T>>
类型变量界限:T 接受 AnyType

输出类型:Array<T>

## 示例

### 示例 1: 基本情况

参数值:

- 表达式: [1, 2, 3]
输出:[ 1, 2, 3 ]

### 示例 2: 基本情况

参数值:

- 表达式: [[ 1 ], [ 2 ]]
输出:[ [ 1 ], [ 2 ] ]

### 示例 3: 空值情况

参数值:

- 表达式: [1,null, 3]
输出:[ 1,null, 3 ]
