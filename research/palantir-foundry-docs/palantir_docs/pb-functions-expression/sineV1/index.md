# 正弦

> 支持于: 批处理, 流处理

支持于: 批处理, 流处理

计算角度的正弦值。

表达式类别: 数值

## 声明的参数

- 角度单位- 角度单位可以是度或弧度。枚举<度, 弧度>
- 角度值- 角度值可以是弧度或度。表达式<确定数值>
输出类型:双精度

## 示例

### 示例 1: 基本情况

参数值:

- 角度单位:degrees
- 角度值:angle
| angle | 输出 |
| --- | --- |
| 0.0 | 0.0 |
| 90.0 | 1.0 |
| 180.0 | 0.0 |

### 示例 2: 基本情况

参数值:

- 角度单位:radians
- 角度值:null
输出:null
