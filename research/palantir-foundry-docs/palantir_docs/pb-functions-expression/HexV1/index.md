# 转换为十六进制

> 支持于: 批处理, 流处理

支持于: 批处理, 流处理

计算给定表达式的十六进制值。

表达式类别: 数值, 字符串

## 声明参数

- 表达式- 要转换为十六进制的列。表达式<Binary | Byte | Integer | Long | Short | 字符串>
输出类型:字符串

## 示例

### 示例 1: 基本情况

参数值:

- 表达式:city_hex
| city_hex | 输出 |
| --- | --- |
| TG9uZG9u | 4C6F6E646F6E |

### 示例 2: 基本情况

参数值:

- 表达式: -12345
输出:FFFFFFFFFFFFCFC7

### 示例 3: 基本情况

参数值:

- 表达式: 12345
输出:3039

### 示例 4: 基本情况

参数值:

- 表达式: hello
输出:68656C6C6F

### 示例 5: 空值情况

参数值:

- 表达式:null
输出:null
