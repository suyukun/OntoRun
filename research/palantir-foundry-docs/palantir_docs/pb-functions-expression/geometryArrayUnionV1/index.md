# 几何数组（单一）合并

> 支持于：批处理，流处理

支持于：批处理，流处理

给定一个几何体数组，将这些合并为一个单一的几何体，合并时不重叠。

表达式类别：地理空间

## 声明的参数

- 表达式- 一个待合并的几何体数组。Expression<Array<T>>
类型变量界限：T 接受 Geometry

输出类型：T
