# 区域

> 支持于: 批处理, 流处理

支持于: 批处理, 流处理

使用球形近似法计算几何图形的面积，单位为平方米。对于线字符串或点，此值等于0。

表达式类别: 地理空间

## 声明的参数

- 表达式- GeoJSON 字符串。表达式<Geometry>
