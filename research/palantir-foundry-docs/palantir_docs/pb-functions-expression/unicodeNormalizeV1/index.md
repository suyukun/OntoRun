# Unicode 规范化

> 支持于: 批处理, 流处理

支持于: 批处理, 流处理

根据 Unicode 标准附件 #15 执行 Unicode 规范化。

表达式类别: 数据准备, 字符串

## 声明的参数

- 表达式-无描述Expression<字符串>
- 规范化形式-无描述Enum<NFC, NFD, NFKC, NFKD>
输出类型:字符串

## 示例

### 示例 1: 基本情况

参数值:

- 表达式:string
- 规范化形式:nfc
| 字符串 | 输出 |
| --- | --- |
| １２３ | １２３ |
| イナゴ | イナゴ |
