# 时间戳减法

> 支持于: 批处理, 流处理

支持于: 批处理, 流处理

从时间戳中减去指定单位的值。

表达式类别: 日期时间

## 声明参数

- 时间戳- 将被修改的时间戳。表达式<时间戳>
- 单位- 时间单位。枚举<天, 小时, 毫秒, 分钟, 月, 季度, 秒, 周, 年>
- 减去的值- 从时间戳中减去的值。表达式<字节 | 整数 | 长整型 | 短整型>
输出类型:时间戳

## 示例

### 示例 1: 基本情况

参数值:

- 时间戳: 2022-02-02T00:00:00Z
- 单位:DAYS
- 减去的值: 1
输出:2022-02-01T00:00:00Z

### 示例 2: 基本情况

参数值:

- 时间戳: 2022-02-02T00:00:00Z

### 示例 3: 基本情况
