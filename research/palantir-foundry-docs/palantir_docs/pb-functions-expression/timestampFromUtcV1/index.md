# 从UTC转换时间戳

> 支持于: 批处理, 流处理

支持于: 批处理, 流处理

将时间戳从UTC转换为给定的时区。

表达式类别: 日期时间

## 声明的参数

- 时区- 目标时区。将考虑城市的夏令时，但不考虑三位数字代码。TimeZone
- 时间戳- 时间戳列。Expression<Timestamp>
输出类型:Timestamp

## 示例

### 示例 1: 基本案例

参数值:

- 时区: Australia/Sydney
- 时间戳: 2020-04-28T10:09:00Z
输出:2020-04-28T20:09:00Z

### 示例 2: 基本案例

参数值:

- 时区: EST
- 时间戳: 2020-04-28T10:09:00Z
输出:2020-04-28T05:09:00Z

### 示例 3: 基本案例

参数值:

- 时区: America/Denver
- 时间戳: 2020-04-28T10:09:00Z
输出:2020-04-28T04:09:00Z

### 示例 4: 基本案例

参数值:

- 时区: America/Denver
- 时间戳: 2020-02-09T10:09:00Z
输出:2020-02-09T03:09:00Z

### 示例 5: 基本案例

参数值:

- 时区: UTC
- 时间戳: 2020-04-28T10:09:00Z
输出:2020-04-28T10:09:00Z

### 示例 6: 基本案例

参数值:

- 时区: EST
- 时间戳: 2020-01-28T10:09:00Z
输出:2020-01-28T05:09:00Z

### 示例 7: 空案例

参数值:

- 时区: UTC
- 时间戳:null
输出:null
