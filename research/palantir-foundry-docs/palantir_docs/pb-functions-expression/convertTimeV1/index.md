# 时间单位转换

> 支持于: 批处理, 流处理

支持于: 批处理, 流处理

表达式类别: 日期时间

## 声明的参数

- 当前单位的数量-无描述表达式<DefiniteNumeric>
- 当前单位- 转换前的单位。枚举<天, 小时, 毫秒, 分钟, 秒, 周>
- 目标单位- 转换后的期望单位。枚举<天, 小时, 毫秒, 分钟, 秒, 周>
输出类型:双精度

## 示例

### 示例 1: 基本案例

参数值:

- 当前单位的数量:days
- 当前单位:days
- 目标单位:minutes
| 天 | 输出 |
| --- | --- |
| 12 | 17280.0 |

### 示例 2: 空值案例

参数值:

- 当前单位的数量:days
- 当前单位:days
- 目标单位:minutes
| 天 | 输出 |
| --- | --- |
| null | null |
