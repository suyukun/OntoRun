# 将时间戳转换为纪元毫秒

> 支持于: 批处理, 流处理

支持于: 批处理, 流处理

将UTC时间戳转换为纪元毫秒。

表达式类别: 转换, 日期时间

## 声明的参数

- 时间戳-无描述表达式<时间戳>
输出类型:长整型

## 示例

### 示例 1: 基本情况

参数值:

- 时间戳: 2022-10-01T09:00:00Z
输出:1664614800000

### 示例 2: 空值情况

参数值:

- 时间戳:空值
输出:空值
