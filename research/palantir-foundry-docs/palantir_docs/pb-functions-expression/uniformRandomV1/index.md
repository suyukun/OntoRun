# 均匀随机数

> 支持于: 批处理, 流处理

支持于: 批处理, 流处理

返回介于0和1之间的均匀随机数列。这不是确定性的，即使使用相同的种子，重复搭建时也不会产生相同的结果。

表达式类别: 数值

## 声明的参数

- 非必填种子- 添加种子意味着随机数将在每次搭建时从相同的序列生成。如果你想要true随机数，则不应提供种子。由于计算可能是分布式运行的，并且不保证随机数提取行的顺序，种子不会产生完全确定的结果。Literal<Long>
输出类型:Double
