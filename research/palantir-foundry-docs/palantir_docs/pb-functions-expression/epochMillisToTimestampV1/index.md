# 从纪元毫秒转换为时间戳

> 支持于: 批处理, 流处理

支持于: 批处理, 流处理

将纪元毫秒转换为UTC时间戳。

表达式类别: 转换, 日期时间

## 声明的参数

- 表达式-无描述Expression<Double | Long>
输出类型:时间戳

## 示例

### 示例 1: 基本情况

描述: 您可以将以毫秒为单位的纪元时间戳转换为时间戳类型参数值:

- 表达式: 1673964111000
输出:2023-01-17T14:01:51Z
