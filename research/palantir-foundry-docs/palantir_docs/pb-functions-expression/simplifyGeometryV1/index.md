# 简化几何

> 支持于：批处理，流处理

支持于：批处理，流处理

此表达式通过使用球形模型从给定的公差距离内移除点来简化GeoJSON几何。小于公差的循环可能会被完全移除。

表达式类别：地理空间

## 声明的参数

- 几何- 有效的GeoJSON几何。表达式<几何>
- 公差- 公差（米）。表达式<长整型>
- 非必填坐标精度- 坐标的小数位数最大值（默认为6位小数）。表达式<长整型>
输出类型：几何
