# 周长

> 支持于: 批处理, 流处理

支持于: 批处理, 流处理

使用球形近似计算几何体的周长，单位为米。对于线字符串或点，这等于0。

表达式类别: 地理空间

## 声明的参数

- 表达式- GeoJSON字符串。Expression<Geometry>
输出类型:Double
