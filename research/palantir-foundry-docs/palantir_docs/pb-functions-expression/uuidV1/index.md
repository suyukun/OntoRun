> 支持于: 批处理, 流处理

支持于: 批处理, 流处理

返回一列uuid。这不是确定性的，并且在重复搭建时不会产生相同的结果。这不是搭建ID列的首选方式，用户应该考虑sha256或其他确定性的方法。

表达式类别: 字符串

## 声明的参数

此函数不接受任何参数。
