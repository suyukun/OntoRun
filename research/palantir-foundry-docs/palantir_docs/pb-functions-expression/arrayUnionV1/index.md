# 数组合并

> 支持于: 批处理, 流处理

支持于: 批处理, 流处理

移除重复项并合并数组列表。

表达式类别: 数组

## 声明的参数

- 表达式- 要合并的数组列表。List<Expression<Array<T>>>
类型变量界限:T 接受任意类型

输出类型:Array<T>

## 示例

### 示例 1: 基本情况

参数值:

- 表达式: [[ 1, 2, 3 ], [ 3, 4 ]]
输出:[ 1, 2, 3, 4 ]

### 示例 2: 基本情况

参数值:

- 表达式: [[ 1, 2, 3 ], [ 3, 4 ], [ 4, 5 ]]
输出:[ 1, 2, 3, 4, 5 ]

### 示例 3: 基本情况

描述: 移除重复项。参数值:

- 表达式: [[ 1, 1 ], [ 1 ]]
输出:[ 1 ]

### 示例 4: 空值情况

参数值:

- 表达式: [first_array,second_array]
| first_array | second_array | 输出 |
| --- | --- | --- |
| [ 1, 2, 3 ] | null | [ 1, 2, 3 ] |
| null | null | [  ] |
