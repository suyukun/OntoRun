# 平均值

> 支持于: 批处理, 流处理

支持于: 批处理, 流处理

计算列中值的平均值。

表达式类别: 数值

## 声明的参数

- 表达式- 计算平均值的列。表达式<数值>
输出类型:十进制 | 双精度

## 示例

### 示例1: 基本案例

参数值:

- 表达式:values
给定的输入表:

| values |
| --- |
| 2 |
| 4 |
| 3 |

输出:3.0

### 示例2: 空值案例

参数值:

- 表达式:values
给定的输入表:

| values |
| --- |
| 2 |
| null |
| 3 |

输出:2.5
