# 截断时间戳

> 支持于: 批处理

支持于: 批处理

返回截断到指定单位的时间戳。

表达式类别: 日期时间

## 声明的参数

- 开始-无描述表达式<时间戳>
- 单位- 用于截断的时间单位。枚举<天, 小时, 毫秒, 分钟, 月, 季度, 秒, 周, 年>
输出类型:时间戳

## 示例

### 示例 1: 基本情况

参数值:

- 开始: 2022-02-01T10:10:10.002Z
- 单位:DAYS
输出:2022-02-01T00:00:00Z

### 示例 2: 基本情况

参数值:

- 开始: 2022-02-01T10:10:10.002Z
- 单位:HOURS
输出:2022-02-01T10:00:00Z

### 示例 3: 基本情况
