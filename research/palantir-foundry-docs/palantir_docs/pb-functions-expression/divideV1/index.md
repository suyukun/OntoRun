# 数字除法

> 支持于: 批处理, 流处理

支持于: 批处理, 流处理

将一个数字除以另一个数字。

表达式类别: 数值

## 声明的参数

- 左- 分子。表达式<数值>
- 右- 分母。表达式<数值>
输出类型:小数 | 双精度

## 示例

### 示例 1: 基本情况

参数值:

- 左:col_a
- 右:col_b
| col_a | col_b | 输出 |
| --- | --- | --- |
| 4 | 2 | 2.0 |
| 11 | 2 | 5.5 |
