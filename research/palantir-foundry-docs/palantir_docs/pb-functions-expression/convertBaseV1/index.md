# 进制转换

> 支持于: 批处理

支持于: 批处理

将一个数字（或其字符串表示形式）从一个进制转换为另一个进制。

表达式类别: 二进制, 转换, 数值

## 声明的参数

- 表达式- 要转换进制的列。表达式<字节 | 整数 | 长整型 | 短整型 | 字符串>
- 从进制- 转换的源进制。字面量<整数>
- 到进制- 转换的目标进制。字面量<整数>
输出类型:字符串

## 示例

### 示例 1: 基础情况

参数值:

- 表达式: 4A801
- 从进制: 16
- 到进制: 10
输出:305153

### 示例 2: 基础情况

参数值:

- 表达式: 8
- 从进制: 10
- 到进制: 2
输出:1000

### 示例 3: 空值情况

参数值:

- 表达式:input
- 从进制: 10
- 到进制: 16
| input | 输出 |
| --- | --- |
| null | null |

### 示例 4: 边缘情况

描述: 当输入由超出给定“从进制”的字符组成时，仅考虑到第一个超出进制字符之前的前导字符。参数值:

- 表达式:input
- 从进制: 2
- 到进制: 10
| input | 输出 |
| --- | --- |
| 123 | 1 |
| 213 | 0 |
| 1032 | 2 |
