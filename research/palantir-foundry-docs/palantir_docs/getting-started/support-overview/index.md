# 支持概述

如果您在使用Palantir平台时遇到任何问题，可以查看下面关于如何调查、诊断和找到合适解决方案的指导。

## 1. 调查问题

在提交支持请求之前，请按照以下步骤解决潜在问题。通过收集以下信息，可以加快调查过程，帮助我们提供最佳解决方案。

- 首先查看平台的出错信息，并将其整理到文档中。
- 如果出错信息不清晰或未提供可操作的下一步，请使用Chrome™ 开发者工具获取关于问题的更多信息。
- 考虑自上次平台正常运行以来是否进行了任何更改。尝试恢复这些更改并测试问题是否已解决。
- 检查状态邮件、警报和公告，以了解已知问题或可能影响您工作的计划维护。
- 搜索平台文档以查看是否有有用的建议。
- 复制errorID/errorInstanceID并与支持团队分享。
- 使用数据沿袭调查管道中的问题（例如，权限、搭建状态、搭建计划等）。选择不同的节点着色选项（例如，上次搭建时间或权限）可以突出显示管道中资源的不同特征。
- 选择不同的节点着色选项（例如，上次搭建时间或权限）可以突出显示管道中资源的不同特征。
- 如果您看到不清楚的出错信息，请检查控制台日志。
## 2. 搜索问题应用程序和Stack Overflow

通过您自己调查获得的附加信息，您可以访问：

- 问题应用程序，以查看其他用户报告的问题，这可能有助于解决或提供您问题的见解。此应用程序通过跟踪过去的问题，提供来自Palantir支持的先前参与，以及问题解决的时间线，为平台中的问题提供透明度。
- Palantir开发者论坛 ↗向您的其他用户提问和回答问题。在这里，您可以找到其他Palantir用户提出的问题，并获得您面临问题的帮助。

## 进一步协助

如果您无法从上述资源或我们的平台文档中找到解决方案，请了解如何准备和提交支持票，其中详细说明了如何收集调试信息并创建类似示例，以便Palantir支持能够快速解决您的问题。
