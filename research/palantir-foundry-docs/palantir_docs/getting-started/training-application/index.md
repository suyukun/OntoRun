# 培训应用

培训应用为您提供从learn.palantir.com ↗精心挑选的课程集合，并链接到所有平台内和公开的学习资料，以学习如何使用Palantir平台。

## 为您的组织呈现培训文档

培训应用允许您呈现记事本文档，其中包含与您的组织相关的培训信息。

要呈现包含培训材料和说明的记事本文档，请创建一个名为Training application的标签类别。每个用户可访问并在标签类别Training application下标记的记事本文档都将在培训应用中显示。您可以自由命名类别中的标签，这些标签将显示在指向文档的链接中。
