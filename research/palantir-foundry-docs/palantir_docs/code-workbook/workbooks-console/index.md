# 控制台

在工作簿的右侧，控制台提供了一个REPL（读取-求值-打印循环），以便对图上的任何变换进行快速的、临时的分析。每个分支启用的语言都有一个控制台。

使用控制台时：

- 使用Enter键执行当前代码输入。
- 使用Shift+Enter输入换行并创建多行语句。
- 使用上下键浏览以前执行的命令。
在控制台下方，使用变量面板设置给定变换的输入类型到控制台。

如果控制台命令返回一个数据框，您可以使用**+ 添加到图中**按钮将控制台命令转换为变换。这允许您在控制台中试验逻辑，然后再将其提升为可重复的变换。

您可以使用键盘快捷键Windows系统下的Ctrl+Shift+Enter或macOS系统下的Cmd+Shift+Enter，将代码直接从变换发送到控制台。
