# 建议模板

对于一组相似的数据集，您可能希望建议应用模板。例如，对于包含每月股票回报率的数据集组，您可能希望建议一个计算年化回报率的模板。建议的模板显示在新变换面板内的一个单独按钮中，使其更易于发现。

## 在模板中配置输入标签

下面，我们看到一个从每月回报率计算年化回报率的模板。对于任何具有标签Finance的数据集，当用户创建以该数据集为父的新变换时，此模板将出现在建议选项卡中。

在创建或编辑模板时，在输入标签字段中配置所需的输入标签。您可以添加多个输入标签。

## 向数据集添加标签

向数据集添加输入标签的一种方法是打开Dataset-app中的数据集。请注意，由于标签与数据集绑定，因此无法在Code Workbook中未持久化的变换中添加标签。这意味着未持久化的变换不支持建议模板。

## 在多节点模板中配置输出标签

与其从Dataset-app手动添加标签，您可以将输出标签配置为多节点模板的一部分。

想象一个具有两个节点的多节点模板，其中第二个节点的输出是一个具有每月股票回报率的数据集。我们希望这个数据集自动添加Finance标签，以便配置了该输入标签的模板将在建议模板下显示。

在创建或编辑多节点模板时，在输出标签下设置所需的输出标签。当应用多节点模板时，输出标签将立即添加到由多节点模板创建的数据集中。
