# 展示可视化

在 Code Workbook 中创建可视化后，您可能希望在 Code Workbook 的上下文之外向协作者展示它。

## 将可视化添加到 Notepad

在 Code Workbook 中生成的可视化可以在 Notepad 文档中展示。您可以在 Notepad 文档中嵌入来自 Foundry 的各种资源，包括 contour面板、Quiver 画布和 Code Workbook 可视化，并可以使用文本、表格和图像对文档进行注释。您还可以创建 Notepad 模板，允许 Workshop 应用程序中的用户根据给定的蓝图生成新的 Notepad 文档。了解更多关于 Notepad 的信息。

您可以通过右键单击图形上的节点并单击Copy for Notepad将 Code Workbook 可视化添加到 Notepad 文档。现在，图像已复制到您的剪贴板，可以粘贴到任何 Notepad 文档中。

## 将可视化添加到报告

截至 2022 年 10 月 3 日，Foundry Reports 默认不再对新客户开放。如果您有需要访问 Foundry Reports 的应用案例，请联系您的 Palantir 代表。对于现有用户，Foundry Reports 仍支持创建由 Code Workbook 生成的可视化仪表盘。

在 Code Workbook 中生成的可视化可以添加到 Foundry Report 中以供展示和协作。您可以通过打开可视化选项卡并单击Add to Report，或通过右键单击图形上的节点并单击Add to Report来将可视化添加到报告中。
