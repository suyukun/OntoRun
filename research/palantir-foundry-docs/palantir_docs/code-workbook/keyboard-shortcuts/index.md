# 键盘快捷键

此页面列出了当前在 Code Workbooks 中可用的 macOS 和 Windows 键盘快捷键。

选择左上角的帮助菜单，然后选择⌘ 键盘快捷键以查看所有键盘快捷键的弹出窗口。或者，您可以使用Shift+?查看所有键盘快捷键。

## macOS 快捷键

### 编辑器

- 在控制台中运行选定代码：Cmd+Shift+Enter
- 打开自动完成建议：Tab
- 关闭全屏只读或编辑器 / 清除新节点：Esc
- 打开全屏编辑器：Cmd+Alt+E
### 执行

- 运行选定数据集：Cmd+Enter
- 运行所有已保存数据集：Cmd+Alt+Enter
### 图形

- 删除选定节点：Del
- 删除选定节点：Backspace
- 缩放到选定节点：Space
- 设计所有图形节点：Cmd+Shift+A
- 按颜色组设计所有图形节点：Ctrl+Shift+G
- 设计选定的图形节点：Cmd+L
- 选择下一个节点：Right arrow
- 选择上一个节点：Left arrow
- 选择所有图形节点：Cmd+A
### 工作簿

- 导入数据集：Cmd+Alt+R
- 打开分支菜单：Cmd+B
- 在工作簿中搜索：Cmd+Shift+F
- 关闭所有辅助面板：Ctrl+Cmd+C
