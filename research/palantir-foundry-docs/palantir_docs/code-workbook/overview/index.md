# 概述

Code Workbook是一款应用程序，允许用户以直观的图形界面使用代码分析和变换数据。

## 目标

Code Workbook 的设计原则包括：

- 迭代速度：用户可以快速测试和优化变换和可视化的逻辑，以产生有用的结果。
- 低门槛：Code Workbook 的图形界面和重用预先编写逻辑的能力旨在使具有不同技术技能的用户轻松入门。
- 协作：不同的用户群体可以共享逻辑并在 Code Workbook 中共同完成单个分析。
- 平台互操作性：用户可以通过将可视化添加到 Notepad、提升生产就绪的管道到 Code Repositories 并在机器学习模型上迭代，在整个平台上实现其发现成果的生产化。
## 功能

Code Workbook 的主要功能包括：

- 用于快速迭代变换逻辑和临时数据探索的交互式控制台。
- 可视化支持，使用常用的包（Matplotlib、Plotly、Seaborn）创建详细的交互式图像。
- 模板通过简单的界面重用复杂和特定领域的逻辑。
- 多语言支持，支持代码和模板语言，允许用户为分析选择最佳语言。
- 分支，通过将用户的更改彼此隔离来促进协作。
- 点击式用户界面，使用户可以轻松自定义 Spark 环境、设置变换的输入类型，并查看节点之间的关系。
