# 复制节点

在 Code Workbook 中可以一次复制一个节点。要复制节点，首先通过选择节点右上角的...按钮或右键单击节点的任意位置打开节点菜单。然后，将鼠标悬停在编辑...上以显示子菜单并选择复制。

## 复制/粘贴节点

也可以通过使用复制/粘贴来复制节点。以下方法允许您在同一个 Code Workbook 或不同的 Code Workbook 中创建节点或一组节点的副本。这样可以让您将一个 Code Workbook 的内容转移到另一个 Code Workbook 中。

- 切换到屏幕右上角的选择模式。
- 通过点击并拖动来绘制一个框来选择要复制的节点。您也可以在 Mac 上按住Cmd或在 Windows 机器上按住Ctrl并依次点击每个节点。

- 右键单击所选节点并选择复制 X 个节点到剪贴板。或者，您可以使用键盘快捷键Cmd+C（macOS）或Ctrl+C（Windows）来复制节点。

- 在选择模式下，使用键盘快捷键Cmd+V（macOS）或Ctrl+V（Windows）将节点粘贴到所需的目标位置。
