# 核心概念

## 工作簿

在 Code Workbook 中与您交互的主要资源是工作簿。工作簿用于从 Foundry 导入数据集，并以这些输入数据集进行以下用途的变换：

- 清理和合并从某些外部来源导入的原始数据，为其他用户生成精选数据集。
- 分析处理过的数据源以获取有用的洞察。
- 训练和应用模型进行预测分析。
- 创建参数化可视化以在报告中显示。
了解更多关于工作簿的信息。

## 变换

变换是一些逻辑片段，它们接收一个或多个输入并返回一个输出。输入和输出可以是 Foundry 数据集或模型。

了解更多关于变换的信息。

## 模板

代码模板使具有不同技术经验的用户能够通过将代码抽象到一个简单的基于表单的界面后面进行协作。用户选择的值被替换到代码模板中，然后可以像工作簿中的任何其他变换一样运行。

了解更多关于模板的信息。

## 环境

每个 Code Workbook 都与一个环境关联。环境包括安装在支持工作簿计算的 Spark 模块上的一组 Conda 包和 Spark 设置。

了解更多关于环境的信息。

## 分支

Code Workbook 中的分支提供了一个针对数据变换量身定制的版本控制体验，使团队能够在一个工作簿中同时操作逻辑和数据。

了解更多关于分支的信息。
