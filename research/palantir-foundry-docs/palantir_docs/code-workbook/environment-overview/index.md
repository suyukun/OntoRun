# 概述

每个代码工作簿都关联一个环境。环境包括一组Conda软件包和安装在支持工作簿计算的Spark模块上的Spark设置。打开工作簿时，您可能会看到等待资源或初始化环境，因为工作簿正在获取Spark模块。在获取到Spark模块之前，您将无法使用控制台或运行变换。

每个用户被指派一个Spark模块，该模块在同一项目中具有相同环境的工作簿之间使用。Spark模块从不在用户之间共享。

### 选择配置文件

您可以通过点击环境然后自定义Spark环境来配置您的环境。您将看到一个预定义配置文件列表。这些配置文件已由管理员配置，作为特定工作流程或用户组的有用默认设置。

要使用预定义配置文件，请在左侧面板中选择它，然后点击更新Spark环境。

### 修改配置文件

如果没有预定义配置文件适合您的应用案例，您可以通过在控制面板中编辑预定义配置文件或在工作簿中自定义预定义配置文件来添加或删除软件包以修改配置文件。这些选项之间的主要区别在于更改的范围。如果您在控制面板中编辑预定义配置文件，安装在该配置文件下的所有工作簿的包将相应更改。相反，如果您在工作簿中自定义预定义配置文件，则只有该特定工作簿安装的包会更改。

要在控制面板中编辑预定义配置文件，您可以配置代码工作簿配置文件的软件包。

要在工作簿中自定义预定义配置文件，打开所需的工作簿，点击环境，选择配置环境，然后点击自定义配置文件按钮。在自定义视图中，您可以通过点击减号删除现有的软件包，或更改其请求的版本。要添加新包，请在软件包侧栏中搜索它并点击加号。添加到配置文件后，您可以选择特定版本，选择AUTOMATIC，或指定自定义Conda版本。

自定义环境初始化将比预定义配置文件慢。

### 添加配置文件

要创建一个新的预定义配置文件以供工作簿使用，您可以在控制面板中配置代码工作簿配置文件。

### 自定义Conda版本

自定义Conda版本可以是：

- 一个版本（例如3.6）
- 一个比较操作和一个版本（例如>=3.6）（接受的比较操作符有=,==,>=,>,<=和<）更多详情，请参见Conda包规范 ↗。
