# 部署计算模块

计算模块功能处于测试阶段，可能并非所有注册用户都可以使用。如果您的注册中可以使用计算模块，请导航至计算模块应用程序以获取最新文档。

## 先决条件

本节假定您已经创建了一个计算模块Docker容器。如果没有，您可以按照指南创建一个基础的Python计算模块。

## 将您的计算模块发布到Foundry

- 首先导航到Foundry中您希望放置计算模块的项目。
- 选择New->Artifacts Repository。
- 在Publish部分，从下拉菜单中选择Docker。
- 在Parameters下更改Image Name为您的Docker镜像名称。
计算模块不支持使用标签latest。

- 按照屏幕上的说明将您的镜像发布到存储库。
- 将您的镜像发布到存储库后，返回概览页面，您应该在1-2分钟内看到您的镜像显示出来。
## 配置您的计算模块

现在您已在Foundry中拥有Docker镜像，您可以准备将其作为计算模块运行。

- 导航到Foundry中您希望放置计算模块的项目。
- 选择New->Compute Module。
- 导航到Configure标签。
- 选择Add Container。
- 输入一个名称，如mycomputemodule。请注意，名称必须是小写的，且不能包含空格或除-之外的特殊字符。
- 选择您在上一步中发布Docker镜像的存储库。
- 选择您要运行的镜像和镜像的标签。
- 选择Confirm。
- 在Runtime下，确保选择了Runtime V1。
- 对于这个示例计算模块，您不需要挂载任何卷、添加任何外部访问或更改任何缩放限制。
- 选择Save。
您的计算模块现在已准备好启动。

## 运行您的计算模块

- 导航到计算模块的Overview标签。
- 选择Start。
- 等待您的计算模块进入Running状态。
## 查询您的计算模块

现在您的计算模块正在运行，您可以通过发送测试查询来验证模块是否正常工作。

- 在概览屏幕底部选择Query标签。
- 输入您的计算模块的函数名称。该函数名称将在请求中传递给您的计算模块，因此可能因计算模块而异。对于您在前一节中构建的计算模块，支持的查询是divide和multiply。
