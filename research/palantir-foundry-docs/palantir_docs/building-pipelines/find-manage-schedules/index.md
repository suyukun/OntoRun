# 查找和管理计划

可以使用搭建计划应用程序搜索和管理计划，以便您可以对搜索应用条件和筛选。例如，您可以通过给定用户或限定于某个项目的计划来搜索暂停的计划，按名称筛选并按最新运行排序。

要访问搭建计划应用程序，请在浏览器左侧的 Foundry 导航侧边栏中查找搭建计划。

从搭建计划的默认位置页面开始，您首先会看到您创建的计划。搜索参数存储在页面链接中，允许您将页面添加为书签或将链接发送给其他用户。

## 添加搜索条件

要查找其他计划，请选择添加更多计划以查看。如果计划符合任何搜索条件，将会被找到。可用的搜索条件包括：

- 文件：按 Foundry 中它们搭建的数据集或其他文件查找计划。如果未指定分支，将使用默认分支。
- 用户：查找由所选用户最后更新的计划。
- 项目：查找限定于给定项目的计划。目前不支持用户限定的计划作为此参数。
## 进一步筛选和选项

计划列表可以通过计划名称（如果计划上存在名称）和暂停状态进一步优化。也可以按名称、创建日期、最后运行日期或计划的最后更新日期排序。

## 计划信息

对于每个计划，显示计划的配置以及最近运行的详细信息。以下详细信息显示在最近 10 次运行（如果计划运行少于 10 次则显示更少）中：

- 总计算：计划最近运行的总 CPU 时间。
- 中位持续时间：最近运行的计划中搭建成功的中位搭建持续时间。
- 平均频率：计划最近运行的平均频率。
彩色圆点代表计划的最近运行，最右边的是最近的。将鼠标悬停在它们上以查看更多详细信息，或者，对于运行过搭建的计划，点击它们以查看该搭建的报告。

## 计划操作

对找到的计划的操作可以单独或批量执行。每个计划卡片上的菜单包含链接，可以在数据沿袭中编辑计划，以及一个链接到指标和历史页面，在那里您可以查看更多计划的性能和历史详细信息，并设置健康检查。还有控制项可以切换暂停、运行或删除计划。

也可以批量暂停、启用或删除计划：

- 在标题中选择选择计划...。
- 选择要执行操作的计划。
- 从标题中选择一个操作。
