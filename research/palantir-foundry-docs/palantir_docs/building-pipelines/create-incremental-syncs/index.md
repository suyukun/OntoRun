# 创建增量同步

虽然可以从配置为SNAPSHOT事务的数据连接同步中在管道中派生仅限APPEND的数据集，但增量管道的主要好处来自于端到端地应用增量。这意味着数据同步到Foundry应由仅将新数据带入系统的APPEND事务组成。配置增量同步的另一个好处是，它们可以最大限度地减少对源系统的负载，并可以减少数据存储需求。
