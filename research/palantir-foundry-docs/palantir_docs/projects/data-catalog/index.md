# 数据目录

数据目录是 Foundry 中经过精心整理的数据和其他资源的交互视图。如果您拥有正确的权限，您可以分析 Foundry 中的每个数据集，但数据目录中的数据集可能对您最有用或最相关。

要访问数据目录，请在侧边栏中选择项目和文件，然后在顶部选择数据目录。

## 集合和文件

数据目录组织为集合和文件。数据目录中的文件可以是任何已保存的分析、数据集、模块或其他与您的应用案例相关的资源。集合是这些文件的组，包含给定主题、受众或目的的所有经过精心整理的数据。任何人都可以查看集合及其描述，但您只能访问与您共享的精心整理的文件。

默认情况下，组织管理员拥有添加和删除集合中的资源以及管理拥有此权限的人员的权限。如果您希望拥有添加和删除集合中资源的权限，请与您的组织管理员联系。

选择一个集合以查看其包含的文件或资源。

在整个 Foundry 中，数据目录数据以紫色复选标记徽章表示，如上图所示。

选择数据集或其他资源以打开和检查。

### 筛选

在文件选项卡和每个集合中都有一个筛选面板。您可以选择标签以按类型或标签类别筛选资源列表，从而轻松找到所需内容。

您还可以按标签（如分析或地区）对筛选结果进行分组，以便在集合中更容易导航。
