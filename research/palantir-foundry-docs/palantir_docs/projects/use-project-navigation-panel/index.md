# 使用项目导航面板

项目导航面板包括预览和项目工作区部分，提供文档工具和文件列表管理工具。

## 封面页

封面页部分提供基于Markdown的富文本编辑器，用于撰写项目文档。有关更多信息，请参阅封面页文档。

## 文件

文件标签显示项目内所有文件的集合。

## 自动保存

当您从现有文件创建新文件时，它会自动保存在项目的自动保存部分，而不是在您的文件中。这些文件标记有Autosaved标签，并且对拥有文件夹或项目访问权限的任何人可见。自动保存文件允许快速工作并减少项目杂乱。

当文件被手动保存时，它们将出现在文件部分。

### 文件权限

当您创建自动保存文件时，它会继承其最初创建所在文件夹的权限。创建自动保存文件的用户是该文件的所有者。

在与其他用户共享自动保存文件之前，您需要手动保存该文件。

请联系您的Palantir代表，以帮助配置自动保存访问权限。

## 项目目录

项目目录是项目内精选文件的列表，通常代表了其他项目外的人在工作中可能想要使用的最有价值的文件。除了精选文件列表外，项目目录还提供了一组维护统计数据和这些精选文件所链接到的项目列表。

## 参考

由于项目定义了相关工作的概念边界和应用及管理访问的安全边界，因此数据流动需要特别注意。

项目参考允许您管理跨项目边界的数据和包的流动，并分为两个部分：文件参考和外部参考。

文件参考包括任何在项目外部使用的文件，这些文件在代码库、代码工作簿、Pipeline Builder、Fusion或Contour中使用。具有编辑者角色的用户可以向项目添加文件参考。可以通过右键点击文件并选择移除参考来删除文件参考。了解更多关于文件参考为何必要的信息。

外部参考通常是从各种数据分析应用程序自动添加到项目中的代码包，以运行搭建。

## 回收站

每个项目都有自己的回收站部分。如果您不再需要项目中的文件，可以通过将文件移动到回收站来删除文件。选择您要删除的文件，然后选择回收站图标将其移至回收站。

如果您改变主意，可以从回收站恢复文件。在回收站标签中，选择文件，然后选择恢复图标。

恢复文件会将其放回您删除前的位置，并恢复之前的权限。

使用X按钮可以永久删除选定的文件。
