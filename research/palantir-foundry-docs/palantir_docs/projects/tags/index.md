# 标签

标签是可以应用于资源的结构化元数据，用于分类和发现。标签是一个有用的构造，但它们不添加或暗示安全性。

标签被组织成类别；每个类别的可见性可以限制在一个或多个组织内。例如，为了组织一个大型跨国公司的销售数据，您可以创建区域（如“EU”、“APAC”或“NA”）和财年（如“2021”或“2022”）的标签类别。然后用户可以在数据目录中筛选集合并按标签搜索。

为了生成全面的标签，请考虑数据的维度。常见的标签类别包括：

- 数据的类型或类别（例如，您可能希望将日志数据与参考表格区分开来标记）。
- 来源系统（数据集来源的外部系统）。
- 刷新计划（如每日、每周或如果是静态则不刷新）。
与应用案例相关的标签也可能有帮助，例如：

- 区域
- 部门
- 项目

## 管理标签

您可以在平台设置的标签部分管理标签和标签类别。选择新标签类别以创建新的标签类别。默认情况下，新的标签类别将被限制在您所属的组织内。

创建标签类别后，您可以在该类别中添加多个标签。如果希望扩展访问权限，还可以向标签类别添加其他组织。

要删除标签类别，请选择该类别然后删除类别。同样，要删除标签，请选择标签然后删除标签。您无法撤销删除操作，类别或标签将从所有资源中移除。

## 启用标签使用

只有被授予“在Compass中将标签应用于资源”工作流程角色的用户才能将标签应用于资源。如果您当前没有此工作流程的角色，请请求管理员通过控制面板中的组织权限选项卡指派。
