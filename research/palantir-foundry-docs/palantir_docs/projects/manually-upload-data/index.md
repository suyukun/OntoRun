# 手动上传数据

您可以从自己的来源手动上传数据以在您的项目中使用。所有数据应被批准用于系统的目的（例如，不包括个人数据）或概念数据。

首先在您的计算机上打开文件以验证其内容。检查标题行的数量以及是否有任何列包含数字或日期/时间数据。这些信息在后续步骤中会很有用。

在Foundry中，导航到您的主文件夹（导航侧边栏中的您的文件），或者如果您希望其他人可以访问您的数据集，则导航到共享文件夹。

在您的主文件夹中，您可以创建一个名为'data'的文件夹来组织您的文件。选择该文件夹以导航到其中。您现在应该在您的文件 > data或/<shared-folder-path> > data。

接下来，将文件拖放到您的文件夹中。Foundry会自动上传文件。上传完成后，您将在文件夹中看到一个与原文件同名的新原始数据集。

或者，您可以选择新建 > 上传文件。选择您的文件，或将其拖放到窗口中，然后选择下一步。在此时，您可以在导入之前自定义数据集的名称。准备好导入文件后，再次选择下一步。
