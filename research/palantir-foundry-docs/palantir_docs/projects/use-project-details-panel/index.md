# 使用项目详情面板

您可以通过选择项目页面右侧图标之一来打开资源详情面板。

## 文档

此部分提供基于Markdown的富文本编辑器，用于在项目或文件夹级别撰写文档，类似于工作区中所有文档部分。

## 活动

活动日志提供项目中所做更改的实时视图，仅在项目级别可见。对于搭建新项目或维护长期项目的团队，活动日志使理解近期活动和协作更加容易。请注意，活动日志仅存储上个月的活动。

## 可发现性

如有必要，您可以让其他组织中的人员发现您的项目及其描述。此功能正在开发中。

## 访问

资源面板中的访问选项卡允许您管理项目内的组和用户访问角色。

对于项目所有者，此面板提供接口以添加所需的权限标记、管理默认访问，并通过向其他用户和组授予角色来配置附加访问。

对于具有只读或编辑角色的用户，访问面板显示具有项目访问权限的当前组概览。

了解更多关于角色的信息。

## 项目使用情况

项目指标视图分解了项目内数据存储和计算使用情况。监控此视图将帮助您识别资源使用中的任何意外更改。

您可以通过选择相关选项来查看每周或每月指标。
