# 移动和共享资源

## 移动资源

Foundry 使在不同空间之间移动文件和其他资源变得简单。选择要移动的文件，然后选择移动图标。

在移动窗口中，为文件选择一个新位置，然后选择移动。

您需要特定的跨项目权限才能将文件从一个项目移到另一个项目。通常，只有资源所有者可以将文件移出项目。

## 共享和管理资源

当您创建一个新资源（例如数据集或**Contour**分析）时，可以通过将其保存到相关项目中来使资源对一组用户可用。

您还可以通过选择项目仪表盘右上角的**+ 新建**，直接从您的项目中创建资源。

Foundry 还允许您通过共享操作共享文件和其他资源，并查看权限。选择任何资源，然后选择共享图标以查看共享面板。

在共享面板中，您可以激活链接共享，以便任何拥有链接的人都可以访问资源。您还可以授予特定用户或群组访问权限。
