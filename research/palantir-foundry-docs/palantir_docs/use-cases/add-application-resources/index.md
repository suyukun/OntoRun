# 添加应用资源

一旦您创建一个新的应用案例，就可以开始向您的应用案例添加新的应用资源。添加应用可以让您直接从应用案例导航到 Foundry 应用，如 Workshop、Slate 和 Quiver。

- Workshop：一个无代码环境下为操作用户创建交互式和高质量应用的应用搭建器。
- Slate：一个在代码优先环境中通过拖放界面构建动态和响应式应用的应用搭建器。
- Quiver：一个用于可视化、分析和变换 Foundry 支持的 Object 和时间序列的分析和仪表盘套件。
## 创建新应用

在应用案例应用中有两种方式创建新应用：从概览页面或通过左侧边栏从应用页面创建。

### 从概览页面创建新应用

在您的应用案例概览页面中，选择+ 创建新应用，位于应用部分的右侧。

如果您的应用案例还没有任何已保存的应用，您也可以在部分中心选择+ 添加新应用。

### 从左侧边栏创建新应用

在左侧边栏选择应用以打开应用页面。然后，选择右上角的创建新应用。

在创建新应用模态框中，选择您想要搭建的应用，然后选择创建。

您也可以直接在应用页面上选择Workshop、Slate或Quiver卡片。

您将被引导到所选的 Foundry 工作区开始搭建您的应用。一旦您保存了新的应用资源，它将自动保存到您的应用案例中以及任何引用的 Ontology 资源。
