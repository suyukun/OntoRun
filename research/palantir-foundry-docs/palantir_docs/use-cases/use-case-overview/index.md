# 概述

应用案例应用程序处于Beta状态，可能无法在您的Foundry环境中使用。请联系您的Palantir代表以获取更多信息。

## 什么是应用案例？

应用案例应用程序允许构建者在单一操作界面内组织他们的工作。通过将文件系统视图与Ontology管理视图相结合，开发人员可以访问一个专注于他们负责工作的精心策划的视图。

应用案例应用程序可以使用任何项目作为其支持项目，但当它由工作流项目支持时效果最佳，作为推荐的管道项目结构的一部分。工作流项目用于存储基于Ontology资源的应用程序，如来自Workshop和Quiver的应用程序。

## 功能

应用案例应用程序的关键功能允许用户：

- 查看所有应用案例在您的组织中并在它们之间导航。
- 创建新的应用案例基于新的项目或现有的项目。
- 直接在界面中创建新应用程序在您的应用案例中。
- 在单一视图中查看所有应用程序在您的应用案例中。
- 查看添加到应用案例或由应用案例中的任何应用程序使用的Ontology资源。
- 快速导航在应用案例及其连接的应用程序之间。
## 用户

应用案例应用程序非常适合与Foundry Ontology合作以创建实际操作应用程序的工作流构建者。对于在不同项目之间移动以访问多种类型应用程序所需资源的构建者来说，它特别有用。

如果您是应用案例应用程序的新手，我们建议您探索以下文档以了解有关导航该空间和开始使用您的第一个应用案例的更多信息。

### 概述

在您的应用案例概述中，您可以找到与您创建的应用案例相关的Foundry资源的摘要。使用这些资源，您可以基于Ontology实体或应用程序输出创建工作流。

应用案例概述还提供了应用案例的快速元数据，包括描述、状态和所有者。

了解有关编辑元数据的更多信息。

### 应用程序

在应用程序部分，您可以找到您编辑的最后三个应用程序以及一个链接到列出所有连接应用程序的页面。

点击本节概述页面右上角的创建新应用程序以打开创建新应用程序模式。

了解有关添加应用程序到您的应用案例的更多信息。

您还可以点击侧边栏中的应用程序以打开应用程序页面查看连接应用程序的完整列表。

### Ontology组件

您的应用案例概述的Ontology部分包含两个子部分：对象类型和操作类型。

对象类型：应用案例视图中的对象类型要么由应用案例中的各种应用程序使用，要么手动添加到应用案例中。

操作类型：应用案例视图中的操作类型要么由应用案例中的各种应用程序使用，要么手动添加到应用案例中。

选择侧边栏中的对象类型以打开应用案例中应用程序使用的所有对象类型或手动添加的对象类型列表。

点击侧边栏中的操作类型以查看应用案例中应用程序使用的操作类型或手动添加到应用案例中的操作类型列表。

### 支持数据

从侧边栏选择支持数据页面以查看按对象类型列出的完整数据源列表。对于每种对象类型，您可以查看输入数据源列表和数据输出数据集（如果存在）。

### 其他资源

选择左侧侧边栏上的其他资源以查看支持项目中存在的所有其他资源的列表。
