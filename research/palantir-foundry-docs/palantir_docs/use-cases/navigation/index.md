# 导航

应用案例应用程序包含各种导航功能和工具，使在 Foundry 资源之间的工作流程更加流畅。我们建议您在创建第一个应用案例之前，先熟悉应用案例应用程序中的各个页面和元素。

通过点击 Foundry 导航侧栏下的应用程序图标开始导航应用案例应用程序。如果那里没有看到应用案例应用程序，请选择查看全部以展开应用程序列表。

## 主页

应用案例应用程序的第一个视图是主页，在这里您可以查看和搜索所有应用案例，并创建新的应用案例。

### 搜索

使用屏幕右上角的搜索栏来搜索现有的应用案例、应用程序或 Ontology 资源。

### 您的应用案例

在此部分，您将找到最近的应用案例列表。应用案例标有激活、实验或弃用状态：

- 激活:在您的 Foundry 实例中发布和运行。
- 实验:正在进行中，并未积极发布。
- 弃用:不再运行。
了解更多关于应用案例元数据。

选择一个应用案例以在应用案例概览页面中查看更多详细信息。

## Foundry 应用程序之间的导航

在管理资源时使用应用案例应用程序的便利之一是能够在您的应用案例和其他 Foundry 应用程序之间来回导航。这在您希望专注于特定应用案例但需要更新应用程序或编辑 Ontology 组件时特别有用。

### Ontology 管理器

应用案例应用程序允许您通过点击对象类型页面右上角的在 Ontology 管理器中查看和编辑，直接跳转到 Ontology 管理器中的对象类型定义页面。

要返回您的应用案例，请点击 Ontology 页面左上角的返回 [应用案例名称]。

了解更多关于Ontology及如何编辑对象类型。

### 在应用案例应用程序和项目视图之间导航

每个应用案例都有一个支持项目，用于存储应用案例中使用的应用程序和其他资源。您可以随时在项目视图和应用案例应用程序视图之间切换。

要从应用案例视图切换到项目视图，请从左侧菜单底部选择切换到项目视图。

要切换回应用案例视图，请在项目视图底部选择切换到应用案例视图。
