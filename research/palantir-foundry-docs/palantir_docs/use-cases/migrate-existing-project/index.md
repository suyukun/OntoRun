# 迁移现有项目

除了创建一个新的应用案例项目外，应用案例应用还允许您将现有的Foundry项目迁移为应用案例支持项目。

按照以下步骤将现有项目迁移为应用案例。

- 首先，导航到您想要迁移为应用案例的Foundry项目。从Foundry导航侧边栏中，选择项目和文件 > 项目以查看可用的项目。找到包含应用案例所需资源的项目，并打开文件夹。
