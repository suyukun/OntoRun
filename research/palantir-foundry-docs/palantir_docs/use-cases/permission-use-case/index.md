# 应用案例的权限

应用案例权限仅管理应用案例元数据的权限。

## 元数据

应用案例元数据的权限通过角色面板进行管理。在应用案例概览页面中，选择左侧边栏或概览页面右上角的**...选项，然后选择管理权限**。

您可以使用角色面板来添加或移除应用案例中的用户或组，并指派他们为应用案例所有者或应用案例编辑者角色。

应用案例所有者：具有应用案例所有者权限的用户可以管理应用案例权限并编辑应用案例元数据。

应用案例编辑者：具有应用案例编辑者权限的用户只能编辑应用案例元数据。

默认情况下，应用案例元数据对组织中的所有人可见，即使用户无法查看或编辑应用案例资源。

## 资源

应用案例中包含的资源的权限由资源本身或支持应用案例的项目的权限进行管理。了解更多关于管理项目和Ontology资源权限的信息。
