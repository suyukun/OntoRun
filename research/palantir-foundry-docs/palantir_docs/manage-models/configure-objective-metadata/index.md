# 配置目标元数据

当一个模型提交到建模目标时，关于该模型和版本的某些元数据会默认被收集。此外，您可以定义附加的特定上下文元数据，以附加到每个提交的模型。

不同的团队有不同的任务或所需的信息，他们希望跟踪。例如，您可能希望监控合规代码、模型供应商ID或在任务跟踪器（如Jira）中的票号。自定义元数据使您能够跟踪任何与模型相关的信息。

设置页面上的显示元数据选项卡提供了更改每个目标默认收集的元数据显示选项的功能。但是，该选项卡中所有的元数据，无论是否被选中，都会显示在每个模型提交的模型详情部分。

自定义模型元数据选项卡提供了一个界面，用于配置额外的自定义元数据字段。

支持多种元数据类型。

有一个JSON编辑器选项，可以轻松地在目标之间复制/粘贴元数据。

在目标中添加自定义元数据后，当有人提交模型时，自定义元数据字段将可供提交者输入。
