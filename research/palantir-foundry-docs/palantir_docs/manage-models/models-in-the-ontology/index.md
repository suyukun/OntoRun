# Ontology中的模型

在搭建操作性工作流时，将模型推理运行在Ontology Object的上下文中通常是有用的，可以将Object属性绑定到模型输入，并通过Ontology的视角解释结果。例如，您可能希望定义一个由模型支持的操作，或将Workshop中的UI元素直接连接到模型输出。这可以通过Object上的函数实现，能够调用到建模目标的实时部署。有关代码编写体验的详细信息，请查看我们的模型上的函数文档。
