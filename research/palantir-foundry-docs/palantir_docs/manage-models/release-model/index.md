# 发布模型

在建模目标中，有两种类型的发布。

生产发布代表当前最好的模型，并将在其建模目标中为所有生产部署提供支持。

预发布是一个被预备成为生产发布的版本；预发布用于所有预发布部署。预发布部署可用于在模型生产化之前测试模型的下游操作用途。测试完成后，目标所有者可以将预发布标记为生产发布。

一旦模型提交被发布，就不能再存档。

## 创建新的预发布

要创建新的发布，请导航到建模目标主页，滚动到发布部分，选择要发布的模型，然后点击发布到预发布。

或者，导航到模型提交页面并点击页面右上角的创建新发布。

给模型一个发布编号和发布说明，然后点击创建发布。

## 创建新的生产发布

如果预发布符合组织的测试标准，可以通过点击模型提交页面或建模目标主页的发布部分中的标记为生产将预发布提升为生产发布。

## 发布历史

每个发布都会覆盖该环境的上一个发布，该环境中的所有部署将自动升级以使用新发布的模型。要查看发布历史、升级时间和发布元数据，请从建模目标主页点击发布并查看完整的发布历史。
