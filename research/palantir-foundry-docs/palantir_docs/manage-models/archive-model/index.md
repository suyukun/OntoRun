# 在一个目标中存档模型

随着建模目标的成熟并积累了许多模型提交，将旧的或被拒绝的模型提交进行存档可以使目标更易于处理和理解。

存档模型提交具有几个影响：

- 无法从该模型创建发布。
- 将模型提交移入存档表，可通过点击模型视图右上角的查看存档链接访问。
Foundry 提供模型存档而不是硬删除，因为目标可以作为之前已部署并用于运营决策的模型的重要记录系统。

要存档模型提交，请导航至模型提交的单独页面，点击右上角的操作按钮，选择存档。

已标记为发布的模型无法存档。

在存档模型提交后，不要忘记调整或移除任何已配置的指标管理管道的搭建计划。
