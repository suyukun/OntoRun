# 提交模型到目标

有两种主要方式可以将模型提交到建模目标：通过用户界面或自动提交。

## 通过用户界面提交

要将模型提交到新的建模目标，请从目标主页中选择蓝色的提交模型按钮：

或者，从现有的建模目标中，在模型视图的右上角点击提交模型。

对于大多数模型，包括模型资产，请选择如图所示的模型，然后导航并选择相关的模型资源。

对于TypeScript 函数模型，请选择TypeScript 函数，然后选择您希望提交的函数名称和版本。

最后，如果适用，请填写此目标的任何必需元数据并选择提交。

## 自动提交

在代码库中训练的数据集支持的模型可以配置为自动提交新事务到建模目标。每当生成数据集支持的模型的变换重新运行时（例如，按计划或接收到新的训练数据时），新模型版本将被提交。这不会自动发布或部署新的提交。
