# 模型目标设置

模型目标有许多可用的配置选项，下面将进行描述。您可以通过点击界面右上角的模型目标设置从模型目标主页导航到模型目标设置页面。

## 检查

目标检查是一种确保模型在投入运行前通过预定义质量检查的方法。目标检查的详细信息可在如何为所有提交设置检查的文档中找到。

## 部署

部署设置页面定义了Python模型提交的模型提交部署配置文件要求，以便它们可以在批量或实时部署中运行。

## 模型元数据

提交到模型目标的模型可以在模型目标内具有特定的模型提交元数据。可以为某个目标配置这些元数据，以确保跟踪模型的相关信息。有关完整的配置详情，请参阅如何配置目标元数据的文档。

## 外观

通过外观设置，您可以配置单个模型目标是在浅色模式还是深色模式下显示。

## 高级

高级设置页面具有非标准的配置选项。通常，不应调整模型目标的高级设置。这些设置的提供是为了与旧功能保持向后兼容性。

### 评估设置

评估仪表盘有两个高级配置选项：仅显示由评估配置生成的指标和在评估仪表盘中显示固定的选项卡。

#### 仅显示由评估配置生成的指标

当模型目标设置为仅显示由评估配置生成的指标时，那么只有通过评估配置创建的指标才会显示在评估仪表盘上。我们建议启用此设置，以确保您的模型目标有一个标准的评估过程。如果不启用此设置，模型目标将无法知道显示的模型指标是否是最新的。

通过旧版管道管理配置的指标管道将不会显示，除非关闭仅显示由评估配置生成的指标。

在某些情况下，例如对于在评估配置发布之前配置的模型目标或具有代码中定义的指标的非生产模型目标，可能更希望显示来自模型目标评估配置之外的指标，可以通过此设置启用。

#### 在评估仪表盘中显示固定的选项卡

评估仪表盘上的模型目标可以选择配置为在评估仪表盘上显示自定义指标视图以及子集选项卡。

### 旧版管道管理

旧版管道管理是一项已弃用的功能。我们建议使用评估配置来配置推理和指标管道。强烈建议从旧版管道管理迁移到评估配置。

### 推理和指标数据集命名

旧版指标管道管理生成的数据集可能会在多个模型目标在同一输出文件夹中创建推理和指标数据集时产生命名冲突，导致意外行为。在更新的评估仪表盘和配置中已解决此问题。

为了保持向后兼容性，可以使用旧版推理和指标数据集命名方案。

#### 更新的命名约定：

- 推理数据集：inference_<Model Submission Name>_<Evaluation Dataset Name>-<Generated Hash>
- 指标数据集：metrics_<Model Submission Name>_<Evaluation Dataset Name>_<Evaluation Library Name>-<Generated Hash>
#### 旧版命名约定：

- 推理数据集：<Model Submission Name> inference
- 指标数据集：<Model Submission Name> metrics
