# 创建建模目标

建模目标应用程序是一个直观的工作空间，供团队在建模生命周期中管理模型。创建建模目标通过将模型、元数据和数据源与模型的审核、发布和部署结合在一起，简化建模项目。

通过在Foundry侧边栏中选择建模目标应用程序并点击新建目标来创建建模目标。

建模目标创建后，您可以选择一个位置来保存目标。我们建议将建模目标保存在一个集中位置，以便所有相关的贡献者、利益相关者和消费者都能访问该项目。

## 配置建模目标

建模目标可以通过多种方式进行编辑和配置。本节提供了关于建模目标可用配置选项的更多信息。

### 编辑描述

创建建模目标后，您可以通过点击编辑描述按钮添加描述。描述字段是Markdown ↗-兼容的；我们建议将此空间用作目标及其目标的README。

### 编辑目标元数据

可以通过以下几种选项编辑目标元数据，包括：

- 建模目标检查是一种确保模型在投入使用前通过预定义质量检查的方法。
- 模型提交元数据使建模目标拥有者能够确保所有提交到该目标的模型具有所需的元数据。
- 模型评估选项允许配置建模目标，以自动生成和搭建推理和指标管道，以便对所有模型提交进行系统化的测试和评估计划。
