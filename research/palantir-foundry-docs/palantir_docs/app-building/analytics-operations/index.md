# 将分析连接到操作

尽管Foundry专注于启用将数据捕获回系统的操作工作流，但利用Foundry的分析能力完成的工作结果也是关键的一部分。此页面介绍了如何使用分析工具以一种有助于决策的连贯方式为最终用户提供价值。

## 仪表盘

通常，在Ontology中对数据进行开放式探索的结果可能会产生对您组织中的其他人有用的有趣见解。起始于一组对象，深入到一个子集，并使用图表或链接对象探索属性，可能产生一种可重复的工作流，可以以有价值的方式与平台的其他能力相结合。

Quiver是用于在Foundry中对对象数据进行开放式分析的应用程序。Quiver仪表盘使您能够创建参数化的、精心策划的视图，最终用户可以用来以结构化方式探索数据。一旦您发布了一个仪表盘，您可以通过几种不同的方式在操作应用程序中使用它：

- 可以将Quiver仪表盘嵌入到Workshop应用程序中，允许您灵活地在结构化工作流中向用户显示仪表盘。
- Quiver仪表盘可以嵌入到Carbon，以便用户可以在其工作区中以选项卡的形式访问模板。
利用此功能，探索性分析可以快速从临时仪表盘或见解过渡为操作工作流的核心部分。

## 模型

Foundry的机器学习能力提供了一整套用于模型开发、集成、评估和部署的工具。一旦模型根据组织标准得到验证，就可以轻松地部署给最终用户。

Workshop对场景的支持，使得可以直接将机器学习部署给最终用户，而无需任何自定义开发或广泛的配置。用户可以与他们熟悉的概念进行交互，同时以易于理解的形式（如预测或估计）查看模型支持的结果。

有关将机器学习与组织成果联系的更多详细信息，请参阅Ontology中的模型。
