# 在应用程序门户中管理应用程序

## 概述

应用程序门户是一个用于发现和访问 Foundry 中所有应用程序的工具。这包括（1）核心 Foundry 平台应用程序和（2）管理员提升到应用程序门户的受信任的自定义应用程序。

### 导航到应用程序门户

您可以通过选择左侧边栏中的应用程序门户图标打开应用程序门户。您将能够查看在Workshop、Slate或Carbon中搭建的任何应用程序以及您已提升的应用程序。您还可以快速访问所有 Foundry 平台应用程序。

您可以将喜爱的应用程序“固定”到左侧边栏以便于访问。在应用程序门户中或编辑应用程序时，选择应用程序名称旁边的星形图标。一旦固定，一个名为已提升应用程序的部分将出现在 Foundry 侧边栏中，列出您喜爱的已提升应用程序。

应用程序门户的权限基于文件系统权限。如果您具有发现者角色，您将被提示请求访问。

## 应用程序门户模式

应用程序门户有两种参与模式：

- 基础，开箱即用：一个发现和了解所有 Foundry 平台应用程序的工具。不需要管理员工作。即使没有任何提升的自定义应用程序，应用程序门户也是左侧边栏中的一个重要工具。
- 高级，基于管理：由管理员、Palantir 代表或客户治理团队将所有受信任的自定义应用程序提升到应用程序门户。
每个多租户堆栈的堆栈或租户都有一个应用程序门户。用户可以查看的已提升应用程序仅限于属于其组织的空间。如果您有权访问共享空间，您还将看到该空间中的已提升应用程序。

## 应用程序门户中的已提升应用程序

已提升的应用程序是由管理员标记为受信任且准备好投入生产的应用程序。每个提升的应用程序都有以下必需的元数据，将显示在应用程序门户和左侧边栏中：

- 名称：这可以与资源名称不同
- 图标
- 描述（非必填）
- 应用程序所有者
- 缩略图
- 集合和标签：您可以使用这些来将已提升的应用程序分类到不同部分，并在应用程序门户中应用筛选。集合是必需的，而标签是非必填的。
已提升的应用程序会获得紫色的信任内容标记，类似于数据目录中的项目。

### 提升应用程序到应用程序门户的权限

管理员可以将 Workshop 模块、Slate 应用程序、Carbon 工作区或外部网页链接提升到应用程序门户。提升应用程序到应用程序门户的权限在控制面板中授予。您必须拥有“组织管理员”或“用户体验管理员”角色。此外，您还必须是应用程序的编辑者或所有者才能提升它。

已提升的应用程序会出现在应用程序门户中，供至少具有发现者角色的用户及其空间访问。

### 如何提升应用程序到应用程序门户

应用程序提升用户界面既可以在应用程序门户中使用，也可以在 Workshop 和 Slate 的编辑模式中使用（请参见下面的示例）。

取消提升已提升的应用程序也是通过提升用户界面完成的，只需选择左下角的取消提升按钮。

您可以更改提升引用的资源，以受控方式发布新应用程序。

## 在应用程序门户中进行分类

您可以使用集合和标签在应用程序门户中对应用程序进行分类，并应用筛选以仅查看某些应用程序。

创建集合和标签或将其添加到已提升应用程序的权限与提升到应用程序门户的权限相同，基于控制面板中“组织管理员”和“用户体验管理员”的角色。

### 集合

集合显示在左侧边栏中，作为应用程序门户中部分的标题。它们被用作应用程序门户中的顶级类别，以优化您的体验。集合在数据目录中创建和管理。创建集合后，您可以从数据目录和文件系统中将已提升的应用程序添加到其中。

只有与已提升应用程序相关联的集合才会在应用程序门户中显示，并且仅在您有权查看/发现这些应用程序时。如果一个集合没有与任何已提升应用程序相关联，或者您无权访问集合中的任何应用程序，它将不会显示。

### 标签

标签显示为已提升应用程序卡片上的标签，并可以从应用程序门户右上角进行筛选。您可以从平台设置的标签部分创建和管理标签。创建后，可以在提升用户界面以及文件系统中将其添加到已提升应用程序中。

只有与已提升应用程序相关联的标签会在应用程序门户中作为筛选显示，并且仅当用户有权查看/发现这些应用程序时。如果一个标签没有添加到任何已提升应用程序中，或者用户无权访问任何带有该标签的应用程序，它将不会显示。
