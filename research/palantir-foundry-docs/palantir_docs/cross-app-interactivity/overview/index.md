# 概述

跨应用交互目前仅适用于同时注册了Foundry和Gotham的客户。未来将会更广泛地提供。

跨应用交互是指在Palantir平台上跨不同应用共享数据的能力。平台中的数据可以通过特定的交互点共享，例如通过拖放操作，或者通过配对应用以实时共享状态。实现跨应用交互的应用创建了一个生态系统，使用户能够无缝地搭建跨越Gotham和Foundry多个应用的工作流。这个生态系统使用户能够以新颖的方式连接应用，因为应用中的每一个交互点都创建了与其他每一个具有交互点的应用的潜在连接。

例如，拖放功能可以让用户将数据从Gaia拖入Workshop应用，同时通过数据丰富确保数据兼容性。

跨应用交互也作为第三方开发者扩展现有功能的插件点，通过在应用之间共享上下文。随着工作流的变化和业务逻辑的演变，跨应用交互解锁了使用Palantir平台创造价值的新方式和多样方式。

## 支持

目前，所有Gotham应用和许多Foundry应用都实现了某种形式的跨应用交互。在Workshop和Slate中搭建的应用，或者在OSDK的协助下，也可以实现跨应用交互。
