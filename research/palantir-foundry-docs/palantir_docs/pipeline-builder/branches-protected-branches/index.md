# 分支保护

当有多个作者对同一Pipeline Builder实例进行贡献，或当该管道支持关键数据资产时，可以保护您的分支，以实现更高水平的治理和防范无意的更改。一个受保护的分支只能通过拉取请求进行修改，并且必须满足一组预定义的要求。

## 如何保护分支

导航到左上角的设置下拉菜单。选择管理分支。

选择分支保护选项卡。在此选项卡中，启用需要提案...以保护主分支和在下面文本框中指定的任何其他分支。完成后选择保存。

所有受保护的分支要求用户在单独的分支上更改，然后这些更改才能合并到受保护的分支中。目前，Pipeline Builder中的所有受保护分支共享相同的审批规则。
