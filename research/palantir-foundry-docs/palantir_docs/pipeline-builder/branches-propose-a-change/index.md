# 提出更改

一旦您创建一个分支以在工作流中协作，您可以进行编辑并向主分支提出更改。

要提出更改，请点击保存以保存您的编辑，然后在顶部工具栏中选择提出。

在提案视图中，为您的提案命名，并包括任何相关细节，以向审批者解释您的提案。在下面的示例中，我们提出更改以添加一个重命名列变换，以清理Facility 数据集中的原始数据。

选择创建提案以向主分支审批者发起请求。
