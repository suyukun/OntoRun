# 变换数据

在将数据集添加到您的工作区后，您可以在Pipeline Builder中开始变换和构建您的数据。

## 选择数据集

要对数据集应用变换，请在工作区中选择一个数据集节点，然后单击变换。

## 搜索变换

在变换页面中，通过名称搜索变换类型或从可用变换列表中浏览。如果您使用的是结构化（表格型）数据集，此字段将显示表格变换的全面列表。

对于像JSON文件这样的半结构化数据集，搜索字段包括文件变换，允许您将数据集解析成表格格式。

了解更多关于数据集的信息。

## 配置变换

在变换配置面板中填写所需信息，包括列、表达式或值。在下面的示例中，我们选择了重命名列变换，选择了要重命名的列，并输入了列的新名称值。

## 应用变换

在完成变换表单后，点击应用将变换添加到您的工作流程中。您将在图形中看到变换节点与原始数据集连接。我们将新的变换命名为清理设施数据，它是原始设施数据集的直接输出。

您可以通过点击变换节点并选择编辑来重命名或编辑变换。
