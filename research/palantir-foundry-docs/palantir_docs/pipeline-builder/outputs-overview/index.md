# 概述

管道输出是Pipeline Builder中管道的最终结果；输出可以是数据集或Ontology组件，如对象类型、对象链接或时间序列。

创建Ontology输出目前是Pipeline Builder中的实验性功能。您的Pipeline Builder版本可能不包括此功能。有关更多信息，请联系您的Palantir代表。

输出帮助您描述管道，从添加数据到创建变换逻辑。输出在您部署第一个管道搭建后创建，允许您在其他Foundry应用中扩展工作流和项目功能。

要添加输出，请在图形右侧的输出面板中选择添加管道输出。

这将带您进入输出类型选择屏幕。

查看以下部分以获取每种输出类型的详细信息。

## 数据集

数据集是Foundry中的基本元素。Pipeline Builder中的工作流从添加数据集开始，继续进行数据集上的变换，并可以以数据集作为输出结束。当您想要搭建一个生成清洁、变换数据的管道时，可以添加一个数据集作为输出。您可以将最终数据集用作Ontology管理器中Ontology搭建的基础。

了解更多关于添加数据集输出。

## 地理时间序列同步

地理时间序列可用于跟踪实体随时间的地理位置，由不同的观测组成。每个观测包含一个标识符、时间戳、位置和其他用户指定的属性。您可以将地理时间序列同步输出添加到您的Pipeline Builder管道中，以便在Foundry中生成批量或流式地理时间数据，使其在下游应用程序（如地图应用程序）中可用。Foundry中的地理时间观测在Pipeline Builder中被写入。

了解更多关于在Pipeline Builder中添加地理时间序列同步。

为了在Pipeline Builder中使用地理时间序列同步输出，您必须为您的注册启用地理时间序列。有关启用此功能的任何进一步问题，请联系您的Palantir代表。

## Ontology输出

将Ontology元素作为输出添加到您的管道中，以引导您的工作流从原始数据集到定义新对象类型元素的清理和结构化数据。在Pipeline Builder中，您可以在一个工作流界面中添加和编辑对象类型、链接类型和时间序列，而无需导航回Ontology管理器。

了解更多关于添加Ontology输出。

### 对象类型

对象类型是现实世界实体或事件的模式定义。将对象类型输出添加到您的工作流中，以帮助指导数据变换为定义的元素，这些元素可以用于在Foundry中搭建应用程序，包括Workshop模块或Slate应用程序。

### 对象链接

链接类型是两个对象类型之间关系的模式定义。链接指的是两个对象之间这种关系的单个实例。如果您在管道中添加两个对象类型输出，可以创建一个链接来定义它们的关系并添加到您的全局Ontology中。使用对象链接在Workshop和Slate中搭建强大的应用程序。

### 时间序列同步

时间序列数据是任何由一个或多个时间戳和值对组成的数据集；这些对测量一个随时间变化的量。这可以包括每年销售量的测量、每天总航班数、每小时的生产输出或亚秒分辨率的高频温度读数。将时间序列同步输出添加到您的管道中，以索引支持时间序列属性的数据。
