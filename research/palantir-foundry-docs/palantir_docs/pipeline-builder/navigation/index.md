# 导航

本页面描述了Pipeline Builder的界面、导航控件和可用工具。

用户可以从顶部工具栏访问Pipeline Builder中的三种不同视图：编辑、提案和历史记录。

## 编辑

编辑视图是您可以开始搭建管道工作流的地方。它分为四个部分：顶部工具栏、详细信息侧栏、图表和预览窗格。

### 顶部工具栏

顶部工具栏允许您管理视图、监控搭建检查状态和编辑搭建设置。

- 撤销/重做：撤销或重做工作流中的最近操作。
- 分支下拉菜单：查看您当前工作的分支名称，或切换到其他分支。您还可以选择创建新分支。了解更多关于分支的信息。
- 保存：保存您的进度。当您的更改被保存到分支时，会出现已填充的已保存状态。
对管道分支的更改不会自动保存。要正确保存对管道分支的更改，您必须在离开图表选项卡之前手动保存更改。

- 提议：一旦您的更改被保存，选择提议请求合并到主分支。从主分支的合并不支持。

### 预览面板

预览面板允许您查看从单个选定节点的样本数据集。选择图表左下方的图标以展开或收缩预览面板。

- 名称：显示选定节点的名称。您可以在此字段中编辑节点名称。
- 搜索：在数据中搜索列名。
您还可以通过右键点击数据集节点并点击打开来访问完整的数据集预览页面。

## 提案

在提案视图中，您可以查看此管道的任何未决、已合并或已关闭的提案。从下拉菜单中选择一个筛选以查看状态类别内的所有提案。

每个提案将显示创建日期和时间、创建它的用户以及一个表示未决、已合并或已关闭状态的图标。

## 历史记录

历史记录视图允许您查看管道工作流中任何分支的最近活动。从下拉菜单中选择一个分支以查看其历史记录。

点击操作以创建新分支、查看详细信息或查看从每个保存版本更改的内容。

### 创建分支

此选项允许您基于选定的分支开始一个新分支。

### 查看详细信息

查看详细信息选项打开图表的只读版本，显示保存活动时管道的状态。此选项是跟踪工作流随时间发展的有用方式，而无需冒将管道恢复到早期状态的风险。

### 查看更改

类似于查看详细信息选项，您可以查看更改以了解管道在给定时间的修改。在此视图中，图表显示分割视图以表示之前保存和应用更改之间的差异或_差异_。

### 查看提案

查看提案允许搭建者审查和编辑现有提案。
