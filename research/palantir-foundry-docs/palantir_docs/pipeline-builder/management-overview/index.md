# 管道管理

本页面概述了在Pipeline Builder中进行管道管理的功能和最佳实践。

## 在管道中重用逻辑

Pipeline Builder通过参数和自定义函数支持在管道中重用逻辑。参数是在管道的多个变换中可以使用的值。自定义函数是一系列变换，集中定义为单个变换。

## 大型管道管理

Pipeline Builder支持分组和优化功能，以帮助管理大型管道。

您可以在Pipeline Builder中创建文件夹和子文件夹来对节点进行分组。这使您能够组织节点，并通过切换子文件夹中节点的可见性来缩小管道的范围。

您可以在Pipeline Builder中使用节点颜色分组来折叠相同颜色的节点，并提高图形的可读性。

您可以通过显示和隐藏节点来专注于图形的某个子部分。您可以手动选择这些节点，或根据颜色分组来显示和隐藏它们。

Pipeline Builder中的任务分组允许您控制输出如何分配到任务中，并为每个任务计算配置文件。

在搭建管道时，您可以将多个输出之间共享的变换节点标记为检查点。这些中间结果将在下次搭建时仅计算一次，从而节省计算资源。

为了更快地预览，您可以在原型设计管道时添加输入采样，以对输入数据进行降采样。管道部署仍将在完整数据集上运行。
