# 创建计划

要在 Pipeline Builder 中为您的管道数据集创建搭建计划，首先在管道工作流中选择数据集节点。右键单击该节点并选择打开以打开完整的数据集预览窗口。

在数据集预览窗格中，单击计划选项卡并选择添加搭建计划。

在新计划窗格中，选择是在父资源更新时搭建数据集还是在特定时间搭建数据集。

- **当父资源更新时：**每当选定的父数据集更新时，将进行搭建。搜索数据集，或从下拉菜单中选择可用的父数据集。
**当父资源更新时：**每当选定的父数据集更新时，将进行搭建。搜索数据集，或从下拉菜单中选择可用的父数据集。

- **在特定时间：**安排搭建在定义的时间间隔发生。选择时间值、发生频率和时间详细信息。例如，您可以安排搭建按小时，每5小时，在每小时的第15分钟，或按月，每6个月，在第二个星期一，在凌晨1:30，在America/Los_Angeles时区。
**在特定时间：**安排搭建在定义的时间间隔发生。选择时间值、发生频率和时间详细信息。例如，您可以安排搭建按小时，每5小时，在每小时的第15分钟，或按月，每6个月，在第二个星期一，在凌晨1:30，在America/Los_Angeles时区。

要添加其他的计划详细信息，包括搭建范围参数、搭建失败操作和通知，单击高级。这将带您进入数据沿袭应用程序，您可以在其中为选定的数据集配置高级搭建计划功能。
