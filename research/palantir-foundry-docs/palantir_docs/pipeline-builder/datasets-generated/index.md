# 自动生成输入数据

在Pipeline Builder中创建手动输入的数据集时，您可以生成虚拟数据来填充您的数据集。

为此，请在您的手动输入数据集中，选择生成虚拟数据。

在左侧，选择您想要生成数据的列。然后，在自动填充字段中，选择该列应包含的数据类别。要查看虚拟数据的示例，请选择示例。

要指定您希望生成多少行，可以在选择您希望在数据集中拥有的行数字段中输入1到1000之间的数字。

一旦决定了所有您希望生成数据的列，选择位于右下角的生成。

使用生成将覆盖您手动输入表中任何先前存在的数据。

您还可以使用另一个数据集生成外键。这将把数据集与另一个数据集中的某一列连接起来。

其他可以在Pipeline Builder中自动填充的数据示例包括：

- 城市:生成一个随机城市名称。
- 公司:一个虚构的公司名称。
- 常量:始终产生相同的值。
- 国家代码:一个两字母的国家代码。
- 电子邮件:一个有效但虚拟的电子邮件地址。
- 名字:包含虚拟名字的字符串。
- 外键:将此数据集与另一个数据集中的某一列连接。
- 全名:名字和姓氏组合成一个字符串。
- 姓氏:一个虚拟姓氏。
- 列表:从预定义列表中加权随机选择一个值。
- 空值:始终生成空值。
- 之一:从加权生成器列表中随机选择。
- 街道地址:一个随机的街道地址。
- 模板:使用帮助函数从模板生成随机字符串。
- 美国州:来自美国的随机州名称。
- 美国州代码:来自美国的随机两字母州名称缩写。
- 美国邮政编码:位于提供的州的邮政编码。
- UUID:一个全局唯一标识符。
