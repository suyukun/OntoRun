# 参数

参数是可以在一个管道中的多个变换中使用的全局值。更新参数值可以同时修改多个变换。

## 创建和编辑参数

在参数视图中创建、编辑和删除参数，可以通过图顶部的参数按钮访问。创建新参数需要设置参数名称和参数类型并定义一个值。现有参数也可以在参数视图中编辑或删除。

编辑参数允许用户在多个变换中使用参数时同时修改多个变换；编辑参数逻辑将导致使用该参数的所有变换中的逻辑更改。

可以创建一个没有值的参数作为在管道工作时的占位符；当在变换中使用时，这种参数将导致变换出错，并且管道无法部署，直到添加一个值为止。

## 参数类型

- 常量值：常量值参数需要一个列类型和一个值。这些参数可以用作任何允许该值的设定列类型的变换中的输入值。
- 正则表达式：正则表达式参数需要一个正则表达式，并且可以用作启用了正则表达式的变换中的输入。
- 结构定位器：结构定位器参数是字符串，可以用来指向结构中的一个元素。
- 列：列参数是列占位符，可以用作变换中的列选择器中的输入。列参数可以通过其名称指向现有列，但其存在性将在使用该参数的每个变换中首先进行验证。
- 表达式：表达式类型参数是空白的Pipeline Builder表达式，可以用作表达式占位符。
