# 数据更新和编辑历史

您可以在右上角的源窗格中查看电子表格中使用的数据源。

有两种方法可以使电子表格与动态数据保持同步：

- 自动更新：启用后，任何时候数据源（即电子表格中使用的Foundry数据集）更新时，使用该数据源的单元格将自动更新。
- 手动：如果未启用自动更新，当数据源更新时，您将在电子表格顶部看到通知栏，您可以选择更新单元格以获取最新数据或保持电子表格不变。
当您与其他用户共享Fusion表时，请确保他们也有源窗格中列出数据集的读取权限。缺乏访问引用数据集权限的用户将无法打开文档。

您可以在历史记录窗格中查看自电子表格创建以来手动和自动保存的快照历史记录。点击其中一个快照将允许您比较更改并在需要时恢复。

Fusion会定期为您的电子表格创建备份快照，但您也可以手动创建快照。
