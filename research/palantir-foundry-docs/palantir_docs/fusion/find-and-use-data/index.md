# 查找和使用数据

## 搜索

查找和使用数据搜索面板使得将数据和Object导入Fusion变得简单。可以通过选择Fusion表格右上角的查找和使用数据框访问搜索面板。

您可以通过在搜索输入区域直接输入值（"搜索一个单元格或关键字"）或者点击"目标"图标然后选择单元格值来进行搜索。

您还可以选择特定的Object类型或数据集进行搜索。如果所选数据集未被索引，系统将提示您对其进行索引。

## 导入数据

找到您想要导入的数据后，选择使用数据并打开导入数据面板，将其导入到表格中。请注意，您最多可以导入2,000行。

导入数据面板将把搜索结果中使用的任何筛选作为导入查询的筛选。例如，如果您搜索Red并为符合color属性或列的一组汽车选择使用数据，您的初始查询将从color == red的汽车开始。

从这里，您可以添加更多筛选，最终将结果数据以数组、下拉或多选下拉的形式添加到您的表格中。

### 数据集数组

以数据集数组导入会在表格中添加一个lookup_array函数。数据集数组不包括来自源的列名。有关如何使用查找的更多信息，请参阅查找数据集。

要展开来自lookup的结果数组，可以Shift+拖动该单元格到单个单元格中。

### 数据集下拉和数据集多选下拉

将数据集下拉添加到表格中，会在每个导入的列中放置一个单选下拉。数据集多选下拉则允许选择多个值。然后，您可以使用此下拉来驱动表格的其他部分。

可以对数据集下拉单元格应用格式，包括合并或调整单元格大小、设置字体大小和设置背景填充。

## 导入Object

与数据集类似，您可以使用筛选来优化导入到表格中的Object列表。筛选可以是值或单元格引用。单元格引用将根据单元格的值进行筛选，使您可以创建一个动态表格，其中的Object集将根据其他值或选择进行更新。在此示例中，基础数据来自美国人口普查局 ↗。

在下面的示例中，CityObject类型有一个筛选，State等于单元格B2的值。目前，单元格值为Arizona，筛选到State为Arizona的城市。可以更改单元格值，这将更新筛选。

应用筛选后，可以选择重新加载以查看结果对象集。您可以将此对象集导入到表格中作为对象下拉或对象表格。默认情况下，最多可将200个Object导入到一个对象下拉或对象表格中。

### 对象下拉

将对象作为下拉添加到表格中，将在一个单元格中放置一个下拉。您可以使用此下拉来驱动表格的其他部分。

对象下拉单元格将显示当前选定的对象及其图标。然后，您可以选择该单元格以打开下拉并选择另一个对象。

可以对对象下拉单元格应用格式，包括合并或调整单元格大小、设置字体大小和设置背景填充。

### 对象表格

对象表格可以用于展示或在表格的其他地方使用。

对象下拉和对象表格可以结合创建一个简单的仪表盘：为此，可以使用对象下拉选择对象，这些对象反过来可用作对象表格中的筛选。

一个Fusion表格不能同时包含Object和以导出数据集同步。如果您有Object，则无法添加新的数据集同步，反之亦然。
