# 格式化单元格

最常用的格式选项（样式、数字/货币格式、冻结窗格等）在电子表格上方的格式栏中可用。

条件格式在与来自lookup函数的动态数据结合使用时尤其有用，以提供变化的视图。

您还可以使用color函数根据自定义逻辑为单元格添加样式。同样，tooltip函数可以用于当用户悬停在单元格上时显示自定义内容的工具提示。

可以通过单击文档选项卡下的数字设置按钮来更改小数和千位分隔符。
