# 概述

Fusion支持标准电子表格公式（单元格引用、加法等）以及函数。Fusion的函数库结合了Contour表达式语言DSL和Fusion特定的电子表格函数。有关函数列表，请访问函数库。

在任意单元格中输入=以使用公式。在公式栏中输入=a将为您提供建议列表。
