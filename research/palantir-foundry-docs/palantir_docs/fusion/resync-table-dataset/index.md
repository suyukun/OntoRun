# 将表重新同步到数据集

数据集可以同步到Lime（ElasticSearch），以便使用像Fusion这样的应用程序执行全文搜索、聚合和编辑。有时需要重新同步数据集，例如当底层的Elasticsearch集群需要迁移时。如果现有索引在数据规模上资源不足，也可能需要重新同步。

通常，重新同步要么按计划进行，要么由平台自动触发。有时，自动触发的重新同步可能会失败，在这种情况下需要手动触发并解决任何出错。

## 常见问题解答

- 如果重新同步失败，我应该怎么办？查询任务详情以调查重建索引任务失败的原因。任务详情页面应解释失败原因并建议解决步骤。
