# 概述

Fusion电子表格看起来和行为类似于其他电子表格应用程序，这意味着您可以在任何地方输入任何内容，使用单元格引用和函数等。然而，请注意，Fusion使用单引号（'）来表示字符串，而不是双引号（"）。

多个用户可以同时编辑一个电子表格，并看到彼此的光标及各自的用户名。单元格中的更改只有在提交后（例如按下Enter键提交）才会对其他用户可见。

可以通过双击工作表名称来重命名工作表。单元格引用按预期工作（例如=A1,=A1:A3,=Sheet2!A1:A3），并且您可以在编辑公式栏时使用鼠标。

您可以拖动公式栏来扩展它。

函数库是Contour表达式语言DSL和Fusion特定电子表格函数的组合。函数列表请访问函数库。

在公式栏中输入=a会为您提供一个建议列表。

在Fusion中，最常见的单元格类型是：

- 字符串（例如Fusion或='Fusion'）
- 数字（例如12或=12）
- 日期（例如2013-02-18或=date(2013, 2, 18)）
- 时间戳（例如2013-02-18 00:00:00）
- 布尔值（例如=true）
- 数组（例如=array(1, 2)）
- 空（例如=null）
在电子表格中，区分小数和其他类型单元格的一个好方法是注意小数将在单元格中始终右对齐。

类似于其他电子表格应用程序，您可以通过复制/粘贴快速填充其他单元格的内容。或者，您可以拖动单元格的填充柄。双击单元格（或单元格区域）的填充柄将自动填充同一列中的任何空单元格，只有在相邻单元格也为空时才会停止。

您还可以在Fusion中使用最常见的电子表格键盘快捷键。可以通过工具栏的文档标签上的键盘快捷键按钮访问快捷键列表。
