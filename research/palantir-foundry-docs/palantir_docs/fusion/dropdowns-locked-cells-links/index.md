# 下拉菜单、已锁定单元格和链接

Fusion电子表格中的任何单元格都可以使用dropdown和multidropdown函数转换为下拉菜单（例如，=dropdown(array(1,2,3))）。dropdown函数还有其他非必填参数，可以在函数库中找到，以自定义行为。

您可以锁定共享电子表格中的任意单元格，以防止意外编辑。一旦锁定，任何用户都需要移除锁定才能再次编辑单元格。

url函数允许您在电子表格的任何单元格中创建链接。您可以使用url_encode和query_params函数来帮助格式化复杂URL的字符串。
