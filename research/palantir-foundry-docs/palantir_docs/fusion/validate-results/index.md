# 验证结果

Fusion提供了一组验证公式。它们显示为按钮，点击后触发。如果验证失败，则会显示解释原因的错误信息。

验证函数最好在串行操作中使用，并结合使用toast操作来显示成功和出错消息。有关更多详细信息，请参阅操作文档。

此页面是可用验证公式的概述。有关公式和参数的完整列表，请参见函数库。

## 枚举

column_enum(...)验证检查列中的条目是否都在特定值列表内。这些列出的值可以手动输入到公式中（例如array('red', 'blue', 'green')）或通过引用输入（例如array_flatten(B3:B14)）

## 非空

column_not_null(...)验证检查列中是否没有空值。

## 数值

column_numeric(...)验证检查列中是否仅包含数值。

## 表头

table_headers(...)验证检查表中是否存在列的列表。

## 表键

table_key(...)验证检查对于列的列表，这些列的条目是否唯一。

例如，在表的name，age列上运行验证将检查name和age条目对是否唯一。一个只有两行的表，例如('David', 21), ('David', 24)将通过验证。一个具有像('David', 21), ('David', 21)这样的行的表将失败。以下是概念数据的截图示例。
