# 索引数据集

在您可以在Fusion中使用数据集之前，您必须确保它们已被索引到Lime中。最简单的方法是在Fusion中的数据选项卡菜单下，通过索引新数据集来完成。下面的截图使用了Foundry参考项目中的一个开源美国机场数据集。

在结果屏幕上，您可以选择多个数据集（和分支）进行索引。

点击设置菜单下的已索引数据集，可以查看Fusion中可用的数据集列表及其当前索引状态（最新、同步中、过时）。
