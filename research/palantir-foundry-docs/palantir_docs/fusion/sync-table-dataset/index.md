# 从Fusion同步数据到数据集

Fusion允许您基于电子表格创建数据集。您可以选择将整个表格同步到数据集，或者选择要同步的表格范围。成功将数据同步到Foundry中的数据集后，其他应用程序（如Contour）可以使用这些数据。

在一个Fusion表格中只能使用一种同步方式：表格同步或表格范围同步。使用两种方式会导致数据集同步重叠，这是不允许的。

## 将表格范围同步到数据集

要将表格的特定部分同步到数据集，首先选择您希望作为数据集提供的电子表格区域。然后，在数据菜单中选择同步到数据集。将会弹出一个窗口，您可以在其中创建一个表格区域，并在电子表格的同一文件夹中设置一个默认名称的同步。

您可以移动、更改名称或更改数据集的分支。您还可以选择修改导出列类型以匹配所需的数据类型。从同一菜单中更改列类型，或通过选择电子表格中的表格标签打开面板进行更改。

选择保存以应用更改。

对导出表格范围的任何未来更改将触发搭建，并在其关联的数据集中反映。例如，如果数据集在Contour中打开，您可以在修改电子表格后更新路径。

一旦Fusion中的数据同步到数据集，您还可以选择将其导出为CSV文件。

一旦将表格范围同步到数据集，对该表格范围的任何更改都将触发搭建，并在其关联的数据集中反映，只要您对关联数据集至少拥有编辑者权限。在编辑表格范围时，您可能会看到数据集上有若干已完成和中止的事务。

您还可以使用电子表格中表格区域列标题上的下拉菜单设置输出数据集的列类型。

## 将Fusion表格同步到数据集

如果需要将整个Fusion表格同步到数据集，可以设置表格同步，而不是表格范围同步。虽然您可以使用表格范围同步从一个Fusion表格中创建多个数据集，但表格同步将只为整个表格创建一个数据集。

要设置表格同步，导航到Fusion文档的底部并右键单击要同步到数据集的表格。选择同步表格到数据集。稍等片刻，您将能够编辑刚刚初始化的同步。

如果需要，您可以通过执行以下步骤更换支持数据集的Fusion表格：

- 使用所需数据创建一个新的Fusion表格。
- 导航到您想替换的Fusion表格，并在表格详情窗口中选择停止同步。
- 转到数据集并通过以下路径删除任务规范：详情标签 > 任务规范 > 编辑 > 删除。
- 导航到新创建的Fusion表格，创建一个要使用的表格，并将其同步到数据集的master分支。
