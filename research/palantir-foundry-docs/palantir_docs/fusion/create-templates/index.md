# 创建模板

任何Fusion电子表格都可以在工具栏的文档选项卡中转换为模板。

当一个Fusion文档被标记为模板时，尝试打开Fusion文档（例如，通过在Foundry中点击它或直接导航到文档的URL）将不会打开底层电子表格；相反，将创建电子表格的副本（用户将被提示选择位置）。

如果您想编辑主模板（而不是创建副本），请在Foundry中右键点击电子表格并选择操作>编辑模板Fusion表。

您还可以创建自定义链接到Fusion电子表格，以在表格中进行特定更改时创建副本。一个带有单元格值覆盖的URL示例是_/copy?Sheet1!A1=test_。
