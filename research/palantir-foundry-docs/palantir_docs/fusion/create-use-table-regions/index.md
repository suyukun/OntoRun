# 创建和使用表格区域

您可以在电子表格中的任何区域创建一个表格——表格区域将区域强制为严格的表格式，并允许您指派列标题，通过列名称（而不是单元格引用）引用列，按任意列排序行，等等。

当新行附加到表格区域时，它将扩大区域，必要时将下方的任何值向下推。

Fusion中的排序与您可能使用过的其他电子表格工具不同。在Fusion中执行排序不仅仅是呈现数据的排序视图，而是实际重新排列表中的行，使单元格按排序顺序排列。这意味着Fusion中的排序不能被“关闭”以返回到原始顺序；相反，您需要撤销排序才能再次查看原始顺序。
