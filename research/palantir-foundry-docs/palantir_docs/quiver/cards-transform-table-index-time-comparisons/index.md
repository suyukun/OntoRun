# 时间比较

返回到:变换索引

本节中的变换比较时间数据类型。这些比较变换对于通过时间列筛选变换表行非常有用。这些比较变换也可以在变换表之外单独使用。了解更多关于如何搜索和添加变换。

- 之前
- 在或之前
- 之后
- 在或之后
- 之间（包含）
- 在
- 不在
### 之前

如果输入时间戳在第二个时间戳之前，则返回True。

### 在或之前

如果输入时间戳在或在第二个时间戳之前，则返回True。

### 之后

如果输入时间戳在第二个时间戳之后，则返回True。

### 在或之后

如果输入时间戳在或在第二个时间戳之后，则返回True。

### 之间（包含）

如果输入时间戳在第二个和第三个时间戳之间（包含），则返回True。

### 在

如果输入时间戳在第二个时间戳，则返回True。

### 不在

如果输入时间戳不在第二个时间戳，则返回True。
