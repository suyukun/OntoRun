# 概述

在Quiver中，卡片是指分析中的任何内容，如可视化。Quiver卡片在画布上表示为框，或在图表上表示为节点。

每个Quiver卡片都有以下内容：

- 类型：大多数卡片都有一个输出类型，可以是值类型（例如：数字、字符串）、数据类型（例如：时间序列、对象集）或可视化类型（例如：分类图表、数据透视表）。某些可视化卡片没有输出类型，这意味着它们不能作为其他Quiver卡片的输入。
- 输入和输出：一个卡片可以将其他卡片作为输入，并生成新的卡片作为输出。输入和输出可以通过在图表上使用卡片上下游的链接来可视化，或者通过打开编辑器面板来查看。
- 配置选项：每个卡片根据其类型有不同的配置选项；这些配置选项可以通过编辑器侧面板访问。
## 卡片类型

Quiver支持多种不同的卡片类型，以满足您的分析和可视化需求。

- 对象和对象集：这些卡片包含直接来自Ontology的对象，或通过一组筛选、周边搜索（链接对象）或数学运算定义的对象。
- 时间序列图表：时间序列图表是时间序列绘图的容器。一个绘图是一个单一的时间序列线。您可以在同一个时间序列图表上有多个绘图，并且单一时间序列可以绘制在多个图表上。
- 可视化：这些卡片用于可视化对象集或时间序列中的数据。可视化类型包括，例如，分类图表、分组时间序列绘图、地图或热网格。
- 表格：表格卡片可以以表格格式显示或变换对象集数据。表格显示卡片包括列表和表格，表格变换卡片包括数据透视表和变换表。
- 变换：变换卡片在单一输入而不是表格中的每一行上应用变换表操作。这些卡片支持的输入和输出类型由变换名称旁的数据药丸指示。
- 指标卡片：一些卡片包含特定值类型（例如：数字、字符串、时间）的指标。这些指标可以来自各种输入，如对象值、对象集聚合、公式、变换表值、函数或输入参数。
- 物化卡片：使用Ontology中包含每个对象实例最新状态的索引数据，通过合并来自输入数据源和用户编辑的数据。输入对象集并对对象数据进行合并，派生新列、筛选或使用分类或Vega图表绘制数据。
- 按钮：Quiver卡片可以用于在分析中添加按钮，使最终用户能够采取操作并将内容写回Foundry；例如，一个按钮卡片可以用于启用用户创建一个对象。
- 文本卡片：这些卡片用于编写和显示文本。
