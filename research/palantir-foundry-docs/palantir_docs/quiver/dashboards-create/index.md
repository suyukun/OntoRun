# 创建仪表盘

## 起始

要创建仪表盘，请选择左侧工具栏上的仪表盘图标（如下所示）。这将打开仪表盘面板。

如果此分析中还没有仪表盘，请选择创建新仪表盘。这将创建一个新的、未发布的仪表盘。

## 重命名仪表盘

要重命名仪表盘，请点击顶部工具栏中的名称并输入新名称。当你离开名称输入框时，新名称将被保存。你将在左侧面板中看到新名称。

你也可以通过点击顶部的名称，从编辑面板重命名仪表盘。

要打开和关闭编辑器面板，请选择顶部工具栏中的设置按钮。

## 添加文档

要为仪表盘提供更多背景信息，你可以在编辑器面板的文档文本框中添加描述。

## 向仪表盘添加内容

### 使用拖放方式向仪表盘添加卡片

要向仪表盘添加内容，请点击左侧面板中的添加到仪表盘部分中的一个卡片，并将其拖动到仪表盘中。

当你将卡片拖动到仪表盘时，你会看到几个高亮的放置区域，指示你可以放置卡片的位置。

如果你的分析中已经有卡片，你可以选择将选中的卡片拖动到同一行的另一个卡片旁边。卡片会自动对齐并调整为相同的宽度和高度。然后你可以使用尺寸调节手柄调整行高。在同一行中最多可以并排添加三个卡片。

你可以使用卡片或单元格左上角的拖动手柄来改变它在仪表盘中的位置。

要删除卡片，请使用卡片右上角的“回收站”图标，如下所示。从仪表盘中删除后，卡片将出现在添加到仪表盘面板中，可以再次添加。请注意，从仪表盘中删除卡片不会删除分析中的卡片。

### 按名称或输出类型筛选卡片

在大型分析中，你可能会迅速得到大量需要搜索的卡片。为了更容易在仪表盘中找到你需要的内容，你可以按名称或卡片输出类型筛选内容。当你悬停在卡片上时，还会看到卡片的预览。

### 从分析模式向仪表盘添加内容

在搭建分析时，你可以直接向仪表盘添加卡片而无需打开仪表盘。要这样做，请点击卡片右上角的仪表盘图标。你可以选择添加到现有仪表盘或新建仪表盘。卡片将被添加到所选仪表盘的底部的新行中。

## 编辑设计并注释仪表盘

### 创建参数和指标单元格

一旦你向仪表盘添加了一个参数或指标卡片，你可以向同一个单元格添加更多相同类型的卡片。然后你可以同时重新定位它们。在仪表盘上这样做，将卡片放在单元格内的蓝色放置区域。
将多个参数或指标添加到同一个单元格的一个好处是，你可以并排添加的数量没有限制。在普通卡片上，你将被限制在同一行最多添加三个。

### 附加侧边栏

使用参数（或指标）单元格的一个常见模式是将它们附加到仪表盘的一侧，这样在滚动时它们始终可见。这对于突出显示关键指标（如 KPI）或创建用户可以轻松访问的参数侧边栏非常有用。尽管这些用例是最常见的，你可以将任何类型的卡片附加到仪表盘的侧面。

### 添加标签页

在仪表盘中你可以创建两级标签页：顶级标签页和卡片级标签页。

#### 顶级标签页

顶级标签页被添加到仪表盘的最顶部，允许你创建多个“页面”。要添加顶级标签页，请选择顶部工具栏中的添加标签页，如下所示。

选择标签页旁边的向下箭头以访问重命名、向右或向左移动或删除标签页的操作下拉菜单。你也可以通过双击标签页名称来重命名标签页。

#### 卡片级标签页

卡片级标签页允许用户在不同的图表之间切换。请注意，你不能在卡片级标签页中添加段落或文本。

要在卡片上添加标签页，请选择右上角的添加标签页图标，如下所示。

选择标签页旁边的向下箭头以访问重命名、向右或向左移动或删除标签页的操作下拉菜单。你也可以通过双击标签页名称来重命名标签页。

### 添加章节

章节从标题到下一个标题，或到仪表盘底部（如果没有其他标题）定义。要创建章节，请选择顶部工具栏中的添加章节。

章节可以使用左侧的拖动手柄重新定位。

章节是自动可折叠的。要折叠章节，请点击章节左侧的箭头，如下所示。

### 添加文本

你可以使用提供的富文本编辑器在仪表盘中添加文本。

要添加文本组件，请选择顶部工具栏中的添加文本。文本组件将被添加到仪表盘的最底部。

你可以通过点击行间的⁠— + ⁠—线，在仪表盘的特定位置添加文本，如下所示。

### 添加工具提示

在仪表盘的每个单元格上，你可以添加一个工具提示，最终用户将可见。点击右上角的(i)（信息）图标来添加工具提示。

### （高级）添加容器

容器不推荐用于标准仪表盘设计。然而，一些情况可能需要更复杂或定制的设计，这时容器会很有帮助。容器允许你在特定配置（如标签页或列表）内将多个卡片添加到单个单元格中。一旦在分析模式中创建，容器可以作为单个单元格添加到你的仪表盘中。

容器可以从分析中的显示菜单中添加。

将容器添加到分析中，然后从分析内容面板中将卡片拖入容器中。你可以使用右侧的卡片编辑器配置容器。

一旦容器在分析模式中配置完成，你可以像常规卡片一样将其添加到仪表盘中。要添加容器，请选择卡片右上角的添加到仪表盘按钮，或从添加到仪表盘部分将其拖动到仪表盘中。

## 选择仪表盘视图样式

要选择仪表盘视图样式，请使用顶部工具栏中的设置按钮打开仪表盘编辑器。

你可以选择三种视图样式：默认、紧凑和拉伸。

### 默认

默认仪表盘视图是一种报告样式视图。此视图设计为更多的空白空间以便于阅读，包括两侧和行之间的较大边距。此样式最适合独立的仪表盘使用。

### 紧凑

在紧凑仪表盘视图中，行被水平拉伸，两侧和行之间的边距被移除，行高保持不变。紧凑视图是嵌入其他应用程序时的一个不错选择，因为没有添加边距的仪表盘可能更适合嵌入。在下面的示例中，卡片中的标题空白（用红色标记）被压缩，使得第2部分上移到视野中。

### 拉伸

在拉伸仪表盘视图中，行在水平和垂直方向上拉伸，使仪表盘的所有内容都适应窗口的大小。这防止了用户在嵌入仪表盘到另一个应用程序时需要滚动。在下面的示例中，两个部分都被压缩以移除空白，并调整图表大小以适应一个窗口。

## 定义你的仪表盘输入和输出

输入和输出的主要目的是将数据传递到嵌入仪表盘的应用程序中或从中传递数据。例如，嵌入仪表盘中的图表可以根据应用程序中的对象集选择进行更新，或 Workshop 指标卡片可以在嵌入仪表盘中突出显示计算值。

你可以为你的仪表盘定义多个输入和输出。
按照以下步骤将输入或输出添加到仪表盘：

- 使用设置按钮打开仪表盘编辑器。
- 选择添加输入或添加输出。
- 从下拉列表中选择要用作输入或输出的数据（例如 对象集、对象、时间序列、变量等）。
- 可选地，将当前数据值设置为输入的默认值，这是没有输入传递时参数的值。
- 可选地，通过选择默认标题并输入新标题，为输入或输出赋予有意义的标题。此标题将在映射输入和输出时在嵌入仪表盘的应用程序中可见。
