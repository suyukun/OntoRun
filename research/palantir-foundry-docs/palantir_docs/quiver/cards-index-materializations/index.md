# 实现卡片

返回:卡片索引

本节中的卡片支持分析Ontology中索引数据的实现。

实现是Quiver中的一种数据类型，提供了一种大规模变换、可视化和分析Ontology数据的方法，可以突破数据合并和变换中存在的50k行限制。

具体来说，实现卡片允许您：

- 对对象数据执行合并（左/右/内/全）
- 派生新列，筛选或聚合对象数据
- 使用分类图表绘制数据
- 转换为变换表并使用Vega图表
使用实现卡片进行大规模分析，以对象集作为输入，Quiver在后台无缝转换对象集。从对象集开始，使用新实现操作下的任何卡片，或使用对象集实现卡片进行显式转换。

要了解哪个基础数据集原语在为实现卡片提供支持，只需将鼠标悬停在数据源图标上。

以下功能可用：

- 表达式
- 筛选实现
- 合并实现
- 数值聚合（实现）
- 对象集实现
- 集合数学（实现）
- 唯一列值（实现）
### 表达式

使用表达式语言派生新列或执行复杂的筛选。此卡片中仅可用的高级功能，例如窗口函数，可以解锁Quiver中的新型分析。要使用，请选择对象集、实现卡片或其他表达式卡片。

选择其他配置...以访问添加新列、替换列、筛选和聚合选项。

在启用AIP的情况下，您可以在表达式卡片中选择AIP配置选项，以使用自然语言创建表达式。

您可以使用的一些示例提示包括：

- “计算一个名为'总用户得分'的新列，通过将两个得分列相乘”
- “计算每个有机类别的'总用户得分'，通过将两个得分列相乘”
- “计算每个有机类别的平均可持续性得分”
- “将有机列中的值更新为驼峰式写法”
- “将两个产品名称列合并到其中一个”
- “计算每个商店每种产品的总收入，考虑价格和销售数量”
AIP提供一个建议，您可以应用。

### 筛选实现

对实现应用额外的筛选条件。选择要应用条件的对象集。

### 合并实现

对两个实现的对象数据集执行左、内或右合并。选择要保留的源和合并实现中的数据列。非必填地，为传入列添加前缀以避免与现有列名称冲突，或注释合并的列。

### 数值聚合（实现）

对数值实现列进行聚合计算。选择对象集作为输入，从可用列中选择适当的指标和属性。

### 对象集实现

使用底层对象集的数据实现，进行灵活的大规模分析。

从对象集卡片的下一步操作菜单中添加任何实现卡片时，Quiver会自动添加此卡片，以将对象集数据类型转换为实现数据类型，并将其用作添加的实现卡片的输入。

### 集合数学（实现）

对两个实现执行并集、交集或差集操作。

### 唯一列值（实现）

检索实现列中的所有唯一值。选择对象集和要使用的属性。
