# 使用公式

几种类型的Quiver卡片允许您在公式框中输入数学表达式，以变换分析中的数据。公式的输入可以是数字、类别图表或时间序列。Quiver为公式使用自定义数学表达式语言。

- 支持基本的算术运算（乘法、除法、加法、减法等），以及更复杂的数学表达式。
- 您可以通过使用其全局标识符（例如$A）来引用分析中的数据。
- Quiver的自动完成功能将建议内置函数，并根据名称匹配分析中的输入。
以下类型的Quiver卡片支持公式：

- 数值公式
- 时间序列数值公式
- 时间序列公式
- 类别公式图
- 段公式图
在一些变换表的变换中，也可以找到公式，例如布尔公式、数值公式或时间序列公式。在变换表中，您可以使用@符号引用公式中的输入列（例如@column > 0）。

请查阅公式语法文档以获取有关支持表达式的更多详细信息。
