### 时间序列组线性聚合

### 自定义图

创建具有自定义颜色、标题等的新图。

### 时间序列数值聚合

返回输入时间序列的聚合（例如：最小值、最大值、平均值、总和）为单一数字。

可用的数值聚合包括：

- 总和
- 平均值
- 标准差
- 最大值
- 最小值
- 相对差异
- 差异
- 乘积
- 计数
- 第一个点
- 最后一个点
