# 使用图形模式

Quiver提供了两种设计模式选项来搭建您的分析：Canvas模式和图形模式。在图形模式中，卡片通过图上的节点表示，输入和输出通过卡片之间的连接表示。您可以通过使用分析菜单头部和侧面面板直接在图形中搭建您的分析。

您可以通过打开屏幕右上角的视图模式下拉菜单查看当前的视图模式并在视图模式之间切换。请注意，在图形中添加卡片到您的分析中也会使它们在Canvas模式中可见（反之亦然），因此您可以在分析过程中在两种模式之间切换。

## 在图形上查看卡片

从Canvas中，您可以切换到图形模式，通过选择卡片右上角的更多操作菜单中提供的两个选项之一来查看卡片依赖关系：

- 在图中查看将切换视图到图形模式，以该卡片为中心显示图上的所有其他卡片的上下文。
- 在图中聚焦将切换视图到图形模式的聚焦模式，仅显示所选卡片及其依赖关系。要再次查看整个图形，请点击**'退出聚焦'**。
## 图形模式中的卡片交互

- 单击卡片以选择它；被选择的卡片将以蓝色高亮显示。相关的基础数据将会出现。
- 双击卡片以缩放并将卡片居中在屏幕上，打开右侧的卡片编辑器，并在适用的情况下，显示卡片下的下一步操作菜单。
下一步操作菜单提供了用户可能想要从特定类型节点执行的常见操作。

## 图形导航

在图形的左下角，您将找到用于放大/缩小、缩放以适应屏幕上的所有卡片以及重置图形设计的按钮。

您还可以通过点击并拖动卡片到所需位置来调整图形设计。请注意，对图形设计所做的更改不会被保存。这意味着如果您切换到Canvas模式，或者离开分析然后重新打开分析，图形将重置为默认设计。
