# 字符串比较

返回到：变换索引

本节中的变换用于比较字符串数据类型。这些比较变换对于以字符串列筛选变换表行非常有用。这些比较变换也可以在变换表之外单独使用。

- 以...开始
- 以...结束
- 包含
- 不包含
- 等于 (字符串)
- 不等于 (字符串)
### 以...开始

如果输入字符串以指定的子字符串开始，则返回True（区分大小写）。将特殊字符如. / @ a -和spaces视为字面搜索字符串的一部分，与"包含"变换相反，后者使用特殊字符作为单词边界。

### 以...结束

如果输入字符串以指定的子字符串结束，则返回True（区分大小写）。

### 包含

如果输入字符串包含指定的子字符串，则返回True（区分大小写）。将特殊字符如. / @ a -和spaces视为单词边界。

### 不包含

如果输入字符串不包含指定的子字符串，则返回True（区分大小写）。

### 等于 (字符串)

如果输入值相同，则返回True（区分大小写）。

### 不等于 (字符串)

如果输入值不同，则返回True（区分大小写）。
