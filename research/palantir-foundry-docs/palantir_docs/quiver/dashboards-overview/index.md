# 概述

Quiver仪表盘模式允许您在只读、交互式仪表盘中展示分析的见解。仪表盘可以作为独立视图使用，也可以嵌入到其他Foundry应用中。

## 主要功能

- 每个分析可以创建多个仪表盘。
- 从空白仪表盘开始，轻松将分析中的内容拖放到仪表盘中。
- 可在三种视图样式之间进行选择，以优化仪表盘以供独立使用或嵌入到其他应用中。
- 将仪表盘嵌入到Foundry的其他部分，包括Workshop模块、Notepad文档、Carbon工作区和Object视图。
## Quiver仪表盘是否取代Quiver模板？

仪表盘是创建使用Quiver分析内容的视图的新方式，可以以只读格式与其他用户共享。仪表盘旨在改进模板，并将逐渐取代它们。

目前，您可以选择创建模板或仪表盘，但我们建议仅使用仪表盘。最终我们将移除创建新模板的功能。

我们不要求现有模板重新搭建为仪表盘。模板将继续按预期工作。您仍然可以共享、嵌入和编辑Quiver模板。如果您希望将现有模板转换为仪表盘以利用仪表盘的附加功能，您需要手动重新搭建，因为没有自动将模板转换为仪表盘的功能。

## 仪表盘和模板之间的主要区别

| 模板 | 仪表盘 |
| --- | --- |
| 输入 |  |
| 在发布模式下可以更改Object类型输入 | 在发布模式下无法更改Object类型输入 |
| 仅支持一个输入 | 支持多个输入 |
| 输入类型仅限于Object或对象集 | 多种输入类型 |
| 创建 |  |
| 在画布上调整卡片大小，并添加容器以组织内容。 | 将内容拖放到仪表盘中，轻松调整大小、对齐、定位和使用标签和部分结构化内容，无需使用容器。容器仍可作为高级功能使用。 |
| 无可折叠部分 | 可折叠部分 |
| 画布和模板之间是一对一映射 | 一个仪表盘可以包含多个画布的内容 |
| 每个分析的画布可以创建一个模板 | 一个分析中可以有无限数量的仪表盘，与用于分析的画布数量无关 |
| 使用 |  |
| 模板不能作为卡片在分析中显示 | 仪表盘可以作为卡片在分析中显示 |
| 嵌入到其他应用中需要RID | 直接从下拉菜单中选择可用的仪表盘，无需RID |
