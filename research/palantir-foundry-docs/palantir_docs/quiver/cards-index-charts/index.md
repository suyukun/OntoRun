### 条形图

创建水平或垂直定向的对象条形图。条形图的类别由对象属性决定，您可以设置值以计数对象或显示属性值或值的聚合。您还可以使用条形图将数据转换为时间序列。

- 支持的聚合指标：最小值、最大值、总和、平均值、计数、唯一计数、百分位数、标准差和方差
- 对于由对象存储 V1 (Phonograph)支持的对象类型，不支持百分位数、标准差和方差指标。
### 折线图

创建由对象属性决定类别的折线图。设置值以计数对象或显示属性值或值的聚合。

- 支持的聚合指标：最小值、最大值、总和、平均值、计数、唯一计数、百分位数、标准差和方差
- 对于由对象存储 V1 (Phonograph)支持的对象类型，不支持百分位数、标准差和方差指标。
### 叠加图

在同一组坐标轴上组合折线图、条形图和分类散点图。叠加图不强制使用同一组坐标轴，但建议使用一致的类别。

### 饼图

创建由对象属性决定类别的饼图。设置值以计数对象或显示属性值或值的聚合。

- 支持的聚合指标：最小值、最大值、总和、平均值、计数、唯一计数、百分位数、标准差和方差
- 对于由对象存储 V1 (Phonograph)支持的对象类型，不支持百分位数、标准差和方差指标。
### 分类公式图

通过计算现有分类图的重叠类别上的函数来创建新的分类（条形、折线、散点）图。公式中还可以包含来自聚合或参数的数值。

### 对象函数图

使用函数在Quiver中创建分类图（条形、折线、散点）。

### 段公式图

通过将公式应用于分类图中显示的特定段来创建新的分类图（例如，通过某些标量值缩放某些段）。公式中还可以包含来自聚合或参数的数值。

### 变换表图

使用变换表中的数据创建分类图（条形、折线或散点）。在编辑器中，使用数据选项卡选择输入变换表，并定义组以及段（非必填）。使用显示选项卡更改可视化类型和其他显示选项。

- 支持的聚合指标：最小值、最大值、总和、平均值、计数、唯一计数、百分位数、标准差和方差
### 分类散点图

创建由对象属性决定类别的折线图。设置值以计数对象或显示属性值或值的聚合。

- 支持的聚合指标：最小值、最大值、总和、平均值、计数、唯一计数、百分位数、标准差和方差
- 对于由对象存储 V1 (Phonograph)支持的对象类型，不支持百分位数、标准差和方差指标。
### 数值散点图

将任意一对数值属性相互绘制。

### 散点图回归

散点图回归用于查看时间序列散点图上的最佳拟合回归线。

- 可以选择线性、多项式（0-13度）或指数回归拟合。
- 用于计算最佳拟合线的时间范围默认设置为源图缩放范围，但可以修改为匹配范围。
### 时间序列散点图

散点图可用于将两个系列相互绘制。底层系列的点将在绘制前自动聚合（使用底层时间范围的1/1000的桶平均值）。

- 可以指定分桶策略（桶的数量和每个桶的点数）以及桶值（例如，平均值、总和、最大值）。
- 包含在交叉图中的每个系列的范围自动设置为底层图缩放范围，但可以修改为手动范围。
### 事件时间轴

通过时间查看事件对象集，如有需要可分为类别。

不支持变换表，仅接受事件集作为输入。考虑使用Vega图作为事件时间轴的替代可视化。

事件时间轴图仅在事件数量不超过配置的单个事件阈值时支持着色。要调整事件阈值，请导航到数据选项卡并调整单个事件阈值字段中的数字。请注意，提高阈值数字可能会影响性能。

或者，您可以放大选定的时间范围以减少图表视图中的事件数量。

### 时间序列分布

分布图显示系列的y轴值的聚合计数。

- 默认情况下，使用整个时间范围，但可以使用时间范围参数指定特定的时间范围。
- 还可以指定箱数以更改图表的频率。
### 相关矩阵

在对象集的属性之间创建相关矩阵。在显示选项卡中选择相关类型（Pearson或Spearman）。

### 热力网格

以三维显示图表，显示两个分类维度和一个按颜色显示的聚合维度。

- 支持的聚合指标：最小值、最大值、总和、平均值、计数、唯一计数、百分位数、标准差和方差
- 对于由对象存储 V1 (Phonograph)支持的对象类型，不支持百分位数、标准差和方差指标。
### 时间序列热力网格

热力网格显示两个时间序列的二维聚合值网格。热力网格类似于散点图，但通过同一桶中出现的点的密度进行着色。

### 地图

在地图上可视化一个或多个对象集。地图由地理空间数据（地理哈希、GeoJSON和区域代码）支持，可以以多种方式绘制。您可以在Workshop地图微件文档中找到地图图层配置的详细描述。

- 点图层在地图上的特定位置绘制每个对象。
- 集群根据缩放级别动态组合一组点。
- 等值线图层可以汇总整个区域以绘制地图的阴影区域。
- 线段用于使用一组直线连接多个点。
### 媒体属性

渲染附加到对象属性的媒体。
