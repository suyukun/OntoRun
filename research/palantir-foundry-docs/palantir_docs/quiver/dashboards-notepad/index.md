# 添加到记事本文档

有两种主要方法可以将仪表盘添加到记事本文档：复制粘贴和嵌入。

## 从仪表盘复制粘贴到记事本

可以使用复制到记事本操作将仪表盘上的卡片复制粘贴到记事本文档中。

不支持复制包含多个参数或指标的单元格。

## 在记事本文档中嵌入仪表盘

在记事本文档中嵌入Quiver仪表盘允许您将仪表盘以PDF格式导出或打印。嵌入仪表盘还允许您在某个时间点锁定数据。

请按照以下步骤将仪表盘添加到记事本文档中。

- 打开记事本文档。
- 选择顶部栏中的**+ 微件**按钮。
- 选择Quiver仪表盘。
- 在右侧的配置面板中，选择您要嵌入的仪表盘。
- 选择您要插入的仪表盘版本，或切换自动更新以始终显示最新版本。
- 最后，如果您的仪表盘定义了输入，输入将显示在仪表盘输入部分。您可以使用下面的映射表将输入映射到记事本文档中的变量。
| Quiver输入类型 | 记事本输入类型 |
| --- | --- |
| Boolean | 字符串 |
| Number | 字符串 |
| 字符串 | 字符串 |
| Time | 字符串，ISO格式 |
| Time Range | 字符串，ISO格式 - ISO格式 |
| Time Series | 不支持 |
| Object | Object |
| 对象集 | 对象集 |
| 字符串列表 | 字符串:["option_1","option_2"] |
