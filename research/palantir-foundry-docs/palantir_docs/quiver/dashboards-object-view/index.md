# 在对象视图中嵌入

发布的Quiver仪表盘可以嵌入到对象浏览器中的对象视图中。

## 添加Quiver仪表盘微件

可以直接从“传统”对象视图构建器标签中添加Quiver仪表盘。

从那里，打开添加微件菜单，并从列表中选择Quiver仪表盘。

## 配置Quiver仪表盘微件

从下拉列表中，选择您想要嵌入的已发布仪表盘。

要将对象视图中的对象用作Quiver仪表盘的输入，请在仪表盘的对象输入名称字段中复制Quiver仪表盘中定义的对象输入的名称。

如果该仪表盘配置了额外输入，您可以在额外仪表盘输入部分通过选择添加项目来映射对象视图中的数据输入。

| Quiver输入类型 | 对象视图筛选类型 |
| --- | --- |
| 布尔值 | 字符串，或字符串列表中的第一个 |
| 数字 | 字符串，或字符串列表中的第一个 |
| 字符串 | 字符串，或字符串列表中的第一个 |
| 时间 | 字符串，或字符串列表中的第一个 |
| 时间范围 | 时间范围或相对时间范围筛选 |
| 时间序列 | 不支持 |
| Object | 不支持 |
| 对象集 | 不支持 |
| 字符串列表 | 字符串列表 |

最后，定义您的微件高度。当仪表盘的视图样式设置为拉伸时，这是必需的，否则微件的默认高度为0像素。
