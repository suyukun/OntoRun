# 发布和共享仪表盘

## 预览您的仪表盘

要预览仪表盘的只读版本，请选择顶部工具栏中的预览按钮。

进入预览模式后，您可以像最终用户一样与仪表盘互动。您还可以更改您定义的输入，以查看这些更改如何影响视图。使用退出预览按钮返回到仪表盘编辑模式。

## 发布您的仪表盘

完成仪表盘编辑后，您需要发布它以便与其他用户共享。这将创建一个由您的Quiver分析支持的单独Foundry资源。发布您的仪表盘将同时创建资源并保存分析。

要发布，请使用顶部工具栏中的发布按钮。系统会提示您选择在Foundry中保存仪表盘的位置。

注意，仪表盘将继承您保存它的文件夹的权限。例如，如果您将其保存在私人文件夹中，除非您手动授予用户访问权限，否则任何用户都无法访问。下一节提供了有关权限如何工作的更多详细信息。

每次重新发布仪表盘时，都会保存一个新版本。

## 共享您的仪表盘

要查看仪表盘，用户至少需要具有只读权限。这些权限可以手动授予，或者从发布资源的父文件夹的权限中继承。

要编辑仪表盘，用户需要在仪表盘和基础分析上具有编辑者或所有者权限。

| 仪表盘权限 | 分析权限 | 可执行操作 |
| --- | --- | --- |
| 编辑者或所有者 | 编辑者或所有者 | 可以编辑和共享仪表盘和分析。 |
| 编辑者或所有者 | 只读 | 可以共享仪表盘但不能共享分析。不能重新发布仪表盘，因为这需要保存分析。 |
| 只读 | 编辑者或所有者 | 可以保存分析但不能保存更新后的仪表盘。 |
| 只读 | 无访问权限 | 可以查看仪表盘但不能更新。 |
| 编辑者或所有者 | 无访问权限 | 可以查看仪表盘但不能更新。 |

## 打开已发布的仪表盘

您可以通过单击分析中的链接或在Foundry中单击资源来在分析之外打开已发布的仪表盘。这将在一个新的只读标签中打开仪表盘。具有适当权限的用户（见上文）将能够从此视图打开支持的分析，并通过选择右上角的编辑按钮编辑仪表盘。
