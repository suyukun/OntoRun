### 从Object上的函数派生属性

添加一个由函数支持的派生列。使用函数创建一个新列，其类型可以是布尔值、字符串、数字或日期/时间，具体取决于函数的输出。

定义返回数值的函数时，建议返回Double或Integer而非Float。
