# 创建和配置图表

图表是可以添加到分析中以可视化数据的卡片。在 Quiver 中有三种类型的图表：

- 时间序列可视化
- 对象图表
- 派生图表
您可以通过在顶部的分析菜单中搜索图表来添加卡片图表。根据图表的类型，不同的配置选项可供选择。

阅读图表卡片索引页面以获取每个图表及其功能的完整描述。

## 时间序列可视化

时间序列可视化以一个或多个时间序列为输入，并返回一个图表。Quiver 提供了大量的时间序列可视化。

## 对象图表

对象图表是用于显示对象集数据的卡片。它们以对象集为输入，并返回一个可视化。对象图表的主要功能是显示原始或聚合数据，提供多种配置选项用于聚合和显示自定义。在某些情况下，图表中的聚合数据（也称为类别图表）可以作为输入用于派生图表以进行进一步分析。

对象图表可以处理更大的规模，使其适合可视化大量数据。

这些图表包括以下内容：

- 条形图
- 折线图
- 饼图
- 数值散点图
- 类别散点图
- 列表
- 表格
- 透视表
可以通过在卡片角落选择图标在编辑器面板中配置对象图表。

每种图表根据其类型会有略微不同的配置选项。通常，您可以在对象图表的编辑器面板上执行以下操作：

- 配置数据（数据选项卡）更改输入对象集定义聚合：按属性分组、x轴/y轴属性、聚合指标等支持的聚合指标：最小值、最大值、总和、平均值、计数、唯一计数、百分位数、标准偏差和方差对于由对象存储 V1 (Phonograph)支持的对象类型，不支持百分位数、标准偏差和方差指标。定义段（非必填）定义排序顺序
- 更改输入对象集
- 定义聚合：按属性分组、x轴/y轴属性、聚合指标等支持的聚合指标：最小值、最大值、总和、平均值、计数、唯一计数、百分位数、标准偏差和方差对于由对象存储 V1 (Phonograph)支持的对象类型，不支持百分位数、标准偏差和方差指标。
- 支持的聚合指标：最小值、最大值、总和、平均值、计数、唯一计数、百分位数、标准偏差和方差
- 对于由对象存储 V1 (Phonograph)支持的对象类型，不支持百分位数、标准偏差和方差指标。
- 定义段（非必填）
- 定义排序顺序
- 配置显示（显示选项卡）更改图表的方向（例如，对于条形图）覆盖段和指标的颜色和标签配置轴标题、格式和位置选择是否显示标签配置图例（是否显示，位置）
- 更改图表的方向（例如，对于条形图）
- 覆盖段和指标的颜色和标签
- 配置轴标题、格式和位置
- 选择是否显示标签
- 配置图例（是否显示，位置）
您可以通过在分析级别使用类别图表覆盖设置为分析中的所有图表定义自定义标签和颜色。

## 派生图表

派生图表是以聚合或变换后的数据（来自其他对象图表或变换表）为输入并创建可视化的卡片。它们可用于执行更复杂的数据分析，如叠加多个图表或将公式应用于数据段。

派生图表可以为任何支持的数据提供更准确的聚合，使其适合于详细的分析和比较。

这些图表包括以下内容：

- 叠加图表
- 变换表格绘图
- 类别公式绘图
- 段公式绘图
- Vega 绘图
派生图表也可以使用编辑器面板配置，通过点击卡片上的齿轮图标访问。数据和显示选项将根据卡片而有所不同。有关每个图表的更多详细信息，请参阅卡片索引页面。
