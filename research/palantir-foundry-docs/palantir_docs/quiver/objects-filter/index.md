# 筛选对象集

您可以通过选择下一步操作菜单，然后选择对象 > 筛选对象集来创建一个筛选的对象集，以添加一个对象筛选卡片。

或者，您可以直接从对象集卡片中的属性列标题通过属性值筛选对象集。属性列标题还包括精确匹配和空值筛选的快速选项。以这种方式添加筛选，会添加一个以所选属性为输入的对象筛选卡片。

要从属性列标题添加筛选：

- 将鼠标悬停在标题上
- 选择添加筛选条件...
- 选择所需的选项
在下面的例子中，我们筛选了一组纽约市的建筑物，其中屋顶高度属性大于或等于30英尺，面积属性在600到750平方英尺之间，结果是一个包含19,592栋建筑的新对象集（在输入对象集的1,100,640栋中）。

## 查看筛选结果

选择显示/隐藏数据按钮，在结果视图和卡片配置视图之间切换。

## 嵌套筛选

一旦应用了初始筛选，您可以通过点击每个筛选规则卡片右侧的**+**图标，为任何筛选规则添加嵌套筛选。嵌套筛选可以应用为AND或OR条件。您会注意到默认逻辑是AND条件，这意味着筛选中的所有条件必须为true才能捕获对象。

例如，这里我们在第一个筛选规则的两个规则之间选择了一个OR条件。因此，第一个筛选条件屋顶高度大于或等于30OR建筑类型是Skybridge将返回所有高于30英尺的建筑（即使那些没有标记为Skybridges）和所有标记为Skybridges作为建筑类型的建筑（即使那些低于30英尺）。然后，第二个筛选条件将所有符合条件的建筑筛选为面积在600到750平方英尺之间的那些。注意，第一个筛选规则中的OR嵌套筛选导致结果对象集中比前一个例子多包括三个结果。

为了使这个逻辑更易读，Quiver会使用EITHER、AND和OR来结构化您的筛选条件，您应该能够像阅读句子一样阅读筛选条件。

您会注意到筛选配置中有第二个下拉选项：筛选条件，默认是IS。您可能希望明确排除对象，而不是包括它们，在这种情况下，您将需要将其更改为IS NOT。为了处理可能有空数据的属性，存在类似的选项IS NULL和IS NOT NULL。如果您正在处理不同类型的属性，如日期或数字，您将看到相同的IS和IS NOT选项，但一旦您添加筛选，您将看到特定于相应数据类型的筛选选项。

## 关联对象筛选

最后一种类型的筛选是基于关联对象的筛选。当您的筛选条件与您正在处理的对象的属性无关，而是与其连接的对象的属性有关时，这些筛选非常有用。

例如，这里我们筛选了一组公司对象，其中行业属性是能源或名称属性名称包含单词能源，将结果公司集限制为仅那些曾经在股票拆分中分割其股票的公司。在这种情况下，筛选不是在公司本身，而是在连接到[TDP]公司对象的股票事件关联对象上。

要在关联对象上添加筛选，从按关联对象筛选列表中选择对象，并按常规方式添加筛选。
