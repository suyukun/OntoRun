# 从对象集创建时间序列

要使用Quiver的时间序列变换（例如导数或累积聚合），您的数据必须是时间序列格式。已经在Ontology中建模为时间序列的数据可以通过搜索栏直接在时间序列选项卡下找到。

在Quiver中工作时，将具有时间戳属性的对象集转换为时间序列也很有用。当(1) x轴是时间且(2)仅显示一个数据系列时，可以从柱状图、折线图和分类公式图表创建时间序列。

要从对象集创建时间序列，请按照以下步骤操作：

- 将具有时间属性的对象集添加到您的分析中。
- 在对象集卡片的下一个操作菜单中，选择图表，然后选择柱状图或折线图来添加图表。或者，选择顶部菜单栏中的放大镜图标，搜索柱状图或折线图，然后将选定的图表添加到分析中。接下来，在图表编辑器中选择对象集作为输入。
- 按对象的时间属性分组。您可以选择所需的分组粒度；这将定义所创建的时间序列的粒度。在下面的示例中，我们通过选择Start Ts作为分组属性来绘制股票事件随时间的计数。
- 在图表的下一个操作菜单中，选择时间序列 > 分类图时间序列。
一个新的时间序列图表将创建在图表卡片下方。在此示例中，我们将显示股票事件对象计数随时间变化的图表转换为时间序列。

现在可以在此时间序列上应用任何Quiver的时间序列变换以进行进一步分析。例如，要计算事件随时间的累积计数，我们可以在时间序列图上添加累积聚合。

请注意，从对象集派生的时间序列与此对象集相关联，因此将根据该输入对象集的更改动态更新。例如，如果您筛选输入对象集，时间序列将更改为仅反映该筛选对象集中的对象。这允许用户工作流程中根据各种用户选择动态生成时间序列。
