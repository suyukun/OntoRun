### 等于

如果数字相同，则返回True。

### 不等于

如果数字不相同，则返回True。

### 大于

如果输入数字大于第二个数字，则返回True。

### 大于或等于

如果输入数字大于或等于第二个数字，则返回True。

### 小于

如果输入数字小于第二个数字，则返回True。

### 小于或等于

如果输入数字小于或等于第二个数字，则返回True。

### 编辑数字

覆盖表中单个单元格的数值列。

### 数值公式

通过组合和在其他数值列上编写公式来创建新的数值列。

### 数字组聚合

将一组数字聚合成一个单一的数字。

### 时间序列数字聚合

将时间序列聚合成一个单一的数字。

数字组和时间序列数字聚合的可用聚合包括：

- 总和
- 平均值
- 标准差
- 最大值
- 最小值
- 百分比变更
- 差异
- 乘积
- 计数
- 第一个点
- 最后一个点
### 向上取整

将一个数字向上舍入到下一个最大的整数。

### 向下取整

将一个数字向下舍入到下一个最小的整数。

### 合并

返回第一个非空值，如果所有输入都为空，则返回空。
