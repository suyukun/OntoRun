# 导入关联对象

关联对象（在它们之间定义了链接的对象）是Ontology的重要组成部分，也是Foundry中对象分析的基础。

Quiver的关联对象集功能允许您创建一个新的对象集，其中包含给定类型的所有对象，并与分析中的现有对象集关联。此过程也称为环绕搜索。

您可以通过下一步操作菜单访问此功能，并选择对象 > 关联对象集，或者在顶部菜单的对象下拉菜单中选择关联对象集。

选择输入对象集后，使用屏幕右侧编辑面板中的下拉菜单选择一个关联对象类型。

在下面的示例中，选择公司与股票系列之间的链接将返回与输入对象集中的505家公司相关的1,964个时间序列对象集。要查看返回的对象集，请单击关联对象集卡片中的表格标签。
