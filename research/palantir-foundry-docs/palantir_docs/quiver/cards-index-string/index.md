# 字符串卡片

返回:卡片索引

本节中的卡片返回并显示字符串。

- 对象属性
- 变换表格列值
- 唯一属性值
- 属性值选择参数
- 字符串参数
- 子字符串
- 合并
- 数组合并
- 代码函数
- 可视化函数属性选择
- 可视化函数字符串
- 查找和替换
- 转换为小写
- 转换为大写
### 对象属性

以对象为输入，并在卡片上显示一个属性。支持的属性类型包括数值型、时间型和字符串型。

### 变换表格列值

从变换表中获取一个字符串列作为输入，并返回字符串值的数组。

### 唯一属性值

返回对象集中文本属性的唯一低基数值集。这也可以用于筛选。请注意，仅使用前1,000个值。

### 属性值选择参数

基于对象集属性的值创建一个多选下拉菜单参数。

### 字符串参数

创建一个字符串输入字段，可在其他卡片（例如筛选）中用作参数。

### 子字符串

从给定的起始索引开始并具有给定长度的字符串的子字符串。

### 合并

返回第一个非空值，如果所有输入都为空，则返回空。

### 数组合并

通过组合输入字符串数组值返回一个字符串（字符串分隔符为非必填）。

### 代码函数

从代码函数返回一个字符串。

### 可视化函数属性选择

使用可视化函数保存可重复的逻辑，从对象属性返回一个字符串。

### 可视化函数字符串

使用可视化函数保存可重复的逻辑，返回一个字符串。

### 查找和替换

将匹配的字符串值替换为不同的字符串。

### 转换为小写

将字符串转换为全小写（非字母字符不变）。

### 转换为大写

将字符串转换为全大写（非字母字符不变）。
