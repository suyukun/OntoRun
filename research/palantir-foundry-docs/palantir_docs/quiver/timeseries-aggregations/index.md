# 时间序列聚合

Quiver支持多种时间序列聚合，可以在一个或多个序列上同时操作。

## 单序列聚合

单序列聚合在一个连续的时间序列上进行操作，为每个指定的_时间窗口_生成一个聚合值。

### 支持的聚合选项

支持以下选项：

- Sum:每个窗口中所有点的和。
- Mean:每个窗口中所有点的平均值。
- Standard deviation:每个窗口中所有点的标准差。
- Max:每个窗口中的最大值。
- Min:每个窗口中的最小值。
- Difference:每个窗口中最后一个点与第一个点的差。
- Relative difference:每个窗口中最后一个点与第一个点的百分比变化。
- Product:每个窗口中所有点的乘积。
- Count:每个窗口中的点数。
- First:每个窗口中第一个点的值。
- Last:每个窗口中最后一个点的值。
### 使用此聚合的Quiver卡片

- 累计聚合：此卡片对输入序列中的每个点应用数据点聚合，其中时间窗口从序列的起始点到当前点（包括当前点）。
- 周期性聚合：此卡片将时间序列划分为固定持续时间的连续时间窗口，并对每个窗口应用数据点聚合。没有数据点的窗口不包括在输出中。
- 滚动聚合：此卡片对输入序列中的每个点应用数据点聚合，时间窗口在当前时间戳结束（包括当前时间戳）并跨越指定的持续时间。随着新数据点被添加到窗口中，旧点会从窗口中移出（如果它们不在指定的持续时间内）。
- 时间序列数值聚合：此卡片对跨越整个序列的单个时间窗口应用数据点聚合。
- 时间序列散点图：此卡片使用周期性聚合。
- 布林带：此卡片使用滚动聚合。
## 多序列聚合

多序列聚合对齐多个连续的时间序列，并从每个序列中组合一个值，为每个时间戳生成一个聚合值。

### 支持的聚合选项

支持以下选项：

- Sum:每个时间戳所有序列点的和。
- Mean:每个时间戳所有序列点的平均值。
- Standard deviation:每个时间戳所有序列点的标准差。
- Max:每个时间戳任何序列中的最大值。
- Min:每个时间戳任何序列中的最小值。
- Product:每个时间戳所有序列点的乘积。
### 使用此聚合的Quiver卡片

- 线性聚合
- 时间序列公式：此卡片允许您执行上述列表中的大多数操作，但使用数学运算符。
## 区间聚合

区间聚合在一个可以通过筛选时间序列卡片生成的区间时间序列上进行操作。它们为序列中的每个区间生成一个聚合值。聚合_包括_每个区间起始时间戳的点，_不包括_结束时间戳的点。

### 支持的聚合选项

支持以下选项：

- Sum:每个区间中所有点的和。
- Mean:每个区间中所有点的平均值。
- Standard deviation:每个区间中所有点的标准差。
- Max:每个区间中的最大值。
- Min:每个区间中的最小值。
- Difference:每个区间中最后一个点与第一个点的差。
- Relative difference:每个区间中最后一个点与第一个点的百分比变化。
- Product:每个区间中所有点的乘积。
- Count:每个区间中的点数。
- First:每个区间中第一个点的值。
- Last:每个区间中最后一个点的值。
- Duration:每个区间的长度，使用时间序列配置的精度（通常为毫秒）。
- Rate change:每个区间中最后一个点与第一个点的差除以区间的长度，使用时间序列配置的精度（通常为毫秒）。
