# 将模板转换为仪表盘

我们建议使用仪表盘而不是模板。仪表盘是从Quiver分析中创建、分享和嵌入内容的首选方法。尽管现有模板仍然支持和可编辑，但创建新模板的功能将被弃用。

要将现有的对象画布模板转换为**仪表盘，您首先需要通过在对象画布模板的画布菜单中选择转换为自由形式画布**，将对象画布模板转换回自由形式画布。

然后，从应用程序底部的画布菜单中，通过画布名称旁边的下箭头进入，选择转换为对象画布模板。

对话框提供了将画布转换为模板（一个遗留功能）或创建一个包含所选画布中所有卡片的新仪表盘的选择。

输入仪表盘标题并选择一个对象或对象集作为对象类型输入。然后选择创建仪表盘而不是转换为模板。

或者，也可以创建一个仪表盘并手动一个一个地将卡片添加到仪表盘中，如果不希望将整个模板转换为仪表盘。
