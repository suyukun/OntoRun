# 概述

可视化函数是使用 Quiver 的点击界面搭建的可重用逻辑模块。这些函数可以在同一个或其他 Quiver 分析中多次使用。可视化函数作为 Foundry 中的独立资源发布，可以与其他用户共享，他们也可以在自己的 Quiver 分析中使用这些函数。

可视化函数允许您：

- 使用点击界面搭建可重用逻辑，无需编码，
- 通过搭建共享的可重用函数库与同事协作，
- 在一个地方轻松更新多个分析中的通用逻辑，减少手动出错或逻辑不匹配的风险，
- 简化大型分析并改善加载和导航性能。
## 输入

一个可视化函数包含零个或多个输入。输入是函数的参数，用户可以在使用函数时进行配置。支持的输入类型包括：指标、对象集、单个对象或时间序列。请注意，虽然可视化（不论是否分类）和表格不是支持的输入类型。

## 输出

一个可视化函数有一个输出。函数的输出是函数返回的结果。支持的输出类型包括：指标、对象集、单个对象或时间序列。

请注意，虽然可视化（不论是否分类）和表格不是支持的输出类型。

包含函数输出的卡片可以作为其他卡片在 Quiver 分析中的输入。

## 逻辑

Quiver 函数的逻辑是分析图中位于输入和输出之间的所有卡片。

请注意，函数的逻辑不能包含可视化（不论是否分类）或表格卡片。
