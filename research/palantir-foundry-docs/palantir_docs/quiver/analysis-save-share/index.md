# 保存和分享分析

## 保存分析

要保存Quiver分析，请选择屏幕右上角的保存。

## 访问分析的历史版本

通过打开屏幕顶部的分析历史菜单，访问并恢复到分析的历史版本。

如果您在当前版本的分析中有未保存的更改，系统会提示您选择清除或将更改保存为新版本。

## 分析权限

Quiver分析的权限来源于Foundry文件系统中的其项目。当您将Quiver分析保存在一个项目中时，任何有权访问该项目的人也可以访问该分析。访问级别在项目和Quiver分析之间保持不变。例如，具有查看权限的用户可以查看（但不能编辑）Quiver分析，而具有编辑权限的用户可以查看和更新分析。

## 分享分析

Quiver分析的编辑者可以与其他用户分享分析。有两种主要方法可以做到这一点：通过分享链接或授予特定用户访问权限。两种方法都可以通过顶部栏的分享按钮访问，以打开一个侧边面板。

选择分享按钮会打开一个带有分享选项的侧边面板。

### 链接分享

链接分享创建一个特定链接，该链接为通过该链接访问分析的用户授予一定级别的访问权限。

### 角色

角色部分允许您为个别用户授予指定的访问级别。

角色显示任何已通过分享链接、直接授予访问权限或通过群组成员身份获得访问权限的用户。

如果您导航到您的Quiver分析并选择**分享...**按钮，也可以从Foundry文件系统访问此分享面板。
