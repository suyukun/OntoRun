# 钻取对象集

您可以通过一次点击弹出操作，从对象集高效钻取到集中的任意特定对象或对象属性。本页解释了如何钻取到对象、时间序列列和对象指标。

## 特定对象

对象集卡片中的行可以作为单独的对象卡片弹出。

要弹出一个对象，将光标移到行上，然后点击出现在行左侧的蓝色弹出对象按钮。点击该按钮将添加一个预配置为所选对象的对象选择器参数和一个以对象选择器为输入的对象卡片。

## 时间序列列

时间序列列直接在对象集卡片中呈现为折线图。所有时间序列列都可以作为时间序列图弹出。

要弹出时间序列，将光标移到时间序列上，然后点击出现在属性单元格右侧的蓝色弹出属性按钮。点击该按钮将添加一个包含所选时间序列图的时间序列图表。

了解更多关于在对象集卡片中添加和删除对象属性和度量的信息。

## 对象指标

所有非时间序列的列都可以作为对象属性（指标）卡片弹出。

要弹出非时间序列属性，将光标移到属性单元格上，然后点击出现在属性单元格右侧的蓝色弹出属性按钮。点击该按钮将添加一个预配置为输入的对象属性（指标）卡片。
