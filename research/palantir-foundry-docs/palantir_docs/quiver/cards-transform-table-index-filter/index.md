### 筛选变换表

根据列值和分析中的数据，保留或删除符合任意或所有条件的变换表行。

条件可以通过公式或可视化编辑器定义。要添加条件，请选择+ 添加筛选。

#### 使用可视化编辑器进行筛选

要配置条件，请选择一列。支持的列类型有字符串、日期、数字和布尔值。

一旦选择了列，选择比较运算符来配置条件。每种列类型提供不同的比较运算符：

- 字符串：以...开始，以...结束，包含，不包含，等于，不等于，字符串转换为布尔值（当字符串列包含true或false值时使用）
- 日期：早于，于或早于，晚于，于或晚于，之间（包括），于，不于
- 数字：大于，大于或等于，小于，小于或等于，等于，不等于
- 布尔值：等于，不等于

#### 使用公式进行筛选

要配置条件，指定一个返回布尔值（true/false）的公式。公式可以将列作为输入，用@引用（例如，@column > 0）。您还可以使用分析中的数据引用其全局标识符$XY（例如，@column > $A，其中$A是分析中的一个数值参数）。

注意，字符串类型在公式中不被支持。要对字符串列类型进行筛选，请使用可视化编辑器。
