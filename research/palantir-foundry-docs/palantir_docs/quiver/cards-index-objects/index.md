# 对象卡片

返回至：卡片索引

这些操作返回对象集卡片，唯有对象选择器返回单个对象卡片。

- 添加对象集
- 对象属性
- 导入已保存的对象集
- 筛选对象集
- 链接对象集
- 集合数学
- 状态筛选
- 交叉筛选
- 由属性定义
- 代码函数对象集
- 对象选择器
选择显示数据和隐藏数据按钮在结果视图和卡片配置视图之间切换。

### 添加对象集

打开搜索栏，您可以在Ontology中搜索对象并将对象集添加到分析中。

添加后，对象集呈现为对象集卡片，显示一个包含个体对象作为行和对象属性作为列的表格。表头显示集合中对象的数量和对象类型信息，以及可见属性的数量。时间序列列直接在表格中呈现为火花线。

对象属性和可用的链接传感器可以通过从右上角选择属性直接从卡片头部添加或移除。这简化了发现存储在对象上作为时间依赖属性或在链接对象上作为度量的时间序列数据的过程。添加或移除属性将添加或移除对象集卡片表格视图中的列。

了解更多关于在Quiver中添加数据的信息。

对象集行（对象集中的个体对象）可以弹出为对象卡片，表格中所有属性值（单元格）可以弹出为时间序列图或对象属性（指标）卡片。这种弹出操作缩短了从包含多个对象的对象集深入到单个对象上的特定时间序列图或属性指标的过程。

### 对象属性

以对象作为输入并在卡片上显示一个属性。支持的属性类型包括数值、时间和字符串。

### 导入已保存的对象集

提示您从项目中导入已保存的对象集。这可以是您在另一个Quiver分析中保存的对象集，也可以来自Foundry的其他地方（例如，来自对象浏览器）。导入会在分析中添加一个对象集卡片，显示集合中的对象数量和集合的元数据。

### 筛选对象集

以对象集卡片作为输入，并根据您可以在对象属性和链接对象属性上定义的一组逻辑条件返回一个（筛选后的）对象集。了解更多关于筛选对象集的信息。

### 链接对象集

也被称为“执行搜索周围”，此操作使用在Ontology中定义的对象之间的链接将其他对象引入分析中。如果您以一组类型为A的对象开始，并创建一个类型为B的链接对象集，您将返回所有具有与所选类型A对象定义关系的正确类型（类型B）的对象。这些对象集不必具有相同的大小，链接对象集可以比起始对象集小或大；然而，您的输入对象集的大小有严格限制为100,000个对象。结果链接对象集的大小没有限制。了解更多关于导入链接对象的信息。

### 集合数学

以两个（或更多）相同类型的对象集作为输入，并根据用户定义的操作返回一个合并的对象集。支持的操作包括两个对象集的并集、交集或差集。

- 在下面的示例中，我们使用集合数学找到一组48,895个Airbnb对象（$B）和一个筛选后的22,326个Airbnb对象（$D）之间的差异。输出是$B中的26,569个Airbnb对象集合，但不在$D中。
此示例中使用的Airbnb数据是开源的。

### 状态筛选

一种特定类型的对象集筛选器，以具有开始日期/时间和结束日期/时间属性以及时间范围的对象集作为输入。状态筛选返回在给定日期范围内打开或关闭的事件的筛选集。当您不想根据开始日期或事件日期发生的时间来定义逻辑，而是希望开始和结束日期定义某个状态的期间（例如在特定时间段内打开或关闭）时，此对象集非常有用。

- 在指定日期范围内打开的对象包括：在日期范围之前打开并在日期范围之后关闭的对象。在日期范围期间打开并在日期范围之后关闭的对象。
- 在日期范围之前打开并在日期范围之后关闭的对象。
- 在日期范围期间打开并在日期范围之后关闭的对象。
- 在指定日期范围内关闭的对象包括：在日期范围之前打开并在日期范围期间关闭的对象。在日期范围期间打开并在日期范围期间关闭的对象。不包括在日期范围开始之前关闭的对象。
- 在日期范围之前打开并在日期范围期间关闭的对象。
- 在日期范围期间打开并在日期范围期间关闭的对象。
- 不包括在日期范围开始之前关闭的对象。
- 在下面的示例中，我们使用状态筛选器返回在2017年期间打开的股票事件集。
### 交叉筛选

创建一个可以基于多个图表上的选择进行控制（筛选）的对象集。这些图表也会相互筛选。了解更多关于交叉筛选的信息。

### 由属性定义

一种专门的对象集，适用于具有作为现有对象集标识符的属性字段的对象。这些对象集用于创建队列，其中队列逻辑由对象集标识符手动定义。

### 代码函数对象集

创建由代码函数定义的对象集。

### 对象选择器

用于搭建交互式仪表盘，它提供一个下拉微件以从输入对象集或对象类型中选择单个对象。为了引导用户如何选择特定对象，配置一个提示和帮助文本。要显示选定对象的视图，打开显示对象视图或从下一个操作菜单中添加一个对象视图卡片。
