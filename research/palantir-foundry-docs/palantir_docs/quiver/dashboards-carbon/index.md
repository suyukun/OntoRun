# 添加到 Carbon 工作区

Quiver 仪表盘可以作为模块添加到Carbon 工作区。在 Carbon 中有三种类型的模块：锚定模块、新标签模块和可发现模块。

## 作为模块添加仪表盘

要添加模块，请在 Carbon 工作区的右上角选择编辑按钮，然后选择您当前的工作区。

可发现模块可以从常规选项卡中添加，而锚定模块和新标签模块可以从菜单选项卡中添加。

一旦决定要添加哪种类型的模块，选择添加项目。这将打开一个对话框。对于类型，选择Quiver 仪表盘，然后使用打开 Compass 对话框按钮找到您要添加的仪表盘。

可发现模块将可通过 Object Explorer 中的在...中打开菜单供用户访问。

## 添加输入参数

系统将为您提供配置选项。您可以选择添加参数以传递给您的 Quiver 仪表盘。要将参数映射到仪表盘输入，您需要更改参数名称以映射仪表盘输入名称。

如果未设置参数值，则它将默认为空值（或对象集的基本对象类型）。

Carbon 仅支持三种类型的参数传递：字符串、对象或对象类型。这意味着如果您的 Quiver 仪表盘输入类型为布尔值、数字或时间，则需要将其作为字符串从 Carbon 传递。请参阅下表了解类型映射信息。

| Quiver 输入类型 | Carbon 输入类型 |
| --- | --- |
| 布尔值 | 字符串:true或false |
| 数字 | 字符串 |
| 字符串 | 字符串 |
| 时间 | 字符串，ISO 格式 |
| 时间范围 | 不支持 |
| 时间序列 | 不支持 |
| 对象 | 对象 |
| 对象集 | 对象类型 |
| 字符串列表 | 字符串:["option_1","option_2"] |

## 设置版本

默认情况下，仪表盘将自动更新到可用的最新版本。您可以通过添加DASHBOARD_VERSION参数并将其值设置为版本号来设置版本。
