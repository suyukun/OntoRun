# 日期/时间卡片

返回:卡片索引

此部分的卡片返回并显示日期/时间值。

- Object属性
- 移动日期/时间
- 变换表列值
- 日期/时间参数
- 时间范围参数
- 合并
- 时间序列起始日期
- 时间序列结束日期
- 日期至今
- 周至今
- 月至今
- 年至今
- 字符串转日期
### Object属性

以一个Object作为输入，并在卡片上显示一个属性。支持的属性类型为数字、时间和字符串。

### 移动日期/时间

以一个日期/时间值作为输入，并返回一个从输入日期起按周/天/小时/分钟/秒或毫秒数移动后的日期/时间。

### 变换表列值

以变换表中的日期/时间列作为输入，并返回日期/时间值的数组。

### 日期/时间参数

创建一个日期/时间输入字段，可在其他卡片中作为参数使用（例如，筛选或公式）。

### 时间范围参数

创建一个时间范围输入字段，可在其他卡片中作为参数使用（例如，筛选或公式）。在编辑器中使用选择单独的起始和结束日期参数设置，以通过不同的日期/时间参数定义起始和结束日期/时间。

- 例如，如果您希望筛选基于事件Object的起始和结束时间，您可以为事件Object的每个起始和结束日期/时间定义单独的日期/时间参数，然后使用这些日期/时间参数定义时间范围参数。
了解更多关于时间范围的信息。

### 合并

返回第一个非空值，如果所有输入均为空则返回空。

### 时间序列起始日期

返回时间序列中第一个点的日期。

### 时间序列结束日期

返回时间序列中最后一个点的日期。

### 日期至今

创建一个从输入日期的00:00开始至输入日期的范围。

### 周至今

创建一个从输入日期所在周的星期一00:00开始至输入日期的范围。

### 月至今

创建一个从输入日期所在月的第一天00:00开始至输入日期的范围。

### 年至今

创建一个从输入日期所在年的1月1日00:00开始至输入日期的范围。

### 字符串转日期

将字符串转换为日期。默认使用美国日期格式（mm/dd/yyyy）。其他日期格式可通过提供日期格式进行解析。无效值将返回Invalid timezone or date。
