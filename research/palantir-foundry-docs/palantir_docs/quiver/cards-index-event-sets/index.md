# 事件集卡片

返回到:卡片索引

本节中的卡片用于批量可视化和分析事件。一个事件由起始和结束时间戳组成，类似于时间范围，但也可以通过其他数据进行丰富以支持分析。

- 事件图
- 事件指示器序列
- 从范围创建事件集
- 从表格数据创建事件集
- 链接事件集
- 时间序列搜索
- 时间偏移事件集
### 事件图

每个事件集使用事件图进行可视化，它在图表的底部时间轴上绘制事件。

- 将鼠标悬停在每个事件上会显示该事件的详细信息。您可以通过工具提示设置配置要显示的事件详细信息。
- 事件根据图表的缩放级别进行分组。将鼠标悬停在事件组上会显示该组中的事件列表。
- 输入数据必须具有日期或时间戳属性或列，才能将其绘制为多个事件。
事件集和事件图由变换表支持，其中每一行被视为单个事件。通过选择转换 > 新变换表，可以通过事件集的下一个操作菜单访问支持的变换表。您可以使用支持的变换表来修改或丰富基础事件数据。例如，您可能希望为每个事件计算一个颜色标签列。然后，您可以在编辑器面板的显示选项卡下的事件选项中的颜色设置中使用该列进行颜色编码。

### 事件指示器序列

事件指示器序列从事件集中创建一个时间序列，指示在给定时间发生的事件数量。

- 请注意，仅会绘制持续时间不为零的事件。
- 要手动调整事件的开始或结束时间，请使用时间偏移事件集卡片来修改输入事件集。
### 从范围创建事件集

通过为每个事件指定时间范围列表来创建事件集。通过选择范围参数或单独输入起始和结束时间戳来创建每个事件。通过编辑编辑器面板数据选项卡中输入事件数据部分的相应字段，自定义事件工具提示中显示的标题和描述。当使用范围参数时，其标题和注释会自动填充事件的标题和描述（如果可用）。

### 从表格数据创建事件集

从表格数据源（如对象集、变换表或物化）创建事件集。每个事件的起始和结束时间戳使用输入表中的列或属性进行填充，这在编辑器面板数据选项卡的事件配置设置中指定。

### 链接事件集

通过从基础对象开始并通过Ontology定义的链接（也称为搜索周边）查找相关对象来创建事件集。可以遍历多个层次的对象关系以搭建所需类型的事件集，然后可以选择性地进行筛选。通过指定哪个对象属性保存此数据，在编辑器面板数据选项卡中的事件配置设置中设置事件的起始和结束时间戳。也可以从起始时间序列创建链接事件集。在这种情况下，时间序列的根对象将用作基础对象。链接事件集是基于对象的，因此事件工具提示使用每个对象的数据进行填充。

### 时间序列搜索

在一个或多个时间序列图上可视化显示满足某些条件的时间，例如当源序列超过值100而另一个序列达到指定阈值时。时间序列搜索公式应返回一个布尔值，并且将在每个布尔值为true的时间间隔上创建一个事件。

- 时间序列搜索结果作为事件显示在事件图中。
- 运行单个搜索或多个搜索：单个: 在单个时间序列图上执行搜索，每个满足指定条件的时间间隔返回一个事件。多个: 在变换表的每一行（限制为1,000行）上执行搜索，每个满足指定条件的时间间隔返回一个事件。使用@property语法在表中搜索属性。
- 单个: 在单个时间序列图上执行搜索，每个满足指定条件的时间间隔返回一个事件。
- 多个: 在变换表的每一行（限制为1,000行）上执行搜索，每个满足指定条件的时间间隔返回一个事件。使用@property语法在表中搜索属性。
- 选择应用旁边的**+可选择设置多个搜索条件。默认情况下，将搜索匹配所有条件的值。通过将合并类型**从AND切换为OR来更改搜索以匹配任一条件。
- 选择性地设置最小或最大条件以查找在特定时间段内为true的公式。例如，仅查找超过一小时或少于一天的事件。
- 在编写公式时，在条件文本框中引用分析中的任何时间序列图或参数（例如，$AN < 5 && $W = $X）。
### 时间偏移事件集

通过将起始和结束时间戳向前或向后移动一段时间来修改现有事件集。
