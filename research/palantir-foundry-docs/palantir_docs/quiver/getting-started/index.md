# 入门

## 开始Quiver分析

要开始Quiver分析，展开左侧Foundry导航栏，然后点击应用程序部分中的查看全部。在分析数据部分中可以找到Quiver。

在这里，您可以通过点击**+新建分析开始一个新的分析，然后为新分析选择一个文件夹并选择保存**。您也可以打开一个现有的分析。

### 添加数据

如果您创建了一个新的分析，您可以通过点击屏幕中央的**+添加数据到分析**按钮来添加初始数据。

您可以随时从分析顶部栏的添加数据部分添加额外的数据。

添加数据部分的项目会打开Quiver的搜索栏，并使您能够搜索Ontology对象集（一个对象的集合）、单个对象或时间序列；搜索仅返回您有权限访问的结果。默认情况下，您的搜索将返回与您的关键词搜索匹配的对象集。您可以通过选择搜索栏下方的标签或使用键盘上的Tab键查看单个对象或时间序列的结果。

一旦找到所需的对象集、对象或时间序列，点击其名称将其添加到分析中。当您完成向分析中添加数据后，点击右上角的X关闭搜索栏。

在下面的示例中，我们将以下内容添加到我们的分析中：

- 一个公司的对象集，
- 一个代表3M公司的单个对象，以及
- 表示3M股票的开盘价格、收盘价格、股息和成交量的时间序列。
### 内部搜索

在搜索栏中找到与您的分析相关的数据后，您可以筛选到一个结果以在所含数据中搜索。如果您在对象类型内搜索，您可以添加该类型的对象。如果您在对象内搜索，您可以添加该对象的属性，包括作为时间序列的时间序列属性。

在下面的示例中，我们在Foundry参考项目中存储的美国交通统计局的开源航空数据中进行搜索。我们首先通过搜索栏添加Objects，然后输入机场。将鼠标悬停在机场对象类型上会显示内部搜索选项。

选择内部搜索后，我们现在可以在所有机场对象的对象名称和属性中搜索一个术语。

我们输入纽约作为搜索词，并看到两个结果：将鼠标悬停在"拉瓜迪亚机场"上，我们可以选择将添加对象到我们的画布中。

### 导入已保存的对象集

在某些情况下，您可能希望添加一个您之前在Foundry中保存的对象集，例如从之前的Quiver分析导出的对象集或从其他Foundry应用程序（如Object Explorer）导出的对象集。您可以通过在顶部菜单中的对象下选择导入已保存的对象集来添加之前保存的对象集。了解更多关于导入和导出对象集的信息。
