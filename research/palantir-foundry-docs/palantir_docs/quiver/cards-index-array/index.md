# 数组卡片

返回:卡片索引

本节中的卡片返回并显示数组值。

- 创建数组
- 拆分
- 阶梯数组
- 数组排序
- 唯一值
- 索引处的值
- 数组包含
- 范围起始
- 范围结束
### 创建数组

通过手动添加值或引用现有数组来定义数组。

### 拆分

从字符串输入返回字符串数组，并在分隔符字符串上拆分。

### 阶梯数组

从起始值、结束值和步长返回数值数组。

### 数组排序

对数组进行排序。

### 唯一值

返回一个包含输入数组中唯一值的数组。

### 索引处的值

返回输入索引处的值。

### 数组包含

如果输入数组包含指定值，则返回True。

### 范围起始

从范围中获取起始值。

### 范围结束

从范围中获取结束值。
