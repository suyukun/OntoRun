# 时间和数值范围

时间和数值范围在使用时间序列数据分析现实世界现象时常被使用，例如在制造优化或金融市场分析中。范围可以用于突出和深入分析数据中的异常，如观察到问题的特定时间段或设备在最佳容量下运行的温度范围。范围还可以通过捕捉特定时间段或数值范围的上下文来丰富时间序列数据，如设备维护期间的时间段。

## 保存新范围

要从时间序列图表中保存新范围：

- 将光标移到图表上，并通过在图表上拖动光标选择一个范围。您可以选择垂直、水平或框选范围。
- 选定的范围将以蓝色高亮显示，选择菜单将自动弹出。如果选择菜单已折叠，请选择...查看菜单选项。
- 从选择菜单中选择保存新范围以创建新范围。此操作有以下后果：一个范围参数将被添加到参数侧面板，并被配置为图表的范围参数。添加的范围参数类型（时间范围或数值范围）取决于进行范围选择的轴（时间轴或数值轴）。当选择的范围是框选时，将添加两个范围参数并为图表配置。选定的范围颜色将从蓝色更改为不同颜色，表示此范围已作为范围参数保存。您可以通过在参数面板或卡片编辑器中选择变量名称来更改范围颜色。范围参数将以选定范围边界作为起始和结束时间戳/值。更改范围参数的起始或结束值将更新图表上高亮显示的范围。
- 一个范围参数将被添加到参数侧面板，并被配置为图表的范围参数。添加的范围参数类型（时间范围或数值范围）取决于进行范围选择的轴（时间轴或数值轴）。当选择的范围是框选时，将添加两个范围参数并为图表配置。
- 选定的范围颜色将从蓝色更改为不同颜色，表示此范围已作为范围参数保存。您可以通过在参数面板或卡片编辑器中选择变量名称来更改范围颜色。
- 范围参数将以选定范围边界作为起始和结束时间戳/值。更改范围参数的起始或结束值将更新图表上高亮显示的范围。
## 更新范围值

要更新现有范围：

- 进行新的范围选择。
- 从选择菜单中选择移动现有范围。
- 选择要更新的范围。
## 以参数控制范围

Quiver中的时间和数值范围由不同的参数类型控制：

- 时间范围参数由起始和结束时间戳定义。
- 数值范围参数由起始和结束值定义。
了解更多关于如何参数化分析。

## 在多个图表中使用相同范围

您可以从时间范围参数编辑器或图表编辑器中将范围参数添加到多个图表。

要从时间范围参数编辑器添加时间范围，请从参数侧面板中选择范围，然后导航到显示选项卡。可见性部分包含所有该范围可以添加的兼容图表。选中图表旁边的复选框以添加范围。将鼠标悬停在列表中的图表上会显示导航到图表编辑器或隐藏该图表上范围（如果已添加范围）的选项。列表的标题中提供批量操作，允许快速将范围添加或隐藏在所有图表上。

要自动将范围添加到新图表，切换自动将此范围添加到新图表。一旦切换开启，可以自定义默认可见性。

要从图表编辑器添加范围，请打开所需图表的编辑器面板，并在范围部分下选择添加范围。

## 使范围具备上下文

默认情况下，Quiver将新时间范围和数值范围命名为“时间范围参数”和“数值范围参数”。考虑为范围赋予有意义的名称，以帮助跟踪每个范围代表的内容（例如，“维护窗口”或“最佳输出”）。

要重命名范围，请打开参数侧面板并选择参数名称。编辑名称，然后选择回车以保存更改。

此外，请考虑配置范围参数的提示和帮助文本，这些在将范围参数添加到仪表盘时是可见的。

## 使用范围计算范围统计

您可以在时间范围参数编辑器的绘图统计选项卡中查看范围统计（最小值、最大值和平均值）。选择计算统计后，将显示在时间序列图表中使用此范围的绘图的指标。统计仅为具有一个时间轴和一个数值轴的绘图计算，不兼容的绘图将不显示。将鼠标悬停在绘图或图表上，将显示导航到各自编辑器的选项。

您还可以使用范围选择或已保存范围与变换表一起计算范围统计，如最大值、最小值和平均值。范围选择，与已保存范围不同，不会被持久化；它们提供了一种快速查看不同范围统计的交互方式。

要在变换表中使用图表范围选择：

- 在图表上选择一个范围，然后选择“保存X轴选择”或“保存Y轴选择”。
- 选择添加变换以添加一个筛选到时间范围变换。
- 设置输入时间序列为时间序列列，时间范围为图表范围选择。
- 点击添加变换以为您希望计算的每个指标添加一个时间序列数值聚合。
- 在图表上选择不同的范围，以查看该范围的计算统计。
## 使用范围比较多个时间段的序列

您可以使用时间范围在不同时间段比较一个序列（或多个序列）。这通过使用范围创建筛选时间序列绘图和相对时间序列绘图来实现。创建筛选绘图可以隔离范围内的序列数据，而相对时间绘图可以在多个时间段视觉上对齐序列。下图展示了使用筛选和相对时间绘图来可视化AAPL股票在多个年份的开盘价的结果。

如上所述的相对比较视图可以直接从所需的时间范围创建。要从范围创建相对时间绘图，从参数侧面板选择范围，并导航到筛选绘图选项卡。从创建筛选绘图下拉菜单中选择所需绘图，然后选择相对时间序列绘图。将使用范围和选定绘图创建筛选绘图，然后将其用作新相对时间绘图的输入。对所有您想比较的序列和时间范围重复此过程。您也可以选择仅通过使用相同的下拉菜单选择筛选时间序列绘图并选择源绘图来创建筛选绘图。使用范围创建的所有筛选和相对绘图都显示在选项卡的当前筛选绘图部分。
