# 在分析中使用仪表盘

在某些情况下，将仪表盘作为卡片添加到您的Quiver分析中可能会很有用。例如，考虑一个您反复使用的可视化，配置相同但输入值不同。为了节省时间，您可以创建一个仅包含此图表的仪表盘并定义其输入。请注意，仪表盘需要已发布，然后才能将其添加到分析中。有两种方法可以将已发布的仪表盘添加到您的分析中：

- 从仪表盘侧边面板中，使用仪表盘旁边的**+**按钮将其添加到分析中。
- 从分析模式中，在顶部菜单中选择显示，然后选择导入已发布的Quiver仪表盘。
当仪表盘被导入到分析中时，它将显示在一个卡片中。在卡片编辑器中，您可以选择要显示的仪表盘，选择仪表盘版本（如果启用了自动更新，编辑器将始终显示最新版本），并配置任何仪表盘输入。
