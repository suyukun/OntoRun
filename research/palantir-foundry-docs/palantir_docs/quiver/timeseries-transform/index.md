# 变换时间序列

Quiver提供了广泛的时间序列变换，这些变换将时间序列作为输入并返回新的时间序列，并以时间序列图的形式呈现。

例如，使用时间序列变换，您可以：

- 使用滚动汇总平滑序列。
- 应用自定义数学公式。
- 计算时间序列的导数。
- 合并或合并多个时间序列。
可用变换的文档可以在时间序列操作页面找到。

## 应用时间序列变换

可以通过将变换卡片添加到分析中，或使用变换表对一组时间序列批量应用变换。

### 应用单个时间序列变换

添加时间序列变换的最简单方法是通过时间序列图的下一个操作菜单。所有时间序列变换都可以在变换类别下找到。

或者，打开搜索栏，搜索所需的变换并将其添加到画布上。

### 批量变换时间序列

要批量应用时间序列变换，请使用变换表。

变换表可以以不同形式将时间序列作为输入，并提供多种方法来变换时间序列数据：

- 时间序列作为列：对时间序列列应用变换。此列可以来自对象集的时间序列属性，或者当使用时间序列图作为变换表的输入时。
- 单个时间序列数据点：通过使用时间序列图作为输入对变换表中的时间序列数据点应用变换。
