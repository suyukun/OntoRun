### Foundry 数据集 (Beta)

在您的分析中可视化 Foundry 数据集。若在 Quiver 中打开的数据集具有特定的时间序列模式，则只能在时间序列预览卡片中使用。

Foundry 数据集卡片是一项 Beta 功能，可能在您的 Foundry 实例中不可用。

### 列表

显示对象集中所有对象的列表。列表卡片对于希望在 Object Explorer 中打开单个对象时非常有用。

### 数据透视表

数据透视表用于在对象集中以表格形式显示汇总数据。对象属性被选择为行和列属性；生成的数据按您在编辑面板中设置的配置根据这些对象属性进行分组和汇总。
数据透视表主要通过三种方式进行配置：行属性、列属性和汇总。

#### 行属性

行属性是具有值的属性，这些值将成为表格的行标题。仅当值集有数据时，行才会出现在表格中。

#### 列属性

列属性是具有值的属性，这些值将成为表格的列标题。仅当值集有数据时，列才会出现在表格中。

#### 汇总

汇总配置允许您设置每个单元格的数据汇总方式，这些单元格按行和列属性分组。汇总可用的五种配置选项包括：

- 计数
- 数值属性之和
- 数值属性的最小值
- 数值属性的最大值
- 近似唯一计数
或者，您可以选择切换到公式指标来编写由上述汇总组成的自定义指标。您还可以选择**+添加系列**来配置任意数量的汇总。这些汇总将并列出现，其各自的列标题位于表示列属性值的标题下方。
例如，假设您有一个美国城市每日降水量的数据集。如果选择城市作为行属性，年份作为列属性，降水量之和作为汇总，那么列标题将是纽约、芝加哥和洛杉矶，行标题将是2015、2016和2017，值将是该城市在那一年中的降水总量。如果未指定行或列属性，则汇总将计算所有对象的值。

行属性和列属性的唯一区别在于它们出现在表格的哪一边。例如，如果您配置了行属性A和B而没有列属性，数据将与您配置了行属性A和列属性B或列属性A和B而没有行属性的数据相同。仅数据的设计不同。

您可以使用数据透视表筛选数据。通过点击标题选择单个单元格或整行和列。点击深入选定内容将数据筛选到具有您选择的行和列的属性值的数据。按住 shift 或 command 键可选择表格的多个区域。

您还可以激活切换按钮以显示总计，在行的右侧（对于行）或底部（对于列）显示汇总数据。请注意，这些汇总适用于该组行或列属性的所有数据；它不是汇总的汇总。选择此选项旁边的信息图标以更深入地解释总计的计算方式。

### 表格

显示所选对象的所选属性作为表格的行，并在需要时使用此表格手动选择某些对象以进行深入分析。表格还可以包括链接对象的属性以及显示为迷你图的对象的时间序列（度量或时间依赖属性）。

### 变换表格

变换表格是允许用户合并和汇总对象、派生属性并对派生属性执行操作、在线编辑表格数据以及执行批量时间序列操作的数据结构。有关变换表格中可用变换的完整列表，请参阅变换表格变换索引。
