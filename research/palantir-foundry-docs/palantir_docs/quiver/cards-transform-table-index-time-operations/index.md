### 日期偏移

根据持续时间偏移日期。在指定的周数、天数、小时、分钟、秒或毫秒之前或之后，返回一个新的时间列。

### 日期/时间偏移

偏移输入时间戳。

### 静态时间

使用静态时间作为列。

### 日到日期

创建从输入日期的00:00起始到输入日期的范围。

### 周到日期

创建从输入日期所在周的第一天（由用户的区域设置定义为星期一或星期日）的00:00起始到输入日期的日期范围。

### 月到日期

创建从输入日期所在月的第一天的00:00起始到输入日期的范围。

### 年到日期

创建从输入日期所在年的1月1日的00:00起始到输入日期的范围。

### 星期几

从日期中获取星期几作为数字。

### 月中的一天

从日期中获取月中的一天作为数字。

### 年中的一天

从日期中获取年中的一天作为数字。

### 一天中的小时

从日期中获取一天中的小时作为数字。

### 月份

从日期中获取月份作为数字。

### 年份

从日期中获取年份作为数字。

### 字符串到日期

将日期的字符串表示，例如18/07/2023或July 18, 2023转换为日期类型。设置被用于在的时区为特定时区、本地或UTC。非必填，还可以提供用于解析的日期格式dayjs 格式 ↗。

### 数字到日期

将日期的数字表示（Unix秒或毫秒，表示UTC中的时间戳）转换为日期类型。这个变换很有用，例如，将对象集日期属性上的数值聚合返回值（数字数据类型）转换回日期类型，以作为其他变换或卡片的输入。
