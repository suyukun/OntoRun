# 全局样式表

除了允许您在应用程序级别为您的 Slate 应用程序应用样式外，样式编辑器还允许您创建和添加全局样式表到您的 Slate 应用程序。全局样式表是在 Foundry 的空间级别存在的样式表，可以在同一空间内的其他 Slate 应用程序中共享，使您能够为所有 Slate 应用程序创建统一的外观。

对于存储在空间之外的应用程序（例如在私人文件夹中），全局样式表不可用。用户需要在空间上拥有slate:edit-stylesheet角色以创建或更新全局样式表，并在空间上拥有slate:view-stylesheet以使用全局样式表。

在您的 Slate 应用程序中启用全局样式表将样式表应用于应用程序，就像它们被添加到样式编辑器的本地样式中一样。这允许这些样式在同一组织中的项目之间重用，以便在给定的组织或项目中的某些或所有应用程序中保持一致的外观和感觉。对这些全局样式表所做的更改适用于所有使用它们的 Slate 应用程序，这意味着如果基础样式指南被更改，编辑者将不需要更改他们所有的应用程序。

如果您在空间上有正确的权限，样式编辑器将如下所示：

全局样式表仅支持 CSS，不支持 Less。

默认情况下，样式表不会自动添加到 Slate 应用程序中。右上角的在应用程序中使用开关将样式表应用于当前的 Slate 应用程序；当开关打开时，您需要保存以便更改被保存到应用程序中。

一旦在应用程序中启用了样式表，对样式表的编辑将立即反映并显示在页面中。但是，编辑不会被保存到全局样式表，直到您在右上角选择更新按钮。这允许您测试对样式表的更改而不会自动影响可能正在使用此样式表的其他 Slate 应用程序。

全局样式表可能被多个 Slate 应用程序使用。在编辑或删除全局样式表时要小心，以确保任何更改都是有意应用于所有 Slate 应用程序，而不仅仅是当前查看的应用程序。
