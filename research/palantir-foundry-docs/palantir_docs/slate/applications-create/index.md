# 创建和发布应用程序

要创建一个新的Slate应用程序，请导航到项目视图并选择+新建 > Slate应用程序。您也可以从导航侧面板打开Slate并选择+ 新建应用程序。

## 创建集成应用程序

要创建集成应用程序，在出现的创建新应用程序弹出窗口中选择集成应用程序选项。添加位置、标题和永久链接以在唯一的URL中标识应用程序。

接下来，了解如何将您的应用程序结构化为页面，以优化可扩展性、可维护性和性能。

## 创建公共应用程序

创建和编辑新的公共应用程序需要权限，如权限中所述。要创建新的公共应用程序，请选择公共应用程序选项。公共应用程序只能在项目中创建，不能存储在私人文件夹中。模板不适用于公共应用程序。

必须首先发布公共应用程序，未认证用户才能查看。

### 发布公共应用程序

为了使新创建的公共应用程序可供使用，必须通过版本对话框或保存旁边的下拉菜单进行发布，假设之前的所有编辑都已保存。与严格的内部应用程序相比，公共应用程序不能自动发布，并且每次发布的版本都需要确认，以防止意外发布。

任何时候只能发布一个版本。标签对未认证用户不可访问，这些用户将被重定向到已发布版本或在没有已发布版本时显示出错信息。

### 取消发布公共应用程序

已发布的应用程序可以随时取消发布，当不再需要时。未发布的应用程序可以由具有所需资源权限的认证用户访问，但未认证用户无法访问。

要取消发布，请在编辑模式下打开版本对话框，并导航到列表中的已发布版本，以地球图标表示。打开上下文菜单并选择取消发布以获得屏幕指导。
