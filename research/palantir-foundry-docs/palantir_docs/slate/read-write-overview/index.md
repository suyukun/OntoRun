# 概述

Slate 可以从 Foundry 和外部系统发送和接收数据。对象集、对象上下文和Foundry 函数提供了对 Ontology 的便捷读取访问，而操作微件专门允许用户将数据写回 Ontology。

查询提供了对各种预配置端点的通用访问。查询中的每个数据源都必须通过管理面板进行配置。配置完成后，用户可以利用查询将数据直接从其他服务拉入其应用程序，或触发后请求将数据直接写入外部数据库。查询的可用性是 Slate 中导入和导出数据的最灵活和开放的功能。

所有导入的数据在 Slate 中都以 JSON 格式表示，从而将所有数据源的数据统一为一个结构。数据一旦进入 Slate，就失去了这种上下文，可以自由操作以生成所需的工作流。

导入和导出组件可以配置为使用变量、函数、微件或其他查询的输出，并动态地读取和写入数据。与对象集或操作相比，查询可以构建为不受预配置交互限制的通用形式。相同的查询可能首先创建一个新的数据点，但第二次运行查询时会更新先前创建的数据点。

对象集、对象上下文、Foundry 函数和操作更容易设置并提供明确的轨道，但相应的灵活性较低。
