# 通过操作进行数据输出

您可能希望配置您的Slate应用程序，以便用户在交互式应用程序中的工作被“写回”Foundry中的底层数据资产。在Slate中执行数据输出的推荐方式是通过Ontology操作和操作微件。或者，您可以通过查询直接将数据写回到Phonograph。

除了通过平台选项卡从Ontology层读取数据外，Slate还支持通过操作使用操作微件写回到Ontology。

Slate对Ontology的数据输出是通过微件配置的，而不是通过平台选项卡，这允许开发人员非必填利用自动生成的操作表单。这使得开发人员可以避免从Slate微件中重新创建所有表单元素。

在此设置中，通常将操作微件放置在对话框容器中，并在需要显示表单时通过Slate事件触发容器打开。

或者，可以关闭表单显示，在这种情况下，微件配置作为模板，根据用户在应用程序内其他微件中的交互和输入收集要提交的值。然后通过事件触发提交，通常来自一个按钮微件。

操作微件还提供Slate事件的挂钩，以广播操作的验证状态以及成功或失败的提交。

查看操作文档以获取有关如何构建和配置操作的更多详细信息，以及查看操作微件文档以获取Slate中微件配置的详细信息。
