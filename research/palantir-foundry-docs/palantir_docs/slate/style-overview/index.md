# 概述

Slate提供了广泛的自定义样式选项，使您能够为用户创建独特的体验，以符合您的企业形象或尝试新的设计。在Slate中，您所看到的一切都可以更改，从画布的背景颜色到按钮的字体和边框半径。

要开始使用自定义样式，您可以应用样式到单个微件。这允许您快速迭代并在本地测试样式，而不会影响应用程序的其他部分。如果您希望为您的应用程序创建一致的外观和感觉，可以定义可以添加到单个微件的CSS类。

此外，Slate的全局样式表使您能够在文档之间共享样式。这些样式表的工作方式类似于自定义样式表；然而，全局样式表可以导入并更新到多个文档中，确保为整个组织提供流畅的体验。

无论您是想创建符合品牌形象的专业外观和感觉，还是想尝试新的设计，Slate的自定义样式都能轻松实现您的目标。
