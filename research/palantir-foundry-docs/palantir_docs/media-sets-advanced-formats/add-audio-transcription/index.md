# 转录音频媒体集

本指南将介绍如何在Foundry中使用媒体集进行音频转录。

## 第1部分：在Foundry中将音频文件导入为媒体集

首先，您应将音频文件导入为媒体集。有两种方法可以实现：

- 直接上传
- 数据连接
导入后，您将能够查看音频媒体集。

## 第3部分：保存管道输出

选择所需的管道输出。您可以输出为数据集或选择通过选择对象类型输出来对输出进行本体化。创建对象类型将允许您在Workshop中使用您的管道输出。
