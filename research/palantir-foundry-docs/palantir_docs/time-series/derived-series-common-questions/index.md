# 常见问题

## 哪些 Quiver 卡片支持在派生序列逻辑中使用？

以下 Quiver 卡片支持在派生序列逻辑中使用：

- Object 时间序列属性
- 筛选时间序列
- 导数
- DSP 筛选
- 积分
- 取样
- 段变换
- 时间序列公式
- 合并时间序列
- 累计聚合
- 周期性聚合
- 滚动聚合
- 时间序列移位
Quiver 卡片即使不输出时间序列也是支持的；然而，它们不会动态更新。卡片在创建时解决的任何值将在派生序列逻辑中固定。

## 为什么我会收到关于多个根对象的错误？

如果您在对话框中收到关于多个根对象的错误，您的分析可能是从一个传感器对象类型开始，并使用了两个不同的单个对象进行比较。例如，您可能从传感器对象类型中提取并比较了传感器对象Inlet pressure和Outlet pressure，而不是Machine 1根对象类型。要创建派生序列，您需要从根对象实例开始。

查看设置派生序列的要求以了解为什么派生序列必须从根对象的角度生成。

## 我可以将相同的派生序列模板应用到不同的对象上吗？

可以。逻辑和计算是模板化的，因此可以从具有相同对象类型的任何绑定对象的角度计算结果。查看关于在Ontology中存储派生序列的部分，并注意相同的编目模板被应用到不同的Machine对象或传感器对象上。

## URL 中的编目模板 RID 和派生序列 RID 有什么区别？

派生序列 RID 是指持有资源名称、描述和其他元数据的 Quiver 资源。在派生序列管理页面上列出的编目模板 RID 是在运行时计算派生序列数据时所使用的模板逻辑的引用。查看关于在Ontology中存储派生序列的部分以获取更多详细信息。

## 如果我的输入系列发生更改，派生系列会相应更新吗？

由于派生系列是在读取时计算的，派生系列将显示输入系列的任何可用更新。例如，在Quiver中可见的对输入系列的任何更改也会反映在派生系列中。

## 我可以将我的派生系列用作另一个派生系列的输入吗？

可以，派生系列可以嵌套并用于计算另一个派生系列。您可以像使用原始时间序列一样使用派生系列。请确保遵循派生系列创建要求，以便新派生系列按预期运行。

## 当我更新派生系列的逻辑时，使用该派生系列的应用程序也会相应更新吗？

派生系列的优势在于无需消耗管道资源即可立即更新逻辑。渲染派生系列的应用程序（通常是Quiver分析或嵌入在应用程序中的Quiver仪表盘）将使用更新的模板逻辑计算派生系列。

## 一个TSP可以包含派生系列和非派生时间序列吗？

可以！一个TSP可以包含混合值，这些值可以是（非派生）时间序列的系列ID，也可以是派生系列的Codex模板RID。这通常用于传感器对象类型。如果您的TSP由多个同步支持并包含派生系列，那么派生系列的Codex模板RID不应采用合格系列ID格式。
