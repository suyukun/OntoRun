# 时间序列同步

时间序列同步保存与任何数量的时间序列（由seriesIds作为键）相关的时间-值对，从而在每个序列和相关的时间-值对上实现高效的索引。时间序列同步由数据集或流支持，并且是时间序列属性的支持数据源。

当 Foundry 在给定对象时间序列属性上解析时间序列属性时，将在该属性的数据源中搜索属性值中包含的seriesId，并返回其关联的时间序列数据。

时间序列同步需要以下列：

- seriesId:序列的标识符（字符串）。
- timestamp:关联值发生的时间（timestamp或long）。对于 long 类型的时间列，必须指定单位。可用单位包括秒、毫秒、微秒或纳秒。
- 对于 long 类型的时间列，必须指定单位。可用单位包括秒、毫秒、微秒或纳秒。
- value:在给定时间戳上的序列值（double、integer、float或字符串）。
- 摄取时间:（非必填）：流数据点被摄取的时间（timestamp）。
如果时间序列属性由多个时间序列同步支持，则属性值中的seriesIds必须完全包含在单个时间序列同步中。

创建时间序列同步时构建的投影所需的变换配置文件的大小会随着输入数据集的大小而变化。对于大于10 TB的数据集，我们建议将您的数据集拆分为多个数据集，按序列标识符分区，然后从这些较小的数据集中创建同步。

## 时间序列目录应用程序

时间序列目录应用程序用于高级时间序列同步配置。可以通过打开时间序列同步资源或手动导航到https://<domain>/workspace/time-series-catalog-app来访问该应用程序。

高级时间序列配置包括以下功能：

- 停止从输入数据集或流继承权限标记。查看我们的时间序列权限文档以获取更多详细信息。
- 设置Spark或Flink计算配置文件。我们建议使用默认计算配置文件。如果没有添加配置文件，将使用默认计算配置文件。
- 我们建议使用默认计算配置文件。如果没有添加配置文件，将使用默认计算配置文件。
- 设置一个计划，以便在输入数据集更新时自动搭建时间序列同步。查看我们的事件触发器和计划文档以获取更多信息。
- 覆盖当前时间序列同步中存在的指定时间序列同步中的seriesIds。这是为传统时间序列设置保留的高级功能。
