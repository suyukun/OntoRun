# 在 Foundry 中使用时间序列

一旦您的时间序列设置完成后，使用时间序列 Object 类型在以下列出的 Foundry 应用程序中创建可视化和分析。

Quiver：创建互动的时间序列仪表盘和分析。下面的示例展示了机器温度读数随时间变化的分析。

Workshop：以时间序列地图、图表和指标卡片搭建高质量的互动应用程序。

Vertex：与时间序列互动，以可视化系统中的变化，并进行深入分析，以查看过去决策的影响、探索当前状态及识别未来潜力。

Foundry Rules：编写规则以识别数据中感兴趣的时间段。

Map：查看和分析与地理空间 Object 相关联的时间序列数据。下面的示例中，飞机传感器读数与地图一起显示，展示了读数发生的位置。
