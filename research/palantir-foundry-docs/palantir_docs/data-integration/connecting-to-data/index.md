# 连接数据

从 Foundry 中获取价值的第一步是将其连接到您的组织的数据源。Foundry 的数据连接工具支持全范围的标准企业数据源，包括基于云的 Object 存储、文件系统、数据库和数据仓库。

根据您需要访问的数据类型，可以使用不同的 Foundry 应用以多种方式连接数据。

## 数据连接

连接到源以运行批处理、流媒体、媒体和 CDC 同步并使用虚拟表。

数据连接框架设计用于随时间管理数据，通过使用数据集交易管理的离散版本。该框架能够提供跨时间的数据版本的完整血统，使您了解哪些同步任务生成了给定数据集的哪些版本。在无法在每次同步时加载完整数据的情况下，它还支持仅同步所需的数据。

数据连接中的细粒度安全性允许跨不同团队的联邦管理数据同步。同步集合，甚至单个数据同步，可以仅对特定团队（通过基于角色或分类的访问控制定义）可见或可编辑。了解更多关于保护数据基础的信息。

您可以独立于实际的同步定义管理同步元数据。这允许完全分支新的配置，在该分支中新的同步被隔离并在影响任何下游变换任务之前进行测试。

## HyperAuto

为了超越简单的数据同步解决方案，Palantir HyperAuto实现了对软件定义数据集成 (SDDI) 的支持。该工具集使组织不仅可以连接到常见的 ERP 和 CRM 系统，还可以以空前的速度以编程方式生成清理、规范化和协调数据集的数据管道。然后，该数据资产可以导入Ontology，将数据转化为操作价值。

## 外部变换

使用 REST API 执行计划的同步并导出到外部系统。

如果您想连接到外部来源以创建同步和导出数据，建议使用代码库来编写使用 REST API 的外部 Python 变换。您还可以将数据集输入和媒体集输出添加到您的变换中。
