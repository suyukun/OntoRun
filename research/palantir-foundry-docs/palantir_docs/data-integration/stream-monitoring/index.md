# 流监控 [Beta]

流监控使您能够对管道的健康状态进行警报。

当管道具备以下条件时，被视为“健康”：

- 从源系统摄取新记录。
- 处理并将记录写入面向用户的Foundry应用程序。
您可以通过设置摄取和输出警报来监控管道的健康状态，当摄取或输出的记录数量在某个时间段内低于用户定义的阈值时，会触发警报。

例如，如果您的流在过去五分钟内摄取了零记录，可以设置摄取监控器发出警报，而如果您的流在过去30分钟内输出了少于1000条记录，可以设置输出监控器发出警报。

- 监控器应仅应用于具有恒定记录流的流。对于不接收恒定数据流的流，例如仅在工作时间发送的记录，这些测试版监控器不支持。
- 支持5分钟和30分钟的时间段。
## 创建监控器

- 打开数据健康应用程序。
- 选择监控视图选项卡。
- 创建或选择现有的监控视图。
- 导航到管理监控器选项卡。
- 选择添加新警报。
- 选择添加监控规则。
## 配置摄取监控器

摄取监控器确保：

- 您的源系统正在生成并发送记录到Foundry。
- Foundry正在将记录写入摄取流的实时视图。
要进行配置：

- 按照创建监控器的说明。
- 选择流数据集作为资源类型。
- 添加要监控的摄取流并选择下一步。
- 在摄取流监控器卡片中选择+ 添加。
- 选择摄取记录数监控器，持续时间为5或30分钟。
- 设置您的阈值并选择下一步。
- 查看您的监控器并选择保存监控规则。
示例：

- 摄取记录数持续时间为五分钟，阈值为零：当您的流在过去五分钟内向实时视图写入零记录时发出警报。
- 摄取记录数持续时间为30分钟，阈值为1000：当您的流在过去30分钟内向实时视图写入少于或等于1000条记录时发出警报。
## 配置输出监控器

输出监控器确保您的管道：

- 处理已摄取的记录。
- 将这些处理过的记录写入面向用户的Foundry应用程序。
在流监控器处于测试版时，时间序列和地理时间序列是唯一可监控的数据格式。

### 时间序列

要监控写入时间序列的记录，您需要在时间序列同步上设置警报。

- 按照创建监控器的说明。
- 选择时间序列同步作为资源类型。
- 添加要监控的时间序列同步并选择下一步。
- 在监控器卡片中选择+ 添加。
- 选择写入Epoch的点数，持续时间为5或30分钟。
- 设置您的阈值并选择下一步。
- 查看您的监控器并选择保存监控规则。
示例：

- 写入时间序列数据库的点数持续时间为五分钟，阈值为零：当您的时间序列同步在过去五分钟内写入零记录时发出警报。
- 写入时间序列数据库的点数持续时间为30分钟，阈值为1000：当您的时间序列同步在过去30分钟内写入少于或等于1000条记录时发出警报。
### 地理时间观察

要监控地理时间观察，您需要在支持观察数据集上设置警报。

- 按照创建监控器的说明。
- 选择地理时间观察作为资源类型。
- 添加要监控的观察数据集并选择下一步。
- 在监控器卡片中选择+ 添加。
- 选择发送的地理时间观察，持续时间为5或30分钟。
- 设置您的阈值并选择下一步。
- 查看您的监控器并选择保存监控规则。
示例：

- 发送的地理时间观察持续时间为五分钟，阈值为零：当您的地理时间同步在过去五分钟内发送零个观察到地理时间时发出警报。
- 发送的地理时间观察持续时间为30分钟，阈值为1000：当您的地理时间同步在过去30分钟内发送少于或等于1000个观察到地理时间时发出警报。
- 确保您在支持观察数据集上设置监控器，而不是错误数据集。
- 发送的地理时间观察仅确保记录已从地理时间摄取发送。这并不保证地理时间服务在摄取后已处理记录。
## 查看指标

要查看监控器下的指标，请在监控视图的管理监控器选项卡中选择监控规则行。

指标仅适用于具有单一目标范围的流或时间序列监控器。

## 监控通知

您可以通过监控视图的管理订阅选项卡配置通知。

要设置电子邮件警报：

- 选择将用户添加到组。
- 搜索并选择一个用户。
- 选择要通知的严重性。
要设置PagerDuty警报：

- 选择创建新的PagerDuty集成。
- 设置集成名称。
- 在PagerDuty中创建一个集成。
- 复制并粘贴集成密钥到集成密钥中。
- 选择警报的严重性。
## 触发警报

您可以在监控视图的故障排除警报选项卡中查看触发的警报。
