# 创建RFC连接

在本节中，将创建一个RFC目标连接，以用于从远程SAP系统提取数据。

- 要创建RFC连接，输入SM59事务代码。
- 创建一个新的ABAP连接，并选择3作为连接类型。
- 在技术设置选项卡中，根据SAP源系统（如ECC实例）的值填写目标主机和系统编号。
- 在登录与安全选项卡中，填写登录凭证和客户端号码（三位数）。SAP在同一张表中存储测试和生产数据，并使用一个客户端 (MANDT)列来使不同的客户端（例如，测试和生产）仅检索相关的客户端数据。对于生产环境，输入生产客户端的客户端号码。
- 保存连接配置。
- 从应用工具栏授权测试并测试连接。
