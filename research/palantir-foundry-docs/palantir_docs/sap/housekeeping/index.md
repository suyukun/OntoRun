# 设置和配置清理任务

清理任务被用于在指定时间点之前删除日志表数据，并关闭未确认的请求以及删除未使用的订阅。

要打开清理设置，请使用事务代码/n/PALANTIR/COCKPIT_03。

## 删除日志表

删除日志表复选框默认应保持选中，以防止日志表无限增长并可能填满所有可用磁盘空间。

启用后，程序将删除表/PALANTIR/LOG_02和/PALANTIR/PAG_02中的记录。程序还会删除/PALANTIR/LOG_01表中的记录，但不会删除此表中的初始化请求。更多信息，请参见下面的删除带有 INIT 请求的 LOG_01 表。

- **创建日志超过（天）和数据间隔（天）：**这些设置应结合使用，以定义删除日志记录的滚动时间窗口。默认设置分别为30天和10天，这意味着当任务运行时，将删除30天到40（= 30 + 10）天之间的任何记录。
- **仅当数据在 Foundry 中时：**这表示只有已确认传输到 Foundry 的页面文件将被删除。
## 关闭已取消 SLT 同步的 SLT 请求

关闭 SLT 请求复选框默认应保持未选中。Palantir 支持团队可能会要求选中此选项以解决已知的 SLT 问题，该问题可能导致由于 ODQDATA 表中的请求过多而导致系统挂起。

启用后，程序会找到在给定日期范围内创建的 SLT 订阅请求，并使用 SLT 关闭功能将请求的ODQMON状态更改为已完成。当请求在ODQMON中设置为已完成时，可以通过ODQMON的增量队列清理任务删除它。

- **SLT 请求的日期范围：**在此日期间隔内创建的 SLT 增量请求将在ODQMON中设置为已完成。
## 重置未使用订阅的 SLT 指针

删除 SLT 订阅复选框默认应保持未选中。Palantir 支持团队可能会要求选中此选项以解决已知的 SLT 问题，该问题可能导致由于 ODQDATA 表中的请求过多而导致系统挂起。

启用后，程序将删除历史ODQMON订阅。

- **最后请求超过（天）：**表示超过此天数的订阅将被删除。
## 删除带有 INIT 请求的 LOG_01 表

删除 LOG_01 INIT 请求复选框默认应保持未选中。Palantir 支持团队可能会要求选中此选项以解决/PALANTIR/LOG_01表过大时的罕见情况。

启用后，此程序将删除/PALANTIR/LOG_01表数据，包括初始化请求。

- **创建日志超过（天）：**表示超过此天数的记录将被删除。默认值为30天，这意味着所有超过30天前创建的数据将从/PALANTIR/LOG_01中删除。
