# Palantir Foundry Connector 2.0 以 SAP 应用的管理控制台

Palantir Foundry Connector 2.0 以 SAP 应用 ("Connector")管理控制台是一个用于管理 Connector 参数的界面。SAP 用户可以通过 SAP GUI 使用/n/PALANTIR/COCKPIT事务代码访问。

## 管理

此选项卡提供访问用于管理 Connector 的主要工具。

### 维护配置表

核心 Connector 参数在此配置表中维护。这些参数控制 Connector 的行为。

这些参数在有关性能参数的文档中进行了解释，关于如何配置远程代理和注册 Connector的文档中，以及用于解决已知 SAP 错误的参数的文档中。

### 设置默认配置参数

默认参数可以在 Connector 的参数表中维护。这些参数在系统中作为默认值，除非在其他地方被覆盖。

| Parameter ID | 参数名称 | 参数值 |
| --- | --- | --- |
| SYSTEM_THRESHOLD | CPU_LOAD | 95 |
| SYSTEM_THRESHOLD | MEMORY_FREE | 11 |
| PAGE | PAGESIZE | 50000 |
| SLT | PAGESIZE | 52437000 |
| SLT | FETCH_OPTION | XML |
| SLT | DEBUG_MODE | OFF |

### 用户授权检查

此工具检查用户是否拥有/PALANTIR/SERVICE_USER角色中定义的所有必要授权。

## 数据传输监控

此选项卡包含用于控制 Connector 如何记录数据传输的设置。

### 调整日志表

此选项将调整日志表以安排任务清除日志。当从版本 v1.4.0 或更早版本升级时，此选项非常有用。数据库表中添加了新字段；这将从现有记录填充新字段。如果您从版本 1.4.0 或之后开始运行 Foundry 同步，则无需使用此选项。

### Foundry 同步日志报告

此选项报告所有 Foundry 同步的日志头、日志项和页面信息。

## 清除日志

此选项卡包含用于控制日志保留的设置。

### 计划任务

此选项安排任务以清除日志表。参数如下：

- 恢复: 指定计划任务将在多少小时后重启。换句话说，它是计划任务的频率（以小时为单位）。默认值：24（表示任务将每天运行）。
- 低相关性数据: 指定在删除之前，项目数据（低相关性）保留多少天。项目数据包括日志项目的消息、页面项目表和增量表信息的项目数据。默认值：31（表示项目数据将在1个月后删除）。
- 高相关性数据: 指定在删除之前，头部数据（高相关性）保留多少天。默认值：365（表示头部数据将在1年后删除）。对于增量更新，此参数应至少为31。
- 仅当传输到 Foundry 时: 指定在删除项目数据时，仅删除传输到 Foundry 的数据。如果启用此参数，所有尚未传输到 Foundry 的数据也将被删除。默认值：启用。
有关更多详细信息，请参阅设置和配置内务管理

## 敏感数据

此选项卡提供用于控制如何处理敏感数据的设置。

### 加密和数据掩码配置

可以从数据掩码选项卡维护数据掩码和加密。

配置在 Object 类型、Object 和字段级别设置，使用以下参数：

- Object 类型: 源 Object 的类型。可能的输入有：TABLEBEXEXTRACTOR函数INFOPROVIDERSLT
- TABLE
- BEX
- EXTRACTOR
- 函数
- INFOPROVIDER
- SLT
- Object: Object 名称。（以上示例中使用了SFLIGHT。）
- Field: 读取后需要掩码/加密的字段。需要为输出中的每个字段创建新行。
- 掩码模式引擎: 用于模式匹配的引擎。支持正则表达式。
- 模式: 用于模式匹配的模式。留空默认匹配整个字段值。
- 掩码字符: 模式匹配后替换的掩码值。可能的输入有：清除匹配的字符 – 使用空格替换模式。'* : 用 * 字符替换模式。每个字符将替换为星号。'# : 用 # 字符替换模式。每个字符将替换为井号。
- 清除匹配的字符 – 使用空格替换模式。
- '* : 用 * 字符替换模式。每个字符将替换为星号。
- '# : 用 # 字符替换模式。每个字符将替换为井号。
- 加密算法: 加密期间使用的算法。支持的算法是 AES12CBC。
- 哈希算法: 哈希期间使用的算法。支持的算法有：MD5SHA1SHA256
- MD5
- SHA1
- SHA256
- 掩码列显示: 显示/隐藏掩码列。选项有：在同一列中显示: 掩码列将显示在原始列名称下。需要填写掩码属性。在新列中显示: 掩码列将显示在 COL_NAME_MASKED 列中。隐藏列: 掩码列将不会显示。
- 在同一列中显示: 掩码列将显示在原始列名称下。需要填写掩码属性。
- 在新列中显示: 掩码列将显示在 COL_NAME_MASKED 列中。
- 隐藏列: 掩码列将不会显示。
- 加密列显示: 显示/隐藏加密列。选项有：在同一列中显示: 加密列将显示在原始列名称下。需要填写加密属性。在新列中显示: 加密列将显示在 COL_NAME_ENC 列中。隐藏列: 加密列将不会显示。
- 在同一列中显示: 加密列将显示在原始列名称下。需要填写加密属性。
- 在新列中显示: 加密列将显示在 COL_NAME_ENC 列中。
- 隐藏列: 加密列将不会显示。
- 哈希列显示: 显示/隐藏哈希列。选项有：在同一列中显示: 哈希列将显示在原始列名称下。需要填写哈希属性。在新列中显示: 哈希列将显示在 COL_NAME_HASH 列中。隐藏列: 哈希列将不会显示。
- 在同一列中显示: 哈希列将显示在原始列名称下。需要填写哈希属性。
- 在新列中显示: 哈希列将显示在 COL_NAME_HASH 列中。
- 隐藏列: 哈希列将不会显示。
配置完成后，用户可以返回 SAP 管理控制台屏幕。

## 预筛选

全局筛选（预筛选）用于控制从 SAP 系统中提取的敏感数据。SAP 管理员可以指定预定义的筛选，这些筛选将添加到 Foundry 请求的筛选中。即使这些筛选值未在 Foundry 中的同步定义中指定，它们也会自动添加到请求中。

要指定筛选，请使用与 Foundry 同步定义中相同的语法。了解更多关于同步语法的信息。
