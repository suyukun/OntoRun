# 概述

Data Health 还允许您设置包含多个检查的检查组。您可以表示相关数据集的分组（例如物理管道）并监控管道的健康状况。

## 检查与检查组

检查组不会运行您的检查或影响检查运行的时间。相反，检查组是用户订阅特定检查集并监控检查组中数据集健康状况的一种简单方式。

您可以将自己添加为检查组的订阅者。如果您已订阅，Data Health 将检查组中的任何检查是否处于失败状态，并向您发送电子邮件摘要通知。您可以根据需要调整摘要的频率。

例如，您可能希望频繁收到关于高紧急检查管道状态的通知（例如每15分钟）。或者，您可能只希望在检查失败时收到通知，而不是在所有检查成功时收到通知 - 这可以通过仅在失败时选项实现。您还可以将摘要频率设置为每周，以减少更新频率。

订阅检查组而不是单个检查的优势在于您将收到汇总的通知摘要，而不是多封电子邮件。此外，通过检查组，您无需订阅每个单独的检查（对于较大的管道，这可能耗时），而可以订阅整个组。

订阅检查组并不会让您订阅所有单独的检查。然而，它会通过可配置的摘要通知组中的所有检查。

通过创建检查组开始。
