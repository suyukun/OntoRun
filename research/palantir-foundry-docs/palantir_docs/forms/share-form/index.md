# 将表单分享给其他用户

Foundry Forms 不再是 Foundry 上数据输入或数据输出工作流的推荐方法。相反，以 Foundry Ontology 构建用户输入工作流，将相关数据结构表示为对象类型，并通过操作配置数据输出交互。在Forms 概述文档中了解更多信息。

在分享表单之前，首先确定另一个用户适合的访问级别。有三种不同的角色可指派给其他表单用户：

- 编辑者：可以编辑文件和修改分享。
- 只读：可以查看文件内容，但不能编辑或修改分享。
- 发现者：只能看到文件名称和元数据。
您可以选择通过链接分享或手动添加用户或组来分享您的表单。

所有响应者至少必须被授予只读角色才能查看表单内容。
