# 验证器

Foundry Forms 不再是 Foundry 上数据输入或数据输出工作流的推荐方法。相反，使用 Foundry Ontology 搭建用户输入工作流，将相关数据结构表示为 Object 类型，并通过操作配置数据输出交互。请在Forms 概述文档中了解更多信息。

在 Foundry Forms 中，每个表单字段可以有一个或多个验证器来防止格式错误的输入。一些验证器的例子包括：

- **正则表达式：**值必须匹配某个正则表达式 ↗。
- **必填：**值必须填写。
- **范围：**值必须在min和max值之间。
在满足所有验证器标准之前，回应者将无法提交表单。
