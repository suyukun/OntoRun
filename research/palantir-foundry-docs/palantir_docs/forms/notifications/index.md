Foundry Forms 已不再是 Foundry 上数据录入或数据输出工作流的推荐方法。相反，使用 Foundry Ontology 搭建用户输入工作流，将相关的数据结构表示为 Object 类型，并通过操作配置数据输出交互。请在Forms 概览文档中了解更多信息。

创建表单后，您可以选择在每次提交后设置通知。
