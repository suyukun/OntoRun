# 数据支持字段

Foundry Forms 不再是 Foundry 上数据输入或数据输出工作流的推荐方法。相反，使用 Foundry Ontology 搭建用户输入工作流，将相关数据结构表示为对象类型，并使用操作配置数据输出交互。详细了解请参阅Forms 概述文档。

数据支持字段将表单链接到 Foundry 中已存在的数据。此页面讨论 Foundry Forms 中可用的七种数据支持字段类型。

## 用户下拉菜单

用户下拉菜单字段允许响应者选择一个 Foundry 用户。该字段显示用户的姓名，但记录用户 ID。用户可以配置以下选项：

- 允许多重选择。
- 如果仅有一个值可用，预填字段。
- 设置占位符。
- 隐藏下拉菜单下方所选用户的列表。
- 使用代码编辑器设置onlyUsersInGroupIds: list<string>。
## 对象下拉菜单

对象下拉菜单字段允许响应者选择给定类型的对象。此字段显示对象的标题，但记录其主键。用户可以配置以下选项：

- 根据属性值指定一个筛选。
- 指定哪些属性应该被搜索。
- 允许多重选择。
- 如果仅有一个值可用，预填字段。
- 显示悬停对象属性的预览。
- 隐藏对象类型图标。
- 设置占位符。
- 使用代码编辑器设置noResultsText: string和displayedProperties: list<string>。
要进行筛选，属性必须在 Ontology 中配置为渲染提示 "低基数"。

## 对象属性下拉菜单

对象属性下拉菜单字段允许响应者选择给定对象类型的属性值。用户可以配置以下选项：

- 根据另一个属性的值指定一个筛选。
- 允许多重选择。
- 如果仅有一个值可用，预填字段。
- 允许创建除给定值以外的其他值。
- 设置占位符。
- 使用代码编辑器设置noResultsText: string。
## 数据集值下拉菜单

数据集值下拉菜单字段允许响应者选择给定数据集的列值。用户可以配置以下选项：

- 根据另一列的值指定一个筛选。
- 允许多重选择。
- 如果仅有一个值可用，预填字段。
- 允许创建除给定值以外的其他值。
- 设置占位符。
- 使用代码编辑器设置noResultsText: string。
要使用此字段，必须将数据集索引到 Lime。

## 对象提供者

对象提供者字段是只读的，并显示所选给定类型对象。用户可以配置以下选项：

- 根据属性值指定一个筛选。
- 显示所有对象的摘要视图或可折叠列表。
- 使用代码编辑器设置maxObjects: integer。
## 对象属性显示

对象属性显示字段是只读的，并显示所选对象的选定属性。用户可以配置以下选项：

- 指定对象的主键或引用它的字段。
- 隐藏对象类型图标。
- 自定义消息：没有选择对象时。值为空时。请求失败时。对象"缺失"时（要么不存在，要么响应者没有适当的权限）。
- 没有选择对象时。
- 值为空时。
- 请求失败时。
- 对象"缺失"时（要么不存在，要么响应者没有适当的权限）。
- 指定当：请求失败时。对象"缺失"时的处理方式。
- 请求失败时。
- 对象"缺失"时的处理方式。
如果引用的字段启用了多重选择，对象属性显示将显示所有对象的属性，并以逗号分隔。

## 用户属性

用户属性字段是只读的，并显示所选 Foundry 用户的选定属性。用户可以配置以下选项：

- 指定用户 ID 或引用它的字段。
- 指定格式（例如，姓，名）。
- 自定义消息：没有选择用户时。值为空时。请求失败时。用户"缺失"时（要么不存在，要么响应者没有适当的权限）。
- 没有选择用户时。
- 值为空时。
- 请求失败时。
- 用户"缺失"时（要么不存在，要么响应者没有适当的权限）。
- 指定当：请求失败时。用户"缺失"时的处理方式。
- 请求失败时。
- 用户"缺失"时的处理方式。
如果引用的字段启用了多重选择，用户属性显示将显示所有用户的属性，并以逗号分隔。
