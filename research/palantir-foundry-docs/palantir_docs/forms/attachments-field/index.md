# 附件字段

Foundry Forms 不再是 Foundry 上数据输入或数据输出工作流的推荐方法。相反，请使用 Foundry Ontology 搭建用户输入工作流，将相关数据结构表示为对象类型，并通过操作配置数据输出交互。请在Forms 概述文档中了解更多信息。

Forms 的附件字段允许响应者在其条目中上传附件。

附件字段支持以下配置选项：

- 允许多次上传：如果启用，此选项允许响应者将多个附件上传到该字段，而不是单个附件。
允许多次上传：如果启用，此选项允许响应者将多个附件上传到该字段，而不是单个附件。

- 目标文件夹：此选项指定附件应上传到哪个文件夹。此字段的所有附件将存储在此文件夹中。
目标文件夹：此选项指定附件应上传到哪个文件夹。此字段的所有附件将存储在此文件夹中。

- 上传模式：此字段有两个选项：默认模式：所有附件将作为独立文件存储在目标文件夹中。子文件夹模式：成功提交表单后，将在指定的目标文件夹内自动创建一个新文件夹。所有附件将作为独立文件存储在此子文件夹中。配置此模式需要两个附加字段：子文件夹名称：此字段的值将用作子文件夹的名称。子文件夹 RID：此字段的值将自动填充为子文件夹的 RID。
上传模式：此字段有两个选项：

- 默认模式：所有附件将作为独立文件存储在目标文件夹中。
默认模式：所有附件将作为独立文件存储在目标文件夹中。

- 子文件夹模式：成功提交表单后，将在指定的目标文件夹内自动创建一个新文件夹。所有附件将作为独立文件存储在此子文件夹中。配置此模式需要两个附加字段：子文件夹名称：此字段的值将用作子文件夹的名称。子文件夹 RID：此字段的值将自动填充为子文件夹的 RID。
子文件夹模式：成功提交表单后，将在指定的目标文件夹内自动创建一个新文件夹。所有附件将作为独立文件存储在此子文件夹中。配置此模式需要两个附加字段：

- 子文件夹名称：此字段的值将用作子文件夹的名称。
子文件夹名称：此字段的值将用作子文件夹的名称。

- 子文件夹 RID：此字段的值将自动填充为子文件夹的 RID。
子文件夹 RID：此字段的值将自动填充为子文件夹的 RID。

在重新提交条目时，附件将上传到此目标子文件夹。如果在重新提交时缺少子文件夹 RID，将创建一个新的子文件夹。然而，新子文件夹的名称和 RID 不会自动保存到此字段。

要使用子文件夹模式，必须在表单中创建一个附加的文本字段。这个字段将是一个空字段，作为上文的子文件夹 RID 选择。为了避免响应者的困惑，请将此字段设置为只读或隐藏。

目标文件夹和上传模式不能被更新配置变换影响。
