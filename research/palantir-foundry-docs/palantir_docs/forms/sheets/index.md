# 表单

Foundry Forms 不再是 Foundry 上数据输入或数据输出工作流的推荐方法。相反，请使用 Foundry Ontology 搭建用户输入工作流，将相关数据结构表示为 Object 类型，并通过操作配置数据输出交互。请在Forms 概述文档中了解更多信息。

表单是围绕一个或多个字段的包装器。每个表单包括一个主表单以及若干非必填的子表单。与字段一样，表单可以受变换的影响，提供了一种方便的方法来一次性显示、隐藏或禁用表单内的所有字段。

通过 Forms 可视化编辑器，用户可以执行各种表单自定义操作：

- 设置标题或隐藏标题和边框。
- 设置列数。
- 设置表单内所有字段的默认标签位置。
- 设置描述，并指定其显示方式。
- 禁用表单内的所有字段。
- 配置多重性。
表单只能添加到表单的末尾。用户无法将表单添加到表单的中间或在表单下方添加单个字段。
