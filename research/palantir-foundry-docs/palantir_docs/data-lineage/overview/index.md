# 概述

数据沿袭是一个交互式工具，帮助全面查看数据如何在Foundry平台中流动。

使用数据沿袭，您可以：

- 轻松查找和发现数据集使用项目、表和列名称搜索数据集点击浏览Foundry项目中的数据
- 使用项目、表和列名称搜索数据集
- 点击浏览Foundry项目中的数据
- 通过强大的界面探索管道展开或隐藏数据集的祖先和后代同时查看一组表的属性通过着色可视化您的管道（例如，对过期的表进行着色）深入了解您的数据细节，例如其架构、最后构建时间以及生成数据的代码
- 展开或隐藏数据集的祖先和后代
- 同时查看一组表的属性
- 通过着色可视化您的管道（例如，对过期的表进行着色）
- 深入了解您的数据细节，例如其架构、最后构建时间以及生成数据的代码
- 与队友协作创建管道快照与其他用户共享
