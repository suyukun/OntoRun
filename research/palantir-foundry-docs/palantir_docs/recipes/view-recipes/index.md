# 查看所有Recipes

Recipes应用程序不再更新，并将被淘汰。不建议使用。我们建议探索其他应用程序和功能以在Foundry中监控条件：

- 自动化:创建在您的数据之上运行的自动化，跟踪个人搜索和Objects，当满足特定条件时触发通知或其他操作。
- Foundry规则:创建基于逻辑的规则以应用于数据集、Objects和时间序列，当满足特定条件时触发警报。
- 大规模监控:使用检查组或监控视图查看Foundry资源的指标更新，包括数据集、代理、计划、Objects和链接类型。
- Workshop:搭建警报收件箱或其他通知工作流，以配置在满足特定条件时将触发的操作。
如果您对为您的监控应用案例实施适当的工作流有疑问，请联系Palantir客服支持。

可以从Recipes应用程序的Recipes管理页面查看所有Recipes。通过Foundry导航侧栏访问Recipes应用程序。

Recipes可以通过搜索栏进行搜索。

Recipes应用程序的您的Recipes选项卡包括您创建的或您为接收者的所有Recipes。
