# 模式

Linter应用程序分为不同的模式。每种模式都有特定的目标和一组规则。

## 资源节省

资源节省模式提供减少基础设施成本的建议，同时实现预期的组织成果。例如，删除未主动交付结果的资源的计算或存储可能会带来大量的资源节省。随着Foundry及其能力范围的发展，可能会出现新的建议。

## 管道弹性

管道弹性模式提供增加Foundry中构建的工作流和管道稳定性的建议。这些建议可以实现管道的最大弹性和稳定性，并提供调试功能。我们建议使用管道弹性模式来审查支持关键工作流的管道。

## Ontology优化

Ontology优化模式帮助您最小化Ontology的存储和索引时间。通过遵循此模式中的建议，您可以有效地用活跃和最新的实体来填充您的Ontology。优化您的Ontology将使用户交互更容易，并在未使用的对象不再索引到对象存储数据库时减少存储成本。
