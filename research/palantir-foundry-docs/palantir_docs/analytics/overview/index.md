# 分析

Foundry为组织中的每一类用户提供了分析能力，并与Foundry Ontology集成。开箱即用，Foundry包含点选和代码为基础的工具，支持基于表的分析、自上而下的可视化分析、地理空间分析、时间分析等。Foundry中的分析旨在超越传统的“只读”范式，将数据写回Ontology，在统一的安全性、传承和治理模型中产生有价值的新见解。

## 核心应用

Foundry的核心分析应用包括：

- Contour，一个自上而下的分析应用，用于快速大规模探索表格数据，通过可视化变换得出新的数据集，并创建图表。
- Quiver，一个多模式图表应用，允许进行以Object为驱动的分析、时间序列驱动的分析、点选机器学习和仪表盘搭建。
- 代码工作簿，一个融合数据工程和数据科学主题的应用，允许快速构建Python、R或SQL驱动的变换，搭建和训练机器学习模型，以及更多功能。
- 记事本，一个集成的解决方案，用于嵌入来自Foundry各处的动态分析、可视化和操作性工件，以及格式化文本和媒体。
- Fusion，一个以电子表格为驱动的应用，将表格计算与Foundry的Ontology和Object驱动查询系统的强大功能相结合。
## 分析连通性

Foundry还被设计为能够深入集成现有的分析工具。组织可以通过标准API和接口将其商业智能、可视化和其他分析应用连接到Foundry。集成选项包括：

- 针对常用工具的开箱即用连接器，如**Power BI®和Tableau**。
- **REST APIs**用于临时连接。
- **ODBC和JDBC驱动**用于一般连接。
- Python ↗和R ↗SDKs用于连接数据科学工具。
- 为Microsoft Report Builder和Excel等工具提供引导式集成，这些工具利用标准接口。
