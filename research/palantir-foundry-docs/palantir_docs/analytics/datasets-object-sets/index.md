# 数据集和对象集

## 数据集

在 Contour 和 Code Workbook 中，用户可以选择输出数据集（表格数据）以捕获分析结果。这些数据集可以在 Contour、Code Workbook 和 Fusion 等应用中使用，并且可以与其他用户共享。

Contour 和 Code Workbook 并未针对创建生产管道进行优化。如果您正在搭建或维护生产管道，请使用包含版本历史、分支和拉取请求以及其他对健壮管道至关重要的功能的代码库应用。有关详细信息，请参见Foundry 用于编写基于代码的变换的工具比较。

### Contour

您可以通过选择路径底部的保存为数据集来保存 Contour 路径的结果。在命名数据集并选择保存位置后，数据集将以分析结果进行搭建。了解有关从 Contour 保存数据集的更多信息。

### Code Workbook

您可以通过选择保存为数据集来选择将 Code Workbook 变换的结果保存为数据集。默认情况下，新的变换不会保存为数据集。了解有关从 Code Workbook 保存数据集的更多信息。

### 什么时候代码库更适合？

我们建议使用代码库应用来创建健壮的生产管道并支持需要额外治理和监控层的工作流。通过代码库，数据工程师可以批量创建高效的管道。

适合代码库的示例工作流包括：

- 需要增量计算的大规模数据的每日管道。
- 高可见性的管道，具有严格的治理，要求能够恢复到历史代码的以前版本，或在成功的单元测试上限制代码更改。
适合在 Contour 或 Code Workbook 中保存数据集的示例工作流是：

- 一次性捕获数据，然后在另一个分析应用中使用。
虽然您可以在 Contour 和 Code Workbook 中创建的数据集上设置搭建计划，但管道化工作流通常属于代码库。

## 对象集

对象集是为将来参考和使用而保存的现实世界实体列表，可在支持对象的 Foundry 应用中使用。对象集作为资源保存，以便于与协作者共享。

对象集有两种类型：

- 静态对象集：静态对象集保存为主键列表，无论输入数据有任何更改，都将保持不变。
- 动态对象集：动态对象集保存为应用于创建对象集的筛选的表示。当新数据符合筛选条件时，对象集将更新。
在 Quiver 分析中创建的对象集可以保存在 Foundry 中。一旦保存，这些对象集可以在新的 Quiver 分析中导入或在另一个 Foundry 应用中打开，如 Object Explorer。

要导出对象集，请通过单击卡片右上角的图标打开对象集卡片的编辑器，然后导航到导出选项卡。

要导入对象集，请使用导入已保存对象引用卡片。

阅读更多关于如何在 Quiver 中导入和导出对象集。

对象集也可以在 Object Explorer 中保存、更新和比较。阅读更多关于如何在Object Explorer中保存对象集的信息。
