# 导出输出

Foundry允许合格用户以平台外使用为目的导出分析输出。

支持的导出包括PDF导出、将可视化导出为图像和以CSV或XLSX格式导出。

## PDF导出

记事本支持将文档下载为PDF，并可以自定义内容，例如页面方向、页眉和页脚以及单个嵌入（图表、表格等）的外观。

了解如何开始使用记事本。

## 可视化导出

您可以在Contour、Quiver和Code Workbook中将单个可视化导出为图像。

在Contour和Quiver中，请在任何图表的右上角寻找按钮（将图表下载为图像），如下所示。

在Code Workbook中，从任何可视化节点的操作菜单中选择下载图像，如下所示。

## 数据导出

您可以在Contour、Quiver和Code Workbook中将分析结果以CSV和/或XLSX格式导出。

### Contour

从Contour导出数据有两种方式，均有100,000行的导出限制：

- 在您的分析路径中添加一个导出面板。
- 或者，您可以在分析中选择相关面板并打开表格面板，然后选择您想要的导出选项。
### Quiver

要从Quiver分析中导出数据，请从任何卡片的操作菜单中选择下载为CSV。

### Code Workbook

要从Code Workbook中导出数据，请从保存为数据集的变换的操作菜单中选择下载为CSV。默认的导出限制是100,000行。请注意，未持久化的变换结果无法下载为CSV。了解有关Code Workbook中持久化和未持久化变换的更多信息。
