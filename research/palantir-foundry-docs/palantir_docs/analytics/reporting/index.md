# 报告

在Foundry中，我们将“报告”定义为创建带有注释的时间点内容，以便在平台内共享或下载。如果您希望创建可供他人直接使用的互动内容，我们推荐使用Foundry的仪表盘产品。

## 记事本

记事本是Foundry的报告工具。使用记事本，您可以创建实时更新和静态（“时间点”）文档，注释文档，在平台内共享文档，并以PDF格式导出文档。

记事本的主要功能包括：

- 简单易用的文档创建和编辑体验。
- 能够从广泛的Foundry资源中添加内容，包括Quiver、Contour、Code Workbook和Object Explorer。
- 支持带有动态输入的文档模板。
- 可定制的PDF导出。
了解如何开始使用记事本。

## （停用）报告

截至2023年8月，新的Foundry报告创建对于大多数客户已被禁用，Foundry报告应用程序对新客户不可用，现有（“传统”）Foundry报告为只读。传统报告仍然可以以仅查看方式使用，并且不需要转换或过渡到新格式，除非需要编辑。阅读有关改进的报告工作流程的信息，以及将在Foundry报告文档中仍受支持的工作流程。

传统的Foundry报告应用程序支持实时仪表盘和静态报告应用案例。然而，其他Foundry工具对这些工作流程提供了更好的支持和更丰富的功能集。我们推荐以下产品用于大多数仪表盘和报告应用案例：

- Contour仪表盘用于由Contour分析生成的内容。Contour仪表盘提供比报告更好的交互性，具有如图表到图表筛选等功能，并且通过易于使用的拖放界面来在迭代分析时搭建仪表盘。了解有关开始使用Contour仪表盘的更多信息。
- Quiver仪表盘用于由Quiver分析驱动的内容。报告不支持嵌入大多数Quiver可视化类型。了解有关开始使用Quiver仪表盘的更多信息。
- 记事本用于跨产品内容和大多数Foundry报告应用案例，如上文所述。了解有关开始使用记事本的更多信息。
如果您正在创建一个包含多个来源内容的仪表盘，例如，一个Contour分析和一个Code Workbook，或两个Contour分析，您可能仍希望使用报告。如果是这样，您可以了解有关开始使用报告的更多信息。
