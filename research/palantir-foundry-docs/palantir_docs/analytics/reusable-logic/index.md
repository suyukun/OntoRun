# 可重用逻辑

在分析应用中，您可以选择保存逻辑片段以供其他用户重复使用。这有助于限制重复工作，缩短实现价值的时间，并允许用户利用由领域专家或更技术性的协作者创建的逻辑。

## Contour

在 Contour 中，您可以保存表达式，以便在各个分析和路径中轻松重用逻辑，并与他人共享逻辑。保存的表达式可以用来创建或替换列或执行聚合。了解更多关于 Contour 的信息。

## Quiver

Quiver 中的可视化函数由一个或多个 Quiver 卡片组成，这些卡片加载、合并和变换数据。可视化函数自动对 Quiver 分析中的数据输入应用一系列逻辑步骤，并可以在其他用户的分析中被使用。了解更多关于 Quiver 的信息。

## 代码工作簿

通过在简单的表单界面后抽象代码，代码工作簿模板为技术性很强的用户提供了一种轻量级的方式，以便与对编写代码可能不太熟悉的用户协作。用户选择的值被替换到模板中，然后可以像工作簿中的任何其他变换一样运行。任何可以用代码创建的变换，例如 Matplotlib 或 Plotly 可视化，都可以用代码模板构建。了解更多关于代码工作簿的信息。
