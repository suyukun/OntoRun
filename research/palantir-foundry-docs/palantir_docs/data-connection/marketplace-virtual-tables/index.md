# 将虚拟表添加到Marketplace产品 [Beta]

使用Foundry DevOps将您的虚拟表包含在Marketplace产品中，以供其他用户安装和重用。了解如何创建您的第一个产品。

## 支持的功能

所有虚拟表都可以打包和同步。

目前，不支持单独打包源，也不支持打包启用虚拟表自动注册的源。

安装人员必须确保目标源在相同位置包含与原始源具有相同模式的表，以保证兼容性和功能性。
