# 源探索

在从源设置同步时，您可能希望探索源及其包含的数据，以便在将数据引入Foundry之前预览同步。根据源类型，Data Connection允许您通过探索页面预览同步中的数据。

要访问探索页面，请按照以下步骤操作：

- 导航到源页面，点击您要配置的源名称。
- 从同步页面的探索和创建同步组件中选择探索链接。
