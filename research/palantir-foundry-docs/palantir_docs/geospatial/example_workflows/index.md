# 示例工作流

为了帮助您了解在何时适合将地理空间工作流应用于您的应用案例，本文档描述了几个常见的地理空间工作流模式。所有示例图像均使用概念性或开源数据。

## 常见操作图

- 摘要：统一组织知识，以增强在趋势、风险和能力方面的决策能力，适用于新兴或紧急响应场景。
- 目的：在统一视图中整合关键上下文、警报和趋势，使高管、利益相关者和决策者能够快速理解复杂情况。
- 地理空间数据输入：区域边界（例如，州、国家或县的多边形）热点位置（例如，医院位置、兴趣点）
- 区域边界（例如，州、国家或县的多边形）
- 热点位置（例如，医院位置、兴趣点）
- 输出：一个反映复杂和动态变化情况的当前状态、关键趋势和新警报的整合仪表盘。
## 地理空间工作规划

- 摘要：使用集成模型智能跟踪工作包，以便更好地优先排序。
- 目的：适用于需要合并在一起、优先排序、审查、批准和指派给现场人员完成的大面积工作。
- 地理空间数据输入：资产位置（例如，反映工作项目的点/线/多边形）工作区域边界（例如，将工作划分为自然块的多边形）随时间变化的现场人员位置
- 资产位置（例如，反映工作项目的点/线/多边形）
- 工作区域边界（例如，将工作划分为自然块的多边形）
- 随时间变化的现场人员位置
- 输出：一个工作规划工具，用于协调工作包，包括管理从规划到现场人员完成的流程。
## 供应链优化

- 摘要：检查您的供应链以识别障碍、发现机会并理解随时间变化的趋势。
- 目的：管理复杂运输网络或地理分散的生产操作中的约束。
- 地理空间数据输入：国家或地区多边形工厂、仓库或供应商位置随时间变化的船舶或卡车位置
- 国家或地区多边形
- 工厂、仓库或供应商位置
- 随时间变化的船舶或卡车位置
- 输出：一个调查应用程序，用于探索您的网络并测试调整约束的场景，以优化整体系统输出。
