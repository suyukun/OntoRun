# 概述

Java变换允许您使用常见的 Java 库进行数据变换，并提供高层和低层 API 用于与 Foundry 数据集交互。它包括对批处理和增量管道的支持，并支持创建和共享代码库以供重用。

开始使用 Java 变换，或探索一些可用功能：

- Java 变换和管道基础
- 增量 Java 变换
- 单元测试
- 处理非结构化文件
- 共享代码
- 高级配置
