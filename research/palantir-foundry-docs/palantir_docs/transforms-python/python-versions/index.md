# Python版本支持

随着Python开发的持续进行，Python软件基金会将旧的Python版本标记为“生命周期结束”（EOL）↗；超过其EOL日期的版本将被官方标记为不再支持。

## Foundry和Python版本管理

从Python 3.9版本起，Foundry将遵循Python软件基金会的EOL计划，并且不支持已弃用的Python版本。弃用的Python版本可能对平台构成安全风险，并且可能与平台运行所需的技术不兼容（例如，Apache Spark不支持较旧的Python版本）。Palantir将通知使用即将达到EOL的Python版本的Foundry用户。

## 如何知道我的工作流是否使用了弃用的Python版本？

如果您的某个工作流使用了弃用的Python版本，您将会通过弹出窗口和横幅收到通知。这些通知将包含如何从弃用版本升级的信息。

## 哪些Python版本是安全的？

Python软件基金会的版本生命周期结束表↗会不断更新，指示哪些Python版本是安全的。我们建议您始终使用最新支持的版本。您可以参考下表了解Foundry对Python版本的支持情况。

| 版本 | 在Foundry中支持 | 在Foundry中EOL开始日期 | 在Foundry中弃用日期 |
| --- | --- | --- | --- |
| 3.6 | 否* | 2023-07-16 | 2024-01-31 |
| 3.7 | 否* | 2023-07-16 | 2024-01-31 |
| 3.8 | 是（即将不支持） | 2024-09-04 | 2025-01-31 |
| 3.9 | 是 | 2025-10-01 | 2025-10-31 |
| 3.10 | 是 | 2026-10-01 | 2026-10-31 |
| 3.11 | 是 | 2027-10-01 | 2027-10-31 |
| 3.12 | 即将推出 | 2028-10-01 | 2028-10-31 |

*这表示在Foundry中已达到EOL的版本，意味着使用此版本的工作流不受支持，并且不保证功能或兼容性。

## Python版本弃用

Python 3.8将在2025-02-01起在Foundry中不再支持。用户将收到通知，告知如何识别受影响的工作流并在截止日期前迁移到非弃用的Python版本。

Python 3.6和3.7自2024-02-01起在Foundry中不再支持。用户应迁移到非弃用的Python版本。

请参阅环境故障排除指南以了解有关更改Python版本的更多信息。
