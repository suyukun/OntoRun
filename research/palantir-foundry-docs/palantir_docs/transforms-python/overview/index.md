# 概述

Python是在 Foundry 中编写数据变换的最全面的语言。它包括对批量和增量管道的支持，支持创建和共享代码库以供重用，并允许在代码中定义数据期望以确保数据管道的高质量。

开始使用 Python 变换，或者探索一些可用功能：

- Python 变换和管道基础
- 增量 Python 变换
- 单元测试
- 处理非结构化文件
- 使用库
- 定义数据期望
- 调用外部系统
- Foundry 中的 Python 版本支持
