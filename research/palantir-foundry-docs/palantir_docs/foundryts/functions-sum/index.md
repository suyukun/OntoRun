# foundryts.functions.sum

## foundryts.functions.sum()

返回一个函数，该函数计算共享时间戳的多个输入时间序列中所有点的总和。

生成的时间序列是所有输入序列的所有时间戳的并集，其中每个时间戳包含输入集合中该时间戳存在的值的总和。

- 返回：一个接受多个时间序列作为输入并生成单一时间序列的函数，其中包含所有时间戳的并集，值为输入时间序列中共享时间戳的所有点的总和。
- 返回类型：(NodeCollection) -> 函数节点
## 数据框架模式

| 列名 | 类型 | 描述 |
| --- | --- | --- |
| timestamp | pandas.Timestamp | 点的时间戳 |
| value | float | 点的值 |

mean()

此函数仅适用于数值序列。
