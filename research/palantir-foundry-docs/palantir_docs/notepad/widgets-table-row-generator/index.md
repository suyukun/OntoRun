# 表格行生成器

此微件仅适用于文档模板。

表格行生成器能够动态生成传递给Notepad文档模板的对象集中的每个Object的行。表格行生成器与章节生成器非常相似，但表格行生成器返回的是行，并且只能用于Notepad表格中。

可以通过表格右键菜单或工具栏中的表格插入操作，将行生成器插入到常规Notepad表格中。或者，选择**+ 添加微件**或在段落字段中键入/以打开微件插入菜单，从中可以插入一个预填充有一个常规行和一个生成器行的表格行生成器。

## 将嵌入的微件与表格行生成器连接

要将嵌入微件的输入参数与其周围的表格行生成器连接，将输入设置为Object from generator。Object from generator输入项将自动在接受对象模板输入的生成器内的微件中可选择。

## 使用表格行生成器排序对象

要对生成器返回的对象进行排序，请使用排序控件。从Sort by下拉菜单中选择一个对象属性进行排序。请注意，能够排序的对象数量上限为2000。

## 模板配置

- 生成器对象集RID：一个传递给表格行生成器的对象集。表格行生成器将为该集合中的每个Object生成一个表格行。请注意，当前可以传递的对象数量上限为100。
