# 段落生成器

此微件仅适用于文档模板。

段落生成器允许您为对象集中的每个Object动态生成文档内容。当从模板生成Notepad文档时，这个生成步骤会发生（请参见上图中概念的可视化）。

要设置段落生成器，可以通过点击**+ 添加微件或在段落字段中输入/来打开微件插入菜单，然后选择段落生成器。接着，通过选择微件并配置生成器对象集**连接一个对象集模板输入，如下图所示。

### 将嵌入的段落与生成器连接

要将嵌入微件的输入参数与其周围的段落生成器连接，您需要将参数设置为Object from Generator。对于接受对象模板输入的生成器内的微件，此参数将自动可选。

下图展示了一个对象属性的示例。

## 使用段落生成器排序对象

要对生成器返回的对象进行排序，请使用排序控件。从按...排序下拉菜单中选择一个对象属性进行排序。请注意，可以排序的对象数量上限为2000。

下图展示了一个通过飞机数量属性对航空公司对象进行排序的示例。

## 模板配置

- 生成器对象集RID：传递给段落生成器的对象集。段落生成器内容将为此集合中的每个Object生成。请注意，可以传递的对象数量上限为30个对象。超过此限制的对象将被忽略。
