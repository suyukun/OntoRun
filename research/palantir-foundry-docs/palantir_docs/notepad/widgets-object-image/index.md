# Object媒体预览

Object媒体预览微件允许您从Object中提取并显示图像。点击+ 微件以添加一个Object媒体预览微件。

Object媒体预览微件可以显示来自Object属性的图像，这些属性包含图像的URL、指向图像的Foundry RID、Base64编码字符串或附件。默认情况下，显示Object的title属性。通过微件属性菜单更改显示的属性为您希望显示的图像所在的属性。

## 微件属性

- Object选择：从中显示图像的Object。
- 显示的属性：包含或指向图像的属性。
## 模板配置

- Object选择：要显示的Object。
