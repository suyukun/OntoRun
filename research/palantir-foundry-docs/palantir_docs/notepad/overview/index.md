# 概述

Notepad是一个面向对象的协作富文本编辑器。除了可以添加和格式化文本和图像等内容外，您还可以集成来自其他 Foundry 应用程序的微件，如 Contour、Quiver、Code Workbook 和 Object Explorer。您还可以创建模板，作为生成新 Notepad 文档的蓝图。

## 功能

Notepad 的关键功能允许您：

- 嵌入图表、表格和图形来自其他 Foundry 应用程序。
- 导出和打印所有 Notepad 文档，并对导出展示进行细粒度控制（嵌入外观、分页符等）。
- 维护结构化链接到嵌入的对象和资源，自动丰富底层 Ontology。
- 冻结内容以捕获时间点上下文。
- 模板化文档以便根据新输入轻松创建报告版本。
## 应用案例

Notepad 支持的工作流包括：

- 临时笔记记录（例如，在调查工作流中记录嵌入旁的笔记）。
- 平台内文档编制（例如，记录管道、数据集或应用程序）。
- 定期报告（例如，使用模板生成每月状态报告）。
- 模板化导出（例如，按需创建文档模板的新副本，给定选定对象）。
Notepad 不太适合：

- 创建仪表盘：Notepad 不支持基于用户输入或图表选择的动态筛选。如果您希望创建仪表盘来展示分析结果，请考虑使用Quiver 仪表盘用于对象或时间序列数据，或Contour 仪表盘用于表格数据。Workshop也可以用于创建仪表盘或更高级的操作应用。
- 复杂的、基于页面的富文本编辑：Notepad 不提供典型桌面文本编辑器的可配置性。Notepad 的设计是一个易于使用的文本编辑器，优化用于与 Foundry 平台的其余部分集成。
