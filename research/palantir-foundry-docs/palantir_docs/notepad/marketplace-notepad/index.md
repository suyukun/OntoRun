# 将文档和模板添加到 Marketplace 产品 [Beta]

使用Foundry DevOps将您的 Notepad 文档和Notepad 模板包含在Marketplace 产品中，以供其他用户安装和重用。了解如何创建您的第一个产品。

## 支持的功能

Marketplace 产品目前支持以下微件类型的 Notepad 文档和模板：

- 列表
- 超链接
- 锚点链接
- 资源链接
- 表格
- 图片
- LaTeX
- 用户提及
- 当前日期
- 分页符
- Quiver 仪表盘
- 值嵌入
对其他 Palantir 创建的默认 Notepad 微件的支持即将推出。

## 将 Notepad 文档和模板添加到产品中

要将 Notepad 资源添加到产品中，首先创建一个产品，然后选择如下所示的Notepad 文档或Notepad 模板内容类型。

添加 Notepad 模板时，系统会提示您选择一个模板版本。

## 将嵌入的 Quiver 仪表盘添加到产品中

如果您的文档或模板包含 Quiver 仪表盘微件，则 Quiver 仪表盘必须与 Notepad 资源一起打包。要与资源一起打包的微件必须仅引用同一仪表盘的一个版本。
