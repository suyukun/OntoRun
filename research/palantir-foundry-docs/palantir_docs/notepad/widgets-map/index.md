# 地图

来自地图应用程序的地图和地图模板可以通过地图微件嵌入到Notepad中。通过点击**+ 添加微件**或在段落字段中输入/来打开微件插入菜单，添加一个地图微件。这将打开一个搜索栏，您可以在其中找到特定的Object并选择它进行添加。

由于网页浏览器资源限制，每个Notepad文档最多只能嵌入4个地图微件。

## 微件属性

- 地图：选择一个地图或地图模板嵌入到Notepad文档中。
地图：选择一个地图或地图模板嵌入到Notepad文档中。

- 地图模板参数：（非必填）在嵌入地图模板时可以定义。如果在简单的Notepad文档中嵌入地图模板，可以将地图模板的参数设置为静态值以生成地图视图。如果在Notepad模板中嵌入地图模板，请定义Notepad模板的输入，并将其用作嵌入地图模板的输入参数。模板输入值将传递给嵌入的地图模板以覆盖地图模板的输入参数。
地图模板参数：（非必填）在嵌入地图模板时可以定义。

- 如果在简单的Notepad文档中嵌入地图模板，可以将地图模板的参数设置为静态值以生成地图视图。
- 如果在Notepad模板中嵌入地图模板，请定义Notepad模板的输入，并将其用作嵌入地图模板的输入参数。模板输入值将传递给嵌入的地图模板以覆盖地图模板的输入参数。
