# 表格

Notepad 提供一个原生的表格微件。您可以通过选择+ 添加微件或在段落字段中使用 / 键盘快捷键打开微件插入菜单来添加一个。您可以使用菜单中的滑块配置表格的尺寸。

当您选择新插入的表格时，特定的表格操作工具栏将在 Notepad 工具栏中出现。表格操作工具栏允许您插入或移除额外的行和列、设置单元格背景颜色，或在默认和密集显示模式之间切换。通过单击垃圾桶图标删除您选择的表格。或者，您可以使用右键菜单插入或移除行和列。

表格行生成器

您可以使用表格行生成器根据对象集中的每个对象动态生成表格行。了解更多信息，请参阅表格行生成器文档。
