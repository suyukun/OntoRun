# Object卡片

Object卡片允许您显示多个Object属性，并附带指向Object的链接。您可以通过点击+ 添加微件或在段落字段中键入/来打开微件插入菜单以添加它。默认情况下，将显示重要属性。您可以从右侧微件配置面板中的可见属性调整显示的属性和属性顺序。

## 微件属性

- **Object选择：**要显示的Object。
- **可见属性：**定义应显示哪些属性及其顺序。
## 模板配置

- **Object选择：**要显示的Object。
