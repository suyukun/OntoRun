# 导出现有的Notepad文档

为了允许其他人从工作坊中将现有文档导出为PDF，请使用Notepad: Export Button微件。可以与Notepad: Embedded Document微件结合使用，以启用编辑和导出工作流程。

## Notepad: Export Button微件

在您的Workshop应用中添加Notepad: Export Button后，创建或引用包含文档RID的变量。此变量可以是Notepad: Linked Documents、Notepad: Template Button或Notepad: Embedded Document微件的输出文档RID，非必填。

### 选项

- 输出文件名: 定义下载的PDF文档的文件名。如果为空，则默认为Notepad文档的名称。
- 按钮显示: 为导出按钮定义设计选项。
- 按钮文本: 定义导出按钮的文本。如果为空，默认为Export。
### Notepad: Template Button微件

Notepad: Template Button微件允许用户生成新的Notepad文档，并可选择从工作坊中导出。
