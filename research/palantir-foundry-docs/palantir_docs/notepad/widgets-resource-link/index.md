# 资源链接

当将另一个Foundry资源（例如，Contour分析或代码库）的链接粘贴到Notepad文档中时，会创建Foundry资源链接。链接将自动显示资源的名称，但保留原始路径。

您还可以通过点击 + 添加微件或在段落字段中输入 / 来插入Foundry资源链接，以打开微件插入菜单。

如果您不希望Notepad将您的链接转换为资源链接，请使用键盘快捷键Ctrl+Shift+V（Windows）或Cmd+Shift+V（macOS）以纯文本形式粘贴链接。
