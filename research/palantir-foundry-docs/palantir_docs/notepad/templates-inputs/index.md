# 添加模板输入

文档模板接受输入参数，这些参数用于驱动由模板创建的新文档中的微件内容。

要向文档模板添加参数，请打开模板并在应用程序的左侧面板中选择模板输入面板。使用+ 添加模板输入选项以添加字符串、数字、日期、时间戳、Object 或对象集输入。微件类型决定了可以使用什么输入类型。

对于每个模板输入，您可以设置一个预览值。预览值允许您在配置模板时将模板输入链接到指定的值。请注意，预览值不是默认值，并且在生成步骤中没有相关性。预览值仅用于确保输入参数和微件正确设置。

之后，您可以使用模板输入来驱动您的可模板化微件的配置。

现有输入参数可以重命名并指派新的预览值。如果输入参数未被任何微件使用，您也可以删除它们。
