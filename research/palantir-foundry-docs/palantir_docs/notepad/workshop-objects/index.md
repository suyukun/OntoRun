# 显示链接到 Objects 的文档

每当 Objects 被嵌入到文档中时（例如，作为Object 卡片或Object 属性），Notepad 会跟踪这些链接。这使您可以显示所有链接到特定 Object 的文档。

## Notepad：链接文档微件

在 Workshop 中使用Notepad：链接文档微件，显示所有包含所选 Object 链接的文档。

您可以调整微件内容的显示样式、显示的字段以及显示顺序。您还可以定义文档的默认排序选项，例如按作者排序。请参见下例。

Notepad：链接文档微件会自动暴露Active Notepad变量。该变量引用当前选中文档的资源标识符（rid），并在选择更改时自动更新。例如，您可以使用它来配置Notepad：嵌入文档微件，以便在 Workshop 中直接显示当前选中文档。
