# 版本历史

您可以在左侧的版本历史面板中浏览所有现有版本。一个版本是文档当前状态的快照，您可以在稍后的时间点重新访问甚至恢复。您还可以手动保存版本。默认情况下，只有用户创建的版本会被显示。在面板的右上角切换筛选到所有版本以查看所有自动保存和手动保存的版本。

## 自动保存版本

默认情况下，当您编辑文档时，Notepad 会每5分钟自动保存版本。这些被称为自动保存版本。只要您在线，Notepad 文档的所有更改都会定期捕获为自动保存版本。

## 用户创建的版本

除了自动保存版本之外，您还可以创建手动版本。

为此，请打开左侧的版本历史面板并选择+按钮以保存新版本。您将能够命名版本并将其标记为已认可，这将在其他保存的版本中突出显示它。认可版本可以用于标记文档的特定发布。

## 回滚到先前版本

您可以选择过去的版本查看或回滚到以前的文档版本。回滚到先前版本将自动保存当前文档状态的版本，然后更新到所选版本。过去的版本默认以只读模式显示。要查看和编辑文档的当前版本，请在左侧的版本历史面板顶部选择当前会话。

## 显示更改

选择显示更改选项并选择一个过去的版本与当前版本进行比较。这将显示所选版本内容的比较。

请注意，格式更改不包括在比较中。格式更改的示例包括：

- 文本格式，如加粗、斜体、下划线、删除线、颜色、高亮和字体大小。
- 图片大小更改。
- 表格格式，如列宽和表格密度。
- 图片大小。
- 对齐更改。
- 列表项嵌套级别。
