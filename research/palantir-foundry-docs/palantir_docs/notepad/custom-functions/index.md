# 自定义函数

当工作流需要富文本格式的输入，或者工作流输出富文本格式的内容时，自定义函数特别有用。函数输入可以是富文本或纯文本，您也可以选择输出是富文本还是纯文本。请注意，如果您需要富文本输入，您的函数应接受Markdown。

此功能与将单个字符串作为输入的函数兼容，并且输出类型为字符串、布尔值、日期、双精度、浮点数、整数或长整数。

## 在Notepad中使用自定义函数

要在Notepad中使用自定义函数，您必须首先创建一个函数。函数可以用TypeScript或Python编写；请参阅函数文档以获取应用案例、支持的功能和函数创建指南。创建自定义函数后，按照以下步骤在Notepad中使用它：

- 在Notepad中，打开或创建文档或文档模板。用内容填充文档，并通过以下两种方式之一选择函数输入：手动突出显示相关内容，然后在工具栏中选择Edit with AIP。将光标放在相关内容上，然后在工具栏中选择Edit with AIP。系统将自动为您进行块级选择。
- 手动突出显示相关内容，然后在工具栏中选择Edit with AIP。
- 将光标放在相关内容上，然后在工具栏中选择Edit with AIP。系统将自动为您进行块级选择。
如果您的注册未启用AIP，Notepad中的自定义函数仍然可用。请在工具栏中选择Edit with functions，并忽略步骤二。

- 进行选择后，将出现一个弹出菜单。选择Functions选项以使用自定义函数编辑所选内容。
- 在函数弹出窗口中，选择一个函数及其输入类型。在Function input下拉菜单中选择纯文本或Markdown。
- 非必填预览输入，并运行函数。
- 查看函数输出，并选择输出是否应为纯文本或使用Markdown格式。默认情况下，输出类型将与输入类型相同。
- 通过选择Replace将输出插入到您的文档中。
