# 嵌入微件

Notepad中的微件允许您将图像、图表、表格、样式元素、链接和与其他Foundry应用程序的连接等内容添加到您的Notepad文档中。

## 支持的集成

Notepad支持嵌入来自几个其他Foundry应用程序的微件，如图表或表格。支持以下集成：

- Object属性
- Object卡片
- Quiver图表
- Quiver仪表盘
- Contour图表
- Code Workbook图表
此外，Notepad还具有许多本地微件：

- 资源链接
- 分页符
- 图像
- 表格
微件参考提供了配置选项和功能的详细描述。Notepad目前不支持嵌入来自Workshop模块或Slate应用程序的视图微件。

## 添加微件

您可以在文档中或直接从源应用程序添加微件。

### 从文档中

- 在段落中使用/键盘快捷键或点击+ 微件打开插入菜单。
- 选择嵌入类型。
- 点击插入添加新微件。
来自其他Foundry应用程序的集成可能需要额外的配置以显示数据或可视化内容。使用右侧的微件属性面板进行配置。

### 从资源中

所有可嵌入的Foundry应用程序中均提供复制到Notepad按钮。点击此按钮会将内容复制到剪贴板，然后您可以将其粘贴到文档中。

## 微件链接

所有在文档中引用的objects、对象集和Foundry资源都会自动链接到文档。使用右上角操作菜单中的查看文档链接按钮查看文档链接。

对象的链接在Workshop的Notepad: 链接文档微件中用于显示引用特定对象的所有文档。有关更多详细信息，请参见显示链接到对象的文档。
