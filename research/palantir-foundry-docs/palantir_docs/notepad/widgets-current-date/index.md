# 当前日期

当前日期微件允许您将当前日期插入到Notepad文档中。使用插入菜单将其添加到您的文档中。

该微件还可以配置为在页面重新加载时自动更新显示的日期。此外，在文档模板中，当前日期微件可以配置为在模板生成期间冻结显示的日期。

## 微件属性

- **自动更新日期：**如果启用，显示的日期将在文档加载时自动更新为当前日期。此选项默认情况下是禁用的。
- **选择日期格式和时区：**允许选择日期应显示的格式和时区。可用的日期格式选项包括：日期，日期和时间，日期和时间（短），ISO瞬间，以及时间。默认情况下，时区设置为用户的时区。这意味着时间显示在查看文档的用户的时区中。或者，您可以选择一个静态时区（例如Europe/London或America/New_York）。

## 模板配置

- **在模板生成时冻结日期：**如果启用，日期微件将在经过模板生成过程后显示生成时的日期。有关更多信息，请参阅关于从模板生成和导出文档的文档。
