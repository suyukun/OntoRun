# 条件部分

此微件仅适用于文档模板。

在Notepad模板中，条件部分允许您根据字符串模板输入的值有选择地在生成的文档中包含内容。

## 添加条件部分

您可以通过单击**+ 添加微件或在段落字段中输入/以打开微件插入菜单，然后在生成器下选择条件部分**选项，向Notepad模板添加条件部分。

首先，选择一个字符串模板输入。您将能够根据此模板输入的值配置规则。

选择字符串模板输入后，您可以配置规则。"如果"部分让您设置规则的条件，"那么"部分让您设置结果。

例如，如果doesPlaneNeedMaintenance模板输入等于YES，则条件部分的内容将显示。

当从模板生成文档时，用户配置的规则决定了条件部分的内容是否会包含在生成的文档中。

您可以为所选模板输入添加预览值，以在模板生成期间预览条件部分的行为。如果在模板生成期间内容将显示，条件部分将有绿色边框；如果内容不会显示，则有红色边框。
