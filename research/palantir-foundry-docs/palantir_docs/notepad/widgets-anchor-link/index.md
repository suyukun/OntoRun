# 锚链接

Notepad允许您创建锚链接以引用文档中特定的部分。将此链接分享给其他用户可以确保他们在访问链接时会被引导到Notepad文档的这个特定部分。同样地，您也可以在较大的文档中使用锚链接来创建自定义大纲。

要复制锚链接，将光标移到您想引用的内容，然后在右侧的拖动菜单中选择复制锚链接。或者，您可以先选择内容，然后在工具栏中选择锚图标。然后，您可以粘贴链接与其他用户分享。

## 显示文本

粘贴到其来源文档中的锚链接将显示复制元素的文本或微件类型。粘贴到单独文档中的锚链接还将显示来源文档的标题。所有锚链接将在工具提示中显示其来源文档的RID。
