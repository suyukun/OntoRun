# 代码工作簿图表

在代码工作簿中生成的图像或Plotly图表等可视化可以通过代码工作簿图表部分添加到文档中。

添加可视化的最简单方法是通过每个代码工作簿图表节点上可用的复制到Notepad按钮。此外，还可以通过单击+ 添加微件或在段落字段中键入/来打开微件插入菜单添加该部分。

## 微件属性

- 面板：选择您要显示的面板。请注意，只有带有可视化的面板可以被选中，其他将被排除。
