# Notepad中的AIP功能

Foundry Notepad具有一系列AIP功能，旨在帮助您更快、更高效地分享本体见解。您可以在Notepad中使用AIP自动进行拼写检查、缩短、修改或翻译文本，同时保留其现有格式。您还可以使用函数通过在AIP逻辑或其他已发布函数中配置的自定义行为来修改Notepad内容。

Notepad的AIP功能包括：

- 修正拼写和语法：支持英语、法语、德语、日语、韩语、西班牙语和乌克兰语。
- 更改写作风格：在“专业”（适合报告）或“自信”（适合公告）风格之间选择。
- 缩短：使文本块更简洁。
- 翻译：将文本从一种支持的语言翻译为另一种。
- 预览多个命令：预览对同一文本块进行多次AIP操作的结果，例如先纠正拼写，然后使文本简洁，再翻译成法语，最后替换原始文本。
- 函数：使用平台内接受字符串输入的函数来替换文档或模板中的文本。这些可以与其他AIP操作结合使用。如果未启用AIP，您仍然可以使用函数编辑Notepad内容。详情请参阅自定义函数。
## 激活AIP功能

要在Notepad中使用AIP，请在工具栏中选择使用AIP编辑按钮。

注意：AIP功能的可用性可能会更改，并可能因客户而异。
