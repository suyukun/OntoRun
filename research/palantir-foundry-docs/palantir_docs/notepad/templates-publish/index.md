# 发布模板

完成 Notepad 模板配置后，发布它以开始使用。

发布模板将保存当前内容、设置和输入参数，并生成一个新的版本号。要发布一个版本，请在右上角工具栏中选择发布，可选地为新版本指定一个名称，然后点击发布模板按钮。

模板版本控制确保更改不会影响已在使用中的生产工作流。当将模板添加到 Workshop 应用程序时，您需要明确引用要使用的版本号。要在生产工作流中接受模板更新，请更新配置以引用新的版本号。

要查看已发布版本的历史记录，请点击顶部工具栏中的图钉图标。这将打开一个表格，其中包含所有已发布版本，以及发布日期和发布用户。
