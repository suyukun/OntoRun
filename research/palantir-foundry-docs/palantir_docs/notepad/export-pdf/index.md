# 以PDF格式导出

Notepad文档设计支持打印和导出，并且支持修改页面方向、定义页面页眉和页脚，以及针对微件的特定打印设置。

## 导出文档

通过右上角的操作菜单，选择导出，然后选择以PDF格式导出来导出文档。Notepad会在文档渲染完成后将其保存为PDF。

导出为PDF时，后台渲染时间是有限制的。如果文档包含许多需要长时间计算的图表，可能会达到限制并阻止图表完全加载。在这些情况下，请使用下面讨论的以打印模式打开选项。

或者，您可以使用以打印模式打开按钮在打印友好的视图中打开文档。一旦页面和所有图表完全加载，您可以使用Ctrl+P键盘快捷键或右上角的打印按钮保存为PDF或打印页面。

请根据文档的页面方向设置打印设计为纵向或横向。确保页面大小与您选择的Notepad页面大小匹配。选择默认边距选项以确保内容对齐。

## 特定打印选项

Notepad提供了额外的打印选项，以在导出前微调您的文档。

### 页面方向

默认情况下，文档以纵向模式显示。要将文档更改为横向模式，请在Notepad工具栏中选择打印选项，然后在页面方向下选择纵向或横向。

### 页面页眉和页脚

要配置页眉和页脚，请在Notepad工具栏中选择打印选项。启用页眉或页脚会打开一个编辑器以添加内容。请注意，这些内容仅在文档打印或导出时可见。

### 页面大小

Notepad文档的默认页面大小是Letter（8.5 x 11英寸）。要配置大小，请在Notepad工具栏中选择打印选项，然后使用下拉菜单选择页面大小。

可用的页面大小选项包括：

- Letter
- Legal
- Tabloid
- A3
- A4
- A5
### 页面分页微件

使用页面分页微件插入自定义分页。分页仅在打印时显示。

### 微件打印配置

一些微件支持特定的打印配置选项。当可用时，通过选择微件，打开微件属性面板并选择打印配置来访问这些选项。

选项包括缩放、在新页面上打印和扩展滚动条。

#### 缩放

打印为PDF可能会限制可用的水平空间（即使在横向模式下），这对一些可视化内容不太适合。例如，屏幕上可以水平滚动的宽表需要调整以适应。缩放级别配置允许您通过缩小显示的内容来实现这一点。

#### 在新页面上打印

默认情况下，如果空间有限，微件会在新页面上打印。这可能不是显示表格或跨越多个页面的微件的首选行为。在这些情况下，您可以禁用在新页面上打印。

#### 扩展滚动条

使用打印时自动扩展表格高度以确保垂直滚动的部分完全展开。此功能目前仅支持Contour表格和Quiver对象及数据透视表。
