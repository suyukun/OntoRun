# 将输入连接到微件

在添加模板输入到您的文档后，您需要将这些输入连接到可模板化的微件。查看每个微件的参考资料，以了解有关在文档模板中每个微件可以模板化哪些属性的更多信息。

首先选择要连接到模板输入的微件，并在右侧打开微件属性面板。然后点击选择并选择一个现有的模板输入或创建一个新的。这将把输入与微件连接起来。

在下面显示的示例中，一个Object属性微件连接到已经存在的aircraft_parameter输入。连接后，Object属性值由aircraft_parameter的配置预览值驱动。
