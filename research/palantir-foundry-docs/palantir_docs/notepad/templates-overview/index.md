# Notepad模板

Notepad模板被用于在基于新输入的现有内容中生成新文档的蓝图。

模板接受字符串、Objects或对象集等输入。模板中的微件可以配置为使用这些参数。根据输入创建新的模板副本时，内容会动态调整。

一些Notepad微件被设计用于在模板中使用。

- 表行生成器允许您为作为输入传递的对象集中的每个Object生成一个表行。
- 段落生成器为每个Object生成整个段落。
- 函数微件支持从TypeScript函数生成字符串。
在上面的例子中，飞机信息模板接收两个输入参数，一个飞机Object和一个航班对象集，以生成新的特定于飞机的文档。

## 从模板生成文档

模板必须在用于生成文档之前发布。下面描述了从模板生成文档的方法。

### 从Notepad主页

您可以在Notepad主页上通过选择从模板新建选项或选择现有模板上的从此模板新建图标，从模板生成文档。

注意：这将从模板的_最新_发布版本生成文档。

### 从Notepad应用程序头部

您可以在Notepad应用程序头部通过打开文件菜单并选择从此模板新建选项，从模板生成文档。

注意：这将从模板的_最新_发布版本生成文档。

### 从Workshop

要生成新的模板副本，请将您的模板嵌入到Workshop中，使用**Notepad: Template Button**微件。这将Workshop变量与模板输入连接起来，以推动生成过程。
