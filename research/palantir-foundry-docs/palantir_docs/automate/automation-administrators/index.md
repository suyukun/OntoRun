# 自动化管理员

默认情况下，自动化所有者和所有通知效果的接收者都会收到自动化警告和出错通知（例如，当自动化即将到期或函数评估出现运行时出错时）。为了防止所有通知效果的接收者收到这些自动化警告和出错通知，您可以指定一组专门的自动化管理员。这些管理员可以是用户或群组。配置后，只有管理员会根据下面的通知类型设置收到自动化通知。

有两种不同的通知类别可供选择：

- 自动化信息通知，包括关于：自动化到期日期临近或已到达的通知因循环或限制自动暂停自动化评估出错
- 自动化到期日期临近或已到达的通知
- 因循环或限制自动暂停自动化
- 评估出错
- 效果失败通知，包括关于：操作执行失败通知发送失败或附件渲染失败
- 操作执行失败
- 通知发送失败或附件渲染失败
效果总是按用户执行，用户只能收到自己的效果失败通知。因此，将效果失败通知更改为仅管理员将阻止失败通知发送给除管理员以外的任何人。
