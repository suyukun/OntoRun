# 为Marketplace产品添加自动化

使用Foundry DevOps将您的自动化包含在Marketplace产品中，以供其他用户安装和重用。了解如何创建您的第一个产品。

## 不支持的功能

以下自动化功能不被Marketplace产品支持：

- 使用保存对象集的自动化。
- 使用非群组接收者的自动化。
此外，请注意以下关于自动化安装的注意事项：

- 使用操作效果或AIP逻辑效果的自动化不能在“生产”模式下安装，因为具有这些效果的自动化不会自动升级。
