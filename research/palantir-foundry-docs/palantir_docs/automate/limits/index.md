# 限制

Automate 应用实现了若干限制以提高执行和触发效果的性能。下表列出了这些限制和预期行为。

## 自动化规模限制

| 描述 | 限制 | 达到限制时的行为 |
| --- | --- | --- |
| 检测到循环，如果循环检测未被覆盖 | 1 次循环（如果循环检测被覆盖则为 50 次循环） | 自动化将被自动禁用 |
| 以计划执行添加/修改/删除条件的对象输入最大大小 | 100K | 保存自动化时出错消息，或在评估自动化时出错，如果输入集增长超过 100K 个对象 |
| 每个自动化的最大接收者数量 | 10,000 | 在保存或评估自动化时出错 |
| 实时执行时每次自动化评估的最大对象数量 | 10,000 | 处理前 10,000 个对象事件，或抛出错误 |
| 当启用每对象执行时，为计划自动化每次评估的最大对象数量 | 1000 | 在评估自动化时出错 |
| 实时执行时对象类型的最大大小 | 10M | 保存自动化时出错消息，或在评估自动化时出错，如果对象类型中的总对象数量超过限制 - 请参阅丢弃对象配置 |
| 以函数支持效果的手动执行对象集最大大小 | 100,000 | 执行自动化时出错消息 |
| 无函数支持效果的手动执行对象集最大大小 | 5,000,000 | 执行自动化时出错消息 |
| 以函数支持操作的自动化最大批处理大小 | 20 | 在运行时出错 |
| 自动化的最大批处理大小 | 1,000 | 在运行时出错 |
