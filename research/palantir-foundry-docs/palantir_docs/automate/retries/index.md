# 重试

自动化有时可能无法执行。当出现这种情况时，Automate 将会显示一个出错，如下图所示。

出错可能是暂时的（临时的）或由于配置无效引起的。Automate 的重试功能为这两种出错类型提供了弹性。

## 手动重试失败

当效果配置不正确时，Automate 可能会出错。例如，当一个操作配置错误导致存在操作效果出错时，使用此操作的自动化可能会失败。为了解决这个问题，您可以更新操作配置并手动重新运行失败的自动化，以确保这些事件是正确的。

可以通过选择重试失败事件手动重试这些失败。这使您能够选择要重试的特定事件，如下图所示。

在选择要重试的事件后，您可以选择要重试的特定效果。请注意，这些效果将基于最新配置进行重试。如果只有一个效果可供重试，那么该效果将自动被选择。

选择重试事件后，将安排一个重试任务，并将在事件日志中显示，如下图所示。有关计划重试任务的更多详细信息可以在手动执行页面查看。

### 手动执行失败

您还可以重试手动执行中失败的效果。为了重试失败的批次，请打开手动执行运行的侧边栏。

选择重试失败批次将允许您配置重试任务的运行方式，例如批次大小。

选择重试将立即安排重新运行失败的效果。

## 配置自动重试

自动化也可能由于暂时原因而失败。这些失败可以手动重试，但您也可以为易受暂时性出错影响的效果配置自动重试。

暂时性出错的例子包括：

- AIP 模型的速率限制出错
- 使用 Webhooks 时的外部服务出错
