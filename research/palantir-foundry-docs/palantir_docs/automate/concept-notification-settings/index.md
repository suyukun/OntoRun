# 通知设置

每个用户可以在各自的用户设置中配置他们希望如何接收来自Automate的通知。这些偏好适用于任何自动化的全局设置。

| 类别 | 活动类型 |
| --- | --- |
| Triggered | 自动化已触发 |
| Recovered | 自动化已恢复 |
| Errors | 评估失败 |
| Other info | 条件已编辑已订阅已取消订阅已静音已取消静音已暂停已恢复 |
