# 示例：发送新问题的每周报告

在此示例中，我们希望发送每周的记事本报告，其中包含上一周所有新创建的客服支持工单的列表。如果没有新工单，我们不想发送报告。我们将使用Support Ticket对象类型，这是我们为此示例创建的自定义对象类型。

## 条件

在自动化创建向导中，我们首先选择Object added to set条件。通过选择Support Ticket对象类型而不添加其他筛选，自动化将在新工单创建时触发。

由于我们只希望每周发送一次报告，因此我们在条件中添加了一个计划，并指定自动化应于每周一上午8点触发。

因为我们在对象添加条件中添加了每周计划，所以每周一自动化将检查上周是否创建了新的Support Ticket对象。

## 效果

当满足条件时，我们希望发送一封包含上周创建的所有客服支持工单的PDF报告的电子邮件。为此，我们首先添加一个通知效果。

由于PDF报告应为上周创建的所有客服支持工单生成，请保持默认对象分组发送一条通知以包含所有新增的Support Tickets。对于收件人，添加包含目标用户的组。或者，为仅通知被指派了新客服支持工单的用户，只选择对象属性支持的用户。

因为信息包含在附加的PDF中，所以我们不需要复杂的通知正文：相反，我们可以依赖于简单通知类型在UI中配置内容。我们还可以在通知中提供一个指向Quiver仪表盘的链接。

### 将记事本文档附加到通知

要设置我们的通知附件，我们将使用记事本模板动态创建一个记事本文档，并将记事本文档的PDF附加到我们的通知中。

首先，我们需要创建一个可以显示所需信息的记事本模板。我们可以遵循记事本文档中概述的步骤来实现。在我们的特定情况下，我们创建一个记事本模板，将Support Ticket对象集作为模板输入。使用模板输入，我们显示一个图表并渲染一个包含对象集内每个对象的标题和描述的表格。
