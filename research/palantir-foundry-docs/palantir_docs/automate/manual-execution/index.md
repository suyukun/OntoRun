# 手动执行

配置的自动化也可以用于现有对象集。这通常用于回填应用案例，以及在广泛发布之前验证自动化是否按预期工作。

要手动执行自动化，首先创建一个新的自动化，并根据需要定义效果。然后，打开自动化并导航到执行选项卡。

当自动化被手动执行时，相关自动化的配置效果将立即被触发（非必填以一组用户定义的对象，具体取决于条件）。

## 执行设置

执行窗口提供了一些可配置的参数：

- 指定对象集：如果自动化是一个对象集条件，则会显示一个指定输入对象集的选项。此对象集必须包含与自动化条件中配置的类型相同的对象。在执行时，定义在此集合中的所有对象将被视为已触发自动化，并将被传递到使用“新对象”参数的任何效果中。如果自动化的条件不涉及对象集，则此参数将不可见。有关可以触发的对象集大小的信息，请参见限制。

- 如果自动化的条件不涉及对象集，则此参数将不可见。

- 批量大小：批量大小参数确定每次执行中的对象数量。例如，如果定义的对象集中有1,000个对象，并且批量大小设置为100，将进行10次单独执行（每次执行集中有100个对象），每次间隔1分钟。对象以非确定性、随机排序进行分区。如果自动化的条件不涉及对象集，则此参数将不可见。
