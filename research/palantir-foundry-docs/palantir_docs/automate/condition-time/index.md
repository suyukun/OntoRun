# 时间条件

要在特定时间或根据计划触发自动化效果，可以使用时间条件。通过选择时间条件卡片来选择它。

默认情况下，将选择每日频率。

## 配置

有两种方式配置时间条件：在用户界面中或作为cron表达式。

### 用户界面

这是默认选项，对于大多数应用案例来说足够。界面提供了设置每小时、每日、每周和每月计划的选项。

### Cron表达式

如果默认的时间条件配置选项对于您的应用案例不够灵活，可以使用自定义的cron表达式。

cron字符串必须正好有五个字段（分钟、小时、日期、月份和星期几）。不支持秒或年份字段。

最低可配置频率为每小时一次。因此，分钟字段只能是0到59之间的数字，不支持其他字符。

输入cron表达式后，您将看到如下截图中所示的自然语言计划预览。

作为参考，以下是一些cron表达式示例列表：

| Cron字符串 | 含义 |
| --- | --- |
| 0 * * * * | 每小时 |
| 0 0 1 1 * | 每年第一天的午夜 |
| 15 8,20 * * * | 上午08:15和下午08:15 |
| 15 8,14 * * 1-5 | 周一到周五上午08:15和下午02:15 |
| 0 9 1W * * | 每月第一个工作日上午09:00 |
| 0 9 L * * | 每月最后一天上午09:00 |
| 0 9 1 3,7,10,12 * | 每年3月、7月、10月和12月的1号上午09:00 |
| 0 9 * * 1#1 | 每月的第一个星期一上午09:00 |
| 0 9 * * 5L | 每月的最后一个星期五上午09:00 |
