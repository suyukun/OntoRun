# 常见问题

## 地理时间序列是否普遍可用？

地理时间序列是一个Beta功能，可能并不适用于所有注册用户。在产品正式发布之前，某些功能可能会更改。

## 什么时候应该使用地理时间序列而不是时间序列？

地理时间序列类似于时间序列，但地理时间序列需要经纬度坐标以及时间戳和序列ID。地理时间序列对于查看实体随时间的移动非常有用，通常是在地图上。时间序列对于通过图表、推导和趋势分析来分析随时间的测量非常有用。如果您的数据不包括地理空间组件，则应使用时间序列。
