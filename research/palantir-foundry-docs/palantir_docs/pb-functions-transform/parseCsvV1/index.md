# 从CSV文件中提取行

> 支持于: 批处理

支持于: 批处理

读取文件的数据集并将每个CSV文件解析为行。

变换类别: 文件

## 声明的参数

- 数据集- 要处理的文件数据集。文件
- 模式- 解析CSV文件时使用的模式定义。类型<Struct>
- 非必填列分隔符- 提供CSV文件中使用的分隔符。默认分隔符是逗号。字面量<字符串>
- 非必填包含最后修改的时间戳- 指定输出数据集是否应包含文件的最后修改时间戳。默认值是false。字面量<布尔>
- 非必填包含头部- 指定CSV文件是否包含头部。默认值是false。字面量<布尔>
