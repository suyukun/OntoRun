# 行大小

> 支持于: 批处理

支持于: 批处理

估算JVM中单行的大小。

变换类别: 其他

## 声明的参数

- 数据集- 用于计算单行大小的数据集。表
- 非必填行大小列别名- 行估算大小值（以字节为单位）的列名，默认为 'size'。字面值<字符串>
## 示例

### 示例 1: 基本情况

参数值:

- 数据集: ri.foundry.main.dataset.a
- 行大小列别名: size
输入:

| a |
| --- |
| 1 |

输出:

| a | size |
| --- | --- |
| 1 | 16 |
