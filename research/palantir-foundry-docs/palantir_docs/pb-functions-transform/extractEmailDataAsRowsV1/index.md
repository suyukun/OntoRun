变换类别: 文件, 媒体

- 数据集- 要处理的电子邮件文件数据集。文件
- 要提取的电子邮件信息- 要包含的元数据列。集合<枚举<附件, 密件抄送, 正文 (HTML), 正文 (纯文本), 抄送, 文件名, 发件人, 头信息, ID, 发送时间戳, 以及更多 ...>>
