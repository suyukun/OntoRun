# 窗口内的项目

> 支持于: 批处理, 流处理

支持于: 批处理, 流处理

对窗口内的数据执行指定的聚合操作。每次收到新行时发出一行。

变换类别: 聚合

## 声明的参数

- 数据集- 要执行聚合的数据集。表格
- 表达式- 要在窗口上评估的表达式列表。列表<表达式<任何类型>>
- 窗口- 用于按窗口对数据进行分组。窗口
