# 心跳检测

> 支持于: 流式

支持于: 流式

检测在一组键中，当记录在可配置的时间内未被看到时。

变换类别: 其他

## 声明的参数

- 数据集- 输入数据集。表格
- 心跳时间单位- 等待特定键的数据的时间单位。枚举<天, 小时, 毫秒, 分钟, 秒, 周>
- 心跳时间值- 等待特定键的数据的时间值。字面值<长整型>
- 按列分区- 用作检测心跳的键的列集合。集合<列<任何类型>>
