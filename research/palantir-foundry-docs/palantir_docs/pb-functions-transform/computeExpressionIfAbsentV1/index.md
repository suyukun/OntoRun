# 如果表达式不存在则计算

> 支持于: 批处理

支持于: 批处理

为新行计算表达式，给定键的值只会计算一次，即使在跨搭建时也是如此。

变换类别: 其他

## 声明的参数

- 数据集- 要应用表达式的数据集。表格
- 表达式- 当键没有结果时要计算的表达式。表达式<AnyType>
- 键- 结果存储在此键下。对于给定的键，结果不会被计算两次。列表<表达式<二进制 | 布尔值 | 字节 | 整数 | 长整数 | 短整数 | 字符串>>
- 存储ID- 存储结果的存储ID。如果更改了此ID，所有结果将被作废。相同的ID不能在同一管道中使用两次。文本<字符串>
- 非必填禁用存储- 如果为true，则存储完全禁用，所有存储参数将被忽略。此时，变换将像常规应用表达式一样运行。文本<布尔值>
- 非必填当以下情况时不要存储结果- 某些结果可能不需要存储。例如，出错结果或空结果。根据结果，选择不应存储的值。如果不存在，则所有结果（即使是空值）也将被存储。表达式<布尔值>
