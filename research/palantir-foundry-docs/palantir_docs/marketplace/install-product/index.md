# 在 Foundry Marketplace 中安装产品

当您找到想要安装的产品时，Marketplace 将指导您通过映射任何所需的输入来创建产品的输出内容。

## 安装指南

要开始安装产品，请在 Marketplace 界面的右上角选择蓝色的Install按钮。如果您已经可以访问现有的安装，此按钮将提示您选择Open，不过您也可以选择Install again再次安装该产品（例如，如果您希望创建一个具有不同输入的新版本）。如果产品版本被发布者撤回，Install按钮将被禁用。

然后将创建一个安装草稿，您将看到一个引导安装的过程。

### 常规

安装过程的第一部分允许您配置产品的名称和安装位置。

- 安装模式：由产品搭建者提供的默认设置。在生产模式下创建的产品被设计为可以安装和升级，而无需对给定安装进行本地更改。在引导模式下创建的产品被设计为可以安装和编辑。有关这如何影响可用安装位置的更多信息，请参见安装位置。
- 安装后缀：这是一个非必填配置，允许您自定义内容将安装到的项目的名称；例如，您可能会为创建为测试的产品添加后缀test。
- 安装位置：以下选项允许您指定产品应安装的位置：项目：您安装的资源将驻留的新项目。生产模式产品必须安装在一个新的、已锁的项目中以确保安全升级，而引导模式产品可以安装在您有编辑权限的任何位置。选择使用现有位置将引导模式产品安装到现有项目或文件夹中。空间：将创建新项目的空间。如果您没有看到所需的空间，请联系您的平台管理员，因为这表明您没有创建新项目的权限。Ontology：将创建任何对象、链接、操作和函数的Ontology。如果您没有看到所需的 Ontology，请联系您的平台管理员，因为这意味着您没有编辑权限。
- 项目：您安装的资源将驻留的新项目。生产模式产品必须安装在一个新的、已锁的项目中以确保安全升级，而引导模式产品可以安装在您有编辑权限的任何位置。选择使用现有位置将引导模式产品安装到现有项目或文件夹中。
- 空间：将创建新项目的空间。如果您没有看到所需的空间，请联系您的平台管理员，因为这表明您没有创建新项目的权限。
- Ontology：将创建任何对象、链接、操作和函数的Ontology。如果您没有看到所需的 Ontology，请联系您的平台管理员，因为这意味着您没有编辑权限。
- 角色：如果您正在安装到新项目中，请添加其他用户或用户组，以便他们可以访问您的安装。这也可以在安装完成后完成。
### 输入

输入是产品内容依赖的实体（如对象或管道）。可以手动映射输入，使用链接产品，或者选择现有文件夹或传统的 Foundry 模板。

链接产品自动使用其他产品的内容满足输入。

#### 输入概览

输入概览页面提供有关当前未映射输入的信息；这些被称为“缺失输入”。

您可以从现有文件夹或传统的 Foundry 模板中选择内容自动映射为输入。

#### 输入映射

在输入概览页面之后，您将有机会选择资源以满足每个所需输入。

在每个资源的页面上，配置选项卡允许您设置每个输入，例如通过指定输入和产品之间的列映射。

相关项选项卡提供有关为何需要输入的信息，显示什么内容需要此输入才能安装。例如，一个 Workshop 应用可能需要特定的对象类型。

##### 占位符输入

为了在所有资源可用之前部署 Marketplace 产品，您可以在指定文件夹中创建临时的存根资源以继续安装。目前支持数据集输入，预计不久将支持其他输入类型。

如果有支持但尚未满足的输入，则将在输入概览页面上看到生成占位符输入的选项。选择生成占位符输入将为每个合适的输入生成占位符输入。

或者，要生成单个占位符输入，请在输入选择器旁边选择...，然后选择生成占位符。

一旦实际资源可用，您可以通过导航到安装页面并选择编辑来重新映射这些输入。

您可以通过选择更改将任何现有占位符输入重新映射为实际资源。

并非所有产品都需要输入映射；例如，如果一个产品仅提供数据集作为内容，则可能不需要映射任何输入。如果您的产品不需要输入映射，此步骤将被隐藏。

### 内容

内容页面提供将要安装的所有资源的摘要，例如应用、函数、链接类型和操作类型。

#### 为 Ontology 实体添加前缀

内容页面包含一个标记为前缀 Ontology 实体的切换选项；类似于使用安装后缀自定义项目名称的方式，您可以使用前缀 Ontology 实体切换选项为所有对象类型、链接类型和操作类型自定义用户指定的前缀（例如，DEV，这将为 Ontology 实体添加[DEV]前缀）。

### 新版本

在安装生产模式产品时，您将有一个额外的安装步骤，以指定自动升级的发布渠道和维护窗口。

在升级中阅读有关这些设置的更多信息。

### 审核

审核页面显示任何必须在安装前解决的验证错误。例如，安装程序可能需要映射用作必需输入的清理数据集中缺失的列，才能使安装成功。

一旦所有输入都已映射，您将能够使用安装选项启动安装。这将提交安装草稿并启动一个任务以创建资源。然后，您将被重定向到任务页面，您可以在那里看到任务的进度。
