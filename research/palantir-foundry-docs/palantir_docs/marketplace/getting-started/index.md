# 入门

在本教程中，您将使用一个包含汽车零件问题的假想数据源安装一个警报收件箱应用程序，我们已将其作为一个独立的Marketplace产品提供。

首先，导航到Foundry实例中的Marketplace，并搜索Marketplace入门教程 - 数据源，如下面所示。如果您无法找到此产品，请联系您的Palantir代表。

## 安装您的数据源

找到教程数据源后，点击右上角的安装。如果您所在组织中有人已经创建了您有权限访问的安装，您将看到打开和再次安装按钮。在这种情况下，选择再次安装以继续安装。

安装时：

- 选择一个空间进行安装。如果您看不到所需的空间或任何空间，请联系您的平台管理员，这表明您没有创建新项目的权限。
- 由于该产品仅包含一个数据集，因此不需要Ontology。
- 启用安装后缀以自定义数据源将被安装的项目名称。
- 该产品没有任何输入，因此您可以跳过所有其他步骤，并在左侧面板底部选择安装。
开始安装后，您将进入安装任务页面。安装完成后，选择右上角的查看安装。从这里，在新选项卡中打开您的Car Part Issues - Source数据集。返回到数据源安装的选项卡。

## 安装您的应用程序

现在我们将开始使用Car Part Issues - Source数据集作为输入来安装目标应用程序。在标题中的产品搜索栏中，搜索Marketplace入门教程 - 警报收件箱。该产品也属于参考资源商店。与数据源产品类似，点击右上角的安装以开始安装，如果您所在组织中有人已经创建了安装，选择再次安装按钮以继续安装。

### 常规

- 选择一个空间进行安装——可能是您用于数据源的相同空间。
- 选择一个ontology进行安装。如果您没有看到所需的ontology或任何ontologies，请联系您的平台管理员，这表明您没有创建新项目的权限。
- 启用安装后缀以自定义数据源将被安装的项目名称。
### 输入

与第一次安装不同，您需要映射一个输入来创建警报收件箱应用程序。这将是您刚刚安装的Car Part Issues - Source，其中包含将填充警报收件箱的假想问题数据。要映射此输入：

从您已打开Car Part Issues - Source的选项卡中，通过点击左上角的文件，然后点击复制完整路径来复制文件路径，如下所示。

您现在需要映射您的Car Part Issues - Source以满足警报收件箱产品的一个必需输入。为此，返回到您的安装，点击选择，然后将您复制的文件路径粘贴到搜索中并选择您的数据集。

如果所有列都正确映射，您将看到如下面的蓝色勾号。

### 内容

此步骤确认将安装的内容，在本例中是一个Workshop应用程序、一个Object类型和三个操作类型。

开启前缀ontology实体以自定义您的Object类型和操作的名称。我们建议在本教程中使用您的名字。

### 新版本

您可以在本教程中跳过此步骤。要了解更多关于自动升级、发布渠道和维护窗口的信息，请访问安装文档。

### 复查

一旦您的输入映射完成，并且您对安装位置和名称自定义满意，选择安装。

### 安装任务

开始安装后，您将进入安装任务页面。安装完成后，选择右上角的查看安装。

## 打开您的应用程序

从您的安装中，在新选项卡中打开Marketplace教程 - 警报收件箱应用程序。在您的Car Part Issue对象索引之前，您的应用程序将不可用，这可能需要几分钟。

您现在有一个警报收件箱工作坊应用程序来帮助您分类Car Part Issues - Source问题！只要存在所需的输入列，您可以再次安装此应用程序，并将其用于新的应用案例。
