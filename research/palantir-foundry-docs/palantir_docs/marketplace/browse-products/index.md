# 在 Foundry Marketplace 浏览产品

产品是产品搭建者提供安装的 Foundry 资源集合。

## 商店

在 Marketplace 中，商店是产品的集合。商店也可以拥有由产品搭建者和商店所有者推广的特色产品。

您可能有权访问一个或多个商店。某些商店，例如Foundry 商店，对所有客户开放，而其他商店则特定于您的注册。例如，您组织中的搭建者可以创建一个商店，以容纳跨多个部门安装的任务管理应用程序集合。此商店将不对其他客户开放。了解有关配置远程商店访问的更多信息。

## 产品详情

从商店中选择产品后，您可以查看有关该产品的各种信息，包括：

- 版本
- 概述
- 更改日志
- 内容
- 输入
### 版本

如果一个产品有多个版本，您可以使用版本选择器选择要安装的版本。在大多数情况下，我们建议安装最新版本。

#### 召回

产品版本可能会被产品搭建者召回。如果一个产品版本被召回，您将在版本名称旁看到一个红色的召回标签。

自动升级将不会安装召回版本，您也无法手动安装召回版本。如果您已经安装了召回版本，您可以继续使用它；然而，我们建议尽快更新到非召回版本。

### 概述

产品的概述包括任何搭建者提供的产品详情，以及将要安装的必需输入和内容的预览。

### 更改日志

产品的更改日志包括任何搭建者提供的关于产品版本之间差异的背景信息。

### 内容

产品的内容是映射必需输入后将安装的 Foundry 资源。

### 输入

产品的输入是必须映射的依赖项，以创建产品的内容。并非所有产品都需要输入。

一旦您决定要安装某个产品，您可以开始安装。
