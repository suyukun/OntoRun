# 概述

以下文档假设您具备容器化基础设施和容器镜像等概念的相关知识。如果您不熟悉这些主题，我们建议您查看Docker 概述文档 ↗

Foundry允许用户将容器镜像与模型适配器一起打包，以创建一个基于容器的模型。然后，该模型可以像非容器支持的模型一样在Foundry中使用。基于容器的模型特别有用，如果模型特别大、预先训练、用Foundry不原生支持的语言编写（如R），或者已经为其他用途进行容器化。

控制面板包含所有与容器治理相关的功能，包括启用容器使用和管理漏洞。如果未启用容器设置，则所有依赖于导入容器的Foundry任务和部署将失败。

一旦启用了容器工作流程，第一步是创建模型并开始将镜像推送到平台。
