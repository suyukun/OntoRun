# 将语言模型导入Foundry

Foundry允许您无需编写代码即可将开源语言模型导入到您的Foundry工作流程中。这些语言模型可以提交到建模目标中，以用于批处理和实时部署。

要使用其他语言模型，您也可以轻松地为新语言模型添加支持。关于下文中使用的模型适配器的详细信息，请参阅语言模型适配器的文档。

## 导入语言模型

支持的开源模型可以通过以下步骤集成，无需编写任何代码：

- 创建一个新的或打开一个现有的建模目标，在其中添加语言模型。在建模目标中，选择添加模型。
- 选择选项导入开源模型。
- 选择一个可用的模型，然后选择下一步。
- 选择创建的模型资源将在Foundry中保存的位置，并决定是否要创建一个沙盒部署。Foundry为可用的开源语言模型提供默认的模型适配器。不过，您也可以配置一个自定义模型适配器。
