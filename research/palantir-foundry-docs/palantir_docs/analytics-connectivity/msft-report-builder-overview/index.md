# 概述

用于 Microsoft Report Builder 的 Foundry 集成：

- 使您能够轻松创建由 Foundry 数据支持的 Report Builder 报告。
- 提供与 Foundry 访问控制的兼容性，包括桌面版的细粒度权限。
- 支持桌面版的词元认证。
## 支持的 Report Builder 产品

- Report Builder Desktop（2020年9月发布或更高版本）
