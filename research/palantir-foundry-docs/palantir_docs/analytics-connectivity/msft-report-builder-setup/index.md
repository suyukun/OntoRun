# 设置

您现在可以从报告搭建器访问Palantir Foundry数据集，并使用它们搭建报告和可视化。要将Foundry与报告搭建器一起使用，您必须在本地计算机上安装Foundry ODBC驱动程序。请按照以下指南完成报告搭建器的安装。

### 步骤1: 安装ODBC驱动程序

要开始设置Foundry报告搭建器集成，您需要安装一个名为ODBC驱动程序的组件。请导航到下载页面: ODBC驱动程序下载并安装驱动程序。

如果您在安装过程中遇到任何问题，请联系您的Palantir代表。

### 步骤2: 开始搭建报告

现在您已经安装了ODBC驱动程序，可以按照Microsoft报告搭建器: 起始指南中的说明，开始搭建第一个由Foundry数据支持的报告。
