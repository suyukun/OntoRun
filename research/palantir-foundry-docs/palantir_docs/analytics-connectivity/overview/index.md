# 概览

Foundry的开放架构使数据和变换逻辑以非专有格式访问成为可能。通过以开放格式存储数据、公开API、支持轻松连接和导出数据以及提供变换代码的访问，Foundry可以轻松与第三方软件和开源工具互操作。

Foundry的开放集成生态系统可以通过安装自定义连接器进一步丰富，这些连接器专门支持与流行商业智能软件（如Power BI®和Tableau）的特定集成。Foundry还提供对ODBC和JDBC驱动程序的访问，这些驱动程序可用于与其他第三方工具的集成。

使用本指南以设置您的Foundry商业智能工具集成，通过Foundry进行身份验证，并开始在第三方工具中使用Foundry数据。

#### 目前可用的连接器

- Power BI® 连接器
- Tableau 连接器
- Microsoft Report Builder 连接器
- Excel
- Qlik Sense
- MicroStrategy
- Foundry ODBC & JDBC 驱动程序
