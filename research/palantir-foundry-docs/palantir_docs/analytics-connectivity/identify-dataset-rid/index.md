# 确定数据集的RID或文件路径

为了在第三方BI工具中处理Foundry数据，您需要指定您希望处理的数据集。一些第三方工具提供用于浏览和选择数据集的图形界面。其他工具则需要您直接输入有关您希望处理的数据集的信息。

Foundry提供了两种指定数据集详细信息的选项：

- "RID"，即数据集标识符
- "位置"，即数据集的文件路径位置
您可以通过导航到数据集的“关于”页面，点击“查看更多”，并从左侧边栏复制“RID”值或“位置”来找到这些值。
