# 下载

本页面提供Foundry 数据集的 ODBC 和 JDBC 驱动程序以及Foundry 数据集的 Tableau 连接器的下载链接。

### 可用下载

- ODBC 驱动程序
- JDBC 驱动程序
- Tableau 连接器
### Foundry 数据集 ODBC 驱动程序

要安装驱动程序，请下载下面由 Palantir 签名的安装文件，并按照屏幕上的说明进行操作。有关配置与 Foundry 连接的进一步说明，请参阅ODBC 安装指南。

此安装程序支持 Windows 64 位。Windows 32 位、Mac 和 Linux 目前不支持。

下载:

- Foundry ODBC 驱动程序 3.39.0 (Windows x64) ↗
### Foundry 数据集 JDBC 驱动程序

要安装驱动程序，请下载下面的 .jar 文件，并按照应用程序特定文档中描述的方式将其放置到您机器上的相关目录。有关配置与 Foundry 连接的进一步说明，请参阅JDBC 安装指南。

需要 Java 11+。

下载:

- Foundry JDBC 驱动程序 3.39.0 (JRE 11+) ↗
### Foundry 数据集 Tableau 连接器 (2021.1+)

Foundry 数据集 Tableau 连接器是一个由 Palantir 签名的 Tableau 连接器，作为 Tableau 连接器 (.taco) 包文件提供。

该连接器也可在Tableau Exchange ↗上获取。Tableau Exchange 上列出的版本与下面链接中的版本没有区别。

下载:

- foundry-jdbc-2.5.0.taco ↗
### Foundry 数据集 Tableau 连接器

如果您的 Tableau 版本在2019.4和2021.1之间，请使用此版本的连接器。此版本提供与上述版本相同的功能，唯一不同的是仅支持词元身份验证（不支持 OAuth），且数据集必须通过 RID/路径加载，而非搜索。

下载:

- foundry-jdbc-1.2.0.taco ↗
