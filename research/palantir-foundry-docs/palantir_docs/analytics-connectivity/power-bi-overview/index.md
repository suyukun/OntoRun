# 概述

## 什么是 Power BI® 的 Foundry 集成？

- 包含一个微软认证的 Power Query 连接器，使您能够轻松创建由 Foundry 数据支持的 Power BI® 报告。
- 支持导入和 DirectQuery模式。
- 提供与 Foundry 访问控制的兼容性，包括 Power BI® Desktop 的细粒度权限。
- 支持 OAuth 认证，以及基于词元的认证，用于 Power BI® Desktop。
## 支持的 Power BI® 产品

- Power BI® Desktop（2020年6月发布或更高版本）
- 通过 Power BI® Gateway 的 Power BI® 服务（2020年6月发布或更高版本）
请注意，Power BI® Report Server当前不被 Power BI® 自定义连接器支持。但是，您可以使用标准ODBC 驱动程序进行连接。

## Power Query 兼容性

作为认证的 Power Query 连接器，该集成使得 Foundry 数据可以从多种微软产品中访问：

- Microsoft Fabric (Dataflow Gen2)
- Power Platform（包括 Dataverse 和 Power Apps）
- Power BI®（数据流和语义模型）
要了解更多关于兼容性的信息，请查看微软 Power Query 文档中的 Palantir Foundry 页面 ↗。
