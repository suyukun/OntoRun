# 项目限制

项目限制允许项目所有者设置哪些权限标记可以或不可以应用于项目内的文件。项目限制防止用户将违反规定的文件保存到项目中。

以下列出了三种类型的项目限制：

- 无限制（默认）：项目中允许所有权限标记，并可以设置为访问要求。
- 允许的权限标记：只有指定的权限标记可以在项目中使用，并可以在项目文件中设置为访问要求。
- 禁止的权限标记：在此项目中不允许使用指定的权限标记，并且不能在项目文件中设置为访问要求。此限制有效地允许带有任何权限标记的数据在项目中使用，但列出的标记除外。
项目限制通常用于防止用户意外合并数据。有些情况下，用户可能需要访问多个权限标记的数据，但某些特定组合的标记数据不应被允许。为了增加这种保护，管理员可以在必要的项目上添加项目限制，以避免用户意外合并不应合并的数据。

例如，一家银行可能有一项要求，即出于合规原因，敏感的投资数据绝不能与研究数据合并。然而，合规官员可能需要分别访问投资和研究数据以开展工作。为了防止合规官员意外合并投资和研究数据，平台管理员可以应用“允许的权限标记”类型的项目限制，以保护包含投资和研究数据的项目。
