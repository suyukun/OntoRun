# 请求敏感操作的理由

使用检查点通过以下步骤请求敏感操作的理由：

- 首先，确定哪种类型的操作需要理由，并验证是否存在相应的检查点类型。
- 遵循检查点配置指南设置理由提示的参数和条件。
- 在检查点应用程序的配置选项卡中，找到您新创建的检查点配置，并使用预览功能查看用户将看到的提示界面。根据需要进行更改。
- 尝试执行与配置匹配的敏感操作来触发检查点，完成理由并提交。尝试查看记录以查找理由的副本。
