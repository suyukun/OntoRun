# 组合 [BETA]

配置组合的功能处于测试阶段。在此功能正式发布前，一些功能可能会发生变化，并且它可能不会在所有注册中都可用。

组合允许用户在一个空间内组织项目。每个组合包含多个项目，每个项目属于一个组合。任何有权访问空间的用户都可以查看其组合，但用户仍需单独获得查看组合内项目的权限。

## 创建组合

具有空间编辑者角色的用户可以从组合页面创建组合。每个组合必须有一个空间和一个唯一的名称。组合创建者可以选择提供一段简短的文字描述，并通过图像或图标颜色配置组合的缩略图。缩略图图像应为正方形，并将被压缩大小。

## 编辑组合元数据

管理员和策展人可以从右上角的操作菜单编辑组合的元数据。名称、描述和标志是可编辑的，但组合在创建后不能在空间之间移动。

管理员和策展人还可以向组合添加Markdown文档。所有能够查看组合的用户都可以查看此文档。

## 策划组合

创建组合后，管理员可以使用添加项目对话框从同一空间中填充项目。该对话框显示与组合同一空间中的所有项目，包括那些已经属于单独组合的项目。由于项目只能属于一个组合，将项目移动到另一个组合将从第一个组合中移除它。

选择要包含在此组合中的项目后，用户可以选择更改每个项目的显示名称。这是一个非必填步骤。

### 额外的组合策展人

通常，只有具有空间编辑者角色的用户可以管理其组合的内容。为了扩展组合策展权限，具有管理访问权限的用户可以打开组合的侧边栏并编辑其策展人列表。这些用户将有权选择添加或移除此组合中的项目，以及编辑其描述和文档。

## 组合目录

已被认可到项目目录或数据目录集合的资源也会出现在按项目或资源类型分组的组合目录中。管理员可以通过在添加内容对话框中搜索资源来提升组合中项目的资源。

## 项目侧边栏

项目侧边栏显示添加到组合中的项目列表。从项目侧边栏，用户可以打开单个项目，组合管理员可以添加或移除项目。
