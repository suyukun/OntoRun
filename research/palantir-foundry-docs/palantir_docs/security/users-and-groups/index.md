# 用户和组

## 用户

对 Foundry 的访问通过一个或多个身份提供者进行管理，这使得 Foundry 能够在用户登录时验证其身份。身份提供者还提供关于用户、其属性和组的信息。Foundry 可以与您现有的身份提供者无缝集成，从而通过您现有的系统实现完整的端到端访问管理。有关通过控制面板配置身份验证的更多信息，请参见身份验证和组织指派。

用户是指经过身份验证后可以访问 Foundry 的个人。用户通常由外部身份提供者（例如 Active Directory 系统）定义。用户具有属性，这是关于用户的公共、结构化的信息。

了解更多关于管理用户的信息。

## 组

组是一组用户。组使管理安全组和定制多个用户的 Foundry 用户体验变得更容易。项目和资源的访问通常是授予组而不是单个用户。保护数据基础文档突出了如何使用组来管理权限。

组通常由外部身份提供者（例如客户的 Active Directory 系统）定义，并应用于整个 Foundry 平台。
