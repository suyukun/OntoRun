# 封面页

项目封面页部分提供了一个基于Markdown的富文本编辑器，用于撰写关于项目的详细文档。

建议项目所有者添加文档以描述项目的目标，并指导用户找到相关文件和活跃的工作区域。此部分还可以提供新用户应请求访问哪些组的说明。封面页还可以用作项目中包含的应用程序的用户指南。

项目所有者可以配置封面页，使其在项目组织中可被所有用户发现，即使在项目应用了权限标记的情况下也是如此。没有访问项目或其文件的用户仍可以发现并查看项目的封面页。这对于包含敏感数据和应用程序的项目非常有用，因为可发现的封面页使相关用户能够找到项目并在适当情况下请求访问。
