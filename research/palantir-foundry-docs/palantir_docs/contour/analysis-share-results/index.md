# 分享结果

## 在Contour仪表盘模式中分享

分享分析结果的最简单方法是创建一个仪表盘。仪表盘是在分析中的一个独立视图，创作者可以在此用文字注释展示结果。

仪表盘在分析过程中通过仪表盘预览面板很容易搭建。主要功能包括图表间的筛选、行内参数引用、全屏展示视图以及以PDF格式导出。

了解更多关于Contour仪表盘模式的信息。

## 在记事本中分享

记事本是Foundry的主要报告工具，推荐用于大多数报告应用案例。使用记事本，您可以创建实时更新和静态（“时间点”）文档、注释文档、在平台内分享文档，并以PDF格式导出文档。

在记事本中，您可以展示来自Contour的结果以及来自Foundry广泛来源的内容，包括Quiver、代码工作簿和Object浏览器。

要将Contour面板添加到记事本中，请打开分析中面板右上角的...菜单，选择复制到记事本。这会将面板复制到您的剪贴板，并使您能够将面板粘贴到记事本中。您还可以通过悬停在Contour仪表盘中的面板上并选择复制按钮来复制Contour面板。

了解更多关于记事本的信息。
