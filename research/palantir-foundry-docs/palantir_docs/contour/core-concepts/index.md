# 核心概念

## 路径

Contour 是一个用于自上而下分析、数据变换和与他人分享结果的工具。在 Contour 中，一个分析由一个或多个分析路径组成。

每个 Contour路径都应以您感兴趣的特定数据集开始；然后您可以添加不同的 Contour面板来可视化、筛选或变换数据。您还可以引入其他数据集并将它们合并到您当前的数据集中。

您可以将路径的结果保存为 Foundry 中一个新的、独立的数据集。您在路径中执行的变换序列被保存为一个 Foundry任务，并作为 Foundry 搭建系统的一部分执行。这意味着如果其中一个基础数据集发生更改，或者您更改了路径的某个部分，您可以轻松地重新计算您的新数据集。（有关 Foundry 如何管理数据的更多信息，请参见搭建）。

您还可以从分析中刷新路径，以获取其基础数据集的最新版本。

## 面板

在 Contour 中，通过串联使用面板进行探索和分析。一些面板用于创建图表或执行计算，而其他面板则用于通过筛选、删除列等操作来处理您的数据集。

## 仪表盘

使用 Contour，您可以搭建仪表盘，以显示 Contour 分析的结果和发现。这些仪表盘支持图表到图表的筛选、行内参数引用、全屏演示视图以及以PDF格式导出。

## 参数

Contour 分析参数允许您轻松切换不同的数据和结果视图。在定义参数之后，您可以在分析路径中使用它们，并在仪表盘模式中展示。这使仪表盘的最终用户能够与仪表盘中展示的实时数据和结果进行交互。
