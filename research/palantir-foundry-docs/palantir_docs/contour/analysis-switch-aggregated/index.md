# 切换到聚合数据

一些允许您计算聚合指标的看板有一个选项可以进行透视。这会将您的工作数据集切换到该看板中计算的聚合数据，而不是原始数据集。任何后续的看板将使用新的聚合数据集。

新数据集将包括您在聚合看板中选择的所有列，以及每个聚合的一列。数据集中不会包含任何总计行或列。

为了提高性能，Contour将在您切换到聚合数据后尝试缓存透视表中计算的聚合数据。如果聚合数据缓存成功，您将在看板的右下角看到一个对勾标记（如下图所示）：

由于Contour不支持列名中包含逗号，因此不建议在使用Contour的透视表看板时对值中包含逗号的列进行操作。请考虑使用表达式看板在使用透视表看板之前修改该列的值。
