# 概述

除了直方图和图表等可视化工具外，Contour还提供了一个表达式面板，使您可以使用Contour丰富的表达式语言从数据中派生新列，执行复杂的筛选或复杂的聚合。Contour的表达式语言结合了SparkSQL中的许多函数。
