# 验证结果

在Contour中，您可以使用各种面板来检查分析生成的数据集。一些最简单的检查结果的方法是：

- 使用表格面板
- 使用表格面板
- 使用直方图面板
## 使用表格面板

通过在分析后插入一个表格面板，您可以快速检查是否有任何新列是正确的，或者之前面板的逻辑是否达到了预期结果。

## 使用表格面板

除了列出您已应用于数据集的面板的路径视图外，Contour还提供了一个表格面板。使用表格面板可以让您在应用每个面板时，以表格形式查看底层数据。

表格面板使表格（而不是面板）成为焦点，因此您可以看到随着您添加每个面板，数据如何更改。这在编写表达式时尤其有用。

您可以通过点击右上角的显示表格来切换到表格面板。再次点击该按钮或点击隐藏表格以返回到路径视图。

## 使用直方图面板

在分析后插入一个直方图面板，可以快速概览不同的数据类别，可用于数据的一般评估或检查筛选的类别是否正确。
