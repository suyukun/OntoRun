# 以数据集保存

您可以通过点击Contour路径底部的以数据集保存，将分析结果以Foundry中的数据集保存。

如果路径已经有一个关联的数据集，该数据集将显示在您的Contour路径底部。点击更新以使用新的逻辑或数据更新该数据集。请注意，如果您在Contour分析中更改了逻辑，通过Dataset Preview或数据沿袭工具搭建的结果数据集将不会更新用于搭建数据集的逻辑。您必须使用更新按钮来应用逻辑更改。如果您通过Dataset-app或数据沿袭搭建，数据更新将会被采纳。

在Contour中搭建的所有数据集将始终使用输入数据集的最新版本。这意味着即使分析使用的是旧版本的数据（例如，通过使用版本选择器），从分析搭建的数据集将始终使用最新版本。

您将无法保存一个以受限视图作为输入的路径为数据集。

在项目范围的分析中，所有输入和输出必须在范围内才能将路径结果保存为数据集。了解更多关于项目引用的信息。
