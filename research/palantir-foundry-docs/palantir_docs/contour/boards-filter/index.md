# 筛选数据

您可以使用Contour的许多可视化面板来筛选和可视化数据。本文档探讨了如何使用直方图、筛选和图表面板来实现这些操作。高级用户可能希望查看Contour的表达式语言以获取更强大的筛选选项。本页上的截图使用了来自Foundry参考项目的开源航空数据。

## 直方图面板

直方图是最简单的筛选方式之一，推荐用于直观地探索不熟悉的数据集。

创建直方图后，只需点击条形图即可筛选：

在直方图中选择条形后，直方图底部会显示保留行，其中column_name等于value。这表明您的工作数据集已被筛选到仅包含该特定列中具有该值的行。（如果您想仅保留不具有该值的行，可以使用下拉选择器将保留更改为移除。）

## 筛选面板

当您已经知道要寻找什么时，筛选面板最为有效。筛选面板非常灵活，可以让您准确输入您想要筛选的内容。

通过从操作栏中选择筛选来添加筛选面板：

点击添加筛选并选择您要筛选的列名（您可以开始输入列名以更快找到它）。输入您想要筛选的值，并用Enter键添加每个值。完成添加筛选后，点击保存。

### 多重数据筛选

- 使用AND 匹配如果您想筛选到同时满足多个条件的数据。
- 使用OR 匹配如果您想筛选到满足多个条件但不一定同时满足/在同一行数据中的数据。
### 调整筛选

当有人为特定筛选创建新的分析（例如carrier_code = DL）时，其他人可以通过更改筛选到他们的应用案例（例如carrier_code = UA）或完全移除筛选来轻松复制他们的分析，以执行全局分析。

在Foundry中，分析操作默认应用于整列，以便于分析大型数据集。如果您希望在较小的行选择上运行分析（类似于在Excel中选择特定单元格范围），请在应用操作之前将数据筛选到所需的行。

## 图表面板
