# 概览

Contour 提供了一个点击式用户界面，用于在大规模表格上执行数据分析。这些分析可以被用于创建交互式仪表盘，以引导和结构化的方式让其他人探索和研究数据。

Contour 的主要功能包括：

- 无需代码即可可视化、筛选和变换数据。
- 将复杂分析组织成分析路径。
- 参数化分析以便轻松切换不同的数据和结果视图。
- 创建交互式仪表盘以分享发现。
- 将分析结果保存为新的数据集，以在其他 Foundry 工具中使用。
- 利用 Contour表达语言进行更高级的变换和聚合。
Contour 非常适合以下分析应用案例：

- 您要使用的部分或全部数据未在 Ontology 中映射。通常，我们建议尽可能使用Ontology 层，但在某些情况下可能不适用（例如一次性上传不会被清理或重用）。
- 您需要处理非常大的数据集。例如，对超过 100,000 个对象进行合并或对超过 50,000 行进行聚合。
- 您希望将分析结果作为新的数据集分享，以在其他 Foundry 工具中使用。了解有关将结果保存为数据集的更多信息。
