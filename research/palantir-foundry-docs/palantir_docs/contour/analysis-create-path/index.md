# 创建路径

在Contour中，有两种类型的数据集可以用来开始新的分析路径：

- 平台上保存的数据集
- 当前分析路径中的结果数据集
## 从Foundry中的数据集开始分析

在Foundry中，每个用户都有一个名为您的文件的文件夹。这个文件夹是用户可以用来进行数据原型设计并与其他用户分享结果的地方。进入文件夹后，用户可以创建他们的首次分析：

- 导航到项目和文件模块。
- 导航到您的文件。
- 通过选择绿色的**+新建操作菜单并在下拉菜单中选择分析**来创建新分析。
- 在新分析生成后选择**+创建新路径**。
- 在相应的文件夹中选择您想要分析的数据集。
## 使用结果数据集开始新路径

单个分析可以包含多个路径，通常使用一个路径中的结果作为新路径的起始点是很有价值的。我们建议在第一个路径上对数据集进行所有的筛选。这使您可以在其他路径中利用结果数据集来生成可视化并进一步变换感兴趣的数据集。我们还建议在您的Contour分析中将参数的使用整合到此主要筛选路径中。

每个路径的底部都是一个结果数据集，反映了使用路径中的面板进行的所有变换。您可以使用结果数据集作为同一分析中新路径的起始数据集，而无需保存结果数据集。

保存结果数据集将使其可以与其他Contour分析以及平台上的其他工具一起使用。如果您在同一Contour分析的另一路径中继续分析，则无需保存结果数据集。
