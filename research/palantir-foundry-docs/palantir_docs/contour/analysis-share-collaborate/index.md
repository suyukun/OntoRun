# 分享和协作分析

## 分享Contour分析

您可以直接与其他用户分享Contour分析。如果您在分享后对分析进行了更改，分享的分析将自动更新，以便其他用户始终看到当前版本。

与其他用户分享资源需要他们拥有您正在使用的项目和数据集的访问权限。点击分享按钮，可以发送分享URL或直接将用户添加到资源并通知他们。也可以与其他用户协作进行分析。如果您希望其他用户能够编辑您的资源，请在生成分享URL时选择编辑者。

如果用户收到权限被拒绝出错，他们需要请求访问权限。一旦该用户的项目访问权限获得批准，他们将能够通过电子邮件查看您分享给他们的分析。

如果您正在合并其他数据集以丰富您的Contour分析，其他用户需要对这些合并的数据集拥有权限才能查看完整的分析。

## 在Contour分析上进行协作

当与其他用户分享Contour分析时，您可以通过在分享时选择编辑者，允许该用户编辑您的资源。这将允许用户更改您的分析，包括但不限于：

- 添加/删除/编辑看板
- 添加/删除/编辑参数
- 删除路径
- 更改分析设置
为了防止分析的并发编辑，Contour使用锁定系统，允许在任一时间内仅有一个用户在一个浏览器窗口中使用编辑模式。如果尝试在另一个用户正在编辑该分析时以编辑模式打开分析，视图模式选择器将更改外观：

弹出框将列出当前正在编辑该分析的用户。在该用户完成编辑之前，您将无法访问编辑模式，完成编辑的方式包括切换到查看模式或关闭Contour分析。之后，您将能够访问编辑模式；您还将在Contour分析的顶部看到通知：

选择重新加载分析后，Contour将重新加载您的分析（以加载可能已做出的任何更改）并尝试再次访问编辑模式。

另外，如果您处于编辑模式且另一个用户正在等待锁定，您将在十五分钟不活动后自动切换到查看模式。

如果您在多个浏览器标签页中打开分析，您只能在其中一个标签页中使用编辑模式。所有其他尝试访问编辑模式的标签页将被置于“文档已锁定”模式。
