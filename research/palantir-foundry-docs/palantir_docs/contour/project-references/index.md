# 项目引用

在 Foundry 中，项目定义了相关工作的概念边界以及应用和管理访问的安全边界。在跨项目边界使用数据时，必须格外小心。

## 引用资源

项目引用为具有更高权限的用户提供了一种机制——通常是数据集或管道的所有者——以允许在其他项目的管道中发现和使用数据。项目引用通过明确承认将数据集导入项目中，为在项目间持久地移动数据增加了一层审查。

要引用资源，请转到项目根级别的项目导航面板。单击+Add按钮以添加对数据集的引用。在下图中，数据集flights和training_data被添加为项目中的引用。这意味着您可以将flights和training_data作为输入用于 Contour 分析中的已保存数据集。

- 要引用资源，您必须在资源上拥有compass:import-resource-from（通常从只读角色扩展）和在目标项目上拥有compass:import-resource-to（通常从编辑者角色扩展）。
- 这些角色可以使用自定义角色进行定制。
## 项目范围的分析

为了在项目范围分析中保存路径末端的数据集，所有输入和输出必须在项目范围内。

- 路径的所有输入数据集必须在项目范围内：它们必须与工作簿在同一项目中，或者作为引用添加到项目中。
- 输出数据集必须与分析在同一项目中。
请参阅侧边栏的设置选项卡中的分析项目范围设置。任何超出范围的输入或输出数据集都将在项目范围对话框中列出。您可以选择直接从对话框中添加引用。

当输入数据集超出范围时，结果面板中也会有一个提示。点击Add references将打开项目范围对话框。

除非您要保存结果数据集，否则无需添加引用即可在 Contour 分析中使用输入数据集。

## 在分析中启用项目范围

对于在默认启用项目范围之前创建的分析，您可以在设置侧边栏面板中启用项目范围。在您可以启用项目范围之前，必须通过添加对输入的引用来解决任何超出范围的输入，并通过将输出移动到用于分析的项目来解决任何超出范围的输出。
