# 更改宽度和高度

Foundry Reports应用程序已停止使用，旧版报告现仅可查看。有关更多详细信息，请参阅Reports停止使用公告。

Foundry Reports中的内容组织为行，每行至少包含一个微件。

## 更改行宽度

每行可以显示为以下三种宽度之一：

- 全宽。占据页面宽度的100%。最小压缩为600px。
- 中宽。显示宽度为820px。最小压缩为540px。
- 窄宽。显示宽度为570px。最小压缩为540px。
默认情况下，添加到报告中的微件将以中宽度显示在其自身的行上。

### 更改单行的宽度

要更改一行的宽度：

- (如有需要)切换到编辑模式。
- 点击行右侧的设计控制按钮。
- 选择一个新的宽度（窄宽、中宽或全宽）。
### 更改所有内容的宽度

为了方便起见，您也可以通过一次操作将报告中的所有内容更改为全宽。有关详细信息，请参阅在报告中将所有内容显示为全宽。

## 更改行高度

大多数微件也可以垂直调整大小。这对于调整图表和其他填充可用容器的内容大小非常有用。

### 自动高度

默认情况下，微件会自动调整大小，根据微件的类型选择一个合理的初始高度。

某些微件将始终自动调整其大小以适应其内容，无法手动调整大小。特别是：

- 文本微件（请参阅在报告中添加文本）
- 表格微件（请参阅在报告中添加表格），以及
- 图像和视频（请参阅在报告中添加新图像或视频）。
从其他Foundry应用程序添加的微件通常可以垂直调整大小。

## 在报告中将所有内容显示为全宽

如果需要，您可以调整报告中单个行的大小（请参阅更改单行的宽度和高度）。然而，一些报告可能包含许多在全宽下看起来最佳的微件。为了方便起见，您可以通过一次操作将报告中的所有内容更改为全宽。
