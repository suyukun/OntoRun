# 概述

从2023年8月起，大多数客户已被禁用新建Foundry报告的功能，现有（“传统”）Foundry报告为只读，并且Foundry报告应用对新客户不可用。传统报告仍可查看且无需转换或过渡到新格式，除非需要编辑。

现在所有客户都有以下选项可替代Reports的仪表盘和报告功能：

- Contour仪表盘用于Contour分析驱动的内容。Contour仪表盘提供比Reports更好的交互性，具备图表到图表的筛选功能，以及简易的拖放界面以在分析迭代中搭建仪表盘。Contour仪表盘支持全屏演示视图和PDF导出。开始使用Contour仪表盘。
- Quiver仪表盘用于Quiver分析驱动的内容。开始使用Quiver仪表盘。
- Notepad用于跨产品报告。使用Notepad，您可以创建实时更新和静态（“时间点”）文档，注释文档，在平台内共享文档，并以PDF格式导出文档。开始使用Notepad。
在禁用新报告创建之前，Palantir提供了以下功能：

- 能够将Contour仪表盘导出为PDF或按计划通过电子邮件发送。
- 能够按计划通过电子邮件发送Notepad文档。
- 能够将传统报告转换为Contour仪表盘或Notepad文档。
如有任何疑问，请联系Foundry支持。

[1] 如果您的平台团队或Palantir代表就报告下线时间表或细节进行了不同的沟通，请参考该信息。

Foundry 报告工具使您能够：

- 显示来自Foundry分析工具（如Contour、Quiver、Fusion和Object Explorer）的图表和可视化。
- 自动更新图表以获取最新的Foundry数据。
- 创建实时报告（图表自动更新为最新的Foundry数据）或静态历史数据报告。
- 撰写关于您的分析工作的富文本描述。
- 通过报告中的评论与同事协作。
- 通过附加图像或其他文件提供更多背景信息。
