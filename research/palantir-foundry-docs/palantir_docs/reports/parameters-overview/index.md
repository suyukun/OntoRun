# 概述

Foundry Reports 应用程序已被终止，遗留报告现仅可作为只读使用。有关详细信息，请参阅Reports 停用公告。

参数允许报告访客轻松切换他们所看到的数据类别。例如：

- 如果您正在撰写一个显示月度销售数据的报告，您可能会创建一个月份参数，以便报告访客可以查看一月、二月或三月的数据。使用月份参数的图表会在用户选择不同月份时更新。
- 如果您正在撰写一个与特定地理区域相关的图表报告，您可能需要一个区域参数，以便报告访客可以查看在观察北美、欧洲或亚洲时图表有何不同。
### 参数类型

有几种不同类型的参数：

- 数字
- 字符串，例如“北美”、“欧洲”、“亚洲”。
- 日期。对于一个显示随时间变化的销售数据的报告，您可以创建起始日期和结束日期参数，以便报告访客可以决定查看哪个日期范围的信息。您还可以设置一个相对日期，使参数的值相对于查看报告的时间。请注意，一周的第一天指的是该周的星期天。
