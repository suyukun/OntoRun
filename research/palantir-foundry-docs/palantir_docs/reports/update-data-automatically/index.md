# 自动更新数据

Foundry Reports 应用程序已停止服务，遗留报告现仅可查看。有关详细信息，请参阅报告停止服务公告。

## 报告打开时自动更新数据

报告默认是实时的，这意味着每当打开报告时，所有内部的图表将加载基础 Foundry 资源中反映的最新数据。

为了使基础 Contour 分析自动更新为最新可用数据，请确保为报告中使用的任何 Contour 分析启用了打开时刷新分析数据设置。

### 刷新特定微件

如果在您查看或编辑报告时图表的数据更新，或者自动刷新已关闭，您将在图表上看到过期警告以及刷新数据的选项。点击更新数据集和逻辑来更新该特定微件：

现在，每次打开报告时，您的报告将刷新报告中所有有更新的微件。

## 禁用报告中的数据更新

要使您的报告静态并显示特定时间点的数据，请更改报告的更新设置：

- 当显示过期警告关闭时，您（以及此报告的访客）将不会在各个微件上看到过期警告。
- 当刷新报告数据和逻辑关闭时，报告将不会在打开时自动更新为最新数据。您可以通过点击微件过期警告内的 "更新数据集和逻辑" 文本手动刷新特定微件的数据。
