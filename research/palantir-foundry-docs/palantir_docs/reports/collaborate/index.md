# 在报告中协作

Foundry 报告应用程序已被终止，旧版报告现在只可查看。详情请参阅报告终止公告。

报告提供了有限的功能，允许多个用户在单个报告上协同工作。

## 在微件上评论

编辑者和访客可以在报告中的任何微件上发表评论，包括文本块、表格、媒体、来自其他 Foundry 应用程序的内容等。

## 添加和删除微件后的更新

当一个用户在报告中添加或删除微件时，报告将立即更新以反映更改（有时会稍有延迟）。其他报告编辑者和访客无需重新加载报告即可看到更改。

## 编辑时锁定

一次只允许一个用户编辑一个微件。当一个报告编辑者正在编辑某个微件时，其他报告编辑者将看到该微件显示为“已锁”，无法编辑。这旨在防止用户覆盖彼此的工作。
