# 添加或更改报告标题

Foundry Reports 应用程序已经被终止，旧版报告现在只能查看。有关详细信息，请参阅报告终止公告。

有几种添加或更改 Foundry 报告标题的方法。

## 通过报告

- 切换到编辑模式。(您必须对该报告有编辑权限才能执行此操作。)
- 点击报告标题。
- 输入新的报告标题。
- 点击标题外部或使用回车键保存更改。
## 通过应用程序头部

- 切换到编辑模式。(您必须对该报告有编辑权限才能执行此操作。)
- 点击屏幕顶部应用程序头部的资源标题。
- 输入新的报告标题。
- 点击标题外部或使用回车键保存更改。
## 通过您的文件视图

与 Palantir Foundry 中的任何资源一样——无论是报告还是其他资源——您可以在项目中查看资源时更改标题：

- 右键点击文件列表中的报告。
- 在出现的上下文菜单中点击“重命名”。
- 输入新的报告标题。
- 点击标题外部或使用回车键保存更改。
## 错误和验证

报告标题中不允许某些字符和格式：

- 标题不能为空。
- 标题不能超过716个字符。
- 标题不能包含斜杠(/)。
- 标题不能包含换行符。
如果特定标题不可接受，应用程序通常会在保存之前显示错误信息。否则，您可能会在保存后看到错误。
