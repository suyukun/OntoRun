# 添加参数

Foundry Reports 应用程序已被淘汰，旧版报告现在仅以查看模式提供。有关详细信息，请参阅报告淘汰公告。

## 在文本中添加参数

您可能希望在文本块中显示参数的当前值。要执行此操作：

- 选择一些文本。
选择一些文本。

- 单击格式工具栏中的参数按钮以创建新的字符串参数。
单击格式工具栏中的参数按钮以创建新的字符串参数。

- 将新参数合并到所需的 Contour 参数中。了解有关合并参数的更多信息。
将新参数合并到所需的 Contour 参数中。了解有关合并参数的更多信息。

合并参数的当前值现在将在查看模式下行内显示（在编辑模式下，仅参数名称将行内显示）。

## 从其他 Foundry 应用程序添加参数

某些 Foundry 应用程序允许编辑者添加参数来控制数据在可视化中的筛选方式。从另一个 Foundry 应用程序向报告中添加微件（例如，从 Contour 添加面板）也会自动添加任何影响它的参数。

### 从 Contour 添加参数

了解有关 Contour 中参数的更多信息。

- 打开 Contour 分析，然后创建或打开路径。
打开 Contour 分析，然后创建或打开路径。

- (如有需要)切换到编辑模式。
(如有需要)切换到编辑模式。

- 创建参数（例如，名为$value的字符串参数）。
创建参数（例如，名为$value的字符串参数）。

- 向您的路径添加一个筛选面板。输入要筛选的列名，然后在值字段中输入参数名（例如$value）。
向您的路径添加一个筛选面板。输入要筛选的列名，然后在值字段中输入参数名（例如$value）。

- 在筛选面板下方创建一个可视化面板*(例如，图表、表格)*。
在筛选面板下方创建一个可视化面板*(例如，图表、表格)*。

- 将可视化面板添加到报告中（参见：从 Contour 添加面板）。
将可视化面板添加到报告中（参见：从 Contour 添加面板）。

可视化面板将出现在您选择的报告中，并且$value参数将出现在报告的参数栏中。更改参数值现在将更改在可视化面板中显示的数据。
