# 复制报告

Foundry Reports 应用程序已被淘汰，旧版报告现在仅作为查看使用。有关详细信息，请参阅报告淘汰公告。

有多种方式可以复制报告，每种方式如下所述。

## 通过报告

- 打开操作菜单。
- 点击复制报告
## 通过应用程序标题

- 打开文件菜单。
- 点击复制文件
## 通过您的文件视图

与 Palantir Foundry 中的任何资源一样，无论是报告还是其他内容，您可以在项目中查看资源时复制报告：

- 右键点击文件列表中的报告。
- 在出现的上下文菜单中点击操作。
- 点击复制报告。
