# 以PDF或PowerPoint格式导出

Foundry Reports应用程序已停止使用，遗留报告现在仅以查看模式提供。有关更多详细信息，请参阅报告停止公告。

报告可以以PDF或PPT格式导出。

导出时，Contour表面板将尝试显示数据集中最多1000行和所有列，这可能会跨越多页。使用预览功能查看导出时报告的外观。
