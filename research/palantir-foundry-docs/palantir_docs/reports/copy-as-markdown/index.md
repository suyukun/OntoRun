# 将报告文本复制为Markdown格式

Foundry Reports应用程序已被淘汰，遗留报告现在仅可查看。有关更多详细信息，请参阅报告淘汰公告。

报告文本可以快速以Markdown格式导出。

Markdown是一种用于样式化文本（如加粗、斜体、下划线）和指定文档结构（标题、表格、列表等）的标记语言。Markdown是一种开源标准，兼容Palantir Foundry内外的许多应用程序。

由于Markdown语法是纯文本，Reports应用程序通过将文本复制到剪贴板以便您粘贴到其他地方来“导出”Markdown。只有文本和表格微件（参见向报告中添加表格）将包含在报告的Markdown表示中。

要以Markdown格式导出报告：

- 点击应用程序右上角的操作。
点击应用程序右上角的操作。

- 点击复制文本为Markdown。
点击复制文本为Markdown。
