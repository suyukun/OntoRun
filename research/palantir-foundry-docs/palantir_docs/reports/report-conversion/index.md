# 将旧版 Foundry 报告转换为 Contour 或 Notepad

旧版 Foundry 报告可以转换为 Contour 仪表盘或 Notepad 文档。

在转换过程中，原始报告不会被删除，您可以多次转换同一报告。除非需要编辑，否则旧版报告无需转换。

一旦您的报告被转换，您可以选择其中一个转换资源作为“指定替代品”，使其成为原始报告的权威转换版本。

## 选择 Contour 或 Notepad

Foundry Reports 将根据您的报告内容建议最佳工具，但您可以选择转换为 Contour 仪表盘或 Notepad 文档，如下所述。

- Contour 仪表盘最适合由 Contour 分析驱动的内容。Contour 仪表盘在交互性上比报告更优，具有图表间筛选等功能，并提供一个简单的拖放界面来搭建仪表盘，同时迭代分析。Contour 仪表盘还支持全屏演示视图和 PDF 导出。如果：您的报告仅包含 Contour 嵌入。您的报告使用参数。

## 选择指定替代品

当旧版 Foundry 报告至少被转换为 Contour 或 Notepad 一次后，您可以从原始报告顶部出现的横幅中访问转换资源。您还可以选择其中一个资源作为原始报告的指定替代品。

当选择了指定替代品后，任何打开 Reports 应用中原始报告的人都会在顶部出现的横幅中看到指向新 Contour 仪表盘或 Notepad 文档的链接。

如果在选择指定替代品后改变主意，您可以将该资源降级并选择另一个资源替换。
