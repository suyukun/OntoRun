# 与他人分享报告

Foundry 报告应用程序已被弃用，遗留报告现在仅可作为只读访问。有关详细信息，请参阅报告弃用公告。

要分享您的报告，请点击报告右上角的分享按钮：

由于 Foundry 旨在确保任何敏感数据的安全，您还需要分享报告中的资源，以便访客可以查看。例如：

- 如果您的报告包含图片或链接到其他 Foundry 文件，请确保您的报告访客也对这些文件拥有查看权限。
- 如果您的报告显示来自特定数据集的信息，您的报告访客需要对该数据集拥有查看权限。
## 预览

要预览他人在接收您的报告时会看到的内容，您可以通过切换编辑/查看模式按钮进入阅读模式：

如果您的报告访客在分享报告和底层数据集/文件后仍无法查看报告的内容，请使用数据沿袭应用程序来确定用户的资源访问和权限。
