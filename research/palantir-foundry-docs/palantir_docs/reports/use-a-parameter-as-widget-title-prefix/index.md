# 使用参数作为微件标题前缀

Foundry Reports 应用程序已停止使用，旧版报告现已仅供查看。有关更多详细信息，请参阅报告停止使用公告。

您可以使用参数作为微件标题的前缀。

参数将始终显示为前缀。目前无法在微件标题的中间使用参数值。

- 在编辑模式下，点击微件右上角的齿轮。
- 选择一个现有的参数作为微件标题的前缀。参数必须是字符串参数。
在编辑模式下，您将看到微件标题中的参数名称。

在查看模式和报告的任何导出中，将填充参数的值。
