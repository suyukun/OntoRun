# 更改参数

Foundry Reports 应用程序已被淘汰，遗留报告现在仅以查看模式提供。有关详细信息，请参阅报告淘汰公告。

## 在编辑模式下设置默认参数值

参数的默认值是打开报告时参数将使用的值。

要编辑参数的默认值：

- (如果需要)切换到编辑模式。
- 在参数栏中选择参数旁边的齿轮图标。
- 找到默认值字段，并根据需要更改值。
- 选择保存。
新默认值将替换可能已存在的任何当前值。

## 在查看模式下更改参数值

通过参数的输入字段更改参数值将使用当前值覆盖默认值。通常情况下，当前参数值在报告再次打开时会恢复为默认值。然而，当前值可以通过将它们存储在 URL 中来保留；详见下文。

### 有用的提示

#### 重新打开报告时保留当前参数值

您可能希望刷新报告并保持当前值不变，或者与非默认值共享报告。Reports 通过在您修改时将参数值附加到报告 URL 来支持这一点。

例如，如果您打开报告，初始 URL 可能如下所示：

/workspace/report/ri.report.main.report.123

将Month参数的值更改为July（覆盖参数的默认值）将自动更新 URL 为：

/workspace/report/ri.report.main.report.123?Month=July

刷新页面时，将为月份参数预填入值July。这在刷新大型、复杂的报告时可以节省时间。

要在打开报告时显示默认参数值，请删除 URL 中的任何尾随参数（例如?Month=July&Year=2019）。

#### 复制带有当前参数值的链接

点击参数栏中的复制链接按钮，以复制一个可分享的 URL，该 URL 将以您当前使用的完全相同的参数值加载报告。
