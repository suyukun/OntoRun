# 参数

您可以在AIP Agent上配置字符串或对象集参数。当包含参数的AIP Agent嵌入到AIP互动微件中时，参数列表将会出现，用户可以将每个参数映射到相应类型的工作坊变量。

## 在AIP Chatbot Studio中的配置

设置参数时，请确保执行以下操作：

- 识别正确的参数：首先识别LLM应该能够与之交互的内容。这些内容可能已经存在于您的工作流程中，例如代表用户当前选择的变量，或者是LLM写入结果的新变量。
- 命名并描述参数：对于每个参数，编写说明以解释其作用。该说明将被注入到代理的提示中，为LLM提供何时使用它的上下文。
- 声明访问模式：指定LLM是否应对每个参数具有读访问、写访问或两者兼有的访问权限。此步骤决定LLM如何与参数交互。
参数还可以在模型选项卡的用户定义系统提示中通过键盘上的斜杠命令/进行引用。

参数可以使用调试参数值部分进行测试。您可以手动覆盖每个参数的值，调试部分将在代理更新参数值时提供视觉反馈。

## 在工作坊中的配置

如果AIP Agent已经配置了参数，则在工作坊中配置代理参数的选项将会显示。有关更多详细信息，请查看AIP互动微件文档。
