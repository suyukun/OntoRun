# 检索上下文

具有检索上下文的AIP代理将在每次接收到新的用户消息时，确定性地从数据源中获取信息传递给LLM。这与具有更快的起始词元时间的单次完成提示策略兼容。

您可以为您的代理配置两种类型的检索上下文之一：

- Ontology上下文
- 文档上下文
## Ontology上下文

Ontology上下文允许用户在发送的每条消息中对对象集执行语义搜索，并将搜索结果作为附加上下文提供给LLM用于其答案。Ontology上下文不同于Ontology语义搜索工具，因为它不是有条件应用的（如果LLM认为不相关，则可能不使用该工具），并且该工具提供了调用函数以返回语义相似对象的附加能力，而不是配置向量属性。

选择Ontology上下文后，配置您希望进行语义搜索的对象集。

我们目前仅支持一种对象类型的对象集，并且该对象类型必须包含一个向量属性以执行语义搜索。该对象集可以是整个对象类型（“静态输入”）或对象集参数（“参数”）。

传递给LLM作为上下文的最大对象数量可以配置，值范围从1到25，默认值为5。您还可以配置1到5个内容属性传递给LLM作为附加上下文。

在会话期间，我们在Object Explorer中用链接呈现内容属性。这在发送消息和接收消息之间的可折叠上下文消息中可见。

## 文档上下文

文档上下文允许用户在发送给LLM的每条消息中包含来自文档的相关文本。文档可以通过与在AIP Threads中添加到对话中的相同方式进行选择和包含在AIP代理的配置中。选择文档上下文 > 选择文档或从最近上传的文档中选择。
