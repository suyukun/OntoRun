# 菜单栏配置

工作区的顶部栏被称为“菜单栏”。切换到工作区编辑侧边栏中的菜单栏配置选项卡，以配置工作区的菜单栏。自定义菜单栏的选项包括：

- 固定模块
- 新标签页模块
## 固定模块

您可以在固定模块部分配置菜单栏中显示的项目。为了便于访问，菜单栏中的固定模块在Carbon中始终可见。我们强烈建议将固定模块限制为预期用户日常工作流程中使用的项目。

为了向菜单栏添加元素，请选择添加元素按钮。这将打开一个弹出窗口，提示您选择模块类型。固定模块可以包括以下内容：

- Object视图
- Object集/探索
- Object类型探索
- 工作室模块
- Quiver模板
- Slate应用程序
- 搜索应用程序
## 新标签页模块

菜单栏包含一个**+图标，允许启动应用程序或在新的Carbon标签页中打开项目。您可以在新标签页模块**部分配置此菜单中显示的项目。新标签页模块可以是与固定模块相同类型的资源。

## 通知

Carbon菜单栏包含一个通知图标，供用户接收通知。并非所有来自Foundry的通知都会显示在Carbon菜单栏中。具体来说，只有以下应用程序和工作流程的通知会显示：

- 公告
- Ontology操作
- Object评论
- 与您共享的资源
- 资源访问请求
- 审批
- 问题
