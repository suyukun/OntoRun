# 概述

Carbon允许搭建人员创建由模块组成的工作流，以便用户访问Foundry应用程序的预定义版本。换句话说，Carbon模块是一个在Carbon标签中打开的参数化应用程序。

模块可以通过连接它们的输入和输出来在导航工作流中链接在一起；例如，航空公司的Carbon工作流可能从Aircraft对象的对象视图开始，然后引导用户进入预制的Quiver分析。

可用的Carbon模块包括：

- 对象视图中的Objects、对象集和对象类型
- Workshop模块
- Quiver模板
- Vertex图
- Slate应用程序
- Object Explorer中的搜索
- Notepad文档（只读）
