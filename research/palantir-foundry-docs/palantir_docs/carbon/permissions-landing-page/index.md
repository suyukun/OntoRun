# 将Carbon设置为Foundry默认位置

在某些情况下，您可能希望用户在访问Foundry时立即进入一个Carbon工作区；换句话说，使Carbon工作区成为Foundry中的用户主页。要为您的整个组织配置此设置，请前往/workspace/control-panel并在左侧面板中导航至平台体验。如果您希望用户进入他们的默认工作区，请将主页URL配置设置为/carbon。

如果您希望在更细致的层面上进行配置，并控制特定用户组的默认位置，请点击新建主页URL。
