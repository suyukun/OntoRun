# 示例工作区

## 航空工作区

Carbon工作区旨在为操作用户提供简化的Foundry界面。下面的截图展示了一个简单的工作区，设计用于航空公司分析师审查与特定航线性能相关的警报。此Carbon工作区包括指向相关应用程序和数据的快速链接，以及访问分析师“收藏”的个人Object。要了解此工作区的构建方式，请参阅入门教程。

## 索赔门户

Carbon工作区还允许用户了解他们的数据并在操作流程中做出决策。例如，公司可能希望为客户支持分析师创建一个界面，以调查保修索赔。在下面显示的Carbon工作区中，用户可以管理、分类和操作向客户支持团队提出的索赔。

Carbon工作区通常在图形用户界面中创建和编辑（如入门教程中所示），但您也可以直接编辑指定Carbon工作区的YAML文件。要查看索赔门户工作区的YAML，请查看YAML代码示例和YAML配置参考。
