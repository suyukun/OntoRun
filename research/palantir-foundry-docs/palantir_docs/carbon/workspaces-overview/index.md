# 概述

Carbon 工作区是一个经过精心策划的应用程序和资源集合，可配置以优化用户工作流程。

Carbon 工作区可以用于提升 Foundry 资源的可发现性，这些资源可以在主页上链接，通过搜索发现，或者添加到 Object Explorer 中的Open in菜单。

通过配置 Carbon 中的导航和自定义菜单栏，工作区搭建者可以创建一个工作流程，使用户能够无缝地浏览他们可以与特定 Object 进行交互的资源。

## 主页

Carbon 提供一个可配置的主页作为每个工作区的入口。主页显示一个 Ontology 感知的搜索栏以及可配置的链接模块、Object 类型和其他 Foundry 资源的部分。或者，可以选择任何模块作为工作区的主页。

管理员可以配置徽标以及主页链接的内容和设计。更多信息，请参阅主页配置文档。

## 菜单栏

每个 Carbon 工作区都有一个可自定义的菜单栏，包含以下组件：

- 导航菜单，这是一个可配置的下拉菜单，包含推广的工作区和外部应用链接。
- 包含锚定模块的标签，这些模块是工作区应用案例的关键。
- 一个非必填按钮，用于在工作区标签中打开其他模块。
- 用于帮助资源的工具按钮，和可选的通知，以及一个工具按钮，提供查看用户个人资料或登出 Foundry 的选项。
阅读更多关于菜单栏配置的信息。

## 推广的工作区

推广的工作区是那些显示在导航菜单中的工作区。推广的工作区在组织级别配置。

在导航菜单中，每个用户将看到他们有权访问的所有推广的工作区，以及他们作为成员或访客的所有组织。

非推广的工作区可以在项目中打开或通过直接链接打开。
