# 将Carbon工作区添加到Marketplace产品 [Beta]

使用Foundry DevOps将您的Carbon工作区包含在Marketplace产品中，以供其他用户安装和重用。了解如何创建您的第一个产品。

## 支持的功能

许多Carbon功能都受到支持，但以下功能除外：

- 演练（即将推出）
- 非Workshop、Object类型或“链接到Foundry应用程序”的模块类型
- 使用组以“默认Object类型进行搜索”
- “选择Objects”项目类型
## 将Carbon工作区添加到产品中

要将Carbon工作区添加到产品中，首先创建一个产品，然后按照下面选择工作区内容类型并选择您的工作区。
