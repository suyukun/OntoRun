# 查看版本历史

工作区版本历史允许您预览、非必填进行编辑，并重新发布以前的工作区版本。如果工作区配置更新导致出错，这使您能够快速返回到已知的工作配置。

## 版本对话框

版本对话框是查看版本元数据的地方，您可以选择一行以设置为预览的版本。

## 版本按钮

可以通过选择位于配置编辑器顶部的版本按钮来启动版本对话框。您当前正在编辑的版本的版本号显示为此按钮中的文本。

### 未保存编辑指示器

如果有未保存的编辑，则版本号后会出现星号（*）。

### 预览版本

当从版本对话框中选择一个版本时，版本按钮旁将显示一个预览标签。
