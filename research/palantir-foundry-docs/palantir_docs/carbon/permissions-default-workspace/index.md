# 设置默认工作区

默认工作区是指用户访问/workspace/carbon/时将被引导至的工作区。

由于用户可以访问多个 Carbon 工作区，我们建议为每个用户组设置一个默认工作区。为了为用户组设置默认工作区，该工作区必须同时被提升并且在为其配置的默认用户组列表中。

要在登录 Foundry 时将用户重定向到默认 Carbon 工作区，您必须首先配置主页 URL。

## 将用户组添加到默认工作区列表

每个 Carbon 工作区都有一个包含该工作区为默认的用户组的列表。管理员可以在配置编辑器中某个工作区的访问选项卡下的默认工作区标题下更新此列表。

请注意，默认工作区更新是独立于其他配置更改保存的；进行更改后，新默认工作区将立即应用。

### 如果用户组没有配置默认工作区怎么办？

如果用户不属于任何配置了默认工作区的用户组，当他们第一次访问 Carbon 时，将被要求从已提升的工作区列表中进行选择。从此时起，最近访问的工作区将被视为用户的默认工作区。

请注意，最近访问的工作区存储在浏览器的 cookie 中，因此如果用户清除 cookie 或在其他浏览器/设备上访问 Carbon，他们将再次被要求从可用的工作区列表中进行选择。

### 如果用户有多个默认工作区怎么办？

如果用户有两个或更多默认工作区，他们实际上将没有默认工作区。这将导致与未配置默认工作区时相同的行为。这可能在两种情况下发生：

- 用户在一个有两个或更多默认工作区的用户组中。
- 用户在两个或多个具有不同默认工作区的用户组中。
如果适用这种情况，并且用户之前访问过 Carbon，他们将默认为最近访问的工作区，如上所述。
