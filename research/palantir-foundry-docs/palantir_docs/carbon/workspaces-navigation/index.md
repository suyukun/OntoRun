# 配置工作区之间的导航

导航菜单允许用户在Carbon工作区之间移动并访问其他Foundry应用程序。为了使工作区在导航菜单中对用户可见，用户必须对工作区资源具有查看权限，并且属于工作区“推广”的组织。导航菜单还可以显示到其他Palantir Foundry应用程序的链接。

请注意，未推广的工作区不会显示在导航菜单中，但用户仍然可以通过直接链接访问它们。

## 推广和隐藏工作区

只有Carbon管理员可以编辑每个组织的推广工作区列表。要配置推广工作区，请通过单击菜单栏中的编辑按钮进入编辑模式。

一旦打开编辑侧边栏，首先在侧边栏顶部的下拉菜单中选择您要配置的组织（A）。请注意，只有当您在多个组织中具有Carbon管理员权限时，才会出现下拉菜单。

选择所需的组织后，您可以通过单击编辑（B）对该组织的工作区进行重新排序和降级，并通过单击完成保存。允许列表的更改将立即保存并实施。

要将新工作区添加到导航菜单中，您可以（C）打开一个现有工作区（尚未推广到允许列表）或（D）创建一个新工作区，然后在编辑侧边栏的访问选项卡中推广工作区。

请注意，推广的工作区配置适用于整个组织，而不是特定工作区。某个组织中的所有用户将看到相同的配置，而不论他们处于哪个特定工作区。

## 向导航菜单添加额外链接

如果用户需要访问Carbon中不可用的平台部分，您可以在导航菜单中配置额外链接。在编辑侧边栏模式下，单击组织部分中的配置以打开组织元数据对话框。从这里，添加到特定平台应用程序的链接或设置到平台其他部分的自定义链接。对于每个链接，您可以设置自定义图标、链接标题或相对URL。

按照这些说明在工作区级别覆盖组织级别的外部链接。
