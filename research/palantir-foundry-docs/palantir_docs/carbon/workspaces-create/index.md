# 创建工作区

每个 Carbon 工作区在 Foundry 中作为一个单独的文件资源存储在一个项目中。每个工作区文件都有其自己的访问权限。

要创建一个新的 Carbon 工作区，首先通过 Carbon 菜单栏右侧的编辑按钮进入编辑模式。

对于没有默认 Carbon 工作区的用户，编辑按钮将不可见。然而，如果他们拥有创建 Carbon 工作区的必要权限，他们可以通过在 URL 中导航到workspace/carbon/edit来访问编辑器侧边面板。

在右侧打开的编辑器侧边面板中，选择底部的创建工作区按钮。

继续为您的工作区命名并选择存储资源的位置。

我们建议将工作区放在您计划包含在工作区中的其他资源所在的同一文件夹中。例如，将工作区放在包含您计划在此特定工作区中展示的所有 Workshop 模块的文件夹中。这样，文件夹级别设置的权限可以应用于所有资源。

将工作区保存到项目中后，您将被重定向到新创建的 Carbon 工作区。

您可以通过检查工作区名称是否与左上角的工作区名称对应来验证这一点。您现在可以继续配置您的工作区。

每个新工作区都创建了一个包含默认图标的默认主页，基于 Object Explorer 的搜索栏，以及两个列，显示重要的 Object 类型（B 列，中间列）和来自 Object Explorer 的已保存探索（C 列，右侧列）。
