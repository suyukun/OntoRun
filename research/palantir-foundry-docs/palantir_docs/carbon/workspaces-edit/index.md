# 编辑工作区

## 访问编辑侧边栏

要编辑工作区，请通过Carbon菜单栏右侧的编辑按钮进入编辑模式。

这将打开编辑侧边栏，您可以在其中选择要编辑的工作区。组织管理员可以通过点击侧边栏顶部的所有工作区按钮查看所有可编辑的工作区。非管理员用户将默认看到他们所有可编辑的工作区。

有关可用配置选项的详细信息，请参阅配置参考，从通用配置开始。

## 保存并发布配置

一旦打开编辑侧边栏，可以通过选择面板右上角的保存按钮保存更新后的配置。保存配置将立即发布更新后的配置。

如果您不想保存对配置所做的更改，可以通过选择放弃按钮（位于保存按钮旁边）来放弃这些更改。
