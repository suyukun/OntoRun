# 入门指南

要配置Carbon工作区，Foundry开发人员需要正确的权限。

本指南演示了使用Foundry培训和资源项目中的资源创建一个简单的Carbon工作区，该项目是Foundry平台的一部分。最终结果是一个航空工作区，旨在供航空公司分析师查看与特定航线表现相关的警报。此工作区包括指向相关应用程序和数据的快速链接，以及访问分析师最喜欢的个人对象。

航空工作区示例代表了Carbon配置的最低要求，旨在用作简单的参考。其余的Carbon文档包含可用配置选项的完整描述。

## 创建一个新的工作区

要配置新的Carbon工作区，首先从应用程序门户打开Carbon工作区。然后，按照说明创建新的Carbon工作区。

## 编辑模式介绍

每个Carbon工作区在右侧边栏中都有四个配置标签：

- 常规：控制工作区的元数据和全局配置。
- 主页：管理登陆页面的内容，包括徽标、搜索和列内容，或用自定义资源替换主页。
- 菜单：选择资源和链接以填充工作区顶部的菜单栏。
- 访问：确定工作区在启动器中的可见性、工作区存储的位置以及用户组的默认工作区。
首先，在常规标签中添加名称和描述。

## 更新主页

默认主页采用三列设计，每列填充一个或多个精选项目块。列上方是非必填徽标和对象资源管理器搜索栏。

在转向列内容之前，让我们限制从搜索栏搜索的对象类型。如果配置了对象类型组，请从组列表中选择这些组，或更改为对象类型列表并选择一个或多个对象类型以限制搜索结果。

要转向主页内容，在列A中，让我们添加此工作区的相关对象类型列表，添加一个新的对象类型（重要且选择）块，并选择列表选项，该选项允许自动选择显示的每个对象类型。

## 更新菜单栏

菜单栏保存链接到在工作区上下文中打开的Foundry资源。在此示例中，我们添加了两个Workshop模块，分别是航线警报收件箱和飞行指挥中心。这些锚定模块将成为工作区中的永久标签。可以将其他资源添加为新标签模块，这些模块将在下拉菜单中可用，选择时将在新标签中打开。

更新菜单栏后，返回主页配置，并在列B中添加一个新的所有菜单栏项目块，内容将自动填充任何在菜单栏中配置的资源。这些资源将在工作区保存后填充。

## 保存工作区

在编辑界面的右上角，点击保存按钮以保存工作区的新版本，然后点击x图标以退出编辑模式并查看工作区的用户视图。

## 接下来是什么？

我们现在有了一个简单但功能正常的Carbon工作区。您可以继续自定义此示例工作区，管理其访问控制，或通过以下链接将其连接到其他应用程序：

- 自定义徽标。
- 查看工作区的可见性和权限。
- 学习如何将资源之间的导航连接在一起以实现多应用工作流。
