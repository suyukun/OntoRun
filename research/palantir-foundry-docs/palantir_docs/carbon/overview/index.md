# 概述

Carbon 应用程序允许为特定用户组配置自定义平台体验，称为工作区。Carbon 可以为需要执行关键操作工作流的非技术用户提供专注的体验。

例如，一个用于飞机零件维护的 Carbon 工作区可能包括：

- 一个包含动态更新的需要维护零件列表的Workshop模块，
- 一组用于对每个零件进行分类的Foundry 操作，
- 一个模块，可用于调查每个零件的维护问题，
- 一个显示随时间变化的维护趋势的Quiver分析。
管理员可以创建多个 Carbon 工作区，以适应特定用户配置文件，并受强大的权限管理。在每个工作区中，管理员可以突出显示相关的工作流和应用程序，选择性地隐藏整个平台的复杂性，并在必要时限制在 Carbon 工作区之外的导航。

Carbon 工作区具有自定义的默认位置页面和配置的一组模块。通过 Carbon 工作区访问 Foundry 时，用户将仅看到特定工作流所需的应用程序和资源子集。

本文档介绍了如何创建、配置和管理 Carbon 工作区的基本知识，并提供了几个不同工作区配置的示例。

## 访问 Carbon

在 Foundry 中，通过导航到应用程序门户并选择Carbon 工作区来访问 Carbon。如果您已经创建了一个 Carbon 工作区并将其提升为可用应用程序，您可以在应用程序门户的推广应用程序部分下搜索工作区名称。
