# 限制离开工作区的导航

在某些情况下，您可能希望确保操作用户仅与Carbon互动以优化他们的体验，并限制对其他Foundry应用程序或功能的访问。

可以在两个层级上限制离开Carbon的导航：工作区和模块。

## 在工作区级别禁用导航

切换到常规配置选项卡（在下图中用红色突出显示），找到离开Carbon的导航部分。

默认设置为启用；您可以通过将设置更改为禁用来限制来自Carbon界面元素的导航。通过这种方式禁用导航的效果如下：

- 导航菜单中将隐藏外部Foundry链接。现有链接的配置将在工作区的配置中保留，但这些链接将不会激活。这允许您在将离开Carbon的导航切换回启用状态时恢复链接功能。
- 现有链接的配置将在工作区的配置中保留，但这些链接将不会激活。这允许您在将离开Carbon的导航切换回启用状态时恢复链接功能。
- 配置编辑器将把外部链接部分呈现为非活动状态（灰显），并显示一条消息通知您设置已被禁用离开Carbon的导航所取代。
- 导航栏右侧元素的导航将被限制。帮助和支持下拉菜单将完全隐藏。通知下拉菜单将显示所有通知。但是，只有在链接保持用户在Carbon内时，链接才可点击。例如，关于共享数据集的通知将显示但不可操作；关于共享Workshop模块的通知将可操作，因为点击链接将在Carbon内打开该模块。
- 帮助和支持下拉菜单将完全隐藏。
- 通知下拉菜单将显示所有通知。但是，只有在链接保持用户在Carbon内时，链接才可点击。例如，关于共享数据集的通知将显示但不可操作；关于共享Workshop模块的通知将可操作，因为点击链接将在Carbon内打开该模块。
- 用户下拉菜单仍将允许用户注销并显示用户名，但用户无法点击进入账户页面（该页面在Carbon工作区之外）。
用户仍可能通过模块内的链接离开Carbon工作区。尽管大多数指向应用程序的此类链接应已被导航框架覆盖，并在Carbon中打开新标签，但在某些情况下，仍可能存在指向Carbon外部应用程序的操作（如数据集预览、数据沿袭、Contour等）。使用控制面板设置来限制用户访问Carbon以外的空间，并依赖模块来遵循这些限制。了解更多关于模块级别限制的信息。

## 在模块级别禁用导航

指向模块的Carbon链接（使用Carbon的导航框架）将使操作用户保持在工作区内；当Carbon工作区的导航被禁用时，这些链接将保持活跃。

某些跨模块的导航操作可能会引导用户进入Carbon工作区外的应用程序。这些操作包括打开对象类型的支持数据集、探索对象类型的数据沿袭或在对象类型上开始新的分析（在Contour、Quiver或Code Workbooks中）。无法在特定Carbon工作区的层级上禁用这些操作。相反，使用控制面板中的应用程序访问页面为操作用户组配置这些设置。

例如，要禁用探索对象类型数据沿袭的操作，请移除对数据集成应用程序组的访问。然后，选择禁用所有访问，或仅使应用程序对选定用户或群组可用。

要禁用在Contour、Quiver或Code Workbook中开始新分析的操作，请在页面顶部切换打开管理多个应用程序选项。

然后，选择您希望禁用的应用程序，并在右上角选择管理应用程序选项以管理访问。

选择保存以应用您的更改。
