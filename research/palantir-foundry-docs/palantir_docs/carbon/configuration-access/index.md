# 访问配置

切换到访问配置选项卡（下图中红色高亮部分）以配置Carbon工作区的位置和可见性，以及为用户组设置默认工作区。

### 工作区位置

位置部分包含一个指向包含您的工作区的资源的链接（下图中红色高亮部分）。点击此链接可以更改访问设置或在项目中移动文件。

### 工作区可见性

在工作区可见性部分（下图红色高亮部分），Carbon组织管理员可以将工作区设置为仅限链接或推广。仅限链接的工作区只能通过直接访问工作区的URL或从项目中打开来访问。推广的工作区会出现在组织的所有成员和访客的导航菜单中。

### 默认工作区

用户可以访问多个Carbon工作区。因此，我们建议为每个用户组设置一个默认工作区。您可以在访问选项卡中的默认工作区部分（下图红色高亮部分）进行设置。请按照设置默认工作区的说明进行操作。
