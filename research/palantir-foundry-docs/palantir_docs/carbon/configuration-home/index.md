# 主页配置

切换到主页配置选项卡以配置工作区的主页。在主页配置选项卡（如下所示）中，您可以配置工作区的徽标、副标题和特色项目。

## 徽标

默认情况下，您的工作区将在Carbon主页的顶部中间显示Palantir徽标。您可以通过导航到徽标部分并点击选择徽标来显示已上传到Foundry的自定义徽标。

继续在项目中选择您的图像文件。这个图像文件现在将取代Carbon工作区中的默认徽标。

要调整徽标的大小，请展开尺寸部分，您可以设置最大宽度和/或高度。

要删除自定义徽标，可以将鼠标悬停在徽标预览上并选择x图标。

## 副标题

在副标题部分，您可以添加一个副标题以显示在主页的徽标下方。例如，您可以提供欢迎消息或工作区的描述。

## 特色项目

Carbon工作区可以重要地显示三列（标记为A、B和C），其中可以包含特色项目。可以显示各种类型的特色项目，包括objects、object类型、已保存的探索等。我们建议策划主页以确保工作区具有对用户工作最有用的资源。

非必填地，列A、B和C可以包含将资源组合在一起的微件。微件可以自定义配置，或者您可以从默认选项列表中选择，例如用户的收藏objects或已保存的探索。

在自定义可配置微件中，可以通过将鼠标悬停在项目上并选择编辑图标来自定义每个项目的外观，这将打开一个编辑对话框。

通过添加标题和描述并选择是否将项目显示为列表或卡片，可以进一步配置微件的显示。列表显示紧凑，显示资源图标以及每个元素的名称。卡片显示较大，可以为每个元素包含自定义缩略图图像。当项目数量较少时，卡片通常更有用。这些选项可以通过展开微件编辑器中的元数据与显示部分进行配置。

## 模块支持的主页

搭建者还可以配置一个模块作为工作区的主页。选择主页配置选项卡上的用Compass资源替换主页将打开一个对话框以允许选择模块和参数。

如果主页中使用了模块，搭建者可以将工作区重置为最后配置的默认主页。
