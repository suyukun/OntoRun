# 配置工作区更新

配置工作区更新的入口在工作区编辑器视图中。这会打开一个对话框，在其中配置更新（更新对话框）。需要注意的是，工作区更新是与工作区配置本身分开保存的；要持久化任何工作区更新，只需在更新对话框中保存，无需同时保存工作区配置（除非还有其他更改）。

然后，您可以预览当前的分步演示，并通过重新排序、存档、新建或编辑现有的分步演示页面来编辑最新的分步演示。

当您编辑分步演示页面时，您可以自定义以下选项：

- 标题（必填）
- 描述
- 媒体
- 文档

## 存档和永久删除更新

随着工作区配置和组成的更改，工作区更新可能会变得过时。例如，更新可能指的是一个不再存在于工作区中的Carbon模块，或者模块内容可能已随着模块的新版本而更改。为了解决这个问题，您可以暂时存档更新（保留以后取消存档的能力）或永久删除更新。

一旦点击存档按钮，更新将被移动到列表底部，可以取消存档或删除。更改保存后生效。永久删除的内容无法恢复，任何用户将不再能够查看。

### 所有已存档的更新

您可以在编辑器的所有已存档的更新选项卡中浏览所有已存档（但未删除）的更新。列表中的任何更新都可以取消存档并恢复到列表中，或永久删除。选择删除操作时，您会收到一个确认对话框以检查删除是否为预期操作；确认后，从所有已存档的更新列表中立即删除。

## 查看

用户将看到他们之前未见过的最新一组配置的工作区更新中的任何步骤。当他们进入工作区时，这些更新将显示给他们。

如果用户提前退出工作区更新，他们可以在新功能侧栏中查看更新（以及所有历史更新）。
