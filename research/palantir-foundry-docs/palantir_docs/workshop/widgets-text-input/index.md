# 文本输入

文本输入微件允许用户在表单字段中输入文本值。

## 配置选项

- 标签为微件设置一个非必填标签。此文本显示在微件的顶部。
- 为微件设置一个非必填标签。此文本显示在微件的顶部。
- 字符串值微件的输出变量，存储用户输入的文本。
- 微件的输出变量，存储用户输入的文本。
- 占位符定义当用户没有输入文本时在输入字段中显示的占位符文本。
- 定义当用户没有输入文本时在输入字段中显示的占位符文本。
- 高度将输入字段的高度设置为单行或多行文本区域。单行按回车触发事件: 设置按下回车键时触发的事件文本区域初始高度: 设置文本输入区域的初始高度
- 将输入字段的高度设置为单行或多行文本区域。
- 单行按回车触发事件: 设置按下回车键时触发的事件
- 按回车触发事件: 设置按下回车键时触发的事件
- 文本区域初始高度: 设置文本输入区域的初始高度
- 初始高度: 设置文本输入区域的初始高度
