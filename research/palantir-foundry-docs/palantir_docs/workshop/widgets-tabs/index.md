# 标签页

标签页微件显示可配置的标签，这些标签会触发Workshop事件，以便在模块的页面和叠加层之间导航。

## 配置选项

以下概述了标签页微件的配置设置：

- 标签页添加项目:添加一个新标签。创建后，选择包含标签的框进行配置。标签:设置标签的标签。点击时添加事件:添加一个在选择标签时触发的Workshop事件。图标:添加一个图标，显示在标签标签的左侧。徽章:显示在标签标签右侧的徽章。默认情况下，标签不会显示徽章。如果构建者选择在标签上显示徽章，他们可以选择通过字符串变量显示文本或通过数字变量显示数值。条件可见性:开启时，允许通过设置布尔变量的值来控制标签的启用/禁用或可见/隐藏。布尔变量:设置一个布尔变量来控制标签的启用、禁用或隐藏。禁用:如果选择，当设置的布尔变量的值为true时，标签将启用，当设置的布尔变量的值为false时，标签将禁用。隐藏:如果选择，当设置的布尔变量的值为true时，标签将可见，当设置的布尔变量的值为false时，标签将隐藏。
