## Workshop主页

使用Workshop主页上的数据直接创建可立即使用的应用程序。目前，支持搭建收件箱、地图和指标应用程序。

首先，选择您想使用的模板。然后，只需选择一个Object类型和将在模板中使用的相关属性。下面的图像展示了创建地图应用程序的过程。

一旦选择了模块的保存位置并选择了创建模块，您将拥有一个与您输入的数据匹配的可用模板。

## Workshop设计中心

Workshop设计中心是一个Marketplace产品，它是示例应用程序和模板的集合，旨在帮助您使用Foundry Workshop（一个低代码应用程序搭建工具）创建卓越的应用程序。

设计中心由六个高质量的Workshop应用程序示例组成，可供您在创建自己的工作流程时使用作为灵感。

设计中心模块旨在作为设计示例和灵感，而非现成的应用模板。这些示例模块附带概念性数据，并提供功能性的端到端应用程序，应用程序构建者可以对其进行逆向工程和分析。我们希望设计中心模块中的概念和模式可以应用于您搭建的新应用或您管理的现有应用。

### 支持的Workshop应用程序

以下Workshop应用程序可在设计中心中使用，每个应用程序都有其独特的功能和特点：

- 警报收件箱：使用Workshop设计一个吸引人的、以操作为导向的收件箱。了解如何创建既有吸引力又实用的收件箱。
- 引导创建表单：搭建一个无缝的创建表单，引导用户完成定义的工作流程。通过创建可管理的步骤和理解引导表单的基本要素，减少用户出错和认知负担。
- 指标仪表盘：创建动态的执行概览和深入分析指标仪表盘，以监控性能。探索如何设计视觉信息丰富的仪表盘，并有效地追踪重要指标。
- 通用操作图：在地图上可视化地理指标。了解地图如何成为启用筛选的有效方式，并探索地理显示数据的好处。
- 租赁预订应用：浏览和筛选纽约市租赁列表以预订您的下次入住。了解如何创建一个高度视觉化的探索性应用程序，并通过直观的筛选选项增强用户体验。
- 插图应用：Workshop中的一小部分插图，展示了将视觉元素融入应用设计的潜力。
## 访问示例模块

要访问Workshop设计中心的示例模块，导航到Workshop设计中心项目。然后，将所需的Workshop模块复制到您选择的位置。

要从您的Foundry注册中访问Workshop设计中心，请联系您的Palantir代表。

## 使用建议

默认情况下，Workshop设计中心中的资产（Ontology对象、应用程序、数据集）设置为只读，我们强烈建议将任何Workshop模块复制到另一个项目中，然后再根据特定应用案例进行修改。如果您的管理员已将资产配置为可读写，仍然需要将设计中心内的Ontology元素（例如Object类型或操作类型）和Workshop应用程序视为只读，因为定期的设计中心更新会覆盖对上述元素的本地更改。

### 收件箱

在Workshop中搭建的常见应用类型是收件箱。通常，收件箱的核心组件包括：

- 一组明确的警报以供审核或任务完成，以及轻松筛选和优先处理它们的能力。
- 每个单独警报或任务的详细视图，允许进行深入审核。
- 配置的操作类型，使每个警报或任务的决策成为可能。
下面的示例显示了一个Workshop收件箱示例，显示了需要分类、审核和操作的航班警报信息。使用的核心微件包括重要术语筛选、筛选列表、Object表和按钮组。此外，启用了状态保存，以允许用户保留对他们最相关的收件箱设置，并与其他用户共享这些保存的视图。

### 通用操作图

高级领导者通常需要一种方式来了解其组织的关键部分如何实时运作。Workshop中搭建的通用操作图可以传达必要的地理空间背景、详细图表和顶级指标，以便快速做出高层决策。

下面的示例显示了一个Workshop通用操作图示例，将COVID病例信息叠加在零售店销售和运营数据之上。其目的是帮助店铺经理了解店铺表现，并在本地病例数量变化时更有效地调整计划。使用的核心微件包括指标卡片、地图、图表：XY和Object表。
