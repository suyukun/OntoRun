# 数字输入

数字输入微件允许用户输入数值。

## 配置选项

- 标签为微件设置一个非必填标签。此文本显示在微件顶部。
- 为微件设置一个非必填标签。此文本显示在微件顶部。
- 显示分组如果开启，用逗号样式的千位分隔符格式化数字输入
- 如果开启，用逗号样式的千位分隔符格式化数字输入
- 包括重置为默认值的选项如果开启，在微件上添加一个按钮，用于清除输入字段
- 如果开启，在微件上添加一个按钮，用于清除输入字段
- 单位前缀如果开启，在微件输入字段的左侧显示只读文本或选择的图标
- 如果开启，在微件输入字段的左侧显示只读文本或选择的图标
- 单位后缀如果开启，在微件输入字段的右侧显示只读后缀。后缀可以是文本、选择的图标或百分号。如果选择了百分号，微件的输出变量将是用户输入的值除以100，将值转换为百分比形式。
- 如果开启，在微件输入字段的右侧显示只读后缀。后缀可以是文本、选择的图标或百分号。如果选择了百分号，微件的输出变量将是用户输入的值除以100，将值转换为百分比形式。
- 输出数据数值：微件的输出变量，存储用户输入的数值
- 数值：微件的输出变量，存储用户输入的数值
