# 配置域

域描述了可以评估模型的有效集合。如果您选择在场景中使用模型，为模型定义域是很重要的。在场景管理器中，您可以选择您的模型并定义域。

对于模型，核心配置选项如下：

- 显示名称：模型的标题。
- 模型：选择要与相关场景关联的模型。
- 域：选择模型域的对象集和筛选条件。请注意，域对象类型应与选择器中显示的对象类型匹配。
