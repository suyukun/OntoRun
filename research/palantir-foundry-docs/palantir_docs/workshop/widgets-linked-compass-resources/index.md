# 关联Compass资源

使用关联Compass资源微件以显示与对象关联的Compass资源、在对象上创建与现有Compass资源的新链接，并上传新文件以直接链接到对象。

## 配置选项

- 选定的对象：确定将在微件中显示的数据的对象集定义变量。
- 标题：显示为微件标题的名称。
- 隐藏上传按钮：切换以显示/隐藏上传按钮，允许用户上传文件到Compass并将上传的文件链接到对象。
- 隐藏链接按钮：切换以显示/隐藏链接按钮，允许用户选择现有的Compass资源链接到对象。
