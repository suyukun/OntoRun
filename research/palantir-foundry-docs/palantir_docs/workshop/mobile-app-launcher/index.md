# 移动应用程序启动器

移动应用程序启动器是一个简单的默认位置，使用户能够搜索、浏览和打开为移动设备使用而设计的Workshop应用程序。

无需进行任何配置即可设置移动应用程序启动器；当您创建一个移动Workshop应用程序时，应用程序将会出现在应用程序启动器中。除了帮助用户查找和使用移动应用程序之外，移动应用程序启动器还提供了一些额外的功能：

- 移动应用程序启动器经过优化，以减少打开时加载的依赖项。这使得应用程序启动器加载更快，减少了移动设备上的带宽使用。
- 进入应用程序或在应用程序内的页面之间导航时，会更新浏览器历史记录，以便在手机上“后退”和“前进”交互按预期工作。这使得用户可以在iOS上从左或右滑动导航，或在Android设备上使用硬件返回按钮返回导航。
一旦您创建了一个或多个移动应用程序，告诉您的用户导航到移动应用程序启动器，以便起始查找和使用您的应用程序。移动应用程序启动器在您的环境中可用，网址为https://<your-foundry-url>/workspace/m。

您可以在桌面设备上打开移动应用程序启动器，但启动器将在桌面屏幕上以全宽显示。为了模拟应用程序在移动设备上的显示效果，我们建议使用您选择的浏览器中的设备模式预览：

- Chrome 设备模式 ↗
- Safari 响应式设计模式 ↗
- Edge 模拟移动设备 ↗
