# 概览

Objects上的函数使代码作者能够在对象数据上编写业务逻辑，并在下游的运营应用中利用这一逻辑。Objects上的函数包括支持读取各种对象类型的属性，灵活地聚合或编辑这些数据，以及遍历Ontology中定义的链接。

在Workshop模块中，函数可以通过多种方式使用，包括：

- 计算和显示指标：微件如指标卡片可以动态地显示由函数计算的数值或分类值，以帮助指导用户的决策。
- 定义复杂对象集：用于在Workshop模块中加载对象数据的复杂对象集可以通过一个函数定义。
- 通过函数支持的操作：可以使用函数定义复杂操作。函数支持的操作使模块能够触发复杂的对象编辑和数据输出集。
