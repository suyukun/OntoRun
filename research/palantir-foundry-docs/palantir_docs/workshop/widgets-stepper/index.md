# Stepper

Stepper微件用于帮助用户导航通过多步骤工作流程，在用户完成一系列步骤时显示和跟踪进度。

## 配置选项

- 类型线性：用户必须按顺序完成步骤非线性：用户可以在步骤之间自由导航，并以任意顺序完成它们
- 线性：用户必须按顺序完成步骤
- 非线性：用户可以在步骤之间自由导航，并以任意顺序完成它们
- 步骤为工作流程的每个步骤创建和定义配置。标签：设置微件中要显示的步骤标签点击时：设置当在微件中点击步骤时要触发的事件已完成：设置一个布尔变量以作为检查，确定何时步骤已完成图标：设置要为步骤显示的图标
- 为工作流程的每个步骤创建和定义配置。
- 标签：设置微件中要显示的步骤标签
- 点击时：设置当在微件中点击步骤时要触发的事件
- 已完成：设置一个布尔变量以作为检查，确定何时步骤已完成
- 图标：设置要为步骤显示的图标
- 样式模板仅文本：在微件中为每个步骤显示有序数字使用图标：在微件中为每个步骤显示图标。图标可以按步骤配置。显示步骤编号：当设置为线性步骤类型并设置为使用图标时，切换开启以在微件上显示步骤编号。已完成颜色：设置步骤已完成时的颜色，由为步骤设置的布尔变量为true时触发。活动颜色：设置用户当前所在步骤的颜色。
- 模板仅文本：在微件中为每个步骤显示有序数字使用图标：在微件中为每个步骤显示图标。图标可以按步骤配置。
- 仅文本：在微件中为每个步骤显示有序数字
- 使用图标：在微件中为每个步骤显示图标。图标可以按步骤配置。
- 显示步骤编号：当设置为线性步骤类型并设置为使用图标时，切换开启以在微件上显示步骤编号。
- 已完成颜色：设置步骤已完成时的颜色，由为步骤设置的布尔变量为true时触发。
- 活动颜色：设置用户当前所在步骤的颜色。
