# 操作日志时间轴

使用操作日志时间轴微件以时间视图显示对象上的操作日志。

## 配置选项

- 显示日志的对象：定义一个包含单一对象类型的对象集以显示其操作日志。
- 显示的操作日志：在时间轴视图中添加要显示的特定操作日志对象类型。操作日志：在指定对象集的对象类型上选择现有的操作日志对象类型。要显示的属性：指定在时间轴视图中每个操作日志实例要显示的属性。
- 操作日志：在指定对象集的对象类型上选择现有的操作日志对象类型。
- 要显示的属性：指定在时间轴视图中每个操作日志实例要显示的属性。
