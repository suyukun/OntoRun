# 饼图

饼图微件用于通过按指定属性类型对对象进行分组，将对象数据以饼图或环形图的形式可视化为比例切片。

饼图微件支持以PNG格式导出当前图表可视化，通过在查看模式下使用“下载图表为图像”选项或“自定义图表导出”选项。当前图表可视化也可以作为图像复制到剪贴板。导出和复制到剪贴板选项会在微件悬停时显示。
