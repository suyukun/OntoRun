# 行内操作

行内操作微件通过嵌入操作表单和表格使用户能够与Ontology互动。此微件需要Ontology中已存在的操作类型。

## 操作配置

您可以在单个行内操作微件中显示多种操作类型，允许用户选择其中一个可用的操作。对于每个操作类型，您可以配置以下元素：

- 操作：从Ontology中选择一个现有的操作类型。确保您的目标用户可以查看并提交该操作。
操作：从Ontology中选择一个现有的操作类型。确保您的目标用户可以查看并提交该操作。

- 默认设计：为每个选定的操作类型选择表单或表格设计。表单设计：在微件中嵌入操作表单，使用户一次可以提交一个操作。此设计推荐用于需要引导式表单交互的小规模数据集。表格设计：在微件中嵌入可编辑的操作表格。操作表格推荐用于大规模数据集，或数据来源于CSV文件时。此设计提供以下好处：键盘导航，支持高效数据输入能够在表格中拖放CSV文件并将列映射到表单字段即时验证字段并向用户展示出错信息所有操作在提交时一次性执行注意：表格设计中的数据规模和支持的配置可能有限。请查看操作类型配置页面以获取更多详细信息。
默认设计：为每个选定的操作类型选择表单或表格设计。

- 表单设计：在微件中嵌入操作表单，使用户一次可以提交一个操作。此设计推荐用于需要引导式表单交互的小规模数据集。
表单设计：在微件中嵌入操作表单，使用户一次可以提交一个操作。此设计推荐用于需要引导式表单交互的小规模数据集。

- 表格设计：在微件中嵌入可编辑的操作表格。操作表格推荐用于大规模数据集，或数据来源于CSV文件时。此设计提供以下好处：键盘导航，支持高效数据输入能够在表格中拖放CSV文件并将列映射到表单字段即时验证字段并向用户展示出错信息所有操作在提交时一次性执行注意：表格设计中的数据规模和支持的配置可能有限。请查看操作类型配置页面以获取更多详细信息。
表格设计：在微件中嵌入可编辑的操作表格。操作表格推荐用于大规模数据集，或数据来源于CSV文件时。此设计提供以下好处：

- 键盘导航，支持高效数据输入
- 能够在表格中拖放CSV文件并将列映射到表单字段
- 即时验证字段并向用户展示出错信息
- 所有操作在提交时一次性执行
注意：表格设计中的数据规模和支持的配置可能有限。请查看操作类型配置页面以获取更多详细信息。

- 参数默认值：您可以在行内操作视图中配置参数的本地默认值。如果未配置参数默认值，将使用Ontology中的操作类型参数配置。
参数默认值：您可以在行内操作视图中配置参数的本地默认值。如果未配置参数默认值，将使用Ontology中的操作类型参数配置。

- 附加选项：自定义操作标题：为微件标题设置自定义标题。无效表单状态：如果操作类型的提交条件未满足，您可以定义操作表单的显示状态。选项为禁用和隐藏，提供禁用或隐藏无效操作的选项。隐藏标题：切换以显示或隐藏操作标题。应用于场景：将操作应用于选定的场景。成功提交操作时：在成功提交操作时触发Workshop事件。输出对象集：在操作提交时创建或编辑的对象集。
附加选项：

- 自定义操作标题：为微件标题设置自定义标题。
- 无效表单状态：如果操作类型的提交条件未满足，您可以定义操作表单的显示状态。选项为禁用和隐藏，提供禁用或隐藏无效操作的选项。
- 隐藏标题：切换以显示或隐藏操作标题。
- 应用于场景：将操作应用于选定的场景。
- 成功提交操作时：在成功提交操作时触发Workshop事件。
- 输出对象集：在操作提交时创建或编辑的对象集。
