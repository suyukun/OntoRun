# Workshop: 嵌入式模块微件

本页面讨论Workshop的嵌入式模块微件。有关Workshop嵌入功能的概述，请参见嵌入概述页面。

## 配置

嵌入式模块微件配置允许搭建者选择一个模块进行嵌入，并定义当前模块中的变量与嵌入模块的模块接口变量之间的映射。

### 模块选择

要配置嵌入式模块微件，首先通过Compass资源选择器选择一个要嵌入的子模块。嵌入时始终使用子模块的已发布版本。

### 接口配置

一旦选择了子模块，子模块的模块接口将在微件配置面板中显示。这允许您将父模块变量映射到子模块接口变量。父模块的变量定义将用于支持在父模块和子模块之间完全共享的变量。任何对变量值的更改（例如，从微件输出或设置变量值事件）将在所有映射了该变量的模块中反映出来。

由于子模块的变量定义不用于映射变量，因此子模块中定义的映射变量的默认变量值不会被使用。同样，这意味着子模块的变量定义中定义的映射变量的任何变量重新计算行为（例如，使用函数支持变量值或变量变换）都不会被使用。在重置变量值事件的情况下，变量的值将重置为父模块的变量定义中设置的默认值。
