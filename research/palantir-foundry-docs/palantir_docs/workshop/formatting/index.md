# 格式化

Workshop 提供了许多格式选项，帮助用户在微件中美化其显示。在本节中，我们将介绍其中的两个选项：数值格式化和条件格式化。

## 数值格式化

数值格式化在用户界面应用中渲染数值时应用特殊格式，使原始数值更适合展示。在 Workshop 中，数值格式化可以在设置 Object Table 微件中的时间序列属性列和 Metric Card 微件中的时间序列属性显示时用于渲染数值。此格式化仅限于 Workshop 模块，而不是全局的 Ontology。了解更多关于设置数值格式化的信息。

下面的例子展示了如何使用数值格式化来美化名为Weekly Cases的 Object 表列中显示的数值，该列展示了每个国家观察到的 COVID-19 每周病例数。

## 条件格式化

条件格式化应用规则以决定数字和折线图如何被美化。在 Workshop 中，条件格式化可以用于美化 Object Table 微件中的时间序列属性列和 Metric Card 微件中的时间序列属性显示。此格式化仅限于 Workshop 模块，而不是全局的 Ontology。了解更多关于设置条件格式化的信息。

下面的例子展示了如何使用条件格式化来美化名为Weekly Cases的 Object 表列中显示的汇总数值和折线图，该列展示了每个国家观察到的 COVID-19 每周病例数。
