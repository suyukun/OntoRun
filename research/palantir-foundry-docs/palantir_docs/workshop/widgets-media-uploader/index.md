# 媒体上传微件

媒体上传微件用于添加一种特殊类型的按钮，允许用户将媒体文件上传到Foundry，并以上传的文件作为输入来触发操作。

## 配置选项

- 按钮配置文本：设置按钮的显示文本。意图：设置按钮的意图颜色。选项包括无、主要（蓝色）、成功（绿色）、警告（琥珀色）或危险（红色）。左图标：此参数控制微件显示文本左侧的图标。设为空白以不显示图标。右图标：此参数控制微件显示文本右侧的图标。设为空白以不显示图标。
按钮配置

- 文本：设置按钮的显示文本。
- 意图：设置按钮的意图颜色。选项包括无、主要（蓝色）、成功（绿色）、警告（琥珀色）或危险（红色）。
- 左图标：此参数控制微件显示文本左侧的图标。设为空白以不显示图标。
- 右图标：此参数控制微件显示文本右侧的图标。设为空白以不显示图标。
- 上传目的地：设置使用此微件上传的媒体文件的上传目的地。上传目的地可以设置为一个数据集、一个Compass文件夹或一个媒体集。静态：通过使用Compass资源选择器选择一个目标文件夹来静态设置文件上传目的地。动态：使用Workshop字符串变量动态设置文件上传目的地的资源标识符（RID）。覆盖分支：切换以启用/禁用使用Workshop字符串变量上传媒体文件到指定分支的功能。允许的文件扩展名：设置允许上传的文件扩展名。
上传

- 目的地：设置使用此微件上传的媒体文件的上传目的地。上传目的地可以设置为一个数据集、一个Compass文件夹或一个媒体集。静态：通过使用Compass资源选择器选择一个目标文件夹来静态设置文件上传目的地。动态：使用Workshop字符串变量动态设置文件上传目的地的资源标识符（RID）。覆盖分支：切换以启用/禁用使用Workshop字符串变量上传媒体文件到指定分支的功能。
- 静态：通过使用Compass资源选择器选择一个目标文件夹来静态设置文件上传目的地。
- 动态：使用Workshop字符串变量动态设置文件上传目的地的资源标识符（RID）。
- 覆盖分支：切换以启用/禁用使用Workshop字符串变量上传媒体文件到指定分支的功能。
- 允许的文件扩展名：设置允许上传的文件扩展名。
- 输出传统上传媒体RID：一个字符串变量，输出已上传媒体的RID。上传的文件名：一个字符串变量，输出已上传媒体的文件名。上传时：可以通过选择操作选项在上传时触发操作。当选择操作选项时，必须选择相关操作类型并配置对应操作表单的参数。默认情况下，上传时设置为无操作。对象启用多文件上传：切换以启用/禁用在一次上传中上传多个文件的功能。启用后，可以为每个上传会话设置允许的最大文件数量。操作：设置在媒体上传时触发的操作。如果启用了多文件上传，则操作将在每个上传的文件上触发。配置操作参数时，可以通过选择特殊的“文件标识符”值来引用上传的文件。对于上传到数据集的文件，“文件标识符”值将是上传的文件名。对于上传到Compass文件夹的文件，“文件标识符”值将是上传文件的RID。对于上传到媒体集的文件，“文件标识符”值将是上传文件的媒体参考。
