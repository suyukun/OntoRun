# 不支持的对象属性类型

某些Ontology 属性非常大，会增加模块的加载时间。这些“低性能”属性通常在 Workshop 中不被支持。关于支持显示不支持属性的某些 Workshop 微件的信息可以在此页面找到。

以下属性类型通常在 Workshop 中不被支持：

- Geoshape:Geoshape 属性是包含大量坐标数组的大型 JSON 字符串。因此，Workshop 通常不支持 geoshape。
- Vector:Vector 属性是大型固定大小的浮点数组。在操作流程中查看 vector 属性的值通常是不必要的，因为用户通常无法从 vector 的值中推导出意义。因此，Workshop 通常不支持 vector。
## 显示不支持属性类型的微件

某些 Workshop 微件可以配置以允许查看不支持的属性类型。对于支持按需查看属性类型的微件，必须通过用户操作来特定揭示不支持的属性，如下所述。在微件配置期间，对于不支持的属性，将显示带有工具提示的警告图标，描述其由于尺寸过大导致的低性能。

以下微件支持按需查看对象的特定不支持属性：

- 对象列表:要在对象列表微件中查看不支持属性的值，请选择加载来揭示其值。
对象列表:要在对象列表微件中查看不支持属性的值，请选择加载来揭示其值。

- 对象表:要在对象表微件中查看不支持属性的值，请选择...按钮揭示其值。
对象表:要在对象表微件中查看不支持属性的值，请选择...按钮揭示其值。

- 属性列表:要在属性列表微件中查看不支持属性的值，请选择加载来揭示其值。
属性列表:要在属性列表微件中查看不支持属性的值，请选择加载来揭示其值。

以下微件支持查看对象的不支持属性：

- 地图:如果在地图微件中配置了 Geoshape 属性，它将自动加载。
