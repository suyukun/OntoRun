# 可视化微件

- 图表: 饼图:将对象数据可视化为饼图或环形图。
- 图表: XY:将对象集可视化为可配置的柱状图、折线图或散点图，支持多系列、轴和样式选项。
- 图表: Vega:基于开源Vega-Lite ↗可视化语法构建的图表。
- 地图:将对象集显示为可配置的、交互式的地理空间可视化。
- 甘特图:将具有时间属性的对象显示在水平时间轴视图中。
- Markdown:显示格式化文本，并可以非必填配置文本中的对象引用。
- 指标卡片:渲染一个可配置的卡片以突出显示关键指标。
- 数据透视表:允许动态分组和汇总对象数据，然后以表格形式显示这些汇总数据。
- 资源列表:显示各种类型的Foundry资源。
- 步进器:跟踪任务的进度，通过一组步骤完成，既可以线性也可以非线性。
- 时间线:可视化时间数据，将对象渲染为时间线上的事件。
- 图表: 瀑布图:将对象数据可视化为瀑布图。
- 媒体预览:给定一个URL、Foundry RID或Base64编码的字符串，渲染指定媒体的预览（例如：PNG、JPEG或PDF）。
- PDF查看器:渲染具有关键字搜索功能的PDF（便携式文档格式）。
- 图像注释:通过在感兴趣的区域周围绘制矩形来注释图像。
- 状态跟踪器:在时间线上显示过程的状态。
- 自由形式分析:允许用户在Workshop应用框架内灵活地独立调查对象数据。
- 编辑历史:显示用户对对象所做的编辑列表。
- 链接的Compass资源:渲染链接到对象的Compass资源。
- 操作日志时间线:在时间视图中渲染对象操作日志。
