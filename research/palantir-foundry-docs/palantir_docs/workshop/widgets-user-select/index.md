# 用户选择

使用用户选择微件以通过单选或多选下拉菜单选择用户。

## 配置选项

- 标签：为微件设置一个非必填标签，以在下拉菜单上方显示文本。
- 占位符：设置非必填占位符文本，以在微件的空选择状态中显示。
- 已选用户：如果选择设置为“单选”，微件将显示为单选下拉菜单。输出变量：微件的输出变量，用于存储用户选择的选项。如果选择设置为“单选”，输出变量将是一个包含所选用户ID的字符串变量。允许清除：切换以启用/禁用清除所选下拉菜单选项。如果选择设置为“多选”，微件将显示为多选下拉菜单。输出变量：微件的输出变量，用于存储用户选择的选项。如果选择设置为“多选”，输出变量将是一个包含所选用户ID的字符串数组变量。指定Multipass组ID：提供一个组ID的字符串数组变量，以筛选下拉菜单中显示的用户为指定组中的用户。用户必须在配置的组上拥有查看组成员资格角色，否则他们将看到权限出错，详见下方。

## Multipass组ID权限

如果提供了multipass组ID，用户需要在组的组织上拥有查看组成员资格权限，否则他们将在此微件中看到权限出错。此权限可以通过在设置 > 平台设置 > 组织中选择感兴趣的组织，然后为组织权限选择管理来授予。阅读更多关于管理组的信息。
