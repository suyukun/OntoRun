# 核心显示微件

- 对象表:以表格形式呈现对象集，每个对象显示为一行。
- 对象列表:以列表形式呈现对象集，每个对象显示为一张卡片。
- 对象视图:为单个Object呈现对象浏览器的对象视图。
- 属性列表:显示来自给定对象集的可配置属性列表。
- 链接:以可展开和折叠的部分呈现对象集的链接类型和链接对象。
- 对象集标题:显示给定对象集的摘要作为标题。
- 标题文本:呈现两行文本，优化为在标题中显示。
