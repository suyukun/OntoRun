# Object 下拉菜单

Object 下拉菜单微件用于从对象列表中选择单个Object。模块搭建者可以使用Object下拉菜单微件来进行以下操作：

- 显示一个或多个对象类型的数据。
- 选择显示哪些属性类型。
- 设置排序标准。
- 显示在Ontology Manager中配置的条件格式和数字格式选项。
- 基于每个Object隐藏空属性以生成更紧凑的显示。
- 设置可以进行搜索的属性。
- 允许列表中不进行选择。

Object下拉菜单微件可用的核心配置选项如下：

- 输入数据标签：为Object下拉菜单微件设置一个非必填标签。此文本显示在微件的顶部。输入对象集：此输入变量决定了将在微件中显示的数据。模块搭建者可以重用模块中其他地方创建的现有对象集变量，或行内定义一个新的对象集变量。下面显示的许多其他配置选项只有在此对象集参数被填充后才能配置。已选择对象：这是微件的一个输出变量，输出当前选择对象的单一对象集。此对象集可以在当前模块的下游微件中使用。允许不选择：如果启用，微件将允许没有选定的Object。
- 标签：为Object下拉菜单微件设置一个非必填标签。此文本显示在微件的顶部。
- 输入对象集：此输入变量决定了将在微件中显示的数据。模块搭建者可以重用模块中其他地方创建的现有对象集变量，或行内定义一个新的对象集变量。下面显示的许多其他配置选项只有在此对象集参数被填充后才能配置。
- 已选择对象：这是微件的一个输出变量，输出当前选择对象的单一对象集。此对象集可以在当前模块的下游微件中使用。
- 允许不选择：如果启用，微件将允许没有选定的Object。
- 属性配置添加属性：选择一个属性以显示在对象标题下方。隐藏空属性：如果启用，空属性将在列表中基于每个Object被隐藏。按以下条件排序项目：指定在下拉菜单微件中对象的排序顺序。如果对象集中存在多种对象类型，则只有共享属性可以进行排序。按以下条件搜索项目：指定进行搜索的对象属性。屏幕上显示的属性：如果启用，将对在下拉菜单微件中显示的所有字符串属性进行搜索。特定属性：如果启用，将对指定的字符串属性进行搜索。所有可搜索属性：如果启用，将对对象集中所有可搜索的属性进行搜索。
- 添加属性：选择一个属性以显示在对象标题下方。
- 隐藏空属性：如果启用，空属性将在列表中基于每个Object被隐藏。
- 按以下条件排序项目：指定在下拉菜单微件中对象的排序顺序。如果对象集中存在多种对象类型，则只有共享属性可以进行排序。
- 按以下条件搜索项目：指定进行搜索的对象属性。屏幕上显示的属性：如果启用，将对在下拉菜单微件中显示的所有字符串属性进行搜索。特定属性：如果启用，将对指定的字符串属性进行搜索。所有可搜索属性：如果启用，将对对象集中所有可搜索的属性进行搜索。
- 屏幕上显示的属性：如果启用，将对在下拉菜单微件中显示的所有字符串属性进行搜索。
- 特定属性：如果启用，将对指定的字符串属性进行搜索。
- 所有可搜索属性：如果启用，将对对象集中所有可搜索的属性进行搜索。
