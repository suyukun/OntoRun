# 微件: 场景选择器

Workshop中的场景选择器微件允许用户从场景列表中选择一个或多个场景，并输出一个活动场景或场景数组。模块搭建者配置场景选择器微件时，可以启用用户选择单独的单个场景或场景数组，以便进行比较或启用选择，而不赋予用户创建场景的能力。

下面的截图展示了场景选择器的多选配置示例。当放置在节标题中时，微件变为下拉菜单而不是面板。

## 配置选项

以下是新添加的场景选择器微件初始状态及其初始配置面板的截图：

对于场景选择器微件，核心配置选项如下：

- 输入数据候选场景：选择适当的场景数组变量或场景变量列表，将场景引入选择器。输出场景：选择返回场景数组使用多选，或使用单选返回单个场景。
- 候选场景：选择适当的场景数组变量或场景变量列表，将场景引入选择器。
- 输出场景：选择返回场景数组使用多选，或使用单选返回单个场景。
