# 链接

链接微件用于显示对象之间的链接关系，并提供对这些路径的探索。配置链接微件的模块搭建者可以：

- 选择可能包含一个或多个对象类型的输入对象集
- 选择要展开、显示、排序的特定链接
下图显示了一个配置好的链接微件的示例，显示了单个Flight Alert的链接对象。在此截图中，Flight Alert的链接出发机场已被进一步展开以显示其链接。

链接微件具有以下配置选项：

- 输入数据对象集: 确定将在微件中显示的数据。模块搭建者可以重用此模块中其他地方创建的现有对象集变量，或行内定义一个新的对象集变量。在此选择对象集后，以下某些配置选项将可供配置。从场景加载数据: 启用使用场景变量。
- 对象集: 确定将在微件中显示的数据。模块搭建者可以重用此模块中其他地方创建的现有对象集变量，或行内定义一个新的对象集变量。在此选择对象集后，以下某些配置选项将可供配置。
- 从场景加载数据: 启用使用场景变量。
- 链接类型配置要显示的链接类型: 默认情况下，所有链接都会在链接微件中显示。选择“指定链接类型”后，可以配置细粒度的控制和功能，如链接级排序。更多详细信息可在以下部分中找到，指定链接配置选项。默认链接展开: 指定默认情况下在第一级自动展开的链接数量。
- 要显示的链接类型: 默认情况下，所有链接都会在链接微件中显示。选择“指定链接类型”后，可以配置细粒度的控制和功能，如链接级排序。更多详细信息可在以下部分中找到，指定链接配置选项。
- 默认链接展开: 指定默认情况下在第一级自动展开的链接数量。
- 链接对象配置启用链接类型的探索: 在每个链接类型级别，启用一个按钮以允许在对象浏览器中查看链接类型。启用链接对象的打开对象视图: 对于每个链接对象，启用一个按钮以允许在对象浏览器中打开链接对象的对象视图。启用悬停时的对象预览:当悬停在链接对象的标题上时，预览链接对象的属性。默认情况下，弹出窗口包括链接对象的重要属性，但可以通过指定链接进行自定义属性配置。
- 启用链接类型的探索: 在每个链接类型级别，启用一个按钮以允许在对象浏览器中查看链接类型。
启用链接类型的探索: 在每个链接类型级别，启用一个按钮以允许在对象浏览器中查看链接类型。

- 启用链接对象的打开对象视图: 对于每个链接对象，启用一个按钮以允许在对象浏览器中打开链接对象的对象视图。
启用链接对象的打开对象视图: 对于每个链接对象，启用一个按钮以允许在对象浏览器中打开链接对象的对象视图。

- 启用悬停时的对象预览:当悬停在链接对象的标题上时，预览链接对象的属性。默认情况下，弹出窗口包括链接对象的重要属性，但可以通过指定链接进行自定义属性配置。
启用悬停时的对象预览:当悬停在链接对象的标题上时，预览链接对象的属性。默认情况下，弹出窗口包括链接对象的重要属性，但可以通过指定链接进行自定义属性配置。

## 指定链接配置选项

下图显示了选择指定链接类型时链接微件及其配置面板的初始状态：

链接微件的指定链接配置面板选项如下：

- 选择链接类型链接类型:一旦选择了起始对象集，从下拉菜单中选择要在微件上显示的链接类型。链接类型标签覆盖:可以用新的标签覆盖链接类型的标签。
- 链接类型:一旦选择了起始对象集，从下拉菜单中选择要在微件上显示的链接类型。
- 链接类型标签覆盖:可以用新的标签覆盖链接类型的标签。
- 链接类型配置按...排序链接对象: 一旦选择了链接类型，可以配置属性和排序方向。
- 按...排序链接对象: 一旦选择了链接类型，可以配置属性和排序方向。
- 链接对象配置在对象预览中显示属性: 如果启用了“启用悬停时的对象预览”，可以配置指定链接类型的链接对象在预览弹出窗口中显示其重要属性或指定属性。
- 在对象预览中显示属性: 如果启用了“启用悬停时的对象预览”，可以配置指定链接类型的链接对象在预览弹出窗口中显示其重要属性或指定属性。
