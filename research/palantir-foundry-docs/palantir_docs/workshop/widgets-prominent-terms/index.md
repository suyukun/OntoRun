# 重要术语

重要术语微件处于测试阶段，可能无法在您的注册中使用。如果您对提前访问感兴趣，请联系Palantir支持。

使用重要术语微件以定义在对象集中用于匹配的常用术语和短语。展示匹配结果的数量，并使用该微件为用户定义一组自定义术语以应用为筛选。

## 配置选项

- **基础对象集：**定义一个对象集作为筛选选项的基础。
- **属性：**选择一个要筛选的属性。
- **筛选变量：**一个对象集筛选变量，包含当前从微件应用的筛选条件；这可用于筛选此模块中的对象集变量。
- **隐藏空术语：**切换以启用/禁用隐藏无结果返回的术语。
- 术语：**使用值筛选：**用于筛选对象集的值，确定在术语行中显示的返回结果的总计数。请注意，筛选使用精确匹配。**显示名称：**在术语行中显示的名称。**图标：**添加一个图标以在术语行中显示。
- **使用值筛选：**用于筛选对象集的值，确定在术语行中显示的返回结果的总计数。请注意，筛选使用精确匹配。
- **显示名称：**在术语行中显示的名称。
- **图标：**添加一个图标以在术语行中显示。
