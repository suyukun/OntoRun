# 微件：场景摘要

Workshop中的场景摘要微件显示与选定场景相关联的操作列表。模块搭建者可以配置场景摘要微件以汇总场景。

用户可以使用X按钮移除特定操作，并撤销之前对列表的更改，包括添加回先前移除的操作。

## 配置选项

下面是一个新添加的场景摘要微件的初始状态截图及其初始配置面板。

对于场景摘要微件，核心配置选项如下：

- 输入数据选择场景变量:选择要查看相关操作的场景。
- 选择场景变量:选择要查看相关操作的场景。
