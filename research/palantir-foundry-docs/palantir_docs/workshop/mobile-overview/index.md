# 概述

Workshop 的移动支持允许您搭建针对移动设备使用优化的网络应用程序，特别是针对手机形式的设备。

对 Workshop 的移动访问是一个有限访问功能，可能不包含在您的注册范围内。如果您有兴趣使用此功能，请联系 Palantir 支持。

配置 Workshop 模块以供移动使用会自动更新许多微件，使其更适合移动设备，例如使表单输入在触摸屏上更易于使用。此外，还提供了一系列特定于移动设备的微件，如下文所述。一些仅用于桌面设备的微件——包括 Object 表、图表和地图——在移动模块中被禁用。

终端用户通过导航到专用的移动应用启动器来访问移动版 Workshop 应用，该启动器位于https://{your-foundry-url}/workspace/m/。这个简化的启动器允许用户轻松浏览、搜索和打开移动版 Workshop 应用。在启动器中打开移动版 Workshop 应用还使用户能够使用浏览器的前进和后退交互直观地导航。了解更多关于移动应用启动器的信息。

通过搭建您的第一个移动版 Workshop 应用开始，或了解更多关于移动应用设计模式和可用微件的信息：

- 设计最佳实践
- 网络访问和身份验证
- 微件: 移动导航栏
- 微件: 二维码阅读器
- 微件: 当前定位管理器
