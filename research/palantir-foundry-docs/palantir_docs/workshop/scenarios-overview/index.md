# 概述

场景功能使能够使用Ontology中的Object和模型的本体概念创建和比较“假设”分析。要了解更多关于Palantir将模型与组织成果相连接的高级方法，请参阅Ontology中的模型。

场景本质上是通过应用一个或多个操作并评估一组模型而在您的Ontology数据中生成的“分叉”或“分支”。

快速入门教程涵盖了利用场景搭建模块的基础知识。
