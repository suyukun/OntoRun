# 筛选微件

- 筛选列表:将可配置的属性类型筛选呈现为直方图、分布图、数据选择器和输入建议选择器。此外，允许进行关键字搜索。
- 对象下拉菜单:允许用户从对象列表中选择单个Object。
- 对象选择器:允许用户从对象列表中选择多个Object。
- 字符串选择器:允许用户从字符串列表中选择一个字符串。
- 复选框:添加一个二进制复选框，允许用户切换一个值。
- 日期和时间选择器:
- 日期输入:允许用户输入单个日期或日期范围。
- 文本输入:允许用户输入文本。
- 数字输入:允许用户输入一个数值。
- 探索筛选药丸:允许用户可视化并将筛选应用于对象集。
- 探索搜索栏:允许用户通过属性类型和链接对象类型可视化并将筛选应用于对象集。
- 重要术语:显示对象集中重要术语的总匹配次数。
- 用户选择:允许用户从下拉菜单中选择Palantir用户。
