# 自由形式分析

自由形式分析微件使用户能够在Workshop应用程序的框架内灵活地独立调查对象数据。

## 可用卡片

### 核心显示卡片

- 指标卡片:显示对象集的数值汇总，包括平均值、计数、最小值、最大值、总和以及所选属性的大致唯一计数。
- 文本卡片:使用富文本编辑器卡片为您的分析添加注释。
### 对象卡片

- 筛选对象集:获取输入对象集并根据定义在对象属性和链接对象属性上的逻辑条件返回对象集。
- 链接对象:展示对象类型之间的关系，并提供对链接对象的探索。
- 对象选择器:选择并固定单个对象（例如，航班警报对象类型中的特定警报）。
### 表格卡片

- 对象表:以表格形式呈现对象集，选择属性显示为表格的列。
- 数据透视表:在表格中显示来自对象集的数据聚合。选择对象属性作为行和列属性；结果数据根据这些对象属性进行分组，并根据指定的配置进行聚合。
### 可视化

- 条形图:创建对象的水平或垂直条形图。类别由对象属性定义，值可以通过对象计数（默认）或属性值的平均值、最大值、最小值或总和来确定。
- 热格:显示三维图表，通过颜色说明两个分类维度和一个聚合维度（计数、平均值、总和、最大值或最小值）。
- 折线图:基于对象属性定义类别。设置值为对象计数（默认）或属性值的平均值、最大值、最小值或总和。
- 饼图:基于对象属性定义类别。设置值为对象计数（默认）或属性值的平均值、最大值、最小值或总和。
- 瀑布图:显示一个属性的累计总和（平均值、计数、最大值、最小值、总和或唯一计数），随着第二个属性的值的增加或减少而变化。

## 配置选项

- 输入对象集:作为分析的基础输入的对象集。
- 空状态标题和描述:定义当路径中没有卡片时微件的配置方式。
- 启用路径保存:保存和分享分析以供将来参考。分析可以保存为私有或公开。启用记事本复制（仅适用于已保存的分析路径）: 复制路径中的单个卡片以添加到记事本。卡片只有在已保存的分析路径中才能复制到记事本。
- 启用记事本复制（仅适用于已保存的分析路径）: 复制路径中的单个卡片以添加到记事本。卡片只有在已保存的分析路径中才能复制到记事本。
- 输出对象集:保存输出对象集以在Workshop应用程序中的其他地方参考。
