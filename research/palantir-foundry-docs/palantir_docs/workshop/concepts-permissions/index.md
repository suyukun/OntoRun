# Workshop中的权限

打开或编辑Workshop模块的能力源于用户在Workshop模块上的权限。这意味着用户必须满足组织和权限标记的要求，并且在模块上拥有角色（直接、通过组或默认角色）。默认情况下，用户需要只读角色以打开Workshop模块，并需要编辑者角色以编辑它。

请注意，打开或编辑Workshop模块的能力与访问数据、操作或函数的能力是分开的，这些可能是完全使用Workshop模块所需的。

Workshop模块中使用或包含的数据、操作或函数的权限是与Workshop模块分开设定的。有关更多信息，请参阅Object权限、操作类型权限和函数权限的文档。

## 检查权限

您可以使用侧栏中的检查访问面板轻松检查用户在Workshop模块上的访问权限。这将显示他们是否满足Workshop模块上的访问要求，以及查看Object类型、链接类型、操作类型和函数的附加数据要求。
