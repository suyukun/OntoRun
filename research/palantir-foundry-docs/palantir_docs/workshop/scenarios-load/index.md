# 加载场景

保存的场景对象可以通过变量系统加载到Workshop模块中。这些保存的场景可以传递到场景管理器，也可以直接传递到任何其他支持场景的微件中。

要加载保存的场景，创建一个新的场景数组变量并选择“从对象集加载的场景”选项。这将把实现场景特征的对象集转换为场景对象数组。

使用普通对象集变量可以填充对象集，从而启用搜索周边和筛选，以访问特定的场景集。在下面的例子中，我们找到与应用程序中选择的特定对象关联的所有场景。

如果配置正确，您将能够在变量选项卡的当前值部分按名称预览加载的场景。

然后，场景数组变量可以用于任何接受场景数组的微件，例如场景管理器，微件将更新以反映加载的场景，因为底层变量会更新。

导致底层场景对象集更改的事件和操作将反映在场景数组变量中。这允许基于应用程序中与其他对象的关系构建非常灵活的加载结构。如果需要从数组中选择特定场景以用于其他微件，可以将数组传递到场景管理器或场景选择器微件中。
