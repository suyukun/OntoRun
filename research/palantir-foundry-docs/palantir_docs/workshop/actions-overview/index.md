# 概述

Foundry中的操作使用户能够轻松定义有意义的构建模块，以创建、编辑、删除和关联Object数据。

例如：

- "Create New Flight"操作创建一个新的FlightObject，并设置该Object上的Flight Number、Time of Departure、Origin和Destination属性。
- "Delay Flight"操作修改现有的FlightObject以延迟其Time of Departure属性。
- "Assign To Flight"操作将一个FlightObject与一个PassengerObject关联。
要了解如何在Workshop中使用操作，请参阅在Workshop中使用操作。
