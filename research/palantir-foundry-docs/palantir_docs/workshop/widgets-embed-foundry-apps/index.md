# 嵌入 Foundry 应用程序

- iframe:在 Workshop 中嵌入 Slate 应用程序或外部应用程序。
- 地图应用程序模板:显示在地图应用程序中创建的现有地理空间模板。
- 记事本 - 嵌入文档:以只读或编辑模式嵌入配置的记事本文档。
- Quiver 仪表盘:渲染从 Quiver 构建和发布的嵌入式仪表盘。
- Vertex 图表:显示在 Vertex 应用程序中创建的现有图表、图表模板或图示。
- Workshop: 嵌入模块:将另一个 Workshop 模块作为微件嵌入。
