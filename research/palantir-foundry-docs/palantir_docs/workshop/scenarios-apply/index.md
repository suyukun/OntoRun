# 应用场景

应用场景将场景相关联的操作应用于Ontology。这些操作是以事务方式应用的，如果任何操作验证失败，则要么所有操作都会被应用，要么都不被应用。

注意，场景中的模型结果不会被应用于Ontology，因为这些代表了预期结果而不是明确可修改的值。

通过按钮组微件中的点击时配置选项中的场景事件选项来应用场景。在场景事件配置部分，选择应用场景以及您希望在点击此按钮时应用的场景变量。

您还可以非必填指定在成功将场景应用于Ontology之后要执行的操作。如果配置了应用操作，那么该操作的验证逻辑也将用于控制应用权限。也就是说，用户必须能够运行配置的应用操作才能够应用场景。

如果您正在应用的场景已保存到一个对象中，那么如果场景有任何未保存的更改，按钮将被禁用。

如果您正在应用一个已保存的场景并使用应用操作，您可以在应用操作的对象参数上设置类型类scenarios:scenario-object-locator，以自动填充支持已保存场景的对象参数。通过这种方式，您可以在成功应用时修改已保存场景对象的特定工作流元数据。
