# 对象视图

对象视图微件用于在Workshop模块中显示嵌入式对象视图，并提供关于单个Object的详细信息。配置对象视图微件的模块搭建者可以：

- 选择输入对象集（单个Object），以确定将显示哪个对象视图。
- 定义在对象视图中将打开的初始选项卡。

## 配置选项

这是新添加的对象视图微件的初始状态及其初始配置面板的截图：

对于对象视图微件，核心配置选项如下：

- 输入数据要显示的Object：此参数是对象视图微件的输入变量，决定将显示哪个Object。由于对象视图微件只会显示一个Object，此对象集应为单例。
- 要显示的Object：此参数是对象视图微件的输入变量，决定将显示哪个Object。由于对象视图微件只会显示一个Object，此对象集应为单例。
- 显示和格式化初始对象视图选项卡ID：非必填。此参数控制当该对象视图加载时最初显示的选项卡。
- 初始对象视图选项卡ID：非必填。此参数控制当该对象视图加载时最初显示的选项卡。
