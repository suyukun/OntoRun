# AIP生成的内容

AIP生成的内容微件可以显示来自AIP逻辑函数的响应，或以视觉化方式流式传输来自LLM的响应（类似于将LLM响应流式传输到变量事件）。

## 配置选项

AIP生成的内容微件有以下三个选项以生成响应：

- 逻辑：此选项需要选择一个AIP逻辑函数。
逻辑：此选项需要选择一个AIP逻辑函数。

- 直接连接LLM：此选项允许在微件中实时显示LLM的响应。它具有以下配置选项：提示：您的提示的字符串变量。当提示更改时清除输出：启用此选项时，当提示变量更改时将清除AIP生成的内容微件输出。当用户直接与提示交互时，这很有用。温度：模型使用的温度，范围在0到1之间。较高的值，如0.8，会使输出更随机，而较低的值，如0.2，会使输出更集中和确定。模型：要使用的语言模型。支持四种OpenAI模型：GPT-3、GPT-4、GPT-4 32K和GPT-4-Turbo。
直接连接LLM：此选项允许在微件中实时显示LLM的响应。它具有以下配置选项：

- 提示：您的提示的字符串变量。
- 当提示更改时清除输出：启用此选项时，当提示变量更改时将清除AIP生成的内容微件输出。当用户直接与提示交互时，这很有用。
- 温度：模型使用的温度，范围在0到1之间。较高的值，如0.8，会使输出更随机，而较低的值，如0.2，会使输出更集中和确定。
- 模型：要使用的语言模型。支持四种OpenAI模型：GPT-3、GPT-4、GPT-4 32K和GPT-4-Turbo。
- 通过提示函数的LLM：此选项与直接连接LLM相同，但提示为函数而非字符串。
通过提示函数的LLM：此选项与直接连接LLM相同，但提示为函数而非字符串。

#### 其他配置选项

- 输出变量：存储响应的字符串或对象集变量。
- 图标：在微件顶部显示的图标；默认为Palantir的AIP图标。
- 按钮标签：按钮内使用的标签；默认为“使用AIP生成结果”。
- 标题：在微件中心显示的标题。
- 加载状态消息：在响应加载时显示的消息。
- 显示加载旋转器：启用时，在加载时显示旋转器而不是加载状态消息。
