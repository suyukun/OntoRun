# 概述

Workshop使应用构建者能够为操作用户创建互动且高质量的应用程序。

Workshop 遵循三个关键原则：

- Object 数据Workshop 通过使用 Object 层作为主要构建块，降低了应用构建者的入门门槛。Workshop 应用程序中的所有数据都从 Object 数据层读取，使应用创建者能够利用丰富的特性，例如对象类型之间的链接。Workshop 利用操作进行数据输出到对象数据，并利用函数实现对象数据上的业务逻辑。
