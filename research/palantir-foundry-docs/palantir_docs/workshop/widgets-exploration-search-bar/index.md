# 探索搜索栏

使用探索搜索栏微件可视化并应用筛选到对象集。该微件支持对对象类型的属性进行筛选，也支持通过链接对象类型及其属性进行筛选。有关如何使用搜索栏的广泛筛选功能的更多信息，请查看筛选结果文档。

## 配置选项

- 模式只读:显示应用于包含单一对象类型的指定对象集的任何不可编辑筛选视图。仅删除:显示应用于包含单一对象类型的指定对象集的任何可编辑筛选视图，允许用户删除任何已应用的筛选。可选地，将包含已应用筛选的对象集筛选变量指定为输出。仅更新现有筛选:显示应用于包含单一对象类型的指定对象集的任何可编辑筛选视图，允许用户删除或编辑任何已应用的筛选。可选地，将包含已应用筛选的对象集筛选变量指定为输出。添加、更新、删除:显示应用于包含单一对象类型的指定对象集的任何可编辑筛选视图，允许用户删除或编辑任何已应用的筛选，并添加新的属性筛选以应用于对象集。可选地，将包含已应用筛选的对象集筛选变量指定为输出。菜单配置可用的属性类型:定义在下拉菜单中显示哪些属性类型。选项包括全部（包括隐藏）、重要、可见或自定义。可用的链接类型:定义在下拉菜单中显示哪些链接类型。选项包括全部（包括隐藏）、重要、可见、自定义列表或无。禁用属性值自动完成:切换以显示/隐藏建议的筛选。禁用关键字筛选:切换以启用/禁用字符串属性的关键字筛选。

- 菜单配置可用的属性类型:定义在下拉菜单中显示哪些属性类型。选项包括全部（包括隐藏）、重要、可见或自定义。可用的链接类型:定义在下拉菜单中显示哪些链接类型。选项包括全部（包括隐藏）、重要、可见、自定义列表或无。禁用属性值自动完成:切换以显示/隐藏建议的筛选。禁用关键字筛选:切换以启用/禁用字符串属性的关键字筛选。
- 可用的属性类型:定义在下拉菜单中显示哪些属性类型。选项包括全部（包括隐藏）、重要、可见或自定义。
- 可用的链接类型:定义在下拉菜单中显示哪些链接类型。选项包括全部（包括隐藏）、重要、可见、自定义列表或无。
- 禁用属性值自动完成:切换以显示/隐藏建议的筛选。
- 禁用关键字筛选:切换以启用/禁用字符串属性的关键字筛选。
- 显示清除按钮:切换以显示/隐藏用于清除搜索字段中所有筛选的按钮。
- 防止用户更改操作符（或、和）:切换以启用/禁用用户更改应用的筛选之间使用的操作符值。
- 图标:添加一个图标以显示在选项卡标签的左侧。
- 填满整个容器宽度:切换以启用/禁用搜索栏跨越其容器的宽度。
- 显示对象类型标签:切换以启用/禁用描述当前对象集的对象类型的标签。
- 显示搜索帮助图标:切换以显示/隐藏链接到筛选结果文档页面的帮助图标。
- 占位符:定义在搜索字段中显示的占位符文本。
