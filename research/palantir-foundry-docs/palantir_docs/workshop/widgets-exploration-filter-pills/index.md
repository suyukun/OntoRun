# 探索筛选药丸

使用探索筛选药丸微件以可视化并对对象集应用筛选。

## 配置选项

- 模式只读:显示应用于指定对象集（包含单一对象类型）的不可编辑筛选视图。仅移除:显示应用于指定对象集（包含单一对象类型）的可编辑筛选视图，允许用户移除任何已应用的筛选。可选择指定一个包含已应用筛选的对象集筛选变量作为输出。仅更新现有筛选:显示应用于指定对象集（包含单一对象类型）的可编辑筛选视图，允许用户移除或编辑任何已应用的筛选。可选择指定一个包含已应用筛选的对象集筛选变量作为输出。添加、更新、移除:显示应用于指定对象集（包含单一对象类型）的可编辑筛选视图，允许用户移除或编辑任何已应用的筛选，并添加新的属性筛选以应用于对象集。可选择指定一个包含已应用筛选的对象集筛选变量作为输出。阻止用户更改操作符（或，和）:切换启用/禁用用户更改应用筛选之间使用的操作符值。
- 只读:显示应用于指定对象集（包含单一对象类型）的不可编辑筛选视图。
- 仅移除:显示应用于指定对象集（包含单一对象类型）的可编辑筛选视图，允许用户移除任何已应用的筛选。可选择指定一个包含已应用筛选的对象集筛选变量作为输出。
- 仅更新现有筛选:显示应用于指定对象集（包含单一对象类型）的可编辑筛选视图，允许用户移除或编辑任何已应用的筛选。可选择指定一个包含已应用筛选的对象集筛选变量作为输出。
- 添加、更新、移除:显示应用于指定对象集（包含单一对象类型）的可编辑筛选视图，允许用户移除或编辑任何已应用的筛选，并添加新的属性筛选以应用于对象集。可选择指定一个包含已应用筛选的对象集筛选变量作为输出。阻止用户更改操作符（或，和）:切换启用/禁用用户更改应用筛选之间使用的操作符值。
- 阻止用户更改操作符（或，和）:切换启用/禁用用户更改应用筛选之间使用的操作符值。
- 显示对象类型药丸:切换启用/禁用描述当前对象集的对象类型的药丸。
