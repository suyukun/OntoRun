### 事件触发/导航微件

- 按钮组:通过具有可配置样式的按钮触发操作、Workshop事件、URL和以指定格式导出。
- 评论:启用Workshop模块中的协作。
- 媒体上传器:将媒体文件上传到Foundry，并使用上传的文件作为输入来触发操作。
- 标签页:显示标签页，可以触发Workshop事件以在模块的页面和层之间导航。
- 行内操作:在Ontology中的操作类型上渲染一个行内操作表单或表格。
