# 编辑历史

编辑历史微件显示了在Ontology Manager中为对象类型启用跟踪用户编辑历史后，对象属性的用户编辑列表。在启用编辑历史之前完成的编辑、由管道完成的编辑或在Object Storage v1上完成的编辑将不会被反映。
