# 微件: 当前位置管理器

当前位置管理器微件是一个测试功能，可能在您的环境中不可用。如果您有兴趣使用此功能，请联系您的Palantir代表。

当前位置管理器微件提示用户分享他们的位置，并将检测到的位置发布为可在您的应用程序中使用的字符串变量。此外，该微件还可以使用Mapbox反向地理编码API向最终用户显示一个人类可读的检测位置预览。

如果用户拒绝访问他们的当前位置，将显示警告，并且不会设置当前位置变量值：

请注意，当前位置管理器微件只会在包含它的页面打开时提示用户分享他们的位置并更新用户的检测位置。如果您的用户导航到应用程序内的不同页面，位置检测和更新将会暂停。我们建议将微件放置在工具栏或其他重要位置，以便在需要时始终可见。在包含当前位置管理器的页面顶部打开一个抽屉式导航不会阻止其更新；只有导航到不同页面才会导致更新暂停。

## 配置选项

以下是当前位置管理器的核心配置选项：

- 标签:显示在位置预览左侧的文本标签。可以为空以移除标签。
- 位置输出变量:以lat,long格式存储用户当前位置的字符串变量。
- 隐藏位置显示:如果启用，标签和位置预览都将被隐藏，但仍会提示用户分享他们的位置。此外，不会尝试反向地理编码用户的位置。适用于无需向用户显示检测位置预览的情况。
