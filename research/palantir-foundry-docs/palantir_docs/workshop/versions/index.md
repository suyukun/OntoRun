# 发布和版本管理

版本管理模块允许构建者安全且迭代地搭建Workshop应用程序；通过发布模块的稳定版本，可以控制终端用户可以访问的版本。这允许在实时Workshop应用程序上进行持续开发，而不必在保存模块时将更改暴露给终端用户。

## 版本历史和设置

版本对话框是构建者可以查看模块已保存版本历史的地方。每个已保存的版本都会显示时间戳、编辑者和描述（如果有的话）。对于每个已保存的版本，构建者可以选择：

- 发布此版本：发布模块的已保存版本，使其可供访客访问。
- 查看此版本：查看特定版本的模块。当查看非发布版本时，警告横幅会出现在模块顶部。
- 恢复到此版本：将历史版本保存为模块的最新版本。有关恢复操作的描述将自动生成。
要编辑模块的先前版本，请按照以下步骤操作：

- 确保在版本对话框中关闭保存时自动发布切换开关。
- 恢复到您想要编辑的版本。
- 使用文件 > 复制文件创建所选版本模块的副本。
- 将原始模块恢复到最新版本，并对创建的副本进行任何所需的编辑。
版本对话框也是构建者可以编辑与保存和版本管理操作相关设置的地方：

- 保存时自动发布：此切换开关控制保存时是否会自动发布新版本。
- 保存时始终提示添加版本描述：此切换开关控制是否在保存新版本时提示构建者添加非必填描述。可以添加描述以帮助记录对模块所做的更改，并建立模块历史的更丰富记录。描述可以在模块的版本对话框中查看、添加和编辑。
