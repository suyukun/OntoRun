# 管理权限

使用Artifact代码库时，请考虑以下权限要求：

- 使用Artifact时，用户必须在Artifact代码库上具有查看权限。
- 将Artifact发布到Artifact代码库时，用户必须在Artifact代码库上具有编辑权限。
- 撤回Artifact时，用户必须在Artifact代码库上具有编辑权限。
无法删除Artifact。

了解更多关于权限和项目访问的信息。
