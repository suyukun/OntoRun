# 召回制品

可以召回 Conda 制品以阻止下游消费者使用被召回的版本编译代码。我们建议在开始召回流程之前，为被召回的制品提供补丁版本。

按照以下步骤召回制品：

- 在您的制品库中搜索Conda 制品，并选择它以在摘要页面中查看版本历史部分。
在您的制品库中搜索Conda 制品，并选择它以在摘要页面中查看版本历史部分。

- 选择要召回的版本，然后点击召回。
选择要召回的版本，然后点击召回。

- 会出现一个召回制品的弹出窗口。在字段中输入召回制品的原因。
会出现一个召回制品的弹出窗口。在字段中输入召回制品的原因。

- 再次查看版本历史，以查看制品现在已被标记为Recalled。
再次查看版本历史，以查看制品现在已被标记为Recalled。

## 取消召回

您可以取消召回制品。

要取消召回制品，选择被召回制品的版本并点击取消召回。

## 删除

Conda 制品可以被召回，但无法删除制品库中的任何制品。如果您明确需要删除制品，您必须删除制品库。
