# Code Repositories 中的 AIP 功能

以下是 Code Repositories 中由 AIP 驱动的功能列表。

## AIP Assist

通过Ask AIP Assist选项或编辑器的右键菜单访问 AIP Assist 功能，并使用 AIP Assist 提升您的代码理解能力。

可以通过导航到设置（紫色齿轮图标）> 首选项 > AIP 功能配置Ask AIP Assist选项。

### 代码解释

您现在可以在 Code Repositories 中使用 AIP 来解释代码片段或整个文件的目的。

### 查找漏洞

在 Code Repositories 中使用 AIP 检查和调试您的代码。

### 翻译

Code Repositories 中的 AIP 可以将您的代码转换为多种语言，例如 Python、SQL、Mesa 或 Java。

## AI 错误增强器

AI 错误增强器提供全面的错误解释和建议的代码更改（如有），并提供访问源文档以获取更多信息的途径。此功能在以下列出的 Foundry 应用程序中可用：

### Code Repositories

在 Code Repositories 中，该功能显示在检查和预览部分。

### 搭建

在搭建中，此功能位于任务状态菜单中。

## 代码自动完成

该功能目前仅限于 Python 仓库。

代码自动完成可以通过解析您当前打开的文件来自动提供相关的自动生成代码，以帮助您生成实现目标的代码。

- 接受建议，请按tab。
- 忽略建议，请按esc，或开始输入其他内容。
可以在窗口底部的编辑器状态栏中直接打开或关闭代码自动完成，也可以通过导航到设置（紫色齿轮图标）> 首选项 > AIP 功能来进行设置。

注意：AIP 功能的可用性可能会发生更改，并且可能因客户而异。
