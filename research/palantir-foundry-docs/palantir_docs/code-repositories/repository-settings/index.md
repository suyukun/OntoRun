## 提交信息设置

默认情况下，在点击提交按钮或搭建数据集时，提交信息将自动生成。您可以通过禁用此选项来鼓励更有意义的信息。提交信息对话框将在每次提交前打开，并要求提交信息。

## 数据集别名

可以通过使用其在 Foundry 中的确切位置（路径）或其唯一资源标识符（RID）在代码中引用数据集。虽然这两种选项都是有效的，但建议尽可能使用 RID，因为这允许资源从一个位置移动到另一个位置而无需对仓库中的代码进行任何更新。

仓库编辑器的提前输入功能将允许您在输入时搜索数据，无论您输入路径、RID 还是自由文本。当您从结果列表中选择一个数据集时，编辑器将根据设置插入其路径或 RID：

- 在可能时自动更改为 RID- 此选项将插入数据集的RID，并提供将变换中的任何路径转换为 RID 的功能。编辑器将显示数据集名称而不是 RID，并允许根据需要进行编辑。
- 不要自动将位置更改为 RID- 此选项将插入数据集的路径，并允许在可能时将 RID 转换为路径。
## 外部系统

信息安全人员可以启用仓库以与外部系统进行交互。这是一个高级功能，允许开发人员编写与开放互联网上的 Web 服务和 API 交互的外部变换Python 代码。由于与外部系统的交互不能保证遵循 Foundry 的严格数据溯源和访问控制实践，因此此功能应仅在对高度可信赖的开发人员的仓库中启用。安全人员可以通过配置允许导出的强制性控制权限标记来限制允许与外部系统交互的数据范围。
