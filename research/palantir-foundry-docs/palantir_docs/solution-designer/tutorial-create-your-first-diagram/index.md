# 教程：创建您的第一个图表

在本节中，我们将创建一个简单的图表，表示与外部系统的常见连接、数据变换和用户可以在Palantir平台中交互的Ontology层。这是平台中的一个常见模式，并为使用解决方案设计工具打下坚实的基础。

- 通过选择新建图表来创建一个新图表。
- 选择外部系统，并在菜单中导航到外部系统。
- 将鼠标悬停在外部系统节点的右边缘，直到看到一个**+符号。点击并选择列表顶部的数据连接器**选项。
- 现在，将鼠标悬停在新的数据连接器节点上，点击并选择数据集以生成一个数据集名称节点。
现在，将鼠标悬停在新的数据连接器节点上，点击并选择数据集以生成一个数据集名称节点。

- 将鼠标悬停在数据集名称上，然后点击并选择数据处理 → Pipeline Builder以添加一个Pipeline节点。
将鼠标悬停在数据集名称上，然后点击并选择数据处理 → Pipeline Builder以添加一个Pipeline节点。

- 按照此模式继续进行以下流程：外部系统 → 数据连接器 → 数据集 → Pipeline Builder → 数据集 → Object → Workshop → 用户组。
按照此模式继续进行以下流程：外部系统 → 数据连接器 → 数据集 → Pipeline Builder → 数据集 → Object → Workshop → 用户组。

- 按住Shift键并选择Pipeline Builder节点和数据集节点，将这两个组件组合在一起。您也可以通过右键点击选中的项目，然后选择组合来组合它们。
- 将该组合命名为数据变换。
将该组合命名为数据变换。

- 选择右上角的保存来完成您的第一个图表。
选择右上角的保存来完成您的第一个图表。

解决方案设计提供了其他图表功能，对于搭建您的应用案例非常有用。请在我们的图表文档中了解更多。

## 提示

- 与您组织中的企业架构师对齐，了解您的Workshop应用程序将如何从Ontology中提取数据。最初，您可以创建一个通用的Ontology节点来抽象地表示所有Object。
- 与五个数据域所有者对齐，了解您将使用哪种类型的数据；创建五个不同的Ontology节点，每个域一个，以显示您的Workshop应用程序将从哪里提取数据。
您的图表不需要一对一详细表示您实际将搭建的内容。您可以选择首先概念性地表示您的应用案例，然后随着更多细节的出现进行迭代。
