# 概述

解决方案设计器是一个交互式工具，用于创建使用Palantir平台搭建的解决方案的架构表示，包括用于第一方和第三方集成点的表示、与平台资源的链接、按需访问文档和最佳实践等。

解决方案设计器使您能够执行以下操作：

- 从行业和技术模式集合中汲取灵感。
- 通过直观的分步指导为您的项目创建解决方案架构。
- 展示和比较各种架构提案，以达成搭建计划和策略的共识。
- 调查新产品和功能，以了解它们如何与平台的其他部分互动。
