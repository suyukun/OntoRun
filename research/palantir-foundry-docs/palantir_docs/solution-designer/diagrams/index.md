# 图表

本节提供了解决方案设计器图表功能的概述以及可以应用于图表的各种配置。

## 节点

画布上的节点代表 Palantir 平台上可用的资源和应用程序。使用以下工具来配置、上下文化和连接图表中的节点。

- 配置面板切换：展开或折叠节点配置面板。
- 询问 AIP Assist：提示 AIP Assist 解释平台组件。
- 组件信息关于：节点及其预期用途的简短描述。文档：链接到相关文档。示例：提供节点使用方式的预览。
- 关于：节点及其预期用途的简短描述。
- 文档：链接到相关文档。
- 示例：提供节点使用方式的预览。
- 标题和节点描述
- 删除节点（悬停显示）
- 节点连接（悬停显示）：从这里拖动以连接节点。
- 调整节点大小（悬停显示）
- 创建/重定向到平台的相关部分
- 将 RID 与资源关联。
- 通过选择铅笔图标添加相关标签
### 节点上下文菜单操作

- 向前发送：将节点向前移一个索引
- 向后发送：将节点向后移一个索引
- 更改背景颜色：更改节点颜色
- 组合：创建单个组
- 删除节点
### 抽象节点（测试版）

抽象节点的功能类似于普通节点。然而，一旦连接，它们会根据连接的输入和输出节点生成建议。您可以从建议的选项中选择，用适当的选择替换抽象节点。

### 分组节点

将节点分组在一起可以让您在概念上组合组件。创建节点组可以帮助增加图表的模块化和组织性，使其更易于理解和导航。

要创建组，请按住Shift并在画布上拖动光标选择多个节点。您也可以通过选择单个节点并按住Shift进行多选。

选中节点后，右键单击并选择组以将节点组合在一起。您可以通过将节点拖入或拖出组来更改组内容。
