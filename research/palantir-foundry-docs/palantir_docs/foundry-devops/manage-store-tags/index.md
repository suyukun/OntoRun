# 管理商店标签

现在可以给市场产品添加标签，以便安装者在浏览商店时获得流畅的体验，并提高产品的发现率。标签是可以应用于产品的标识，而类别是标签的集合。这些可以被用于在市场商店中筛选产品。所需权限请参阅编辑商店标签权限。

## 在商店中配置类别和标签

标签在商店级别定义，仅存在于给定的商店中。标签被组织成类别。这些可以通过位于DevOps主页上的设置选项进行配置。

类别和标签的名称在创建后可以进行编辑，但在一个商店内不能有重复的类别名称，或在一个类别内不能有重复的标签名称。类别和标签只能永久删除，这也会从产品中删除任何相关标签。删除后，类别和标签无法恢复，标签需要重新创建并重新添加到产品中。这里可以重新排序类别，以控制市场商店中类别筛选的顺序。

## 在产品上应用标签

一旦在商店中定义了标签，它们就可以应用到相关产品上。要应用标签，您需要创建并发布产品的新版本。
