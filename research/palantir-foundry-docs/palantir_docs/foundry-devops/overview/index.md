# 概述

Foundry DevOps 处于有限测试阶段。

## Foundry DevOps [测试版]

Foundry DevOps使您能够快速开发和部署在 Foundry 中搭建的数据支持工作流包，利用您组织的Ontology、AI模型、管道、数据连接或端到端应用案例。

Foundry DevOps 的关键特性包括：

- 灵活的打包Foundry 资源的任意组合为产品。
- 自动化版本和依赖管理确保随着产品规模的扩大，模块化组件的无缝同步。
- 使用发布渠道标记新产品版本，确保版本仅到达符合条件的安装。
- 管理一系列安装。
Foundry DevOps 非常适合应用案例，如：

- 产品分发：在 Foundry Marketplace 中为您组织内的其他安装者或更广泛的 Foundry 社区发布您的产品。
- 搭建生态系统：为每个生态系统参与者（客户、子公司、部门等）安装您的产品，并使用他们的输入数据。
- 版本管理：创建与开发环境相对应的安装，并为升级和发布渠道定制维护窗口。
- 引导新应用案例：安装您的产品一次，以作为您最新定制应用案例的起始点。
