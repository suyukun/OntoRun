# 以导出和导入产品

Marketplace产品可以从一个本地商店导出并导入到另一个本地商店。可以在同一注册下的任意两个本地Marketplace商店之间共享，或在两个不同的注册之间共享。所需权限，请参阅导出产品权限和导入产品权限。

## 导出产品

Marketplace产品可能包含敏感数据，并且导出的文件未加密。敏感数据可能包括数据集、媒体集、模型和元数据，包括名称、描述和架构。导出Marketplace产品时请牢记安全性。

具有足够权限的用户可以从本地商店导出选定的产品。Marketplace产品以文件形式导出，该文件仅应用于短期传输而非永久存储。我们保留对文件格式进行重大更改的权利，这可能导致文件无法导入。出口者有责任验证产品是否允许导出到平台外，并确保在之后安全处理。导出的文件经过代码签名；在传输过程中对文件的任何更改将导致文件无法导入。

## 导入产品

Marketplace产品可能包含敏感数据。敏感数据可能包括数据集、媒体集、模型和元数据，包括名称、描述和架构。确保您被允许将产品导入到您的商店，并在这样做时牢记安全性。

具有足够权限的用户可以导入从另一个本地商店导出的Marketplace文件。进口者有责任验证产品是否允许导入到平台。在大多数情况下，这意味着出口者和进口者之间的合作以确保仅合适的数据在Marketplace商店之间传输。
