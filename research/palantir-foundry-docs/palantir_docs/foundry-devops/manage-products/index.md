# 管理产品

选择商店后，您将能够看到所有您拥有编辑或查看权限的产品。您可以使用搜索栏旁边的筛选选项来查看已发布的产品、产品草稿或两者同时查看。

选择产品以查看产品概览，您可以从中启动新版本、查看以前的版本以及查看每个发布阶段的最新产品版本。产品概览页面显示最新版本的预览。

产品页面以表格形式显示所有产品的版本，您可以访问每个版本的相应页面。

要创建新版本，请从产品页面的右上角选择启动新版本。

## 产品版本

使用产品页面上的版本表导航到产品版本页面。产品版本页面显示每个版本的内容、输入、本地安装和更改日志。

## 发布渠道

您可以用发布渠道标记产品版本，以便将特定版本推送到跟踪每个渠道的相关安装中。每个版本可以标记为发布、预稳定或稳定。每个安装跟踪一个发布渠道，默认情况下，所有安装都设置为跟踪发布发布渠道。此设置可以在安装时的安装设置中找到。

要使用发布渠道标记产品版本，首先导航到产品版本页面，然后使用右侧的选择器选择发布渠道。

发布渠道是分层的，而不是互斥的。根据跟踪：

- 发布：安装接收标记为发布、预稳定或稳定的版本。
- 预稳定：安装接收标记为预稳定和稳定的版本。
- 稳定：安装接收标记为稳定的版本。
## 产品弃用

要弃用产品，请从产品概览页面上启动新版本按钮旁边的下拉菜单中选择弃用，以隐藏产品不在店面显示。目前不支持产品的彻底删除。

## 撤回产品版本

如果需要撤回产品版本，请导航到产品概览页面并使用产品版本表找到您想撤回的版本。然后，选择撤回版本。

您还可以直接从产品版本页面撤回版本，如下所示。

对于本地市场商店，此操作将阻止新的手动安装、升级和自动升级安装被撤回的版本。如果您已安装被撤回的版本，现有安装将不受影响。被撤回的版本将不会被推荐给用户，并且在市场中可见性有限。

对于远程市场商店，不支持撤回操作。在本地市场商店发出的撤回不会反映在使用该商店作为远程商店的不同注册中。

如果包含撤回信息的产品被手动上传到另一个本地市场商店，撤回信息将被保留。
