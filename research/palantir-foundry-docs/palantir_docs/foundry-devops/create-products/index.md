# 创建产品

本页面包含在 Foundry DevOps 中创建新产品的说明。用户可以通过市场商店浏览和安装可用产品。阅读更多关于您可能想要创建产品的应用案例。

## 商店

要创建新产品，请选择一个商店以发布您的产品。要选择现有商店或创建新商店，请在右上角选择更改商店选项。

新商店将保存到一个项目中，并继承该项目的权限。具体来说，任何拥有商店项目编辑权限的人都可以在该商店中创建新产品和编辑现有产品，任何拥有查看或编辑商店项目权限的人都可以从该商店安装产品。

## 产品创建

选择商店后，选择新产品开始创建您的产品。

### 常规

为您的产品命名，并在常规步骤中根据产品配置其他设置。

### 内容

内容是用户安装您的产品时会创建的部分。要开始搭建您的产品，请选择您希望包含的内容。一些资源类型会被高亮显示，但您始终可以选择查看更多实体类型以查看支持的资源类型完整列表。

DevOps 将自动识别依赖关系，因此我们建议首先添加最下游的资源。例如，如果您想要打包一个Workshop 应用和五种object 类型，请先仅添加 Workshop 应用。添加内容后，选择一个资源以打开右侧的信息面板。

选择依赖关系选项卡以查看依赖关系。依赖关系也将作为输入显示。

### 输入

随着您添加内容，依赖关系将自动显示为输入。产品安装者需要提供资源以满足这些输入。

要查看更多关于特定输入的信息，请选择输入以打开信息面板。依赖者选项卡包含关于哪些内容资源需要此输入的信息。

在设计您的产品时，您可以选择将输入提升为内容。有两种方法可以做到这一点：从依赖关系选项卡或从输入列表。

- 要从依赖关系选项卡提升输入为内容，请查看单个资源的内容信息面板，然后选择批量编辑以批量选择多个依赖项进行包含。
- 要从输入列表提升输入为内容，请选择您想要包含的资源，然后在右上角选择包含。
一般来说，如果您希望安装者提供他们自己的资源版本（例如，他们自己的数据源、object 类型等），我们建议将该要求列为输入。如果您希望您的产品为安装者提供资源，则应将输入提升为内容。如果您将所有输入提升为内容，您的安装者在安装过程中将无需映射任何内容。

### 文档

在文档步骤中，您可以添加一个简短描述，它将对在商店中浏览产品的用户可见，以及安装者安装您的产品时会获得的内容截图，如有相关信息，还可以添加包含如何使用您的产品信息的更长描述。

### 安装模式

使用安装模式设置您产品的任何安装的默认设置。这些设置可以在每次安装时更改。

- 生产模式：推荐当您希望集中管理所有安装并使用自动升级等功能时。默认情况下，安装启用了自动升级，并且资源安装到受限项目中以确保安全升级。
- 引导模式：推荐当您预计安装者将使用您的产品作为其自定义工作的起始点时。默认情况下，安装禁用了自动升级，并且安装者可以安装到他们拥有编辑权限的任何位置。
### 审核与发布

当您对您的产品满意后，选择发布使产品在商店中可用。根据产品的大小，发布可能需要几分钟。
