## 后续步骤

下一步是将此示例工作流程转换为您组织中的实际工作流程。

这通常包括：

- 将来自多个数据源的数据集成到 Foundry 中，以创建一个features_and_labels数据集，可用于训练和测试不同的模型。
- 尝试不同的模型架构、参数和特征，以获得最佳的模型性能。
- 将您的模型预测集成到 Foundry Ontology 中，以便通过批量部署、实时部署或 Python 变换在操作应用程序中使用。
- 创建预发布检查在您的建模目标中，以确保模型在发布前获得批准。
- 创建“数据输出”操作，以捕获用户操作作为新数据集，并使用这些数据进行模型的持续再训练和改进。
- 创建模型推断历史，以改进和迭代您的模型，以获得更准确的性能和使用。
