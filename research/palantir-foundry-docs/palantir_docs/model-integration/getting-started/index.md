# 起始

在开始建模工作流之前，确保您对Foundry核心概念、代码仓库、Python变换、Ontology和函数有一个高层次的理解。

如果您是Foundry的新手，监督学习教程提供了从建立新项目到将模型部署到生产环境的完整指南。

## 常见的模型创建工作流

- 在Jupyter®代码工作区或代码仓库中使用Palantir平台的数据训练模型
- 导入模型权重并将其注册为模型
- 导入并注册一个容器作为模型
- 注册一个外部托管的模型
## 部署模型以进行推理和使用

- 使用Foundry ML Live部署模型
- 将模型用作Python变换的输入
- 评估模型性能
- 使用模型“部署”进行批量推理
## 为Ontology中的使用注册模型

- 注册一个Live部署以在Typescript函数中使用
- 注册一个模型以直接在Ontology中用作函数
