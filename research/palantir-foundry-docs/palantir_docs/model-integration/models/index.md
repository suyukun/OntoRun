# 模型

在 Foundry 中，模型是用于推理的工件，包含机器学习、预测、优化、物理模型或业务规则。在一个应用案例中，模型对您的数据进行编码以创建预测并支持决策。

在 Palantir 内开发或集成的模型提供：

- 完整的版本历史、细粒度的模型权限管理、自动依赖管理、模型血统和API管理
- 通过模型部署进行实时推理的无代码托管
- 通过建模目标应用进行模型管理、评估和部署
- 绑定到 Foundry Ontology，允许通过Foundry 应用、模型上的函数和场景基础设施进行操作化。
### 架构

Palantir 中的模型资源由两个相关但不同的组件组成：

- 模型工件：保存训练模型的模型权重或容器。
- 模型适配器：描述平台如何与模型工件交互以加载、初始化和执行模型推理的逻辑。
适配器作为 Python 库的一部分发布，以支持与存储的模型工件进行通信。它使平台能够加载、初始化和运行任何类型模型的推理。适配器设计灵活，可用于包装手动上传的模型文件或检查点、在 Foundry 中训练的模型或任何任意的功能逻辑。
