# 开始使用 HyperAuto V1

本文档适用于 HyperAuto V1。如果您使用的是 HyperAuto V2，请参阅HyperAuto V2 入门文档。

以下步骤指导创建一个 SDDI 实例：

- 从侧边栏或在[foundryinstance URL]/workspace/sddi-app打开 SDDI Cockpit，并选择创建新实例。
从侧边栏或在[foundryinstance URL]/workspace/sddi-app打开 SDDI Cockpit，并选择创建新实例。

- 按照屏幕上的说明选择适当的源类型。
按照屏幕上的说明选择适当的源类型。

- 输入您首选的存储库名称，并选择所需的存储库位置以及管道输出文件夹位置。对于管道输出文件夹，HyperAuto 提供了建议的位置。
输入您首选的存储库名称，并选择所需的存储库位置以及管道输出文件夹位置。对于管道输出文件夹，HyperAuto 提供了建议的位置。

- 配置您希望应用 HyperAuto 的数据连接源。此源应具有与您在步骤 1 中选择的相同源类型。分别确定原始数据和元数据的文件夹位置。这些文件夹将随后存放从源同步的原始数据和元数据集。

- 在“同步数据”步骤中同步数据库元数据表。这将从您的源系统同步相关的元数据表，并将其添加到指定的自动管道生成器存储库中，以在后台生成管道。

您的 SDDI 实例现在应该可以正常运行，并准备从您的源中清理表格。要了解有关配置和执行 SDDI 流的更多信息，请导航到Cockpit。
