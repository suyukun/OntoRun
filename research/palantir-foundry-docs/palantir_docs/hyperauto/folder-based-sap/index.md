# 基于文件夹的SAP数据管道

HyperAuto V2 还支持从SAP数据创建数据管道，而无需直接连接到SAP。这提供了灵活性，能够支持多种架构，包括源镜像、静态数据提取和预筛选数据。

## 为SAP静态数据设置HyperAuto V2数据管道

要在SAP数据集上创建HyperAuto V2数据管道，请设置一个包含以下内容的单个Foundry文件夹：

- 输入表数据集（每个SAP表一个数据集）
- 数据字典表
将所有数据集直接放置在同一文件夹中，以确保自动检测功能正常工作，并最小化数据管道创建步骤。通过SAP表名（例如，MARA）命名输入表数据集，将有助于自动映射过程并减少所需的手动步骤数量。

数据需要是原始SAP表的未变换提取，包含其技术列名。

### 数据字典表

数据字典表包含来自SAP的必要元数据，HyperAuto利用这些元数据生成数据管道，包括表和列的描述，以及表之间关系的描述。

创建基于文件夹的SAP HyperAuto数据管道所需的数据字典表包括：

- DD02L（SAP系统中表的详细信息）
- DD02T（不同语言中表的描述文本和标签）
- DD03L（字段定义、数据类型和长度）
- DD04T（多种语言中的数据元素描述和标签）
- DD05S（外键关系的详细信息，包括父表和子表字段）
- DD08L（SAP系统中表之间外键关系的元数据）
数据字典表必须是其原始格式且未筛选的，以确保HyperAuto正常工作。

## 创建基于文件夹的数据管道

- 一旦您设置好输入文件夹，导航到HyperAuto主页以创建新的数据管道。这可以通过Foundry左侧边栏中的应用程序浏览器找到。
- 点击**+ 创建数据管道**以打开创建数据管道对话框。
- 在这里，您可以选择创建一个典型的数据管道（这将需要实时SAP连接）或基于文件夹的SAP数据管道。选择“文件夹（仅SAP）”并通过点击浏览选择您的输入文件夹。
点击创建数据管道以进入HyperAuto数据管道创建向导。

### 设置向导

- 现在，您将定义基本的数据管道配置，类似于基于源的数据管道。
首先，为数据管道选择一个有效的名称和位置。

- 源配置步骤确保HyperAuto知道数据字典表，以便它可以读取必要的元数据来搭建数据管道。
如果输入设置正确，这些将被自动映射。否则，在继续之前手动映射每个元数据表。

- 下一步是选择要处理的输入。默认情况下，仅显示可发现的输入（那些在输入文件夹中按名称直接匹配的数据集）在输入选择界面中。
若要显示所有可用表（基于数据字典表）点击显示未发现的表。

添加一个未发现的表将需要您手动将输入映射到适当的Foundry数据集，以便将其用作输入。

创建一个未映射输入的数据管道将导致该输入被忽略。

- 根据需要选择数据管道配置，然后点击创建HyperAuto数据管道以完成向导并触发数据管道创建。
