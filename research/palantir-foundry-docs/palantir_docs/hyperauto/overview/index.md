# 概览

HyperAuto V2 带来了新的用户体验和性能提升，包括实时流支持，以便在瞬间提供更有用的应用程序就绪数据。

目前，HyperAuto V2 仅支持 SAP 数据源。

Palantir HyperAuto —— 也称为软件定义数据集成（Software-Defined Data Integration, SDDI）—— 是一套能力，旨在在组织中最常用和关键的系统之上提供开箱即用的端到端数据集成能力。作为数字化转型的快速通道，HyperAuto 使您能够自主创建有价值的工作流，使用 ERP、CRM 和其他组织关键数据。

通过 HyperAuto，您可以同步、集成和构建数据，以便立即在主要数据系统之上搭建新的工作流。HyperAuto 支持的最广泛使用的系统包括：

- SAP (V2)
- Salesforce (V1)
- Oracle NetSuite (V1)
## HyperAuto V1

HyperAuto V1 支持广泛的 ERP 和 CRM 源系统，并包含全面的功能，例如通过派生元素实现的内置智能和自动Ontology 创建。V1 将继续可用并受到支持，直到所有源类型和必要功能在 HyperAuto V2 中可用。

对 HyperAuto V1 的更新将提前通知。

更多信息，请参阅HyperAuto V1 文档。
