# HyperAuto V2 入门指南

本指南适用于 HyperAuto V2。要开始使用 HyperAuto V1，请参阅HyperAuto V1 文档。

如果您没有直接连接到系统并且正在处理静态数据，可以创建一个基于文件夹的管道。

按照以下步骤创建您的第一个 HyperAuto 管道：

- 导航到您希望从中同步数据的支持源。您可以在 Foundry 实例的数据连接应用中找到所有源的列表。
导航到您希望从中同步数据的支持源。您可以在 Foundry 实例的数据连接应用中找到所有源的列表。

- 在源的特定概览选项卡中，选择创建 HyperAuto 管道以打开 HyperAuto 管道向导。
在源的特定概览选项卡中，选择创建 HyperAuto 管道以打开 HyperAuto 管道向导。

- 定义新的 HyperAuto 管道资源的名称和位置以及任何相应的生成资源。请注意，HyperAuto 管道必须与输入数据集位于同一项目中。
定义新的 HyperAuto 管道资源的名称和位置以及任何相应的生成资源。请注意，HyperAuto 管道必须与输入数据集位于同一项目中。

- 如果适用，请选择源子系统（例如，SAP 源的"上下文"），以及摄取方法（批处理或流式处理，详细信息请参见架构）。

- 在输入配置步骤中，选择您希望处理数据的源表。您可以按类别（"模块"）或按工作流单独选择表。您还可以选择没有数据连接同步的表作为输入。如果选定的输入已有同步，HyperAuto 将默认使用最近的一个。要重新配置选定的输入，将鼠标悬停在配置输入表按钮上。在此菜单中，您可以选择替代的现有同步或创建新的同步。

- 决定所需的管道配置，包括语言和变换选项。详细信息请参见配置选项。

- 选择创建 HyperAuto 管道。您的新 HyperAuto 管道将被创建并开始处理数据。您将被重定向到管道的概览页面，在那里您可以监控生成进度。

- 一旦生成成功，您可以使用概览页面管理和监控管道及其相关资源，包括输入同步和数据集，以及输出数据集和Object。选择查看生成器管道以打开只读生成器管道，并更详细地查看变换逻辑。配置选项卡显示 HyperAuto 管道的输入和管道配置。在此选项卡中选择编辑以创建新的提案并更新配置。
