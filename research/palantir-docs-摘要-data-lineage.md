## data-lineage 模块
- **定位**：交互式血缘工具，回答"数据从哪来/为何不是最新/谁改过/哪些派生受影响"。
- **图模型**：节点=资源（数据源/数据集/Object 类型/工件），边=数据集间沿袭关系。
- **图的构建**：搜索助手加资源；点节点看直接父级；展开祖先/后代；可定义显示层级数。
- **血缘触发搭建**：三种策略 = ①搭建所有上级（默认仅过期上级，可强制重搭）②所选数据集之间所有变换 ③仅所选数据集；按依赖顺序执行；受分支影响。
- **列级能力**：基于"选择属性直方图"的"常见列"聚合（按列名统计出现频次，点列高亮含该列的数据集）——**列级血缘以"列名是否出现"为单位，非逐字段映射**。
- **来源验证**：节点详情含预览（前 300 行）、历史、代码、数据健康、搭建时间线（甘特图）。
- **血缘与权限**：按用户两种着色 = "数据集中的数据访问"（沿血缘传播）与"资源访问"（角色）；两者不同步。权限标记模拟：可模拟添加/移除标记对派生数据集的影响。
- **血缘与 Ontology**：数据集可带"定义 Object 类型"指示器；只读 Object 类型=1 个上级，启用数据输出=2 个。
- **诊断"数据集不是最新"**：用搭建状态着色，正在运行的可见。
