## 验收口径
- 可表达集内（R/A 27 题）：ANSWER 正确率 = 验收主指标（目标 ≥90%）
- 域外（D 3 题）：必须 DECLINE（100% 拒答，不瞎编）
- P95 exec ≤500ms（纯执行层，不含 LLM 转换）
- 30 题全部在演示脚本中有代表性抽样

## M3b 落地备注（2026-08-26）
- 实体名适配：本稿 R/A/D 中的"华夏新能源集团 / 华辰制造"来自设计文档（企业画像 §六）的
  演示主线占位，DES 生成的真实 ap_anping 数据用另一批虚构企业名（如 中科智造控股集团有限
  公司、联发建材产业发展集团）。M3b 冒烟（scripts/smoke_risk_chat.py）按题目模式适配到
  真实企业，并以直接 SQL 交叉验证答案正确性（不改为改数据去迁就题面）。
- R04（Top500CustomerRisk）/R20（CoDebtCustomer）/R21（Collateral）等涉及无源表对象的题：
  当前可表达集拒答（fail-closed），或经聚合/排行对象等价回答（R04 用 warning_signal
  group_by 客户 + sum(risk_exposure) 取 Top5）。
- 双签边界：high_risk 动作（adjust_warning_level/approve_disposal/close_warning/
  adjust_concentration_limit/register_risk_project）确认前绝不执行；confirm_warning 非高风险。
