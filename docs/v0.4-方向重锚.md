## 〇、为什么重锚

宪法三层目标（求职/影响力/方法论）不变，脊柱之问（"消费者从人看报表变成大模型读+操作，建模范式必须变"）不变。变的是三个病灶：

1. **三切面失衡**：S1→S3 拼命把"证据"做大（三个行业、54 表、698 测试），但"根"（方法论叙事）与"放大器"（表达）严重滞后——没有脊柱的证据堆 = 迷茫感来源。
2. **产品面背叛论点**：嘴上"为 Agent 而建"，界面是"为 BI 而建"的壳（菜单+表格浏览器，Agent 缩在一个菜单项）。
3. **什么都想要**：DES 模拟器、方法论呈现、血缘追溯、规则配置、双行业演示全都要，结果没有重点没有特色。

## 一、S4 拍板共识（2026-08-27 全部经 Jack 确认）

1. **聚焦金控风险一处场景**：零售演示收起（降为跨行业可复用性一页证据）；DES 降级为后台数据生产线（撤 /des 门面）；构建器/血缘/规则配置收进证据链叙事，不单独立菜单。
2. **Agent 对话框 = 唯一一级入口**，对象/链接/图谱降为对话证据链的展开态。
3. **33 对象一个不删**，12 个核心链对象进门面（前端信息架构层裁剪，schema 物理裁剪挂起）。
4. **口径真相源 = 核心链口径包 v0.3**：双层集中度口径（银行层 15% 法定 / 集团层内部限额 12%+预警线 10%）、红橙黄中文三级、生命周期七态、R1a-R6 规则（M2 只注册剧本命中的 R1a/R2）、四部法规条款级锚定+双模型（豆包/DeepSeek）对抗复核。
5. **终极验收（§九）**：中信金控风险合规部**风险技术管理处**处长——5 分钟内感受到价值、显专业、看得出智能体优势；反面 = 像玩具/不如 Excel/术语让内行皱眉。处长画像：风险系统建设者本人，价值主张 = "不替代你的系统，给你的系统加语义层+AI 前端"（业务需求开发量/口径对齐/报送手工/新规落地四痛点）。
6. **零幻觉口径**：本体覆盖内零幻觉（答案可点开证据链），覆盖外诚实拒答——不承诺"什么都能问"。
