# ADR-0012：本体管理台技术选型（AntD 6.x · 混合首页）

日期：2026-09-10
状态：已接受（Jack 授权 Rose 论证后拍板；论证见 docs/research/antd与图谱首页论证_v0.1.md）

## 背景
管理台（后台）UX 五问中两项待技术论证：组件库选型、图谱首页可行性。论证子代理核出关键事实：仓库 web/（早期本体驱动 UI 应用）已用 React19+antd^6.6.0+xyflow；chatbi/ 是零组件库包——两者是同仓独立包，依赖物理隔离。

## 决定
1. **组件库 = AntD 6.x**（仅管理台新包引入；chatbi 保持零组件库不动）：表格/表单/抽屉/布局全是 AntD 主场；单人（AI）维护+数仓同学未来接手，成熟组件库交接成本最低；仓库已有 antd6，不养 5/6 双大版本。风险对策：与 chatbi 双视觉语言用 token 对齐。
2. **首页 = 混合首页**：图谱主体（≥70% 视区，业务域聚类预置坐标+懒初始化）+ 顶部待确认横条。尊重 Jack"图谱当首页、能看清全局"的意图，横条对冲审美风险保底日用价值。**降级判据**：上线一个月图谱交互趋零 → 换工作台首页（路由换序约半天）。
3. 权限：MVP 全员可确认+落身份（ADR-0011 已定），实施时接口预留双负责人制（Jack 2026-09-10 补充）。

## 理由与后果
- 新增依赖（antd 6）属"先问"档——Jack 已于 2026-09-10 授权"论证后由 Rose 定"，本 ADR 即记录；
- React Flow + d3-force 维持概念设计选型（几十节点性能无虞）；
- 后果：管理台实施任务书按此三项编写，排 F（语义层）交付后启动。
