## 派活前自查（Rose 硬门禁，三行缺一不派；2026-09-11 制度首日复盘新增）
1. 门槛稿 NC 状态列无未解决项（机器检查：状态列仅允许 RESOLVED / N-A）；
2. D1 基线命令已**亲跑**且输出已贴本稿（开工前，非交付后第一次跑）；

## 0. 级别声明（先定级，防偷偷降级）
- **S 级**（免填，但必须一行声明）：单文件 <50 行改动、无新依赖、一句话能说清验收 → 直接做。
- **M 级**（填 A + D）：单模块功能。
- **L 级**（填全表）：跨模块 / 新方向 / 改本体 schema / 涉演示路径。
- 本块级别 = ___ ；若从 L 降 M/S，理由 = ___ 。

## A. 需求（消杀根因①：spec 缺陷）
- [ ] A1 一句话命题：给谁、解决什么问题、成功后世界有何不同。〔完成标志：Jack 一句话复述，Rose 无需追问〕
- [ ] A2 用户故事 ≤5 条，P1/P2/P3 排序，每条独立可测、独立可交付。〔完成标志：砍掉 P2/P3 后 P1 自成闭环〕
- [ ] A3 验收标准（EARS：WHEN <条件> THE SYSTEM SHALL <可观察行为>），逐条挂用户故事。〔完成标志：每条能想到对应测试/命令，名字写上〕
- [ ] A4 边界条件 ≥3 条：空输入/失败路径/权限外/重复提交类。〔完成标志：每条有"系统应当怎样"的明确答案，不是"再说"〕
- [ ] A5 非目标（本轮不做什么）显式列出。〔完成标志：Jack 拍板；交付物出现非目标内容 = 退回〕

## B. 设计（只定会返工的部分；M 级可跳）
- [ ] B1 技术上下文：动哪些文件/模块、依赖不变量、数据存哪、怎么测。〔完成标志：git diff --stat 预期范围可预估〕
- [ ] B2 关键决策 ≤5 条 + 理由与备选（进 docs/adr/ 雏形）。〔完成标志：每条能说清"为什么不是另一个方案"〕
- [ ] B3 接口/数据契约：schema/API/表结构，以代码形式存在（Pydantic/TS 类型/DDL）。〔完成标志：可 import〕
- [ ] B4 宪法门禁：对照 AGENTS.md 三铁律 + 最小实现 + 边界三档逐条过。〔完成标志：结果写入本稿〕

## C. 计划（消杀根因②：执行偏差）
- [ ] C1 任务按用户故事分组，每任务带确切文件路径 + 完成判据。〔完成标志：Rose 只看本表就能派活，无需追问〕
- [ ] C2 前置任务（foundational：路由壳/注册表骨架类）单独成组。〔完成标志：有"完成即解锁"判据〕
- [ ] C3 可并行任务标 [P]，串行依赖写明。〔完成标志：并发派活 ≤4 限额内排得开〕
- [ ] C4 时间盒与止损线：预期轮次；**同一任务返工 ≥2 轮 → 停，回 B 修 spec，不许第 3 次 patch**。〔完成标志：止损线写进派发单，子代理可见〕

## D. 验收（消杀根因③：验证缺位）
- [ ] D1 可执行验收命令集合（增量测试/lint/tsc；子代理禁跑全量 pytest），**开工前先跑一遍记录基线**，不是交付后第一次跑。〔完成标志：基线输出已贴本稿〕
- [ ] D2 验收看 diff：改动行 ↔ A 表条目对照；搭车改动退回。〔完成标志：对照表在收口节填写〕
- [ ] D3 演示路径：Jack 5 分钟能亲手走一遍的脚本（点哪里、看什么、应是什么）。〔完成标志：写在收口节，不靠子代理口述〕
- [ ] D4 DoD 一句话：什么叫绿、什么不算完。〔完成标志：与 A3 逐条对得上，无新增判据〕

## NC 确认协议（Jack 体验保障，2026-09-11 裁决补丁；答题卡交互 Jack 认可同日，持续打磨）
> Jack 裁决：所有 NC 与默认建议均需事前确认（不授权代答）；配套规则防确认负担失控：
1. 答题卡制：Jack 只看答题卡，永不读门槛稿全文。每题 = 编号 | 白话问题（≤2 行）| 选项 a/b/c | Rose 推荐。
2. 答法极简：回「1a 2b 3默认」或语音口述均可；默认级整批一句「按默认」清零。
3. NC 预算：每块 NC ≤10 题（阻塞级 ≤4），超预算 = spec 没做好回炉，不推给 Jack。
4. 批量推送：攒批出卡不零碎打断；看不懂的题 = Rose 翻译失职，回炉重写，不许 Jack 猜。
5. 豁免通道：紧急 hotfix 可先干后补（事后补登 NC＋worklog 记原因）。
