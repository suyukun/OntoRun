### B2 关键决策（为什么不是另一个）
1. **业务域做主封装轴，表→域登记制进 git**：老板/数仓头脑里的地图是业务分块不是加工分层（存储层只 4 值封装度不够）；登记≠猜测（禁表名前缀兜底）。不是：存储层主轴（晒工程结构）、一表多域（图变重计数重复）、映射走确认生命周期（过度治理）。
2. **域图布局=自写确定性力导向（固定种子+碰撞分离+缓存）**：≤10 域规模下引 dagre/elk 收益不成比例（ADR-0012 不引新库）；手工坐标让登记制失去「加域零布局成本」；QC-5 无重叠从判据变构造保证。
3. **三问卡与分歧卡分离，R8 四选项含逃生口**：二值模型装不下双合法裁决（v0.1 已证）；A8 裁决逃生口把「不敢」变「上报留痕」，留痕本身是信任链数据。不是：强制必裁（把分歧变单点）。
4. **试算=只读端点走既有语义查询链路+当日缓存**：图表明细同源铁律禁手填假数字。不是：静态快照（会过期失真）、前端算（真相源错位）。
5. **两里程碑交付，M1 先行**：M1（确认流+R8+三问卡+试算+队列+搜索）≈5 天独立闭环可演示；M2（域图+目录+历史轻改）≈4 天。不是：一次全量交付（9 天无中间验收点风险大）；砍 M2（域图是 Jack 点名要的方向）。

### B3 接口/数据契约（落形后才开工，T0a 产物可 import）
```python
class Domain(BaseModel):
    key: str; name: str; description: str
# registry.py: DOMAINS: list[Domain]; TABLE_DOMAINS: dict[str, str]  # table_id -> domain.key

class DivergenceOption(BaseModel):
    key: str; label: str; value_evidence: str; applies_to: str
class Decision(BaseModel):
    option_key: str; decided_by: str; time: datetime; commit: str
class CaliberRule(...):  # 增可选字段，向后兼容
    divergence: list[DivergenceOption] | None = None
    decision: Decision | None = None

class TrialResult(BaseModel):
    rule_id: str; month: str; value: float; unit: str
    generated_at: datetime; source: Literal["semantic_query", "cache"]
# GET /api/trial/{rule_id}?month=YYYY-MM → TrialResult | 503 {detail:"trial_unavailable"}
# POST /api/rules/{id}/confirm body: {verdict, confirmer, decision?: {option_key}}
#   option_key ∈ {account,user,both,escalate}; escalate → 记录 escalated，状态不翻转
```
- lineage payload 增量：`nodes[].domain`；`domains: [{key,name,table_count,pending,divergent}]`；`edges[].severity: settled|pending|divergent`＋`weight: N`（聚合边）。前端 api.ts 手写镜像，openapi 生成留发布期。
