## 〇、S3 一句话目标

> 给**风控管理部领导**演示：一套金控集团风险预警系统，能用自然语言问任何风险问题、得到精准答案、还能执行真实的业务动作（处置/审批/推送）——全程本体驱动、可审计、拒答不瞎编。

## 一、S3 三大工作目标

### 目标 1：DES 升级为"企业模拟引擎"（复用 + 借鉴 + 自研薄壳）
- **直接复用**：Faker/Mimesis（数据生成）、pyDMNrules（规则引擎）、S2 的确定性+配置+manifest 基建
- **借鉴标准**：TOGAF（画像）、DDD（业务域）、BPMN 2.0（流程）、DMN（规则）、SynEval（质量）
- **自研薄壳**：企业调研编排器（DSH skill）——行业输入 → 画像→业务域→流程→规则→数据→质量门禁流水线
- **边界**：DES 产出业务调研**初稿**（不具约束力）；本体是**执行真相源**；确定性只承诺"生成段"

### 目标 2：本体语义层全量建（30-35 对象 + 11 动作 + 指标注册）
- 全部业务表建对象（业务对象视角，部分聚合），30-35 个对象类型
- 11 个动作全部注册：A 预警生命周期 7 + B 集中度限额 2 + C 风险项目 2
- 全部走动作模板（参数 schema + 预检 + 状态机 + 权限 + 双签 + 审计 + 回滚），读/写引擎分离
- 指标注册：comb_dim_index 全部维度指标 → 物化预聚合

### 目标 3：Agent 对话窗口 + 演示界面（让领导 5 分钟看懂价值）
- 读引擎（受限结构化查询）+ 写引擎（动作模板）产品化
- 独立风险预警演示界面（替代现有 AI 查询页，统一 AI 入口）
- 演示剧本 6 步：Landing→数据→图谱→问答→动作+双签→拒答

## 五、风险与缓解

| 风险 | 缓解 |
|---|---|
| 范围大（全量） | 脊柱先行：主线跑通再补全，避免一次性全量 |
| 业务规则真实性 | 规则从真实表结构字典还原 + 30 题评测集验证 + 产物请 Jack 过目 |
| LLM 调研非确定 | 调研段冻结后进生成段，确定性只承诺生成 |
| 数据密度 | 行分布设计（核心表 ≥3-5 万行）+ rows-per-object 健康指标 |
| 火山配额 | M0 评估；调研分批 + 评测集复用 |
| 脱敏规模 | 半自动改写 + 门禁校验 |
