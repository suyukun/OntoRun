# 安平金控 · 业务规则建模（DES 企业模拟 STEP 4 初稿 · DMN 决策表）

> 方法：DMN（Decision Model and Notation），pyDMNrules 兼容。初稿，供 M2 本体参考 + DES 数据生成用。
> 依据：企业画像 + 业务流程 + 金融风控通用业务认知（预警分级/五级分类/集中度监管标准）。

## 规则 1：预警等级判定（红/黄/蓝）
输入：信号类型、风险评分、押品贬值幅度、关联交易异动幅度、集中度超限比例
输出：预警等级（RED 红 / YELLOW 黄 / BLUE 蓝）

| 条件组合 | 等级 |
|---|---|
| 押品贬值幅度 ≥30% 或 集中度超限 ≥20% 或 风险评分 ≥80 | RED |
| 押品贬值 15-30% 或 集中度超限 10-20% 或 关联异动 20-50% 或 风险评分 60-80 | YELLOW |
| 其余异常信号（轻微） | BLUE |
| 无异常 | NONE（不产生预警） |

## 规则 2：五级分类（金融资产风险分类）
输入：逾期天数、减值比例、风险项目状态
输出：NORMAL 正常 / ATTENTION 关注 / SECONDARY 次级 / DOUBTFUL 可疑 / LOSS 损失

| 条件 | 分类 |
|---|---|
| 逾期 0 天 且 无重大风险 | NORMAL |
| 逾期 1-90 天 或 有预警未处置 | ATTENTION |
| 逾期 91-180 天 或 已降级为次级 | SECONDARY |
| 逾期 181-360 天 或 已重组/展期 | DOUBTFUL |
| 逾期 >360 天 或 已确认损失 | LOSS |

## 规则 3：大额客户集中度限额与预警
输入：集团客户在集团内全部敞口 / 集团资本净额
输出：是否超限、预警等级、是否需审批调整

| 条件 | 动作 |
|---|---|
| 敞口/资本净额 ≤10% | 正常 |
| 10% < 敞口/资本净额 ≤15% | 黄警，提示监控 |
| 15% < 敞口/资本净额 ≤25% | 橙警，需处置方案 |
| >25% | 红警，需立即处置 + 审批调整限额 |

## 规则 4：编码规则（数据生成用）
- 客户号：CUST-{YYYY}-{6位流水}
- 集团客户号：GRP-{YYYY}-{6位流水}
- 预警信号号：SGN-{YYYY}-{8位流水}
- 审批单号：APP-{YYYY}-{8位流水}
- 风险项目号：PROJ-{YYYY}-{8位流水}
- 押品编号：COL-{YYYY}-{8位流水}
- 处置编号：DSP-{YYYY}-{8位流水}

## 规则 5：预警信号类型（SGN_LVL1/LVL2 主题）
一级主题：信用风险、市场风险、操作风险、流动性风险、合规风险
二级主题（信用风险示例）：逾期、欠息、押品贬值、关联交易、涉诉、经营异常、财务恶化、评级下调

## 规则 6：处置措施类型（DEAL_TYPE 语义映射）
| 处置类型 | 说明 |
|---|---|
| SUBMIT_REVIEW 提交审核 | 处置方案提交审核 |
| MGMT_REVIEW 管理审核 | 管理部门审核 |
| SUBMIT_APPROVE 提交审批 | 提交集团审批 |
| DEPT_LEADER_APPROVE 部门领导审批 | 部门领导审批 |
| WARN_REASON_UPDATE 预警事由修改 | 修改预警事由 |
| PUSH_SUBSIDIARY 推送子公司 | 推送子公司执行 |
| PUSH_HOLDING_LEADER 推送金控领导 | 推送集团领导 |
| LEADER_OPINION 领导批示 | 领导批示 |

## 规则 7：审批规则（APPROVE_RULE）
- ANY_ONE：一人审批即可通过
- ALL：全员审批通过才通过
- 岗位链：风险预警管理岗 → 风控部门负责人 → 集团风控领导（NODE_SEQ 1-3）

## 锚定
规则集将用于：① DES 数据生成（STEP 5 保证数据符合规则）；② M2 本体动作前置校验参考；③ M3 评测集 ground truth 判定。执行真相源在本体。
