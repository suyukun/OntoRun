# S3 M4 前端页面结构设计（v1）

> 目标：把 S3 的价值展示为可交互界面，替代现有"像玩具"的前端。
> 受众：风控管理部领导（5 分钟看懂）。技术：React 18 + TS + Vite + AntD（沿用现有 web/）。
> 原则：本体驱动 UI（schema 元数据自动生成），每页能回答"这体现语义接口什么价值"（研究对象锚定）。

## 一、路由与页面结构（新增/改造）
| 路由 | 页面 | 来源 | 说明 |
|---|---|---|---|
| / | Landing 价值页 | 新增 | 一句话价值主张 + 三大入口 + 演示按钮 |
| /browse | 数据浏览 | 改造 BrowsePage | 金融对象列表/详情/链接遍历 |
| /graph | 本体图谱 | 改造 GraphPage | 金融对象全链接成图（无孤岛） |
| /chat | 对话窗口 | 改造 ChatPanel | 精准问答 + 动作双签 + 拒答演示 |
| /actions | 动作 | 改造 ActionsPage | 11 动作列表/执行/审计 |
| /audit | 审计 | 改造/新增 | 审计记录可追溯 |

## 二、Landing 页（核心新增，价值叙事）
- Hero：安平金控集团风险管理部 · 风险预警系统
- 一句话："用自然语言问风险问题、执行真实处置，全程本体驱动、可审计"
- 三大入口卡片：看数据 / 问问题 / 执行操作
- "看演示"按钮 → 触发 6 步演示剧本
- 页脚一行研究价值锚定："语义接口层：LLM 经业务本体理解与操作，不直接碰库"

## 三、数据浏览页（改造）
- 侧栏：金融对象（按业务域分组：客户/预警/处置/审批/风险项目/押品/共债/集中度/机构）
- 主区：对象列表（schema 自动生成列）+ 详情（属性+链接 out/in）+ 链接遍历
- 关键：无空对象（每对象有数据）、无孤岛（链接可遍历）

## 四、本体图谱页（改造）
- 节点=对象类型，边=链接类型（标注基数）
- 金融对象全链接成图（客户→预警→处置→审批 全链路）
- 可点击节点看详情、点击边看链接说明
- 修复 S2 孤岛问题（Vendor 等孤立节点不再出现）

## 五、对话窗口页（改造，核心）
- 顶部：示例问题引导（"华夏新能源集团集中度多少？""本月红色预警几条？"）
- 主区：对话流（用户/AI 消息）
- 双签 UI：LLM 提议高风险动作 → 展示参数卡片 → 确认/驳回按钮 → 执行结果 + 审计
- 拒答展示：域外问题 → 明确"超出可答范围" + 引导可查项
- 会话持久化（localStorage，沿用）

## 六、动作页（改造）
- 11 动作列表（分组：预警生命周期/集中度/风险项目）
- 每动作：参数表单（schema 自动生成）+ 高风险标注 + 双签提示
- 执行结果展示：源数据变化 + 审计 ID

## 七、审计页（新增）
- 审计记录列表（时间/动作/操作人/结果）
- 可追溯：从一次处置 → 审批链 → 源数据变更
- WORM 哈希链展示（体现"出问题可追溯"）

## 八、数据源切换
- 默认加载 ap_anping（安平金控金融数据）
- 独立 data/s3_demo/ + 切换开关（演示环境隔离）
- 演示预热：核心问题预跑 + 物化缓存

## 九、验收
- 无空页面、无孤岛节点、无"像玩具"观感
- 5 分钟演示剧本 6 步全通
- 每页可回答"这体现语义接口什么价值"
