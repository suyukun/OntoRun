## 〇、一句话定位

> **安平金控风险管理部的"集团客户风险预警处置"系统**：当集团客户的授信集中度逼近/突破监管红线，系统自动亮灯（预警信号），风险管理部确认、定级、处置、审批、推送、关闭——**每一步真实写回、全程可审计**。我们的本体把这套业务封装成 Agent 可理解、可操作、可治理的语义接口。

### 三档叙事（外行理解关的载体）

| 档 | 内容 |
|---|---|
| 10 秒 | "哪家集团借钱太多快超过监管红线了？系统自动亮红灯，风险部确认处置，每步留痕。" |
| 1 分钟 | 监管规定一家银行对单一集团客户的授信不得超过资本净额 15%。金控集团下面有银行、证券、保险，集团客户借的钱分散在各家附属机构，单看哪家都没超，合起来可能早就超了。风险管理部要的就是**穿透看全口径**：集中度指标实时算，接近红线亮黄灯、突破红线亮红灯，然后走确认→定级→处置方案→双签审批→关闭的标准流程。 |
| 5 分钟 | 演示剧本（见 §7）：一个虚构集团"天晟农业控股"通过 5 家子公司在安平系 3 家机构融资，合计集中度逼近红线——Agent 回答"目前最大风险敞口在哪"→ 亮出预警信号 → 发起处置 → 双签审批拦截越权 → 每个答案展开证据链（哪张表哪条规则）。 |

## 一、背景设定口径（模拟企业）

- **安平金控**：模拟金融控股集团，按《金控试行办法》第二条设定——控股两类以上金融机构（安平银行、安平证券、安平资管等），自身仅做股权投资管理。
- **视角主体**：安平金控**风险管理部**（集团视角，非单家附属机构视角）。集中度指标 = 并表口径下集团客户在安平系各机构的授信归集。
- **专业准确性关键声明**：2003 指引 / 2018 办法的授信集中度红线，监管原文的义务主体是**商业银行**；金控集团风险管理部看的是**附属机构执行口径的归集监测**（挂靠金控办法第三十二条"并表管理+大额风险暴露预警报告制度"、第三十三条"联合授信与融资风险预警线"）。本演示全部指标按此视角计算，不得表述为"金控公司直接放贷"。

## 三、预警触发规则口径（Agent 问答与规则校验的事实源）

| # | 规则 | 量化口径 | 监管锚 | 触发级别 |
|---|---|---|---|---|
| R1 | 集团客户授信集中度 | 集团授信余额/安平银行资本净额：≥13.5%（红线的 90%，内部预警线）黄色；>15% 红色 | 2003 指引第十二条（2010 修订口径"授信余额≤资本净额15%"） | 黄/红 |
| R2 | 关联客户组风险暴露 | 组合计/一级资本净额 >20% | 2018 办法第八条 | 红 |
| R3 | 单一客户贷款集中度 | 贷款余额/资本净额 >10% | 2018 办法第七条 | 红 |
| R4 | 重大关联交易 | 单笔≥法人口径净资产 1% 或 >10 亿；年度累计≥5% 或 >50 亿 | 2023 关联交易办法第十六条 | 黄 |
| R5 | 对外担保集中度 | 金控对集团外担保余额/净资产 >10%；关联融资>提供方资本净额 10% 或>接受方 20% | 金控办法第三十六条（五）（七） | 红 |
| R6 | 行为类触发 | 虚假材料/挪用贷款/逃废债/拒绝检查等六情形 | 2003 指引第十八条（提前收回贷款情形） | 红 |

> **13.5% 内部预警线是安平内部口径的设定**（监管只要求"设置预警线"，未规定数值——2003 指引第二十六条、2018 办法第三十二条），演示中必须如此声明，不得说成"监管要求 13.5% 即预警"。

## 四、预警分级与生命周期口径

- **分级（安平内部口径，三级）**：🔵 蓝色=关注（不紧急，纳入监测）→ 🟡 黄色=紧急（预计形成实质风险）→ 🔴 红色=危急（风险基本确定）。
- **依据声明**：分级无国家强制标准。行业一手披露：苏州银行 2021 半年报=红/橙/黄三级；武汉金控 2024 募集说明书=一/二/三级。"红橙黄蓝四级"未找到银行集团客户预警的权威原文。安平采用蓝/黄/红为**内部设定**，叙事中不得称为"监管分级"。
- **生命周期状态机**（行业主流，武汉金控披露）：**生成 → 确认（核实+定级）→ 处置（行动方案+跟进）→ 终态**。终态三种：①核实信息不准确→**撤销**；②分析后不构成风险→**排除**；③情况好转→**解除**（填解除报告经审批）。映射动作：confirm_warning / adjust_warning_level / submit_disposal / approve_disposal / push_warning / close_warning。
- **处置动作五类**（武汉金控口径，处置方案的枚举空间）：①额度管控（冻结未用额度/暂停新增授信/提前收回）②排查核查（实地核查/账户只入不出/加密检查频次）③担保缓释（处置押品/更换或追加保证人/追索代偿→落 collateral）④结构调整（变更授信条件/下调分类/资产保全/诉讼）⑤退出。

## 七、演示剧本（口径版，6 步）

1. **问现状**："目前集中度最高的集团客户是谁？"→ Agent 从授信明细归集计算，回答天晟农业控股 14.2%，附证据链（明细行+计算口径）。
2. **亮预警**：14.2% > 13.5% 预警线 → 系统已生成黄色预警信号（展示 warning_signal 与规则 R1 的命中）。
3. **定级确认**：风险管理部经 Agent 确认信号、上调为红色（R2 关联组暴露 20.8% 命中）——confirm_warning + adjust_warning_level。
4. **发起处置**：提交处置方案（冻结未用额度+追加押品）——submit_disposal，押品对象联动。
5. **双签拦截**：Agent 提议的调整试图越过审批 → approve_disposal 双签环节人工驳回一处越权参数——展示"LLM 提议≠直接生效"。
6. **闭环留痕**：推送附属机构（warning_push）、立项跟进（risk_project）、最终解除关闭（close_warning）；全程 audit 可回放。
