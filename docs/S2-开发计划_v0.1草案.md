- **量级**：从 S1 的 123MB 跨越到 **100GB-1TB 级**（诚实降级自 PB，DuckDB 胜任；设量级 gate：100 万 / 1 亿行）；

- **研究**：本体论落地方法论随 S2 落地长出来（三层：文档骨架 + 可执行规范 + 指针版 UI）。

## 2. 阶段规划（串行 + 治理骨架前置，每阶段配可机验门禁）

### 阶段 P0：前置决策（0.5 周，不可跳过）
- Jack 拍板 C1/D1/D2/D3/#5（推荐见决策包）；
- 定方法论骨架名（六阶段框架名开工前定稿，落地填血肉，避免 P5 重写）；
- 建 S2 goal + 切新窗口 + 派活。

### 阶段 P1a：DES 垂直切片（3 周）——最高风险项，最先做
- 内容：3 系统×1 表（ERP/MES/WMS）+ 一物多码问题注入 + 本体映射 + 查询契约；
- 技术：SQLite + 标准库 + pydantic；1 企业=1 目录 N 系统=N db；YAML 2 层；
- 门禁：MARA 确定性（SHA256 同）· 注入率 ±2% · 编码 100% · 跨系统映射可查 · **Jack 业务验收（开工前先给 Jack 看 YAML 配置+表结构，别等 3 周后）**。

### 阶段 P1b：DES 横向铺开（1-2 周）——为 P2 提供足够数据量
- 内容：10-20 表，10 万行级（制造业核心：物料/工单/库存/BOM/订单）；
- 门禁：**量级压力测试**——1000 万行跑 5 个代表性查询（跨库 join/聚合/过滤/链路），P95+内存达标，不达标提前换方案（PostgreSQL+Citus/Parquet 分区）。

### 阶段 P1.5：治理骨架（0.5 周，新增，防补丁式返工）
- 内容：权限元数据 schema + 审计最小骨架（append-only）+ 映射置信度打标骨架；
- 作用：P2/P3/P4 都在此骨架上建，避免后期返工（A2 共识）；
- 门禁：权限元数据可写 · 审计骨架可查 · 映射打标骨架可跑。

### 阶段 P2：ChatBI 最小闭环（2-3 周）——读侧核心价值
- 内容：本体读侧（对象→指标→物化结果）+ DuckDB 物化 + 受限结构化查询 + head-to-head 实验；
- 技术：DuckDB（已装+已验证）；dbt 语义层模式参考（明确自研点=本体映射层，非度量定义层）；
- 门禁：**head-to-head 定靶值**（baseline 直查 ≥X% / 本体版 ≥Y% / Δ≥Z 百分点）+ P95 延迟（定义数据集/硬件/查询 mix）+ 拒答率>0 + **C4 流转契约（SQLite→DuckDB 刷新机制）+ reconcile 测试**；
- Plan B：实验失败则直接采用 LLM 写 SQL + 多层守卫（显式写进计划）。

### 阶段 P3：映射治理 + 审核（2 周，映射 schema 已前置到 P1.5）
- 内容：分级置信度 + 审核流程（先全人工审 CLI/CSV，UI 后置）+ 阈值校准；
- 门禁：**ground truth ≥300 问/域，标注 ≥2 人+仲裁**，top-5 recall ≥80%；自动化映射对人工版 recall 显式化；
- 产出：映射管道 + 阈值校准报告 + 审核痕迹落审计骨架。

### 阶段 P4：权限 + 会话 + 审计完善（1.5 周，骨架已前置）
- 内容：数据权限下沉（DuckDB 视图/RLS）+ 语义层操作权限 + 审计 WORM 完善 + 会话 SQLite 持久化（TTL 分级）；
- 门禁：越权 0 · 审计不可篡改（WORM）· 会话重启不丢；
- 说明：WORM 用成熟方案（S3 Object Lock/immudb/append-only+哈希链），不重造。

### 阶段 P5：方法论 + 指针版 UI + 收口（2 周）
- 内容：白皮书 v2（改"落地笔记/观察与反模式"，不预设反模式 Top15）+ 方法论静态指针 UI（链到真实运行/git commit）+ C 档收尾（CI/UX/start_dev.sh）+ 全量复核；
- 门禁：白皮书有真实运行支撑 · CI 全绿 · E2E 一条命令 · **每阶段 S1 全量 pytest 零回归（贯穿）** · tag v0.2.0。

## 2.5 贯穿纪律（每阶段 DoD 必含）
1. S1 全量 pytest 零回归（19 测试）；
2. 可观测性最小集（查询链路追踪/metrics）；
3. LLM 成本模型（单查询成本上限 + 低成本 fallback）；
4. rollback 计划（每阶段失败如何退：重做/降级/抽样）；
5. 数据安全：PII 脱敏 + 字段级加密声明；
6. 编码/本地化（GBK/UTF-8、中文分词、字段长度）。
