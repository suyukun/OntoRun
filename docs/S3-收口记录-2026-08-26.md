## 二、已验证的核心能力（冒烟实证）

1. **精准问答**（读引擎）："本月红色预警几条？"→86（GT 一致）；"集中度超限客户？"→407；"审批到哪个岗位？"→风险预警管理岗审核；P95 158ms。
2. **真实动作**（写引擎）：adjust_warning_level BLUE→RED 真实写回 + 状态迁移 + 审计；审批通过/驳回；集中度限额调整（旧值保留）；风险项目登记/进展更新。
3. **双签**：high_risk 动作必须先 need_confirm → 人工确认才执行；拒绝不执行；审计留痕。
4. **域外拒答**：无源表对象/不可达字段/资本充足率 → 明确 DECLINE + 引导可查项（fail-closed 不瞎编）。
5. **DES 企业模拟**：TOGAF 画像 + DDD 域 + BPMN 流程 + DMN 规则 + SynEval 质量门禁，编排器 skill 已注册。
