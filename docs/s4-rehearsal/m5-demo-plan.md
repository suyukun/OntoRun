## 三、现场问答预案（两轮彩排刁钻问题沉淀）

| 问 | 答（锚点） |
|---|---|
| 预警线 9/10/12 谁定的？ | base.ap_sys_param 参数行原文回显：出处（金控办法 32/33 自设）+审批人（安平风管部 2025-06-30）+版本 v3 |
| 12.8% 没到 15% 红线为什么红？ | 双层口径：15% 管银行层单家、12% 是金控自设归集限额（主动加严非虚报）；参数行回显 |

| 这数据是真的吗？ | 每个答案点开证据链：表名/规则/分母/明细行，F11 审计可回放 |
| 跟我的 1104 报送什么关系？ | 不直接出报文；初稿省 60% 底稿功夫（如实边界） |
| 剧本外问题（答不出） | 如实拒答 + 给可查项清单（「能帮你查 X/Y/Z」）——拒答是卖点不是缺陷 |
